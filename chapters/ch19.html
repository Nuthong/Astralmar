19.1 สถานการณ์: Contoso Pets

นักพัฒนาส่วนใหญ่มักเริ่มโปรเจกต์ด้วยการพัฒนาฟีเจอร์ที่ import หรือสร้างข้อมูลของแอปก่อน เมื่อแอปของคุณเข้าถึงข้อมูลที่มันต้องพึ่งพาได้แล้ว คุณถึงเริ่มพัฒนาฟีเจอร์ที่ประมวลผลข้อมูล และสร้างรายงานต่อได้

สมมติคุณเป็นนักพัฒนาที่ชอบช่วยเหลือชุมชนท้องถิ่น คุณกับเพื่อนเริ่มธุรกิจที่ช่วยหาบ้านใหม่ ให้แมวและสุนัขจรจัดหรือถูกทอดทิ้ง ธุรกิจของคุณเริ่มต้นเล็กๆ มีสัตว์จรจัดแค่ไม่กี่ตัว แต่ตอนนี้ กำลังเติบโตขึ้นเรื่อยๆ คุณอยากสร้างแอปพลิเคชันที่ช่วยจับคู่สัตว์ที่คุณดูแลกับคนที่กำลังมองหา สัตว์เลี้ยง คุณพบว่าการมีคำอธิบายลักษณะของสัตว์อย่างละเอียดเพื่อแชร์ให้เจ้าของในอนาคตเป็น เรื่องสำคัญมาก และการอธิบายนิสัยของหมาหรือแมวก็ช่วยให้พวกมันน่าสนใจสำหรับเจ้าของในอนาคต มากขึ้นด้วย คุณจึงตัดสินใจสร้างแอปที่ช่วยจัดการข้อมูลของหมาและแมวที่คุณกำลังดูแลอยู่

บทนี้จะพาคุณผ่านกระบวนการพัฒนาฟีเจอร์ที่เกี่ยวกับข้อมูลของแอป Contoso Pets คุณจะใช้ selection และ iteration statement สร้างข้อมูลตัวอย่าง แสดงรายชื่อสัตว์ที่คุณดูแล และเพิ่มสัตว์ ตัวใหม่เข้าธุรกิจของคุณ ตลอดทั้งแอป คุณจะใช้ตัวแปรและ expression ควบคุม code branch ต่างๆ และดูแลให้ตัวแปรถูก scope อย่างเหมาะสม

แอปที่คุณจะพัฒนาจะ:

  • เพิ่มข้อมูลตัวอย่างที่กำหนดไว้ล่วงหน้าลงใน array ของสัตว์เลี้ยง
  • วน code block "แสดงเมนูและรับตัวเลือกจากผู้ใช้" เพื่อสร้าง outer loop ของแอป
  • implement code branch ที่ตรงกับตัวเลือกเมนูที่ผู้ใช้เลือก
  • แสดงข้อมูลทั้งหมดที่เก็บอยู่ใน array ของสัตว์เลี้ยง (ตามตัวเลือกเมนูของผู้ใช้)
  • วน code block "เพิ่มข้อมูลสัตว์ตัวใหม่" ที่ให้ผู้ใช้เพิ่มสัตว์ตัวใหม่หนึ่งตัวหรือมากกว่าเข้า array (ตามตัวเลือกเมนูของผู้ใช้)

19.2 ข้อกำหนดของโปรเจกต์

สเปกของแอป Contoso Pets มีดังนี้:

  • สร้าง C# console application
  • เก็บข้อมูลแอปใน multidimensional string array ชื่อ ourAnimals
  • array ourAnimals เก็บ "ลักษณะของสัตว์เลี้ยง" ต่อไปนี้สำหรับสัตว์แต่ละตัว:
    • หมายเลข Pet ID
    • สปีชีส์ (แมวหรือสุนัข)
    • อายุ (ปี)
    • คำอธิบายสภาพร่างกาย/ลักษณะทางกายภาพ
    • คำอธิบายนิสัย
    • ชื่อเล่นของสัตว์
  • สร้างชุดข้อมูลตัวอย่างที่แทนหมาและแมวที่กำลังดูแลอยู่ในปัจจุบัน
  • แสดงตัวเลือกเมนูเพื่อเข้าถึงฟีเจอร์หลักของแอป — ฟีเจอร์หลักที่รองรับงานต่อไปนี้:
    • แสดงข้อมูลสัตว์ทั้งหมดใน array ourAnimals
    • เพิ่มสัตว์ตัวใหม่เข้า array ourAnimals — ภายใต้เงื่อนไข: ต้องกรอกสปีชีส์ (หมาหรือแมว), ต้องสร้าง pet ID โดยอัตโนมัติ, ลักษณะทางกายภาพบางอย่างอาจยังไม่ทราบ จนกว่าสัตวแพทย์จะตรวจ (เช่น อายุ พันธุ์ สถานะทำหมัน), ชื่อเล่นและนิสัยอาจยังไม่ทราบ ตอนสัตว์เพิ่งมาถึง
    • ตรวจสอบให้อายุและคำอธิบายทางกายภาพของสัตว์สมบูรณ์ (หลังสัตวแพทย์ตรวจ)
    • ตรวจสอบให้ชื่อเล่นและคำอธิบายนิสัยของสัตว์สมบูรณ์ (หลังทีมงานรู้จักสัตว์ตัวนั้นมากขึ้น)
    • แก้ไขอายุของสัตว์ (ถ้ารู้วันเกิดและสัตว์มีวันเกิดระหว่างอยู่ในความดูแล)
    • แก้ไขคำอธิบายนิสัยของสัตว์ (สัตว์อาจมีพฤติกรรมต่างไปหลังอยู่ในความดูแลนานขึ้น)
    • แสดงแมวทั้งหมดที่มีลักษณะตามที่ผู้ใช้กำหนด
    • แสดงหมาทั้งหมดที่มีลักษณะตามที่ผู้ใช้กำหนด

โครงสร้างข้อมูลตั้งต้น

เริ่มต้นด้วยการประกาศตัวแปรที่ใช้เก็บและประมวลผลข้อมูลสัตว์เลี้ยงและตัวเลือกเมนู:

Program.cs 
// the ourAnimals array will store the following:
string animalSpecies = "";
string animalID = "";
string animalAge = "";
string animalPhysicalDescription = "";
string animalPersonalityDescription = "";
string animalNickname = "";

// variables that support data entry
int maxPets = 8;
string? readResult;
string menuSelection = "";

// array used to store runtime data, there is no persisted data
string[,] ourAnimals = new string[maxPets, 6];

ตัวแปร animalSpecies ถึง animalNickname ใช้เก็บค่าของแต่ละลักษณะของ สัตว์เลี้ยงชั่วคราว — ทีหลังคุณจะกำหนดค่าเหล่านี้ให้ multidimensional string array ชื่อ ourAnimals แต่ละตัวเริ่มต้นด้วย string ความยาวศูนย์ ""

สังเกตบรรทัด string? readResult; — เครื่องหมาย ? ทำให้เป็น nullable type variable เวลาอ่านค่าที่ผู้ใช้กรอกด้วย Console.ReadLine() ควรใช้ nullable type แบบนี้เสมอ (ทบทวนจาก บทที่ 18)

ℹ️ Multidimensional Array คืออะไร string[,] ourAnimals = new string[maxPets, 6]; คือ array 2 มิติแบบ rectangular (สี่เหลี่ยมผืนผ้า — ทุกแถวมีจำนวนคอลัมน์เท่ากัน) สังเกตเครื่องหมายจุลภาค [,] ในการประกาศชนิด — มิติแรก (maxPets = 8 แถว) แทนสัตว์แต่ละตัว มิติที่สอง (6 คอลัมน์) แทนลักษณะ 6 อย่างของสัตว์แต่ละตัว เข้าถึง element ได้ด้วย ourAnimals[แถว, คอลัมน์] เช่น ourAnimals[0, 0] คือ pet ID ของสัตว์ ตัวแรก — ต่างจาก array ที่คุณเคยใช้ในบทก่อนๆ ซึ่งเป็น array มิติเดียว

19.3 สร้างข้อมูลตัวอย่าง + Menu Loop

สร้างข้อมูลตัวอย่างด้วย switch-case

ใช้ for loop วนสร้างข้อมูลตัวอย่างให้สัตว์ 4 ตัวแรก (ที่เหลือเป็นค่าว่าง) — ต้นฉบับ MS Learn ให้เริ่มจาก if-elseif-else แล้วแปลงเป็น switch-case เพื่อความอ่านง่าย (ทบทวนหลักการเลือกจาก บทที่ 16: ใช้ switch เมื่อมี else if มากกว่า 2-3 บล็อก) เราจะเขียนเป็น switch ตั้งแต่แรกเลย:

Program.cs 
for (int i = 0; i < maxPets; i++)
{
    switch (i)
    {
        case 0:
            animalSpecies = "dog";
            animalID = "d1";
            animalAge = "2";
            animalPhysicalDescription = "medium sized cream colored female golden retriever weighing about 65 pounds. housebroken.";
            animalPersonalityDescription = "loves to have her belly rubbed and likes to chase her tail. gives lots of kisses.";
            animalNickname = "lola";
            break;

        case 1:
            animalSpecies = "dog";
            animalID = "d2";
            animalAge = "9";
            animalPhysicalDescription = "large reddish-brown male golden retriever weighing about 85 pounds. housebroken.";
            animalPersonalityDescription = "loves to have his ears rubbed when he greets you at the door, or at any time! loves to lean-in and give doggy hugs.";
            animalNickname = "loki";
            break;

        case 2:
            animalSpecies = "cat";
            animalID = "c3";
            animalAge = "1";
            animalPhysicalDescription = "small white female weighing about 8 pounds. litter box trained.";
            animalPersonalityDescription = "friendly";
            animalNickname = "Puss";
            break;

        case 3:
            animalSpecies = "cat";
            animalID = "c4";
            animalAge = "?";
            animalPhysicalDescription = "";
            animalPersonalityDescription = "";
            animalNickname = "";
            break;

        default:
            animalSpecies = "";
            animalID = "";
            animalAge = "";
            animalPhysicalDescription = "";
            animalPersonalityDescription = "";
            animalNickname = "";
            break;
    }

    ourAnimals[i, 0] = "ID #: " + animalID;
    ourAnimals[i, 1] = "Species: " + animalSpecies;
    ourAnimals[i, 2] = "Age: " + animalAge;
    ourAnimals[i, 3] = "Nickname: " + animalNickname;
    ourAnimals[i, 4] = "Physical description: " + animalPhysicalDescription;
    ourAnimals[i, 5] = "Personality: " + animalPersonalityDescription;
}

สังเกตว่าท้าย for loop แต่ละรอบ เราเอาค่าของตัวแปรชั่วคราวทั้ง 6 ตัวไปกำหนดให้ แถวที่ i ของ ourAnimals — โดยเติม prefix อย่าง "ID #: " และ "Species: " นำหน้าค่าจริง เพื่อให้ตอนแสดงผลอ่านง่ายขึ้น (และใช้ prefix นี้ เป็นค่า default สำหรับเช็คว่าสัตว์ตัวนั้นมีข้อมูลหรือยังในหัวข้อถัดไปด้วย)

ℹ️ execution ไม่ fall-through ระลึกไว้ว่าการทำงานของแต่ละ switch section ห้าม "fall through" ไปยัง section ถัดไป break statement ใช้รับประกันว่าจะไม่เกิด "fall through" (ทบทวนจาก บทที่ 16)

สร้าง Menu Loop ด้วย do-while

ตอนนี้สร้าง do loop ที่ครอบตัวเลือกเมนูและโค้ดที่อ่าน input จากผู้ใช้ loop นี้ รับประกันว่าเมนูหลักจะ refresh ให้ผู้ใช้ทุกครั้งที่เลือกเมนู และวนซ้ำจนกว่าผู้ใช้จะเลือกออก จากโปรแกรม

Program.cs 
do
{
    // display the top-level menu options
    Console.WriteLine("Welcome to the Contoso PetFriends app. Your main menu options are:");
    Console.WriteLine("1. List all of our current pet information");
    Console.WriteLine("2. Add a new animal friend to the ourAnimals array");
    Console.WriteLine("3. Ensure animal ages and physical descriptions are complete");
    Console.WriteLine("4. Ensure animal nicknames and personality descriptions are complete");
    Console.WriteLine("5. Edit an animal's age");
    Console.WriteLine("6. Edit an animal's personality description");
    Console.WriteLine("7. Display all cats with a specified characteristic");
    Console.WriteLine("8. Display all dogs with a specified characteristic");
    Console.WriteLine();
    Console.WriteLine("Enter your selection number (or type Exit to exit the program)");

    readResult = Console.ReadLine();
    if (readResult != null)
    {
        menuSelection = readResult.ToLower();
    }

    // switch statement goes here (หัวข้อถัดไป)

} while (menuSelection != "exit");

เพราะครอบตัวเลือกเมนูของโปรแกรมไว้ข้างใน do loop คุณมั่นใจได้ว่าผู้ใช้จะเห็น ตัวเลือกเมนูอย่างน้อยหนึ่งครั้งเสมอ — เงื่อนไข while (menuSelection != "exit") ทำให้ loop วนไปเรื่อยๆ จนกว่าผู้ใช้จะพิมพ์ "exit" (ใช้ .ToLower() ตอนอ่านค่า ทำให้พิมพ์ "Exit" หรือ "exit" ก็ใช้ได้เหมือนกัน)

สร้าง switch Statement สำหรับตัวเลือกเมนู

ตอนนี้เขียน switch statement ที่แตก code execution ตามค่าที่กำหนดให้ menuSelection สร้าง switch label ที่ตรงกับหมายเลขเมนูแต่ละอัน การแยก switch label แต่ละอันช่วยให้แต่ละตัวเลือกเมนูถูกจัดการแยกกันชัดเจน

สังเกตว่า case pattern ตอนนี้เป็น case "1": ไม่ใช่ case 1: แบบตอน สร้างข้อมูลตัวอย่าง — เพราะตอนนั้นเช็คค่า int (ตัวแปร i) แต่ตอนนี้ เช็คค่า string (menuSelection) ที่มาจาก Console.ReadLine() เสมอ

case "1": และ case "2": ยังว่างเปล่า (แค่มี comment + break) — เพราะนั่นคือฟีเจอร์ที่คุณกำลังจะ implement เต็มรูปแบบในหัวข้อ 19.4-19.6 ถัดไป ส่วน case "3" ถึง case "8" เป็น placeholder ที่ให้ feedback แก่ผู้ใช้ ก่อน (จะ implement จริงในบทที่ 20)

19.4 แสดงข้อมูลสัตว์ทั้งหมด (เมนู 1)

ทำไมต้องใช้ for ไม่ใช่ foreach กับ Multidimensional Array

เป้าหมายคือวนผ่านสัตว์แต่ละตัวใน ourAnimals ทีละตัว แล้วทำไมไม่ใช้ foreach ล่ะ ในเมื่อรู้อยู่แล้วว่า foreach ถูกออกแบบมาสำหรับวน ผ่านแต่ละ item ใน array?

เหตุผลที่ไม่ใช้ foreach ในสถานการณ์นี้ก็เพราะ ourAnimals เป็น multidimensional array — เพราะ ourAnimals เป็น multidimensional string array แต่ละ element ข้างในเป็น string แยกกัน ถ้าใช้ foreach วนผ่าน ourAnimals มันจะมองแต่ละ string เป็น item แยกกันในลิสต์ที่มี 48 string items (8 × 6 = 48) foreach จะไม่แยกประมวลผลสองมิติออกจากกัน พูดอีกแบบคือ foreach loop จะไม่รู้จัก "8 แถว" ของ string element ที่แต่ละแถวมี "6 คอลัมน์" เพราะเราต้องการทำงานกับสัตว์ทีละตัว และประมวลผลลักษณะทั้ง 6 อย่างในการวนซ้ำครั้งเดียวกัน foreach จึงไม่ใช่ตัวเลือกที่ถูกต้อง

💡 ถ้าเป็น jagged array ล่ะ ถ้า ourAnimals เป็น jagged array (array ของ array) แทน คุณจะใช้ foreach ได้ — สร้าง foreach ชั้นนอกวนผ่าน element ที่เป็น string array แต่ละตัว (แถว) แล้ว foreach ชั้นในวนผ่าน string element ในนั้น (คอลัมน์):
ตัวอย่าง jagged array
string[][] jaggedArray = new string[][]
{
    new string[] { "one1", "two1", "three1" },
    new string[] { "one2", "two2", "three2" }
};

foreach (string[] array in jaggedArray)
{
    foreach (string value in array)
    {
        Console.WriteLine(value);
    }
    Console.WriteLine();
}
สำหรับแอป Contoso Pets การใช้ rectangular multidimensional array กับ nested for loop ทำได้ง่ายกว่าการใช้ jagged array กับ nested foreach — ตอนนี้คุณเห็นแล้วว่า ทั้งสองแบบทำงานยังไง เลือกใช้ตามความเหมาะสมในโปรเจกต์ต่อๆ ไปได้เลย

สร้าง Outer Loop วนผ่านสัตว์แต่ละตัว

Program.cs 
for (int i = 0; i < maxPets; i++)
{
}

ทบทวนจาก บทที่ 17: for statement มี 3 ส่วนควบคุม — array ถูก index จาก 0 เสมอ หมายความว่า array ที่มี n element จะ index ตั้งแต่ 0 ถึง n-1 คุณต้องการให้ initializer, condition, และ iterator ตรงกับมิติของ array ในกรณีนี้คุณต้องการให้ for loop เริ่มที่ 0 เพิ่มทีละ 1 และจบที่ maxPets-1

ourAnimals ถูกประกาศไว้ว่า string[,] ourAnimals = new string[maxPets, 6]; — คุณรู้ว่า maxPets มีค่าเป็น 8 ในที่นี้ maxPets ระบุ "จำนวน" element ในมิติแรกของ array ไม่ใช่หมายเลข index แบบ zero-based ที่ใช้อ้างอิง element ดังนั้นแม้ maxPets = 8 หมายเลข index ของ array จะมีค่าตั้งแต่ 0 ถึง 7

เช็คว่าสัตว์ตัวนี้มีข้อมูลหรือยัง

Program.cs 
for (int i = 0; i < maxPets; i++)
{
    if (ourAnimals[i, 0] != "ID #: ")
    {
        Console.WriteLine(ourAnimals[i, 0]);
    }
}

ลองพิจารณาว่า if statement นี้ประเมินอะไร และทำไม:

  • ฝั่งซ้ายของ expression — ourAnimals[i, 0]: loop control variable i ใช้ระบุว่ากำลังตรวจสัตว์ตัวไหนอยู่ มิติแรก (i) แทนหมายเลข ของสัตว์ ส่วน 0 ใน [i, 0] ตรงกับลักษณะ petID
  • ตัวดำเนินการเปรียบเทียบ — ใช้ != expression จะเป็น true เมื่อค่าที่กำหนดให้ petID (ourAnimals[i, 0]) ไม่เท่ากับ ค่าฝั่งขวา
  • ฝั่งขวาของ expression — ค่า string คงที่ "ID #: " นี่คือค่า default ที่กำหนดให้ petID ตอนสร้างข้อมูลตัวอย่าง เมื่อสัตว์ตัวนั้นถูกกำหนดลักษณะ จริง ค่า petID จะถูกอัปเดต และจะไม่เท่ากับค่า default นี้อีกต่อไป

บอกได้ว่า code block ของ if จะรันเมื่อสัตว์ตัวปัจจุบันมีการกำหนดลักษณะแล้ว เท่านั้น

Inner Loop แสดงลักษณะทั้ง 6 อย่างของสัตว์แต่ละตัว

Program.cs 
for (int i = 0; i < maxPets; i++)
{
    if (ourAnimals[i, 0] != "ID #: ")
    {
        Console.WriteLine();
        for (int j = 0; j < 6; j++)
        {
            Console.WriteLine(ourAnimals[i, j]);
        }
    }
}

ตอนนี้คุณมี for loop ตัวที่สอง ที่ "ซ้อน" (nested) อยู่ข้างใน code block ของ loop แรก loop ชั้นนอกวนผ่านสัตว์ใน ourAnimals loop ชั้นในวนผ่านลักษณะของสัตว์ แต่ละตัว เพราะข้อมูลสัตว์ถูกเก็บใน multidimensional array การเข้าถึงลักษณะของสัตว์จึงทำได้ ง่าย

สังเกตชื่อ loop control variable ชั้นในคือ j — เมื่อ nest for loop กัน แนวทางที่นิยมคือใช้ i ในชั้นนอกและ j ในชั้นใน (ทบทวนจาก บทที่ 17) ทำตามธรรมเนียมแบบนี้ช่วยให้คนอื่นอ่านโค้ดคุณง่ายขึ้น เพราะเก็บ 6 ลักษณะต่อสัตว์หนึ่งตัว initializer คือ int j = 0; และ condition คือ j < 6; ตรงกับช่วง index ของ array ที่ต้องการ (0-5)

บรรทัด Console.WriteLine() เปล่าๆ ก่อนเข้า loop ชั้นในถูกใช้แทนที่ข้อความ petID เดี่ยวๆ — เพื่อให้เห็นช่องว่างแบ่งระหว่างสัตว์แต่ละตัวชัดเจนขึ้นตอนแสดงผล

19.5 Loop สำหรับเพิ่มสัตว์ตัวใหม่ (เมนู 2 — ส่วนที่ 1)

นับจำนวนสัตว์ที่มีข้อมูลแล้ว

Program.cs (ใน case "2":) 
string anotherPet = "y";
int petCount = 0;

for (int i = 0; i < maxPets; i++)
{
    if (ourAnimals[i, 0] != "ID #: ")
    {
        petCount += 1;
    }
}

ตัวแปร 2 ตัวนี้ควบคุมการวนซ้ำของ while loop ที่ใช้กรอกข้อมูลสัตว์ตัวใหม่:

  • anotherPet เริ่มต้นด้วยค่า y ก่อนเริ่ม while loop — ทีหลังจะได้รับค่าจากผู้ใช้ (y หรือ n) ข้างใน loop
  • petCount แทนจำนวนสัตว์ที่มีการกำหนดลักษณะแล้ว — จะถูกกำหนดค่าคำนวณไว้ นอก while loop และเพิ่มค่าทีละ 1 ข้างใน while loop ทุกครั้งที่เพิ่มสัตว์ตัวใหม่เข้า ourAnimals
⚠️ scope ตัวแปรให้แคบที่สุดเท่าที่จำเป็น scope ของตัวแปรควรแคบที่สุดเท่าที่จะทำได้เสมอ (ทบทวนจาก บทที่ 15) ในแอป Contoso Pets คุณอาจจะ scope petCount ไว้ระดับแอปทั้งตัวแทนที่จะ scope ไว้แค่ใน case "2": ก็ได้ — scope ที่กว้างกว่านี้จะทำให้เข้าถึง petCount จากที่ไหนก็ได้ในแอป คำถามคือ ควร scope ตัวแปรระดับไหน ตอนที่ยังไม่ แน่ใจว่าจะถูกใช้ในส่วนอื่นของแอปหรือไม่? มันน่าดึงดูดที่จะ scope petCount ไว้ ระดับแอปทั้งตัว "เผื่อไว้" แม้ตอนนี้จะยังไม่ได้ใช้ที่อื่นก็ตาม — แต่การ scope ตัวแปรกว้างเกิน จำเป็นอาจนำไปสู่ปัญหาได้ scope ที่สูงเกินจำเป็นทำให้แอปต้องการทรัพยากรมากขึ้น และอาจเปิด ช่องให้เกิดความเสี่ยงด้านความปลอดภัยที่ไม่จำเป็น เมื่อแอปของคุณใหญ่และซับซ้อนขึ้น มันต้องการ ทรัพยากรมากขึ้น โทรศัพท์และคอมพิวเตอร์จัดสรรหน่วยความจำให้ทรัพยากรเหล่านี้ตราบเท่าที่มันยังอยู่ ใน scope แอปในโลกจริงมักเข้าถึงได้จาก cloud หรือแอปอื่น และมักถูกปล่อยให้รันค้างไว้แม้ไม่ได้ ใช้งาน จึงสำคัญที่จะควบคุมความต้องการทรัพยากรและพื้นที่เสี่ยงด้านความปลอดภัยให้เล็กที่สุด เท่าที่ทำได้ — ถ้าภายหลังคุณตัดสินใจใช้ petCount กว้างขึ้นในแอป ค่อยอัปเดตโค้ด scope ให้สูงขึ้นทีหลังได้เสมอ

สร้าง while Loop รับข้อมูลสัตว์ตัวใหม่

Program.cs (ใน case "2":) 
while (anotherPet == "y" && petCount < maxPets)
{
    // (ข้อมูลจะถูกกรอกและบันทึกตรงนี้ — หัวข้อ 19.6)

    // increment petCount (the array is zero-based, so we increment the counter after adding to the array)
    petCount = petCount + 1;

    // check maxPet limit
    if (petCount < maxPets)
    {
        // another pet?
        Console.WriteLine("Do you want to enter info for another pet (y/n)");
        do
        {
            readResult = Console.ReadLine();
            if (readResult != null)
            {
                anotherPet = readResult.ToLower();
            }

        } while (anotherPet != "y" && anotherPet != "n");
    }
}

if (petCount >= maxPets)
{
    Console.WriteLine("We have reached our limit on the number of pets that we can manage.");
    Console.WriteLine("Press the Enter key to continue.");
    readResult = Console.ReadLine();
}

ทำไมใช้ while เป็น loop ชั้นนอกตรงนี้ ไม่ใช่ do-while? เพราะเงื่อนไข anotherPet == "y" && petCount < maxPets ถูกรู้อยู่แล้วก่อนเข้า loop (จากการนับ petCount ในหัวข้อ 19.5a) — ถ้า Contoso Pets เต็มความจุอยู่แล้ว (petCount >= maxPets) code block นี้ไม่ควรทำงานเลยแม้แต่ครั้งเดียว ตรงกับหลักการ เลือก while vs do-while ที่เรียนใน บทที่ 18 หัวข้อ 18.4

ข้างในมี do-while loop ตัวเล็กซ้อนอยู่อีกชั้น (validate ว่าผู้ใช้ตอบ "y" หรือ "n" เท่านั้น) — ใช้ do-while ตรงนี้เพราะต้องถามคำถามและรับคำตอบอย่างน้อยหนึ่ง ครั้งเสมอ

⚠️ ลำดับสำคัญมาก: increment ก่อน แล้วค่อยถาม สังเกตว่า petCount = petCount + 1; ทำงานก่อนถามว่า "ต้องการเพิ่มอีกไหม" เสมอ — เพราะ array เป็น zero-based ตอนที่ petCount เท่ากับ 4 (มี สัตว์ตัวอย่าง 4 ตัวอยู่แล้ว) นั่นหมายถึงคุณกำลังจะบันทึกข้อมูลให้สัตว์ตัวที่ 5 พอบันทึกเสร็จและ increment แล้ว petCount จะเป็น 5 — ตอนแสดง prompt "Do you want to enter info for another pet" ครั้งแรก petCount จึงเป็น 5 ไปแล้ว ถ้าสลับลำดับ (ถามก่อน increment ทีหลัง) ตรรกะการตรวจ maxPets จะเพี้ยนทันที

19.6 อ่าน ตรวจสอบ และบันทึกข้อมูลสัตว์ตัวใหม่ (เมนู 2 — ส่วนที่ 2)

ตอนนี้เติมเนื้อในของ while loop จากหัวข้อก่อน — สำหรับสัตว์แต่ละตัว ต้องรับและ ตรวจสอบข้อมูล 5 อย่าง: สปีชีส์, อายุ, ลักษณะทางกายภาพ, นิสัย, และชื่อเล่น แต่ละอย่างใช้ do-while loop วนจนกว่าจะได้ input ที่ยอมรับได้ — รูปแบบซ้ำเดิมทั้ง 5 จุด ทำให้เห็นแพทเทิร์นการ validate input ที่ใช้ซ้ำได้บ่อยในโลกจริง

รับและตรวจสอบสปีชีส์ (บังคับกรอก)

Program.cs (ในต้น while loop) 
bool validEntry = false;

// get species (cat or dog) - string animalSpecies is a required field
do
{
    Console.WriteLine("\n\rEnter 'dog' or 'cat' to begin a new entry");
    readResult = Console.ReadLine();
    if (readResult != null)
    {
        animalSpecies = readResult.ToLower();
        if (animalSpecies != "dog" && animalSpecies != "cat")
        {
            validEntry = false;
        }
        else
        {
            validEntry = true;
        }
    }
} while (validEntry == false);

// build the animal ID number - for example C1, C2, D3 (for Cat 1, Cat 2, Dog 3)
animalID = animalSpecies.Substring(0, 1) + (petCount + 1).ToString();

animalSpecies เป็นฟิลด์ที่บังคับกรอก — do-while loop จะไม่ ยอมออกจน validEntry เป็น true (คือผู้ใช้พิมพ์ "dog" หรือ "cat" เท่านั้น)

animalID ถูกสร้างขึ้นอัตโนมัติจากตัวอักษรแรกของสปีชีส์ต่อด้วยหมายเลขลำดับ — ใช้ Substring(0, 1) (ทบทวนจาก บทที่ 10) ตัดตัวอักษร แรกของ animalSpecies ออกมา ("d" หรือ "c") แล้วต่อด้วย (petCount + 1).ToString() — บวก 1 เพราะ petCount เป็น zero-based (สัตว์ตัวที่ 5 มี petCount = 4 แต่ควรได้ ID ลงท้ายด้วย 5)

รับและตรวจสอบอายุ (ตอบ ? ได้ถ้ายังไม่รู้)

Program.cs 
// get the pet's age. can be ? at initial entry.
validEntry = false;
do
{
    int petAge;
    Console.WriteLine("Enter the pet's age or enter ? if unknown");
    readResult = Console.ReadLine();
    if (readResult != null)
    {
        animalAge = readResult;
        if (animalAge != "?")
        {
            validEntry = int.TryParse(animalAge, out petAge);
        }
        else
        {
            validEntry = true;
        }
    }
} while (validEntry == false);

ใช้ int.TryParse() (ทบทวนจาก บทที่ 18) ตรวจว่าค่าที่ กรอกเป็นตัวเลขจำนวนเต็มที่ถูกต้องหรือไม่ — ค่าคืนกลับของ TryParse() เป็น bool เอามากำหนดให้ validEntry ได้โดยตรงเลย ไม่ต้องเขียน if-else เพิ่ม แต่ถ้าผู้ใช้พิมพ์ ? (ยังไม่รู้อายุ) ก็ยอมรับได้ ทันทีโดยไม่ต้องผ่าน TryParse()

  • Bforeach statement ตรวจสอบแต่ละ array item แยกกันได้ดีกว่า
  • Cfor statement ทำให้นักพัฒนาแยกจัดการแต่ละมิติของ array ได้

3. ทำไมการ scope ตัวแปรไว้ในระดับต่ำสุดเท่าที่จำเป็นจึง สำคัญ?

ดัดแปลงเมนู 1 (หัวข้อ 19.4d) ให้แสดงเฉพาะสัตว์สปีชีส์แมวเท่านั้น (ใช้ ourAnimals[i, 1] ซึ่งเก็บ "Species: cat" หรือ "Species: dog" เช็คด้วย Contains("cat") ทบทวนจาก บทที่ 14)

ดูเฉลย
Program.cs
for (int i = 0; i < maxPets; i++)
{
    if (ourAnimals[i, 0] != "ID #: " && ourAnimals[i, 1].Contains("cat"))

ใช้ && รวม 2 เงื่อนไข: "มีข้อมูลแล้ว" และ "เป็นแมว" เข้าด้วยกัน — นี่คือ พื้นฐานของเมนู 7 "Display all cats with a specified characteristic" ที่จะ implement เต็มรูปแบบในบทที่ 20

ข้อ 4กลาง

ในหัวข้อ 19.6a มีข้อจำกัดหนึ่งอย่าง: ถ้าผู้ใช้พิมพ์ชื่อสปีชีส์ที่มีตัวพิมพ์ใหญ่ปนกัน เช่น "DOG" มันควรถูกยอมรับ อธิบายว่าบรรทัดไหนในโค้ดทำให้กรณีนี้ทำงานถูกต้อง แล้วลองเขียน test case ที่พิสูจน์ว่าถ้าลบบรรทัดนั้นออก โค้ดจะปฏิเสธ "DOG" หรือไม่

ดูเฉลย

บรรทัด animalSpecies = readResult.ToLower(); แปลง input ให้เป็นตัวพิมพ์ เล็กทั้งหมดก่อนเทียบกับ "dog"/"cat" ถ้าลบ .ToLower() ออก (เหลือแค่ animalSpecies = readResult;) การพิมพ์ "DOG" จะไม่ตรงกับเงื่อนไข animalSpecies != "dog" && animalSpecies != "cat" (เพราะ string comparison ใน C# แยกตัวพิมพ์เล็ก-ใหญ่โดย default) ทำให้ validEntry เป็น false ตลอดไป กลายเป็น infinite loop ที่ผู้ใช้พิมพ์ "DOG" ยังไงก็ไม่ผ่าน

ข้อ 5ยาก

เขียนฟังก์ชันย่อย (แค่ code block ธรรมดา ยังไม่ต้องใช้ method) ที่นับจำนวนหมาและแมวแยกกัน จาก ourAnimals แล้วพิมพ์ผลสรุปแบบ: "มีหมา 3 ตัว, แมว 2 ตัว"

ดูเฉลย
Program.cs
int dogCount = 0;
int catCount = 0;

for (int i = 0; i < maxPets; i++)
{
    if (ourAnimals[i, 0] != "ID #: ")
    {
        if (ourAnimals[i, 1].Contains("dog"))
        {
            dogCount += 1;
        }
        else if (ourAnimals[i, 1].Contains("cat"))
        {
            catCount += 1;
        }
    }
}

Console.WriteLine($"มีหมา {dogCount} ตัว, แมว {catCount} ตัว");
ข้อ 6ท้าทาย

วิเคราะห์: ถ้า maxPets ถูกเปลี่ยนจาก 8 เป็น 4 (พอดีกับจำนวนสัตว์ตัวอย่าง) จะเกิดอะไรขึ้นเมื่อผู้ใช้เลือกเมนู 2 ทันทีตอนเริ่มโปรแกรม โดยไม่ต้องรันจริง ลองไล่ตรรกะทีละบรรทัดด้วยตัวเอง แล้วอธิบายว่า while loop รับสัตว์ตัวใหม่ จะเข้าทำงานหรือไม่ ทำไม

ดูเฉลย

จะไม่เข้าทำงานเลย — เพราะ petCount ที่คำนวณได้จากข้อมูลตัวอย่าง 4 ตัวจะ เท่ากับ 4 พอดี ซึ่งเท่ากับ maxPets ใหม่ (4) เงื่อนไข while (anotherPet == "y" && petCount < maxPets) จะเป็น false ตั้งแต่ก่อนเข้า loop ครั้งแรก (เพราะ petCount < maxPets คือ 4 < 4 ซึ่งเป็นเท็จ) และโค้ดจะกระโดดไปที่ if (petCount >= maxPets) ทันที แสดงข้อความ "We have reached our limit" เลยโดยไม่ถามข้อมูลสัตว์ตัวใหม่แม้แต่คำถามเดียว — นี่คือตัวอย่างที่ดีว่าทำไมต้องเลือก while (เช็คก่อนเข้า) แทน do-while (เข้าก่อนเช็ค) ในจุดนี้
