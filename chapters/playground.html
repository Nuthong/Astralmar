เล่นโค้ด C#

Write your own C# and run it for real

เขียนโค้ด C# อะไรก็ได้ในกล่องด้านล่าง แล้วกด ▶ Run (หรือกด Ctrl+Enter) เพื่อคอมไพล์และรันจริงทันที — เครื่องมือเดียวกับที่ใช้รันตัวอย่างโค้ดทั้งเล่ม ทำงาน ในเครื่องคุณล้วนๆ ไม่มีการส่งโค้ดออกไปที่ไหนเลย

ยังไม่รู้จะเขียนอะไรดี? ลองกดตัวอย่างด้านล่างเพื่อโหลดโค้ดตัวอย่างเข้ากล่องได้เลย:

Program.cs (แก้ไขได้)
Output


    
💡 กด Tab ในกล่องโค้ดเพื่อเยื้อง 4 ช่องว่าง (ไม่กระโดดออก
       จากกล่อง) โค้ดที่พิมพ์ไว้จะถูกจำไว้ในเครื่องอัตโนมัติ ครั้งแรกที่กด Run ในเซสชันนี้อาจ
       ใช้เวลาสักครู่เพื่อโหลด C# runtime — ครั้งถัดไปจะเร็วขึ้นมาก


    

      ⚠️ ถ้ากด Run แล้วค้างที่ "กำลังโหลด C# runtime…" ตลอด
      แปลว่าคุณเปิดหน้านี้ด้วยการดับเบิลคลิกไฟล์โดยตรง (file://) — เบราว์เซอร์บล็อกไม่ให้หน้า
      แบบนี้โหลดไฟล์ประกอบกันเอง ต้องปิดแท็บนี้ แล้วไปดับเบิลคลิก start-book.bat
      ในโฟลเดอร์เดียวกับ index.html แทน (เปิดครั้งเดียว จะพาเข้าเล่มให้อัตโนมัติ)
    


    

      ⚠️ ข้อจำกัดอื่นที่ควรรู้
      กล่องนี้ไม่มี Console.ReadLine()/ReadKey() ให้ใช้จริง (ไม่มี
      stdin ในบราวเซอร์) และถ้าโค้ดมีลูปไม่สิ้นสุดจริงๆ แท็บนี้จะค้าง ต้องรีเฟรชหน้าใหม่ — เหมือน
      ข้อจำกัดของทุกเครื่องมือรันโค้ดในบราวเซอร์ทั่วไป
