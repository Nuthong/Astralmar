31.1 สถานการณ์และสเปก

method เป็นแนวคิดพื้นฐานของการเขียนโปรแกรม มันให้ code reusability ปรับปรุงความอ่านง่าย และ ลดขนาดโค้ดของคุณ method ช่วยให้คุณแตกปัญหาซับซ้อนเป็นงานที่เป็นโมดูล และช่วยจัดระเบียบโค้ด ตอนนี้คุณเรียนรู้เรื่อง method แล้ว คุณพร้อมเริ่มพัฒนาฟังก์ชันการทำงานเพิ่มเติมให้โปรแกรมของ คุณแล้ว!

สมมติคุณเป็นผู้ประสานงานอีเวนต์ของสวนสัตว์เลี้ยงแห่งหนึ่ง คุณต้องประสานงานการมาเยี่ยมชมของ โรงเรียนต่างๆ เป็นประจำ และจัดการให้กลุ่มนักเรียนหลายกลุ่มได้เยี่ยมชมสัตว์ คุณตัดสินใจเขียน แอปที่ช่วยวางแผนการมาเยี่ยมชมของโรงเรียน แอปแบ่งนักเรียนเป็นกลุ่ม และกำหนดชุดสัตว์ให้แต่ละ กลุ่ม นักเรียนจะหมุนเวียนกลุ่มหลังเยี่ยมชมสัตว์ที่กำหนดให้เสร็จ คุณตัดสินใจสุ่มลำดับสัตว์ เพื่อ ให้การมาเยี่ยมชมของแต่ละโรงเรียนไม่ซ้ำกัน

โมดูลนี้จะพาคุณผ่านขั้นตอนที่จำเป็นในการพัฒนาแอปสวนสัตว์เลี้ยงของคุณ โค้ดของคุณจะใช้ method วางแผนการมาเยี่ยมชมให้โรงเรียน 3 แห่ง สุ่มลำดับสัตว์ แบ่งนักเรียนเป็นกลุ่ม และแสดงผลลัพธ์ คุณ จะใช้ method ที่รับพารามิเตอร์และคืนค่า รวมถึงพารามิเตอร์แบบ optional ด้วย

สเปกของโปรเจกต์

คุณกำลังพัฒนาแอปให้ Contoso Petting Zoo ที่ประสานงานการมาเยี่ยมชมของโรงเรียน Contoso Petting Zoo เป็นบ้านของสัตว์ 18 สายพันธุ์ต่างกัน ที่สวนสัตว์ นักเรียนที่มาเยี่ยมชมจะถูกแบ่ง เป็นกลุ่ม แต่ละกลุ่มมีชุดสัตว์ที่กำหนดให้ หลังเยี่ยมชมชุดสัตว์ของตัวเองแล้ว นักเรียนจะหมุนเวียน กลุ่มจนกว่าจะเห็นสัตว์ทุกตัวในสวนสัตว์

โดยค่าเริ่มต้น นักเรียนถูกแบ่งเป็น 6 กลุ่ม อย่างไรก็ตาม บางชั้นเรียนมีนักเรียนน้อยหรือมาก จึง ต้องปรับจำนวนกลุ่มตามความเหมาะสม สัตว์ยังควรถูกกำหนดให้แต่ละกลุ่มแบบสุ่มด้วย เพื่อให้ประสบการณ์ ไม่ซ้ำกัน

ข้อกำหนดการออกแบบของแอป Contoso Petting Zoo มีดังนี้:

  • ปัจจุบันมีโรงเรียนมาเยี่ยมชม 3 แห่ง:
    • โรงเรียน A มี 6 กลุ่มมาเยี่ยมชม (จำนวนเริ่มต้น)
    • โรงเรียน B มี 3 กลุ่มมาเยี่ยมชม
    • โรงเรียน C มี 2 กลุ่มมาเยี่ยมชม
  • สำหรับโรงเรียนที่มาเยี่ยมชมแต่ละแห่ง ทำงานต่อไปนี้:
    • สุ่มลำดับสัตว์
    • กำหนดสัตว์ให้จำนวนกลุ่มที่ถูกต้อง
    • พิมพ์ชื่อโรงเรียน
    • พิมพ์กลุ่มสัตว์

31.2 วางแผนด้วย Pseudo-code

ในขั้นตอนแรกของกระบวนการพัฒนา คุณจะเริ่มวางแผนแอปผ่าน pseudo-code (ทบทวนจาก บทที่ 28) คุณจะระบุขั้นตอนและ method ที่จำเป็นต่อการทำงานให้เสร็จ คุณยังต้องพิจารณา input และ output ของ method เหล่านี้ด้วย การเตรียม method ผ่าน pseudo-code เป็นขั้นตอนที่มีประโยชน์มากในงานเขียนโค้ดใดๆ และช่วยให้คุณพัฒนาโค้ดที่ปราศจากบั๊กได้เร็วขึ้น

ในขั้นตอนนี้ คุณจะแปลงขั้นตอนที่กำหนดไว้ในสเปกของแอปให้เป็น pseudo-code — เริ่มจากโฟกัสที่ การเขียน pseudo-code สำหรับโรงเรียนแค่แห่งเดียวก่อน พอคิดโค้ดสำหรับโรงเรียนหนึ่งได้แล้ว คุณ ประยุกต์ตรรกะเดียวกันกับโรงเรียนอื่นได้ง่ายๆ

งานแรกคือสุ่มลำดับสัตว์ สร้าง pseudo-code method สุ่มสัตว์ในสวนสัตว์เลี้ยง:

Program.cs 
// RandomizeAnimals();

คุณยังไม่ต้องเติมตรรกะสุ่มสัตว์ตอนนี้ ตอนนี้แค่โฟกัสที่วางแผนแอปในภาพรวมก่อน คุณสมมติได้ว่า method RandomizeAnimals() นี้มีอยู่จริง และจะสุ่มลำดับ array pettingZoo ได้อย่างถูกต้อง

ต่อไป สร้าง pseudo-code method กำหนดกลุ่มสัตว์:

Program.cs 
// AssignGroup();

เหมือนเดิม คุณสมมติได้ว่า method นี้กำหนดสัตว์ให้กลุ่มย่อยได้อย่างถูกต้อง แล้วไปทำงานถัดไป

คุณพิมพ์ชื่อโรงเรียนได้ง่ายๆ ด้วย Console.Write:

Program.cs 
Console.WriteLine("School A");

สุดท้าย คุณต้องพิมพ์กลุ่มสัตว์:

Program.cs 
// PrintGroup(group);

สังเกตว่าคุณเพิ่มพารามิเตอร์ให้ method นี้ — คุณรู้ว่าต้องพิมพ์กลุ่มสัตว์ที่ต่างกันหลายครั้ง จึงใช้ method ทำงานนี้ โดยรับกลุ่มเป็น input parameter ลองคิดสักครู่ว่าจะ initialize argument group ตรงไหนใน pseudo-code ของคุณ

กำหนด argument group ด้วยการอัปเดตบรรทัด AssignGroup:

Program.cs 
// var group = AssignGroup();

เพราะคุณเขียน pseudo-code สำหรับงานทั่วไปเสร็จแล้ว ลองพิจารณาว่าจะกำหนด data type ไหนให้ตัวแปร group — คุณต้องการให้โรงเรียน A มีสัตว์แบ่งเป็น 6 กลุ่ม และคุณรู้ว่ามีสัตว์ 18 ตัว คุณยังรู้ว่าสัตว์แทนด้วย string ดังนั้นคุณใช้ 2D array ที่มี 6 กลุ่ม กลุ่มละ 3 สัตว์ได้

Program.cs 
string[] pettingZoo =
{
    "alpacas", "capybaras", "chickens", "ducks", "emus", "geese",
    "goats", "iguanas", "kangaroos", "lemurs", "llamas", "macaws",
    "ostriches", "pigs", "ponies", "rabbits", "sheep", "tortoises",
};

// RandomizeAnimals();
// string[,] group = AssignGroup();
Console.WriteLine("School A");
// PrintGroup(group);
Output
School A

คุณไม่ต้องเพิ่ม argument ให้ method AssignGroup เลย เพราะค่ากลุ่มเริ่มต้นคือ 6 (คุณจะทำให้มันเป็น optional parameter ในหัวข้อ 31.4)

💡 ทำไมต้องเขียน pseudo-code ทั้งที่โค้ดยังรันไม่ได้จริง สังเกตว่าตอนนี้แอปทำแค่พิมพ์ "School A" เท่านั้น ทั้งที่โค้ดที่เหลือถูก comment ไว้หมด — นี่คือ จุดประสงค์! การ "รันได้" ตั้งแต่ขั้นตอนวางแผนช่วยยืนยันว่าโครงสร้างโดยรวมของโปรแกรมไม่มี syntax error ก่อนที่คุณจะเริ่มเติมรายละเอียดของแต่ละ method ทีละตัว — เป็นแพทเทิร์นเดียวกับที่เรียนใน บทที่ 28 หัวข้อ 28.5 (placeholder method) แค่คราวนี้ใช้ comment แทนที่ จะใช้ method ว่างเปล่า

31.3 สร้าง Method สับเปลี่ยน Array

ในขั้นตอนนี้ คุณพัฒนาโค้ดให้งานย่อยแรกเสร็จสมบูรณ์ คือสุ่มลำดับสัตว์ในสวนสัตว์เลี้ยง จำได้ไหม ว่าคุณอ้างอิงถึง method RandomizeAnimals() ไว้ใน pseudo-code แล้ว

การสุ่มลำดับ element ของ array อาจดูเป็นงานที่ยากมาก ก่อนเริ่ม ลองคิดสักครู่ว่าจะสลับค่าของ ตัวแปร 2 ตัว a กับ b ยังไง

ถ้าคุณกำหนดค่า a = b ตรงๆ ทันที คุณจะเสียค่าเดิมของ a ไป แล้วได้ ตัวแปร 2 ตัวที่มีค่าเท่ากับ b ทั้งคู่ คุณต้องใช้ตัวแปรชั่วคราวเก็บค่าของ a ก่อนถึงจะเขียนทับมันได้ มาใช้แนวคิดนี้เริ่มทำงานกัน

Program.cs 
void RandomizeAnimals()
{

}

สำหรับ method นี้ คุณไม่ต้องใช้พารามิเตอร์ input เลย เพราะคุณจะใช้ตัวแปร global pettingZoo ที่มีอยู่แล้ว เริ่มเขียนโค้ดสลับ element บาง element ใน array กัน

Program.cs 
int i = 0;
int r = 1;

string temp = pettingZoo[i];
pettingZoo[i] = pettingZoo[r];
pettingZoo[r] = temp;

ในโค้ดนี้ คุณใช้ i และ r ชั่วคราวแทน index สุ่มบางตำแหน่งใน array จากนั้นสลับค่าที่ทั้งสอง index ด้วยความช่วยเหลือของตัวแปร temp สังเกตว่าการใช้ temp ป้องกันไม่ให้คุณเสียค่าเดิมของ pettingZoo[i] หลังถูกเขียนทับ ต่อไป ตั้งค่า r เป็นค่าสุ่มแทน 1

Program.cs 
Random random = new Random();

int i = 0;
int r = random.Next(pettingZoo.Length);

string temp = pettingZoo[i];
pettingZoo[i] = pettingZoo[r];
pettingZoo[r] = temp;

ในขั้นตอนนี้ คุณ initialize object random ช่วยสุ่มตัวเลข และ initialize r เป็นจำนวนเต็มสุ่มระหว่าง 0 ถึงความยาวของ array pettingZoo ทำให้ มั่นใจว่าจะไม่เข้าถึง index เกินขอบเขตของ array คุณประยุกต์โค้ดนี้กับ array ทั้งชุดเพื่อสุ่ม ทุก element ได้

แก้ไข element ด้วย for loop:

Program.cs 
Random random = new Random();

for (int i = 0; i < pettingZoo.Length; i++)
{
    int r = random.Next(pettingZoo.Length);

    string temp = pettingZoo[i];
    pettingZoo[i] = pettingZoo[r];
    pettingZoo[r] = temp;
}

ตอนนี้คุณวนผ่านแต่ละ element ใน array เลือก index สุ่มหนึ่งตำแหน่ง แล้วสลับกับ element ปัจจุบัน อย่างไรก็ตาม ถ้ารันโค้ดนี้แล้วสังเกตความเปลี่ยนแปลงของ pettingZoo คุณ อาจสังเกตเห็นปัญหา element บาง element ไม่ถูกสลับเลย และบาง element ถูกสลับหลายครั้ง

คุณปรับปรุงการกระจายของ element ที่ถูกเลือกแบบสุ่มได้ ด้วยการอัปเดตช่วงขณะที่คุณเลื่อนผ่าน array

Program.cs 
int r = random.Next(i, pettingZoo.Length);

ตอนนี้ ในขณะที่คุณวนผ่าน for loop คุณอัปเดตช่วงของ index ที่เลือกแบบสุ่ม เพื่อไม่ รวมค่าน้อยกว่า i เพราะ index ที่ค่าน้อยกว่า i ถูกสลับไปแล้วใน iteration ก่อนหน้าของ loop

💡 นี่คืออัลกอริทึม Fisher-Yates Shuffle แพทเทิร์นการสับเปลี่ยน array แบบนี้มีชื่อเรียกในวงการว่า Fisher-Yates shuffle — เป็นอัลกอริทึมมาตรฐานที่รับประกันว่าทุก element มีโอกาสเท่ากันที่จะจบลงที่ตำแหน่งไหนก็ได้ (ไม่ เอนเอียง) เคล็ดลับสำคัญคือการจำกัดช่วงสุ่มให้แคบลงเรื่อยๆ ตามที่ loop ดำเนินไป (random.Next(i, ...) แทน random.Next(0, ...)) เพื่อไม่ให้สุ่มไปโดน element ที่สลับเสร็จแล้ว

uncomment การเรียก RandomizeAnimals() โดยลบเครื่องหมาย // ที่นำ หน้าออก:

Program.cs (ฉบับสมบูรณ์ของขั้นตอนนี้) 
string[] pettingZoo =
{
    "alpacas", "capybaras", "chickens", "ducks", "emus", "geese",
    "goats", "iguanas", "kangaroos", "lemurs", "llamas", "macaws",
    "ostriches", "pigs", "ponies", "rabbits", "sheep", "tortoises",
};

RandomizeAnimals();
// string[,] group = AssignGroup();
Console.WriteLine("School A");
// PrintGroup(group);

foreach (string animal in pettingZoo)
{
    Console.WriteLine(animal);
}

void RandomizeAnimals()
{
    Random random = new Random();

    for (int i = 0; i < pettingZoo.Length; i++)
    {
        int r = random.Next(i, pettingZoo.Length);

        string temp = pettingZoo[r];
        pettingZoo[r] = pettingZoo[i];
        pettingZoo[i] = temp;
    }
}

ยืนยันว่าข้อความ "School A" แสดงตามที่คาดไว้ ตามด้วยรายการสัตว์ที่สุ่มลำดับแล้ว สัตว์ไม่ควร เรียงตามตัวอักษร — foreach loop ที่เพิ่มเข้ามาแค่ใช้ทดสอบ method ชั่วคราว ให้ ลบออกหลังยืนยันผลลัพธ์เสร็จแล้ว

31.4 สร้าง Method พร้อม Optional Parameter

ในขั้นตอนนี้ คุณพัฒนาโค้ดให้งานย่อยอีกอย่างเสร็จสมบูรณ์ คือกำหนดสัตว์ในสวนสัตว์เลี้ยงให้กลุ่ม ต่างๆ จำได้ไหมว่าคุณอ้างอิงถึง method AssignGroup() ไว้ใน pseudo-code แล้ว

Program.cs 
string[,] AssignGroup(int groups)
{

}

จำได้ไหมว่าคุณตัดสินใจแล้วว่า method นี้ควรคืนค่าเป็น 2D array จำนวนกลุ่มยังเปลี่ยนได้ตามขนาด ของโรงเรียนที่มาเยี่ยมชม แต่มีขนาดกลุ่มเริ่มต้นอยู่ที่ 6 ดังนั้นคุณควรทำให้พารามิเตอร์นี้เป็น optional

เปลี่ยน groups เป็น optional parameter:

Program.cs 
string[,] AssignGroup(int groups = 6)
{

}

จำได้ไหมว่า optional parameter ถูกนิยามด้วยการกำหนดค่า default ให้มัน (ทบทวนจาก บทที่ 29) required parameter ต้องถูกประกาศก่อน optional parameter เสมอ ต่อไปคุณจะเริ่มเพิ่มตรรกะให้โค้ด

Program.cs 
string[,] AssignGroup(int groups = 6)
{
    string[,] result = new string[groups, pettingZoo.Length/groups];

    return result;
}

เพราะ method ของคุณระบุ return value ไว้ คุณเริ่มนิยาม method ด้วยการสร้างค่าที่จะคืนก่อน วิธีนี้ทำให้คุณเพิ่มตรรกะต่อได้โดยไม่มี compile-time error

สังเกตว่าคุณใช้ [groups, pettingZoo.Length/groups] กำหนดขนาด array — groups แทนจำนวนกลุ่มสัตว์ที่คุณต้องการสร้าง pettingZoo.Length/groups สะท้อนว่าแต่ละกลุ่มมีสัตว์กี่ตัว ตัวอย่างเช่น เพราะ pettingZoo เป็น array คงที่ ที่มี 18 element ขนาด 2D array สำหรับโรงเรียน A คือ [6,3]

ต่อไป กำหนดสัตว์ให้แต่ละกลุ่ม:

Program.cs 
string[,] AssignGroup(int groups = 6)
{
    string[,] result = new string[groups, pettingZoo.Length/groups];

    for (int i = 0; i < groups; i++)
    {
        for (int j = 0; j < result.GetLength(1); j++)
        {

        }
    }

    return result;
}

ในโค้ดนี้ for loop ชั้นนอกวนผ่านแต่ละกลุ่ม for loop ชั้นในวนตาม จำนวนสัตว์ที่กลุ่มควรมี ต่อไปคุณต้องกำหนดสัตว์

Program.cs 
int start = 0;

for (int i = 0; i < groups; i++)
{
    for (int j = 0; j < result.GetLength(1); j++)
    {
        result[i,j] = pettingZoo[start++];
    }
}

ในโค้ดนี้ คุณนิยาม start แทนตำแหน่งเริ่มต้นของ pettingZoo การใช้ marker แบบนี้ช่วยให้คุณเลื่อนผ่าน array pettingZoo ทีละ element ได้ แม้ for loop ทั้งสองจะวนจำนวนรอบไม่เท่ากันก็ตาม

ℹ️ start++ คือ postfix increment pettingZoo[start++] ใช้ตัวดำเนินการ postfix increment (++ ต่อท้าย) — มันอ่านค่า start ปัจจุบันไปใช้ index อาร์เรย์ก่อน แล้วค่อยเพิ่มค่า start ขึ้น 1หลังจากนั้น เทียบเท่ากับเขียน 2 บรรทัดแยก: result[i,j] = pettingZoo[start]; start = start + 1; — เขียนรวมกันแบบนี้กระชับ กว่าและเป็นแพทเทิร์นที่พบบ่อยเวลาต้อง "อ่านแล้วเลื่อนตำแหน่งถัดไป" ทีละ element

ตอนนี้ method ของคุณกำหนดสัตว์ในสวนสัตว์เลี้ยงให้จำนวนกลุ่มที่ระบุแล้ว uncomment การเรียก AssignGroup ได้เลย

Program.cs (ฉบับสมบูรณ์ของขั้นตอนนี้)

31.5 สร้าง Method แสดงผลลัพธ์

ในขั้นตอนนี้ คุณนิยาม method แสดงผลลัพธ์ของกลุ่มสัตว์ คุณยังทำการกำหนดกลุ่มสัตว์ให้โรงเรียน ที่มาเยี่ยมชมแห่งอื่นให้เสร็จสมบูรณ์ด้วย

Program.cs 
void PrintGroup(string[,] group)
{

}

จำได้ไหมว่าคุณตัดสินใจให้ method นี้รับ 2D array เป็น input ตอนนี้แค่ต้องให้ method พิมพ์ เนื้อหาของ 2D array นั้นออกมา

Program.cs 
void PrintGroup(string[,] group)
{
    for (int i = 0; i < group.GetLength(0); i++)
    {
        for (int j = 0; j < group.GetLength(1); j++)
        {
            Console.Write($"{group[i,j]}  ");
        }
    }
}

ตรงนี้ คุณใช้ GetLength(0) หาจำนวนแถวใน array และ GetLength(1) หาจำนวนคอลัมน์ (ทบทวนจาก บทที่ 19) แล้วใช้ Console.Write พิมพ์ element พร้อมช่องว่างเพิ่มระหว่างชื่อสัตว์ ต่อไปเพิ่มข้อความช่วยอธิบายและขึ้นบรรทัดใหม่ แบ่งแต่ละกลุ่ม

Program.cs 
void PrintGroup(string[,] group)
{
    for (int i = 0; i < group.GetLength(0); i++)
    {
        Console.Write($"Group {i + 1}: ");
        for (int j = 0; j < group.GetLength(1); j++)
        {
            Console.Write($"{group[i,j]}  ");
        }
        Console.WriteLine();
    }
}

ตอนนี้คุณมีโค้ดครบสำหรับงานเตรียมการมาเยี่ยมชมของโรงเรียนแล้ว uncomment การเรียก PrintGroup แล้วรันโค้ดดูผลลัพธ์:

31.7 ⚠️ กับดักที่พบบ่อย

อาการสาเหตุ / วิธีแก้
บาง element ใน array ไม่ถูกสุ่มเลย บางตัวถูกสลับซ้ำหลายรอบ ใช้ random.Next(0, pettingZoo.Length) แทน random.Next(i, pettingZoo.Length) — ต้องจำกัดขอบเขตล่างเป็น i เสมอ ไม่ใช่ 0 ตายตัว ไม่งั้นจะไม่ใช่ Fisher-Yates shuffle ที่ถูกต้อง (ทบทวนหัวข้อ 31.3)
IndexOutOfRangeException ตอนกำหนดสัตว์ลง 2D array จำนวนกลุ่มที่ส่งเข้า AssignGroup() หารจำนวนสัตว์ทั้งหมด (18) ไม่ลงตัว เช่น เรียก PlanSchoolVisit("School D", 5) — 18/5 ปัดเศษ integer division จะได้ 3 ทำให้เหลือสัตว์ 3 ตัวที่ไม่มีที่ลง — สเปกนี้ออกแบบมาให้ใช้ได้แค่กับตัวหารลงตัว (1, 2, 3, 6, 9, 18)
ลืม uncomment การเรียก method แล้วสงสัยว่าทำไมไม่มีอะไรเกิดขึ้น ทบทวนหัวข้อ 31.2-31.5 — ทุกครั้งที่เติมโค้ดให้ placeholder method เสร็จ ต้องกลับไปลบ // หน้าบรรทัดที่เรียก method นั้นด้วยเสมอ
PrintGroup() พิมพ์สัตว์ผิดจำนวนคอลัมน์ต่อกลุ่ม ใช้ GetLength(0) กับ GetLength(1) สลับกัน — GetLength(0) คือจำนวนแถว (จำนวนกลุ่ม) GetLength(1) คือจำนวนคอลัมน์ (จำนวนสัตว์ต่อกลุ่ม) ทบทวนจาก บทที่ 19
ชื่อพารามิเตอร์ groups ใน PrintGroup() ทำให้สับสนกับตัวแปร groups ใน AssignGroup() ไม่ใช่บั๊ก — เป็นคนละตัวแปรที่ scope แยกกันสนิท (ทบทวน method scope จาก บทที่ 29 หัวข้อ 29.3) แต่การตั้งชื่อซ้ำแบบนี้ทำให้อ่านโค้ดสับสน ได้ง่าย ควรตั้งชื่อพารามิเตอร์ให้ต่างกันเพื่อความชัดเจน แม้ compiler จะไม่ error ก็ตาม

ข้อ 1ง่าย

เพิ่มการเรียก PlanSchoolVisit("School D", 9); ต่อจากโรงเรียน C — ตรวจสอบว่า ได้ 9 กลุ่ม กลุ่มละ 2 ตัวสัตว์

ข้อ 3กลาง

สร้าง method int CountAnimalOccurrence(string animal) ที่นับว่าสัตว์ชื่อที่ กำหนดปรากฏใน pettingZoo กี่ครั้ง (ควรได้ 1 เสมอถ้าไม่มีชื่อซ้ำ) ทดสอบกับ "goats" และ "dragons" (ไม่มีในสวนสัตว์)

{

    else
    {
        Console.WriteLine(schoolName);
    }

    PrintGroup(group);
}

เรียกใช้ด้วย PlanSchoolVisit("School A", showCount: true); ได้ (ใช้ named argument ข้าม groups ไปตั้งค่า showCount โดยตรง ทบทวนจาก บทที่ 29)

ข้อ 5ยาก

เขียน method string[] FlattenGroups(string[,] group) ที่แปลง 2D array ของกลุ่มสัตว์กลับเป็น 1D array เรียงตามลำดับเดิม (แถว 0 ก่อน แล้วแถว 1 ...) ทดสอบกับ ผลลัพธ์จาก AssignGroup(3)

ดูเฉลย
Program.cs
string[,] group = AssignGroup(3);
string[] flat = FlattenGroups(group);
foreach (string animal in flat)
{
    Console.WriteLine(animal);
}

string[] FlattenGroups(string[,] group)
{
    string[] result = new string[group.Length];
    int index = 0;

    for (int i = 0; i < group.GetLength(0); i++)
    {
        for (int j = 0; j < group.GetLength(1); j++)
        {
            result[index] = group[i, j];
            index++;
        }
    }

    return result;
}

ใช้ group.Length (ไม่ใช่ GetLength) หาจำนวน element ทั้งหมดใน 2D array เพื่อกำหนดขนาด array ผลลัพธ์ 1 มิติให้พอดี

ข้อ 6ท้าทาย

วิเคราะห์: ถ้าลบบรรทัด int r = random.Next(i, pettingZoo.Length); ใน RandomizeAnimals() แล้วใช้ random.Next(pettingZoo.Length) แทน (ไม่จำกัดขอบเขตล่างด้วย i) โค้ดยัง "ทำงานได้" ไหม (ไม่ throw exception)? แต่มีปัญหา อะไรซ่อนอยู่ อธิบายโดยไม่ต้องรันจริง

ดูเฉลย

โค้ดยังทำงานได้โดยไม่ throw exception — เพราะ random.Next(pettingZoo.Length) ยังให้ค่า index ที่ถูกต้องเสมอ (0 ถึง Length-1) ไม่มีทาง out of bounds ปัญหาที่ซ่อนอยู่ คือคุณภาพของการสุ่ม — โค้ดยังคง "ทำงาน" ในแง่ที่ไม่ error แต่การกระจายตัวของผล การสุ่มจะไม่สม่ำเสมอ (biased) เหมือนที่อธิบายไว้ในหัวข้อ 31.3: บาง element อาจถูกสลับ กลับไปกลับมาหลายรอบ บาง element อาจไม่ถูกแตะเลยตลอดทั้ง loop ทำให้ผลลัพธ์สุดท้ายไม่ใช่ การสุ่มแบบสม่ำเสมอจริงๆ (uniform random permutation) แม้จะ "ดูสุ่ม" ด้วยตาเปล่าก็ตาม — นี่คือตัวอย่างของบั๊กที่ตรวจจับยากมาก เพราะโปรแกรมไม่ error และผลลัพธ์ดูสมเหตุสมผลผิว เผิน แต่จริงๆ ผิดในเชิงสถิติ
