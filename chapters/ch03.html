3.1 ทำไมต้องจัดรูปแบบสตริง

ในฐานะนักพัฒนา คุณจะต้องเขียนโค้ด C# เพื่อรวมและจัดรูปแบบข้อมูลทั้งแบบ literal และตัวแปร ให้กลายเป็นค่าใหม่ ค่านั้นอาจถูกแสดงผล บันทึกลงไฟล์ หรือส่งผ่านเครือข่าย โชคดีที่ C# มีวิธีรวมและจัดรูปแบบข้อมูลให้เลือกหลายแบบ

สมมติคุณอยากแสดงผลลัพธ์ของแอปพลิเคชันแบบ command-line ที่กำลังเขียนอยู่ โดยต้องแสดงทั้ง ข้อความ literal ข้อความในตัวแปร ข้อมูลตัวเลข และข้อความภาษาอื่นๆ จะจัดรูปแบบให้ผู้ใช้เข้าใจ ได้ถูกต้องยังไง?

ในบทนี้ คุณจะใช้ character escape sequence จัดรูปแบบสตริงให้มีอักขระพิเศษ เช่น tab และการขึ้นบรรทัดใหม่ — รวมถึงอักขระจากภาษาอื่นอย่างคันจิหรือซีริลลิก! คุณจะได้เรียนวิธี concatenate (ต่อ) สตริงสองอันเข้าด้วยกัน และใช้ string interpolation สร้าง เทมเพลตสตริงที่มีส่วนที่แทนที่ได้

3.2 ลงมือ: Escape Sequence, Verbatim String และ Unicode

สมมติสถานการณ์: หัวหน้าให้คุณทำ mockup เครื่องมือ command-line สำหรับออกใบแจ้งหนี้ ทั้งภาษาอังกฤษและญี่ปุ่น ยังไม่ต้องสร้างฟังก์ชันจริง แค่ทำหน้าตา command-line ให้ทีมบิลลิ่ง ดูอนุมัติก่อน

Character Escape Sequence คืออะไร

escape character sequence คือคำสั่งบอก runtime ให้แทรกอักขระพิเศษที่มีผลต่อผลลัพธ์ ของสตริง ใน C# escape sequence เริ่มด้วย backslash \ ตามด้วยอักขระที่ต้องการ escape เช่น \n เพิ่มบรรทัดใหม่ และ \t เพิ่ม tab

โค้ดนี้ใช้ escape sequence เพิ่มบรรทัดใหม่และ tab:

Program.cs 
Console.WriteLine("Hello\nWorld!");
Console.WriteLine("Hello\tWorld!");
Output
Hello
World!
Hello	World!

Escape เครื่องหมายคำพูดคู่

ถ้าอยากแทรกเครื่องหมายคำพูดคู่ลงในสตริง literal ล่ะ? ถ้าไม่ escape คอมไพเลอร์จะงง เพราะคิดว่าคุณจะปิดสตริงก่อนกำหนด:

Program.cs
Console.WriteLine("Hello "World"!");
Output
Error summary:
  CS1003: Syntax error, ',' expected
  CS0103: The name 'World' does not exist in the current context
  CS1003: Syntax error, ',' expected

ใช้ escape sequence \" แทน:

Program.cs 
Console.WriteLine("Hello \"World\"!");
Output
Hello "World"!

Escape เครื่องหมาย backslash

แล้วถ้าอยากใช้ backslash เพื่อจุดประสงค์อื่น เช่น แสดง path ของไฟล์ล่ะ?

Program.cs
Console.WriteLine("c:\source\repos");
Output
(1,22): error CS1009: Unrecognized escape sequence

C# สงวน backslash ไว้สำหรับ escape sequence เท่านั้น ปัญหาอยู่ที่ลำดับ \s — ส่วน \r ไม่ error เพราะมันเป็น escape sequence ที่ถูกต้อง (carriage return) แต่ในบริบทนี้เราไม่ได้ต้องการ carriage return แก้ปัญหาด้วยการใช้ \\ เพื่อ แสดง backslash ตัวเดียว:

Program.cs 
Console.WriteLine("c:\\source\\repos");
Output
c:\source\repos

สร้าง mockup command-line ด้วย escape sequence

Program.cs 
Console.WriteLine("Generating invoices for customer \"Contoso Corp\" ... \n");
Console.WriteLine("Invoice: 1021\t\tComplete!");
Console.WriteLine("Invoice: 1022\t\tComplete!");
Console.Write("\nOutput Directory:\t");
Output
Generating invoices for customer "Contoso Corp" ...

Invoice: 1021		Complete!
Invoice: 1022		Complete!

Output Directory:

Verbatim String Literal

verbatim string literal จะคงช่องว่างและอักขระทุกตัวไว้ตามที่พิมพ์ โดยไม่ต้อง escape backslash เลย สร้างด้วยการใส่ directive @ ไว้หน้าสตริง literal:

Program.cs 
Console.WriteLine(@"    c:\source\repos    
        (this is where your code goes)");
Output
    c:\source\repos    
        (this is where your code goes)

สังเกตว่าสตริงนี้ยาวคร่อม 2 บรรทัด และช่องว่างที่เกิดจากคำสั่งนี้ถูกคงไว้ในผลลัพธ์ทุกตัว

เพิ่มบรรทัดโค้ดนี้ต่อจากของเดิม:

Program.cs 
Console.Write(@"c:\invoices");
Output รวมกับโค้ดก่อนหน้า
Generating invoices for customer "Contoso Corp" ...

Invoice: 1021		Complete!
Invoice: 1022		Complete!

Output Directory:	c:\invoices

Unicode Escape Character

คุณสามารถเพิ่มอักขระที่เข้ารหัสไว้ในสตริง literal ด้วย escape sequence \u ตามด้วยรหัส 4 ตัวอักษรแทนอักขระใน Unicode (UTF-16):

Program.cs 
// Kon'nichiwa World
Console.WriteLine("\u3053\u3093\u306B\u3061\u306F World!");
Output (ถ้าคอนโซลรองรับ Unicode)
こんにちは World!
⚠️ ข้อควรระวัง คอนโซลบางตัว เช่น Windows Command Prompt แบบเดิม อาจแสดง Unicode บางตัวไม่ได้ และจะแทนที่ ด้วยเครื่องหมายคำถาม ? แทน อีกอย่างคือตัวอย่างนี้เป็น UTF-16 อักขระบางตัวต้องใช้ UTF-32 ซึ่งต้องใช้ escape sequence ต่างออกไป — เรื่อง Unicode เป็นหัวข้อที่ลึกมาก บทนี้แค่แสดงให้เห็นว่าทำอะไรได้บ้างเท่านั้น

ทำ mockup ให้จบ โดยเพิ่มวลีภาษาญี่ปุ่นที่แปลว่า "วิธีออกใบแจ้งหนี้ภาษาญี่ปุ่น":

Program.cs 
Console.WriteLine("Generating invoices for customer \"Contoso Corp\" ... \n");
Console.WriteLine("Invoice: 1021\t\tComplete!");
Console.WriteLine("Invoice: 1022\t\tComplete!");
Console.Write("\nOutput Directory:\t");
Console.Write(@"c:\invoices");

// To generate Japanese invoices:
// Nihon no seikyū-sho o seisei suru ni wa:
Console.Write("\n\n\u65e5\u672c\u306e\u8acb\u6c42\u66f8\u3092\u751f\u6210\u3059\u308b\u306b\u306f\uff1a\n\t");
// User command to run an application
Console.WriteLine(@"c:\invoices\app.exe -j");
Output
Generating invoices for customer "Contoso Corp" ...

Invoice: 1021		Complete!
Invoice: 1022		Complete!

Output Directory:	c:\invoices

日本の請求書を生成するには：
	c:\invoices\app.exe -j

3.3 ลงมือ: ต่อสตริงด้วย Concatenation

บ่อยครั้งคุณต้องรวมข้อมูลจากหลายแหล่ง ทั้งสตริง literal และตัวแปรที่มีทั้งข้อความและตัวเลข ในหัวข้อนี้ คุณจะใช้ string concatenation รวมสองค่าขึ้นไปเป็นสตริงใหม่

String Concatenation คืออะไร

"Concatenation" เป็นศัพท์เฉพาะของโปรแกรมเมอร์ หมายถึงการรวมค่า string สองค่าขึ้นไปให้กลายเป็นค่า string ใหม่ ต่างจากการบวกเลข ค่าที่สองจะถูกต่อท้าย ค่าแรกไปเรื่อยๆ

การต่อสตริงใช้ string concatenation operator คือเครื่องหมายบวก +:

Program.cs 
string firstName = "Bob";
string message = "Hello " + firstName;
Console.WriteLine(message);
Output
Hello Bob

สังเกตลำดับ — สตริงแรก "Hello " อยู่ก่อนในสตริงใหม่ และค่าในตัวแปร firstName ถูกต่อท้ายเข้าไป

ต่อหลายตัวแปรและสตริง literal พร้อมกัน

ทำการต่อสตริงหลายครั้งในบรรทัดเดียวได้:

Program.cs 
string firstName = "Bob";
string greeting = "Hello";
string message = greeting + " " + firstName + "!";
Console.WriteLine(message);
Output
Hello Bob!

เลี่ยงตัวแปรกลาง

ในขั้นตอนก่อนหน้า คุณใช้ตัวแปรเสริมเก็บสตริงใหม่ที่ได้จากการต่อ นอกจากมีเหตุผลจำเป็นจริงๆ คุณควรเลี่ยงตัวแปรกลางแบบนี้ และทำการต่อสตริงตรงจุดที่ต้องใช้เลย:

Program.cs 
string firstName = "Bob";
string greeting = "Hello";
Console.WriteLine(greeting + " " + firstName + "!");
Output
Hello Bob!
💡 หลักการ ตัวแปรกลาง (intermediate variable) ไม่ผิด แต่ถ้าไม่ได้ช่วยให้โค้ดอ่านง่ายขึ้นจริงๆ ก็ไม่จำเป็นต้องมี — ยิ่งโค้ดสั้นและตรงประเด็น ยิ่งดูแลรักษาง่าย

3.4 ลงมือ: ต่อสตริงด้วย Interpolation

Concatenation ง่ายและสะดวก แต่ string interpolation กำลังได้รับความนิยมมากขึ้นเรื่อยๆ โดยเฉพาะเมื่อต้องรวมสตริง literal และตัวแปรจำนวนมากเข้าเป็นข้อความเดียว

String Interpolation คืออะไร

String interpolation รวมหลายค่าเป็นสตริง literal เดียว โดยใช้ "เทมเพลต" และ interpolation expression ตั้งแต่ 1 ชุดขึ้นไป — interpolation expression คือ ปีกกาเปิด-ปิด { } ข้างในใส่ expression C# อะไรก็ได้ที่คืนค่าออกมา สตริง literal จะกลายเป็นเทมเพลตเมื่อมี $ นำหน้า

แทนที่จะเขียนแบบนี้:

Program.cs
string message = greeting + " " + firstName + "!";

เขียนแบบนี้กระชับกว่า:

Program.cs
string message = $"{greeting} {firstName}!";

ในตัวอย่างง่ายๆ นี้ ประหยัดไปไม่กี่ตัวอักษร แต่ลองนึกภาพเวลามีการรวมค่าที่ซับซ้อนกว่านี้ string interpolation จะกระชับกว่ามาก และหลายคนมองว่าไวยากรณ์นี้อ่านง่ายกว่าด้วย

ใช้ Interpolation รวมสตริงกับตัวแปร

สร้างสตริง literal แล้วเติม $ นำหน้า ข้างในสตริงต้องมีปีกกา {} อย่างน้อย 1 ชุด ข้างในปีกกาใส่ชื่อตัวแปร:

Program.cs 
string firstName = "Bob";
string message = $"Hello {firstName}!";
Console.WriteLine(message);
Output
Hello Bob!

Interpolation กับหลายตัวแปร

Program.cs 
int version = 11;
string updateText = "Update to Windows";
string message = $"{updateText} {version}";
Console.WriteLine(message);
Output
Update to Windows 11

เลี่ยงตัวแปรกลางได้เหมือนกับ concatenation:

Program.cs 
int version = 11;
string updateText = "Update to Windows";
Console.WriteLine($"{updateText} {version}!");
Output
Update to Windows 11!

ผสม Verbatim กับ Interpolation

ถ้าอยากใช้ verbatim literal ในเทมเพลตของคุณ ใช้ทั้งสัญลักษณ์ @ และ $ พร้อมกันได้เลย:

Program.cs 
string projectName = "First-Project";
Console.WriteLine($@"C:\Output\{projectName}\Data");
Output
C:\Output\First-Project\Data

$ ทำให้อ้างอิงตัวแปร projectName ในปีกกาได้ ส่วน @ ทำให้ใช้ \ โดยไม่ต้อง escape

3.5 ท้าทาย: ข้อความสองภาษา

โจทย์ตามต้นฉบับ MS Learn

เริ่มจากโค้ด 2 บรรทัดนี้ (ห้ามแก้ไข 2 บรรทัดนี้ แต่เพิ่มโค้ดก่อน/หลังได้):

Program.cs — บังคับใช้
string projectName = "ACME";

string russianMessage = "\u041f\u043e\u0441\u043c\u043e\u0442\u0440\u0435\u0442\u044c \u0440\u0443\u0441\u0441\u043a\u0438\u0439 \u0432\u044b\u0432\u043e\u0434";

ตัวแปร projectName ต้องถูกใช้ 2 ครั้งในผลลัพธ์ ตัวแปร russianMessage เก็บข้อความ "View Russian output" ภาษารัสเซีย ต้องใช้ตัวแปรนี้ในโค้ดที่พิมพ์ข้อความด้วย

กฎ: ใช้ Console.WriteLine() หรือ Console.Write() ได้แค่ 2 ครั้งเท่านั้น — ถ้าต้องขึ้นบรรทัดใหม่หรือจัดรูปแบบเพิ่ม ต้องใช้เทคนิคที่ เรียนในบทนี้ (escape sequence, verbatim, interpolation) จัดการเอง

ผลลัพธ์ที่ต้องได้
View English output:
  c:\Exercise\ACME\data.txt

Посмотреть русский вывод:
  c:\Exercise\ACME\ru-RU\data.txt

สังเกตการขึ้นบรรทัดใหม่ ระยะเว้น และวิธีใช้โค้ด 2 บรรทัดที่บังคับให้ใช้ด้วย

💡 ขอคำใบ้

คำใบ้ 1: รวม $ (interpolation) กับ @ (verbatim) เข้าด้วยกันเป็น $@"..." จะช่วยเรื่อง path ที่มี \ ได้มาก

คำใบ้ 2: ใช้ \n และ \t ภายในสตริง interpolation เพื่อจัดบรรทัดใหม่และย่อหน้า โดยไม่ต้องเรียก WriteLine เพิ่ม

3.6 เฉลยและวิเคราะห์

Program.cs — เฉลยตัวอย่าง 
string projectName = "ACME";
string englishLocation = $@"c:\Exercise\{projectName}\data.txt";
Console.WriteLine($"View English output:\n\t{englishLocation}\n");

string russianMessage = "\u041f\u043e\u0441\u043c\u043e\u0442\u0440\u0435\u0442\u044c \u0440\u0443\u0441\u0441\u043a\u0438\u0439 \u0432\u044b\u0432\u043e\u0434";

Console.WriteLine($"{russianMessage}:\n\t{russianLocation}\n");
Output
View English output:
	c:\Exercise\ACME\data.txt

Посмотреть русский вывод:
	c:\Exercise\ACME\ru-RU\data.txt

นี่เป็นเพียงหนึ่งในหลายวิธีที่แก้โจทย์นี้ได้ อาจตั้งชื่อตัวแปรต่างไป หรือใช้ escape sequence ต่างไปก็ได้ อาจใช้ Console.Write แทน Console.WriteLine หรือรวมค่าต่างไปก็ได้ ขอแค่ทำตามกฎของโจทย์และได้ผลลัพธ์ตรงตามที่กำหนด

เทคนิคสำคัญของเฉลยนี้คือ $@"..." — ผสม interpolation กับ verbatim ในตัวเดียว ทำให้ใส่ตัวแปร {projectName} ได้ และใช้ \ ใน path ได้โดยไม่ต้อง escape เป็น \\

เฉลย: ข้อ C. \" คือ escape sequence สำหรับเครื่องหมาย คำพูดคู่โดยเฉพาะ ข้อ A ไม่ใช่ escape sequence ที่มีอยู่จริง ข้อ B ใช้กับเครื่องหมาย คำพูดเดี่ยว (ซึ่งใน string ปกติไม่จำเป็นต้อง escape อยู่แล้ว)

2. โค้ดข้อใดใช้ string interpolation ได้ถูกต้อง (สมมติตัวแปร value เป็น string)?

  • AConsole.WriteLine(@"My value: {value}");
  • BConsole.WriteLine($"My value: {value}");
  • CConsole.WriteLine(@"My value: [value]");
เฉลย: ข้อ B. interpolation ต้องขึ้นต้นด้วย $ และใช้ปีกกา {} ข้อ A ใช้ @ (verbatim) จึงพิมพ์ {value} ตามตัวอักษร ไม่แทนค่าให้ ข้อ C ทั้งสัญลักษณ์และวงเล็บผิดทั้งคู่

3. ฝัง Unicode สำหรับข้อความทักทายภาษาไทยไว้ในสตริง แต่พอรันแล้วเห็นแต่เครื่องหมายคำถาม เป็นไปได้ว่าเกิดจากอะไร?

  • Aลืมใส่ escape sequence \u
  • Bใช้รหัส Unicode ผิดตัว
  • Cคอนโซลของผู้ใช้ไม่รองรับอักขระ Unicode ชุดนั้น
เฉลย: ข้อ C. คอนโซลบางตัวแสดง Unicode บางชุดไม่ได้ และจะแทนที่ด้วย ? โดยอัตโนมัติ — ถ้าลืม \u โค้ดจะ error ตอนคอมไพล์เลย ไม่ใช่ แสดงผลเป็น ? และถ้าใช้รหัสผิดตัว จะได้อักขระอื่นที่ถูกต้องแต่ไม่ใช่ตัวที่ต้องการ ไม่ใช่เครื่องหมายคำถาม

4. โค้ดข้อใดต่อ \ เพียงตัวเดียวเข้ากับสตริง directory ได้ถูกต้อง?

  • Adirectory = directory + "\";
  • Bdirectory = directory + '\';
  • Cdirectory = directory + @"\";
เฉลย: ข้อ C. ในสตริงแบบ verbatim @"\" เครื่องหมาย backslash ไม่ถูกตีความเป็นตัวเริ่ม escape จึงได้ backslash ตัวเดียวตรงๆ ข้อ A ทำให้สตริง ไม่ปิดสมบูรณ์ (syntax error) ข้อ B ใช้เครื่องหมายคำพูดเดี่ยวแบบ char literal ผิดวิธี

ข้อ 2ง่าย

เขียนโค้ดพิมพ์ค่าตัวแปร name และ age ด้วย string interpolation ให้ได้ผลลัพธ์: ฉันชื่อ ปาล์ม อายุ 20 ปี

เขียนโค้ดต่อสตริง (concatenation ด้วย +) แสดง path ไฟล์นี้ให้ตรงเป๊ะ โดยห้ามใช้ verbatim @ — ต้อง escape เอง:

backslash แต่ละตัวต้องเขียนเป็น \\

ข้อ 5กลาง

เขียนโค้ดข้อ 4 ใหม่ แต่คราวนี้ใช้ $@"..." (interpolation + verbatim ผสมกัน) แทน ให้ผลลัพธ์เหมือนเดิมทุกตัวอักษร แต่โค้ดต้องสั้นและอ่านง่ายกว่าเดิม

Program.cs

ข้อ 6ท้าทาย

เขียนโปรแกรมพิมพ์ใบเสร็จสั้นๆ ให้ตรงเป๊ะทุกตัวอักษร (สังเกต tab หลังเครื่องหมาย ":" และบรรทัดว่างก่อนคำว่า "ขอบคุณ") ใช้ตัวแปรอย่างน้อย 2 ตัว (ชื่อร้าน, ยอดรวม) ผสมกับ escape sequence และ interpolation ตามที่เรียนมาทั้งหมด:

ร้าน:	กาแฟดีดี
ยอดรวม:	150 บาท

ขอบคุณที่ใช้บริการ "กาแฟดีดี" ครับ
💡 คำใบ้

ใช้ \t คั่นระหว่างหัวข้อกับค่า และ \n\n สร้างบรรทัดว่างก่อนข้อความสุดท้าย ส่วนชื่อร้านในบรรทัดสุดท้ายต้อง escape ด้วย \"

ดูเฉลย
Program.cs
string shopName = "กาแฟดีดี";
int total = 150;

Console.WriteLine($"ร้าน:\t{shopName}\nยอดรวม:\t{total} บาท\n");
Console.WriteLine($"ขอบคุณที่ใช้บริการ \"{shopName}\" ครับ");

📌 สรุปบทที่ 3

เป้าหมายของบทนี้คือให้คุณเขียนโค้ดจัดรูปแบบสตริงที่มีอักขระพิเศษ เช่น เครื่องหมายคำพูดคู่ บรรทัดใหม่ tab และช่องว่างอื่นๆ รวมถึงอักขระ Unicode คุณยังได้รวมสตริงด้วยสองเทคนิค ด้วย character escape sequence คุณเพิ่มอักขระพิเศษในสตริง literal ได้ทั้งแบบ escape ตรงๆ หรือแบบ verbatim string คุณเพิ่มอักขระ Unicode จากภาษาอื่นอย่างคันจิญี่ปุ่นและซีริลลิก รัสเซียได้ คุณใช้ string concatenation ง่ายๆ ด้วยเครื่องหมาย + และอัปเกรดไปใช้ string interpolation เพื่อรวมค่าเข้ากับเทมเพลต
