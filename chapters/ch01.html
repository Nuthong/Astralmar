1.1 ทำไมต้องเริ่มที่ "Hello World"

ภาษา C# ใช้สร้างแอปพลิเคชันได้หลากหลายมาก เช่น:

  • แอปธุรกิจสำหรับเก็บ วิเคราะห์ และประมวลผลข้อมูล
  • เว็บแอปพลิเคชันแบบไดนามิกที่เข้าถึงผ่านเบราว์เซอร์
  • เกม ทั้งแบบ 2D และ 3D
  • แอปด้านการเงินและวิทยาศาสตร์
  • แอปบนคลาวด์
  • แอปมือถือ

แต่คำถามคือ จะเริ่มเขียนแอปพลิเคชันได้ยังไง? แอปทุกตัวประกอบขึ้นจากโค้ดหลายบรรทัดที่ทำงาน ร่วมกัน วิธีที่ดีที่สุดในการเรียนเขียนโปรแกรมคือการลงมือเขียนโค้ดจริง — พิมพ์เอง ไม่ใช่แค่อ่านผ่านตา เพราะการพิมพ์เองจะช่วยให้จำและเข้าใจได้ลึกกว่าการอ่านเฉยๆ มาก

💡 หลักการเรียนของเล่มนี้ ทุกตัวอย่างโค้ดในหนังสือควรพิมพ์ตามเอง อย่างน้อยครั้งแรก แม้จะมีปุ่ม Copy ให้ก็ตาม การพิมพ์เองจะฝึกให้มือคุณคุ้นกับไวยากรณ์ และทำให้เจอ error จริงที่สอนอะไรได้มากกว่าการก็อปวาง

เมื่อจบบทนี้ คุณจะเขียนโค้ด C# เพื่อพิมพ์ข้อความออกทาง standard output ของคอนโซล (เช่นหน้าต่าง Terminal) ได้ — โค้ดไม่กี่บรรทัดนี้จะเป็นครั้งแรกที่คุณได้เห็นไวยากรณ์ของ C# และจะให้ข้อมูลเชิงลึกที่มีค่ามากทีเดียว

1.2 ลงมือ: พิมพ์โค้ดแรกของคุณ

ในแบบฝึกหัดแรกนี้ คุณจะใช้ C# พิมพ์ประโยคในตำนานของโปรแกรมเมอร์ ออกทางคอนโซล

เตรียมโปรเจกต์

เปิด PowerShell แล้วสร้างโปรเจกต์ใหม่สำหรับบทนี้โดยเฉพาะ:

PowerShell 
dotnet new console -o ch01-hello
cd ch01-hello
คำสั่งนี้ไม่มีผลลัพธ์แสดงบนคอนโซล แค่สร้างโฟลเดอร์และไฟล์เท่านั้น
ℹ️ ทางเลือกอื่น ถ้ายังไม่อยากติดตั้ง .NET บนเครื่อง สามารถใช้ C# Code Editor ของ Microsoft ที่รันในเบราว์เซอร์แทนได้ (ต้องมีอินเทอร์เน็ต) — แต่แนะนำให้ใช้ dotnet บนเครื่องตามบทที่ 0 เพื่อได้ประสบการณ์ตรงกับที่จะใช้จริงในบทถัดๆ ไป

เขียนโค้ดแรก

เปิดไฟล์ Program.cs ในโฟลเดอร์ ch01-hello ด้วย Notepad ลบเนื้อหาเดิมทั้งหมด แล้วพิมพ์โค้ดนี้ ให้เหมือนต้นฉบับทุกตัวอักษร:

Program.cs 
Console.WriteLine("Hello World!");

บันทึกไฟล์ แล้วกลับไปที่ PowerShell รันคำสั่ง:

PowerShell 
dotnet run
Output
Hello World!

dotnet run ทำสองงานให้เสร็จในคำสั่งเดียว: คอมไพล์โค้ดของคุณให้เป็นรูปแบบที่เครื่องรันได้ แล้วรันโปรแกรมที่คอมไพล์เสร็จนั้นทันที

ถ้าเจอ error ต้องทำยังไง

การเขียนโค้ด C# คือ งานที่ต้องแม่นยำ พิมพ์ผิดแม้แค่ตัวเดียวก็จะได้ error message ทันที ลองดูตัวอย่าง

ถ้าพิมพ์ console เป็นตัวพิมพ์เล็กแทนที่จะเป็น Console:

Program.cs 
console.WriteLine("Hello World!");
Output
Error summary:
  CS0103: The name 'console' does not exist in the current context

C# เป็นภาษาที่ คำนึงถึงตัวพิมพ์เล็ก-ใหญ่ (case-sensitive) คอมไพเลอร์มองคำว่า console กับ Console ต่างกันเหมือนคำว่า "แมว" กับ "หมา"

อีกตัวอย่าง ถ้าใช้เครื่องหมายคำพูดเดี่ยว ' แทนคู่ ":

Program.cs 
Console.WriteLine('Hello World!');
Output
Error summary:
  CS1012: Too many characters in character literal
💡 error ไม่ใช่เรื่องถาวร แค่หามันเจอ แก้ แล้วรันใหม่ ถ้าเจอ error ให้ดูให้ละเอียดทีละตัวอักษรว่าพิมพ์ตรงกับต้นฉบับหรือไม่ ตัว editor ที่ดีจะขีดเส้นใต้สีแดงใต้จุดที่มีปัญหาให้ล่วงหน้าก่อนรันด้วยซ้ำ

ลองพิมพ์ข้อความใหม่

คอมเมนต์บรรทัดเดิมด้วยเครื่องหมายทับคู่ // (สั่งให้คอมไพเลอร์ข้ามบรรทัดนั้น) แล้วเพิ่มโค้ดใหม่ตามนี้:

Program.cs 
// Console.WriteLine("Hello World!");

Console.Write("Congratulations!");
Console.Write(" ");
Console.Write("You wrote your first lines of code.");
PowerShell 
dotnet run
Output
Congratulations! You wrote your first lines of code.

ความต่างระหว่าง Console.Write กับ Console.WriteLine

โค้ด 3 บรรทัดที่เพิ่งเพิ่มไป แสดงความต่างระหว่างเมธอด Console.WriteLine() กับ Console.Write():

  • Console.WriteLine() พิมพ์ข้อความออกคอนโซล แล้วขึ้นบรรทัดใหม่ต่อท้ายทันที (เหมือนกดปุ่ม Enter)
  • Console.Write() พิมพ์ข้อความออกคอนโซลโดยไม่ขึ้นบรรทัดใหม่ — การเรียก Console.Write() ครั้งถัดไปจึงพิมพ์ต่อในบรรทัดเดิม

ลองอัปเดตโค้ดเพื่อเห็นความต่างชัดๆ:

Program.cs 
Console.WriteLine("Congratulations!");
Console.Write("You wrote your first lines of code.");
PowerShell 
dotnet run
Output
Congratulations!
You wrote your first lines of code.

1.3 ผ่าโค้ดทีละชิ้น

มาถอยกลับมาคิดกันว่า "ภาษาโปรแกรม" คืออะไร และโค้ดของคุณสื่อสารคำสั่งกับคอมพิวเตอร์ได้ยังไง

ภาษาโปรแกรมคืออะไร

ภาษาโปรแกรมอย่าง C# ให้คุณเขียนคำสั่งที่ต้องการให้คอมพิวเตอร์ทำ แต่ละภาษามีไวยากรณ์ของตัวเอง แต่พอเรียนภาษาแรกแล้วไปลองภาษาที่สอง คุณจะพบว่าแนวคิดหลักๆ คล้ายกันมาก หน้าที่ของภาษาโปรแกรมคือให้มนุษย์สื่อสารความต้องการออกมาในรูปแบบที่มนุษย์อ่านเข้าใจได้ คำสั่งที่คุณเขียนเรียกว่า ซอร์สโค้ด (source code) หรือเรียกสั้นๆ ว่า "โค้ด"

ตอนนี้นักพัฒนาแก้ไขโค้ดได้ แต่คอมพิวเตอร์ยังไม่เข้าใจโค้ดนั้น — โค้ดต้องถูก คอมไพล์ ให้เป็นรูปแบบที่คอมพิวเตอร์เข้าใจก่อน

คอมไพล์คืออะไร

โปรแกรมพิเศษที่เรียกว่า คอมไพเลอร์ (compiler) จะแปลงซอร์สโค้ดของคุณให้เป็นรูปแบบที่ หน่วยประมวลผลกลาง (CPU) ของคอมพิวเตอร์รันได้ ตอนที่คุณกด dotnet run เมื่อกี้ โค้ดถูกคอมไพล์ก่อน แล้วค่อยถูกรัน

ทำไมโค้ดต้องถูกคอมไพล์? แม้ภาษาโปรแกรมส่วนใหญ่จะดูลึกลับตอนแรก แต่จริงๆ แล้วมันยัง "อ่านง่ายกว่า" ภาษาที่คอมพิวเตอร์ชอบมาก CPU เข้าใจคำสั่งที่แสดงผลด้วยการเปิด-ปิด สวิตช์เล็กๆ นับพันนับล้านตัว คอมไพเลอร์คือสะพานเชื่อมสองโลกนี้ โดยแปลคำสั่งที่มนุษย์อ่านออก ให้กลายเป็นชุดคำสั่งที่คอมพิวเตอร์เข้าใจ

ไวยากรณ์ (syntax) คืออะไร

กฎการเขียนโค้ด C# เรียกว่า ไวยากรณ์ (syntax) เหมือนภาษามนุษย์ที่มีกฎเรื่องเครื่องหมายวรรคตอน และโครงสร้างประโยค ภาษาโปรแกรมก็มีกฎเช่นกัน กฎเหล่านี้กำหนดคำสงวน (keyword) และ operator ของ C# รวมถึงวิธีประกอบมันเข้าด้วยกันเป็นโปรแกรม

ตอนพิมพ์โค้ด คุณอาจสังเกตว่าสีของคำและสัญลักษณ์ต่างๆ เปลี่ยนไป — เรียกว่า syntax highlighting ช่วยให้มองเห็นจุดที่พิมพ์ผิดกฎไวยากรณ์ได้ง่ายขึ้น

โค้ดของคุณทำงานยังไง

มาโฟกัสที่บรรทัดนี้ที่คุณเพิ่งเขียน:

Program.cs
Console.WriteLine("Hello World!");

เมื่อรัน คุณเห็นข้อความ Hello World! ถูกพิมพ์ออกคอนโซล เมื่อวลีถูกล้อมด้วย เครื่องหมายคำพูดคู่ในโค้ด C# มันถูกเรียกว่า literal string — พูดง่ายๆ คือคุณต้องการ ให้ตัวอักษร H, e, l, l, o ไปจนจบ ถูกส่งออกไปตามตัวอักษรทุกประการ (ตามตัวอักษร = "literal")

Console เรียกว่า คลาส (class) คลาส "เป็นเจ้าของ" เมธอดต่างๆ หรือพูดอีกแบบคือเมธอดอาศัยอยู่ภายในคลาส การจะเรียกใช้เมธอด คุณต้องรู้ว่ามันอยู่คลาสไหน ตอนนี้ให้คิดว่าคลาสคือวิธีแทนวัตถุหนึ่งชิ้น ในกรณีนี้ เมธอดทั้งหมดที่ทำงานกับคอนโซลเอาต์พุต ถูกนิยามอยู่ภายในคลาส Console

มีจุด (หรือมหัพภาค) คั่นระหว่างชื่อคลาส Console กับชื่อเมธอด WriteLine() จุดนี้คือ ตัวเชื่อมเข้าถึงสมาชิก (member access operator) พูดอีกแบบ จุดคือวิธีที่คุณ "นำทาง" จากคลาสไปยังหนึ่งในเมธอดของมัน

WriteLine() เรียกว่า เมธอด (method) — สังเกตเมธอดได้เสมอเพราะมันมีวงเล็บต่อท้าย แต่ละเมธอดมีหน้าที่เดียว งานของเมธอด WriteLine() คือเขียนข้อมูลหนึ่งบรรทัดออกคอนโซล ข้อมูลที่จะพิมพ์ถูกส่งเข้าไปทางระหว่างวงเล็บเปิด-ปิด เรียกว่า พารามิเตอร์ขาเข้า (input parameter) บางเมธอดต้องการพารามิเตอร์ขาเข้า บางเมธอดไม่ต้อง แต่ถ้าจะเรียกใช้เมธอด คุณต้องใส่วงเล็บ ต่อท้ายชื่อเมธอดเสมอ — วงเล็บนี้เรียกว่า ตัวเรียกใช้เมธอด (method invocation operator)

สุดท้าย เครื่องหมายเซมิโคลอนคือ ตัวจบคำสั่ง (end of statement operator) ข้อความสั่ง (statement) คือคำสั่งที่สมบูรณ์หนึ่งชุดใน C# เซมิโคลอนบอกคอมไพเลอร์ว่า คุณพิมพ์คำสั่งจบแล้ว

อย่าเพิ่งกังวลถ้ายังจำแนวคิดและศัพท์เหล่านี้ไม่ได้หมด สิ่งที่ต้องจำตอนนี้คือ ถ้าจะพิมพ์ข้อความ ออกคอนโซล:

  • ใช้ Console.WriteLine("ข้อความของคุณ");
  • ขึ้นต้นด้วยตัวพิมพ์ใหญ่ที่ Console, Write, และ Line
  • ใช้เครื่องหมายวรรคตอนให้ถูกต้อง เพราะมันมีบทบาทพิเศษใน C#
  • ถ้าพิมพ์ผิด แค่หาให้เจอ แก้ แล้วรันใหม่
💡 เคล็ดลับ ลองทำ cheat sheet ของตัวเองไว้ จนกว่าจะจำคำสั่งสำคัญๆ ได้ขึ้นใจ

ลำดับการทำงาน (flow of execution)

สิ่งสำคัญที่ต้องเข้าใจคือลำดับการทำงาน — โค้ดของคุณถูกรันทีละคำสั่ง เรียงจากบนลงล่าง จนกว่าจะไม่มีคำสั่งเหลือให้รัน บางคำสั่งต้องให้ CPU รอก่อนจะทำงานต่อได้ บางคำสั่งใช้เปลี่ยน ลำดับการทำงานได้ (จะได้เรียนในบทหลังๆ เรื่อง if/else และ loop)

1.4 ท้าทาย: แสดงผล 2 บรรทัด

โจทย์ท้าทายแบบนี้จะปรากฏในแทบทุกโมดูล เพื่อตอกย้ำสิ่งที่เรียนมาและสร้างความมั่นใจก่อนไปต่อ

โจทย์ตามต้นฉบับ MS Learn

ลบโค้ดเดิมทั้งหมดใน Program.cs แล้วเขียนโค้ดใหม่ให้ได้ผลลัพธ์ตรงนี้เป๊ะ:

ผลลัพธ์ที่ต้องได้
This is the first line.
This is the second line.

คุณเพิ่งเรียนวิธีแสดงข้อความด้วยโค้ดบรรทัดเดียว (WriteLine) และวิธีแสดง ข้อความด้วยหลายบรรทัด (Write ต่อกันหลายครั้ง) — ในโจทย์นี้ให้ใช้ทั้งสองเทคนิค จะใช้เทคนิคไหนกับบรรทัดไหน หรือจะแบ่งข้อความบรรทัดใดบรรทัดหนึ่งเป็นกี่ชิ้นก็ได้ตามใจคุณ ขอแค่ผลลัพธ์สุดท้ายตรงตามที่กำหนด

💡 ขอคำใบ้

คำใบ้ 1: คุณต้องใช้ Console.WriteLine() อย่างน้อย 1 ครั้ง และ Console.Write() อย่างน้อย 1 ครั้งในโค้ดชุดนี้

คำใบ้ 2: WriteLine() ขึ้นบรรทัดใหม่ให้อัตโนมัติ ส่วน Write() ไม่ขึ้น — เลือกใช้ให้ตรงกับจุดที่ต้องการขึ้นบรรทัดใหม่

1.5 เฉลยและวิเคราะห์

ต่อไปนี้คือหนึ่งในหลายวิธีที่แก้โจทย์นี้ได้ ไม่ใช่คำตอบเดียวที่ถูก:

Program.cs — เฉลยตัวอย่าง 
Console.WriteLine("This is the first line.");

Console.Write("This is ");

1.7 ❓ Knowledge Check

คำถามชุดนี้แปลจาก Module Assessment จริงของบทนี้ใน Microsoft Learn

1. Console.Write กับ Console.WriteLine ต่างกันยังไง?

  • AConsole.Write พิมพ์ผลลัพธ์แล้วขึ้นบรรทัดใหม่
  • BConsole.WriteLine พิมพ์ผลลัพธ์แล้วขึ้นบรรทัดใหม่ (พิมพ์ผลลัพธ์บนบรรทัดใหม่)
  • CConsole.WriteLine เติมการขึ้นบรรทัดใหม่ต่อท้ายผลลัพธ์
เฉลย: ข้อ C. WriteLine เพิ่ม "line feed" ต่อท้ายข้อความที่พิมพ์ ทำให้การเรียกครั้งถัดไปเริ่มบรรทัดใหม่ ส่วน Write ไม่เพิ่มอะไรต่อท้าย จึงพิมพ์ต่อในบรรทัดเดิม (ข้อ A และ B สลับบทบาทกันจากความจริง)

2. หน้าที่หลักของคอมไพเลอร์คืออะไร?

  • Aตรวจหาคำผิด (spelling) ในโค้ดเป็นหลัก
  • Bรันโค้ดของคุณเป็นหลัก
  • Cแปลงโค้ดของคุณให้เป็นรูปแบบที่เครื่องรันได้ (executable) เป็นหลัก
เฉลย: ข้อ C. คอมไพเลอร์แปลซอร์สโค้ดที่มนุษย์อ่านออก ให้เป็นรูปแบบที่ CPU ประมวลผลได้ — ส่วนการ "รัน" เป็นหน้าที่ของ runtime ไม่ใช่คอมไพเลอร์โดยตรง และการตรวจคำผิดเป็นเพียงผลพลอยได้จากการตรวจไวยากรณ์ ไม่ใช่หน้าที่หลัก

3. ข้อใดถูกต้องเกี่ยวกับภาษา C#?

  • AC# ไม่สนใจตัวพิมพ์เล็ก-ใหญ่ (case insensitive)
  • BConsole เป็นเมธอด และ WriteLine() เป็นคลาส
  • Cใช้เครื่องหมายคำพูดคู่เพื่อสร้างค่าคงที่แบบสตริง (literal string)
เฉลย: ข้อ C. literal string ต้องล้อมด้วย double-quote เสมอ ข้อ A ผิด เพราะ C# เป็น case-sensitive (สนใจตัวพิมพ์เล็ก-ใหญ่) ข้อ B สลับบทบาทกัน — ที่จริง Console คือคลาส และ WriteLine() คือเมธอด

4. โค้ดบรรทัดนี้ผิดตรงไหน? Console.WriteLine("What is wrong with me?")

  • Aตัว L ใน WriteLine ควรเป็นตัวพิมพ์เล็ก
  • Bขาดเครื่องหมายเซมิโคลอนท้ายบรรทัด
  • Cสตริงควรใช้เครื่องหมายคำพูดเดี่ยว
เฉลย: ข้อ B. สังเกตว่าท้ายบรรทัดไม่มี ; — ทุกคำสั่งใน C# ต้องปิดท้ายด้วยเซมิโคลอน ข้อ A ผิดเพราะ WriteLine สะกดถูกอยู่แล้ว (ตัว L ต้องใหญ่) ข้อ C ผิดเพราะ double-quote ที่ใช้อยู่ถูกต้องแล้ว

1.8 ✍️ แบบฝึกหัดท้ายบท

ข้อ 1ง่าย

เขียนโปรแกรมพิมพ์ชื่อของคุณเองออกทางคอนโซล ด้วย Console.WriteLine() หนึ่งบรรทัด

ดูเฉลย
Program.cs
Console.WriteLine("สมชาย ใจดี");

เปลี่ยน "สมชาย ใจดี" เป็นชื่อของคุณเองได้เลย

ข้อ 2ง่าย

เขียนโปรแกรมให้ได้ผลลัพธ์ตรงนี้ (3 บรรทัด) โดยใช้ Console.WriteLine() 3 ครั้ง:

วันที่ 1: เริ่มเรียน C#
วันที่ 2: เข้าใจ WriteLine
วันที่ 3: เขียนโปรแกรมเองได้
ดูเฉลย
Program.cs
Console.WriteLine("วันที่ 1: เริ่มเรียน C#");
Console.WriteLine("วันที่ 2: เข้าใจ WriteLine");
Console.WriteLine("วันที่ 3: เขียนโปรแกรมเองได้");
ข้อ 3ง่าย

โค้ดนี้คอมไพล์ไม่ผ่าน หาจุดผิดและแก้ให้ถูก:

Program.cs (ผิด)
console.WriteLine('สวัสดี C#')
ดูเฉลย

มีจุดผิด 3 จุด: (1) console ต้องเป็น Console ตัวใหญ่ (2) ต้องใช้ "…" ไม่ใช่ '…' (3) ขาดเซมิโคลอนท้ายบรรทัด

Program.cs (ถูก)
Console.WriteLine("สวัสดี C#");
ข้อ 4กลาง

เขียนโค้ดผสม Console.Write() และ Console.WriteLine() ให้ได้ผลลัพธ์ตรงนี้เป๊ะ (สังเกตว่าบรรทัด 2 มาจากการพิมพ์ต่อกัน 2 ครั้ง):

ยินดีต้อนรับ
ชื่อ: ปาล์ม อายุ: 20
💡 คำใบ้

บรรทัดแรกใช้ WriteLine ได้เลย บรรทัดสองต้องใช้ Write สองครั้งแล้วปิดท้ายด้วย WriteLine (หรือ Write ตามด้วยการขึ้นบรรทัดวิธีอื่น) ลองคิดว่าใครควรขึ้นบรรทัดใหม่ ใครไม่ควร

ดูเฉลย
Program.cs
Console.WriteLine("ยินดีต้อนรับ");
Console.Write("ชื่อ: ปาล์ม ");
Console.WriteLine("อายุ: 20");
ข้อ 5กลาง

โค้ดนี้มี error 2 จุด หาให้ครบและแก้ทั้งหมด:

Program.cs (ผิด)
Console.WriteLine("บรรทัดที่หนึ่ง");
Console.write("บรรทัดที่สอง")
💡 คำใบ้

อ่านทีละบรรทัด บรรทัดที่ 2 ผิดที่ชื่อเมธอด และผิดที่ตัวจบคำสั่ง

ดูเฉลย

จุดที่ 1: write ต้องเป็น Write (W ใหญ่) — จุดที่ 2: ขาดเซมิโคลอนท้ายบรรทัดที่สอง

Program.cs (ถูก)
Console.WriteLine("บรรทัดที่หนึ่ง");
Console.Write("บรรทัดที่สอง");
ข้อ 6ท้าทาย

เขียนโปรแกรมพิมพ์กรอบข้อความแบบ ASCII art ให้ตรงตามนี้เป๊ะทุกตัวอักษร (รวมช่องว่างและเครื่องหมาย) — ข้อนี้ฝึกความละเอียดแม่นยำแบบเดียวกับที่ MS Learn เน้นในบทนี้:

|  Hello, C# World  |
+------------------+

ดูเฉลย
