Perform Basic Operations on Numbers in C#
⏱ ใช้เวลา 55–75 นาที 📦 ผลลัพธ์ บวก ลบ คูณ หาร หารเอาเศษ เพิ่ม/ลดค่า ได้อย่างถูกต้อง 🎯 ความยาก เริ่มต้น

🎯 จบบทนี้คุณจะ...

  • ทำการดำเนินการทางคณิตศาสตร์กับค่าตัวเลขได้
  • สังเกตการแปลงชนิดข้อมูลโดยปริยาย (implicit conversion) ระหว่าง string กับตัวเลข
  • แปลงชนิดข้อมูลแบบชั่วคราวด้วยการ cast
ℹ️ ความรู้ที่ต้องมีมาก่อน เข้าใจ literal/variable ของ string, int, decimal จาก บทที่ 2 และ string concatenation/interpolation จาก บทที่ 3 แล้ว

4.1 ทำไมต้องดำเนินการกับตัวเลข

แอปที่คุณสร้างด้วย C# มักต้องดำเนินการกับข้อมูลตัวเลขทั้งแบบ literal และตัวแปร เช่น:

  • บวก ลบ คูณ หารพื้นฐาน
  • ดำเนินการหลายขั้นตอนที่ต้องทำตามลำดับที่กำหนด
  • หาเศษที่เหลือจากการหาร
  • เพิ่มหรือลดค่าทีละหน่วย

สมมติคุณอยากแปลงหน่วยวัด เช่น แปลงอุณหภูมิจากองศาฟาเรนไฮต์เป็นเซลเซียส พอคำนวณได้แล้ว ก็ต้องแสดงผลเป็นข้อความที่จัดรูปแบบให้ผู้ใช้เข้าใจ วิธีทำคือใช้ operator (ตัวดำเนินการ) กระทำกับ operand (ตัวถูกดำเนินการ) อย่างค่า literal และตัวแปร

ในบทนี้ คุณจะดำเนินการทั้งกับ string และตัวเลข จะเห็นว่าคอมไพเลอร์ทำงานต่างกันไปตามชนิด ข้อมูลรอบๆ ตัวดำเนินการ และจะเข้าใจว่า operator กระทำกับ operand ยังไง

4.2 ลงมือ: บวกเลขและ Implicit Conversion

บวกเลขสองค่า

การบวกเลขสองค่า ใช้ addition operator คือเครื่องหมายบวก + — ใช่แล้ว เครื่องหมาย + ตัวเดียวกับที่ใช้ต่อสตริงในบทที่แล้ว! การใช้สัญลักษณ์เดียวทำหลาย หน้าที่แบบนี้เรียกว่า overloading the operator (โอเวอร์โหลดตัวดำเนินการ) ซึ่งเกิดขึ้น บ่อยมากใน C#

คอมไพเลอร์เข้าใจว่าคุณตั้งใจทำอะไร โดยดูจากชนิดข้อมูลของ operand รอบๆ + ถ้าทั้งสองข้างเป็น int มันจะบวกให้:

Program.cs 
int firstNumber = 12;
int secondNumber = 7;
Console.WriteLine(firstNumber + secondNumber);
Output
19

ผสมชนิดข้อมูลจนเกิด Implicit Conversion

ถ้าใช้ + ระหว่างค่า string กับ int จะเกิดอะไรขึ้น?

Program.cs 
string firstName = "Bob";
int widgetsSold = 7;
Console.WriteLine(firstName + " sold " + widgetsSold + " widgets.");
Output
Bob sold 7 widgets.

กรณีนี้คอมไพเลอร์เข้าใจว่าคุณต้องการต่อสตริง (concatenate) เพราะ + ถูกล้อมด้วย operand ชนิด string กับ int มันจึงแปลงตัวแปร int widgetsSold เป็น string ให้ชั่วคราวโดยปริยาย เพื่อต่อเข้ากับ ส่วนที่เหลือของสตริง — คอมไพเลอร์พยายามช่วยคุณเวลาทำได้ แต่ในอุดมคติ คุณควรระบุเจตนา ให้ชัดเจนกว่านี้

กรณีที่ซับซ้อนขึ้น: ผสมบวกเลขกับต่อสตริง

Program.cs 
string firstName = "Bob";
int widgetsSold = 7;
Console.WriteLine(firstName + " sold " + widgetsSold + 7 + " widgets.");
Output
Bob sold 77 widgets.

แทนที่จะบวกตัวแปร widgetsSold กับค่า literal int 7 คอมไพเลอร์กลับปฏิบัติกับทุกอย่างเป็น string แล้วต่อกันหมด (ทำงานจากซ้ายไปขวา พอเจอ string ครั้งแรกแล้ว ทุกอย่างถัดจากนั้นจะกลายเป็นการต่อสตริง)

ใช้วงเล็บบอกเจตนาให้คอมไพเลอร์ชัดเจน

Program.cs 
string firstName = "Bob";
int widgetsSold = 7;
Console.WriteLine(firstName + " sold " + (widgetsSold + 7) + " widgets.");
Output
Bob sold 14 widgets.

วงเล็บ () กลายเป็นตัวดำเนินการที่ถูกโอเวอร์โหลดอีกตัว ในที่นี้วงเล็บเปิด-ปิด ทำหน้าที่เป็น ตัวดำเนินการลำดับการคำนวณ (order of operations) เหมือนในสูตร คณิตศาสตร์ — บอกให้แก้วงเล็บชั้นในสุดก่อน ได้ผลบวกของ widgetsSold กับ 7 ก่อน แล้วค่อยแปลงผลลัพธ์เป็น string เพื่อต่อกับข้อความที่เหลือ

⚠️ ข้อควรระวัง ควรหลีกเลี่ยงการคำนวณและต่อสตริงในบรรทัดเดียวกันแบบซับซ้อนขนาดนี้ในโค้ดจริง — ตัวอย่างนี้มีไว้เพื่อให้เข้าใจว่าคอมไพเลอร์มอง operator กับ operand ยังไงเท่านั้น

4.3 ลงมือ: การดำเนินการทางคณิตศาสตร์

บวก ลบ คูณ หาร

Program.cs 
int sum = 7 + 5;
int difference = 7 - 5;
int product = 7 * 5;
int quotient = 7 / 5;

Console.WriteLine("Sum: " + sum);
Console.WriteLine("Difference: " + difference);
Console.WriteLine("Product: " + product);
Console.WriteLine("Quotient: " + quotient);
Output
Sum: 12
Difference: 2
Product: 35
Quotient: 1

+ บวก · - ลบ · * คูณ · / หาร — แต่ผลหาร (quotient) อาจไม่ตรงกับที่คุณคาดไว้ เพราะ quotient ถูกกำหนดเป็น int ค่าหลังจุดทศนิยมจึงถูกตัดทิ้ง (truncate) เนื่องจาก int เก็บเศษทศนิยมไม่ได้

หารด้วย decimal ให้ได้เศษ

ถ้าอยากให้การหารแม่นยำ ต้องใช้ชนิดข้อมูลที่รองรับเศษทศนิยมอย่าง decimal:

Program.cs 
decimal decimalQuotient = 7.0m / 5;
Console.WriteLine($"Decimal quotient: {decimalQuotient}");
Output
Decimal quotient: 1.4

ต้องมีทั้งตัวรับผลลัพธ์ (ฝั่งซ้ายของ =) เป็น decimal และต้องมีตัวเลขอย่างน้อย หนึ่งตัวในการหารเป็น decimal ด้วย (จะเป็น decimal ทั้งคู่ก็ได้) ตัวอย่างนี้ ก็ใช้ได้เหมือนกัน:

Program.cs
decimal decimalQuotient = 7 / 5.0m;
decimal decimalQuotient = 7.0m / 5.0m;

แต่บรรทัดเหล่านี้ใช้ไม่ได้ (หรือได้ผลลัพธ์ที่ไม่ถูกต้อง):

Program.cs (ผิด)
int decimalQuotientA = 7 / 5.0m;
int decimalQuotientB = 7.0m / 5;
int decimalQuotientC = 7.0m / 5.0m;
decimal decimalQuotientD = 7 / 5;
⚠️ ทำไม decimalQuotientD ถึงผิด แม้ตัวรับผลลัพธ์จะเป็น decimal แต่ 7 / 5 ทั้งสองข้างเป็น int ล้วน — คอมไพเลอร์หารแบบ int (ตัดเศษ) ก่อน ได้ 1 แล้วค่อยแปลงเป็น decimal ทีหลัง จึงได้ 1.0 ไม่ใช่ 1.4

Cast ผลลัพธ์จากการหาร int

ถ้าไม่ได้ทำงานกับ literal แต่ต้องหารตัวแปรชนิด int สองตัว โดยไม่อยากให้ผลลัพธ์ ถูกตัดเศษ ต้อง cast ชนิดข้อมูลจาก int เป็น decimal การ cast คือการแปลงชนิดข้อมูลแบบหนึ่ง ที่สั่งให้คอมไพเลอร์ปฏิบัติกับค่านั้นเป็นอีก ชนิดหนึ่งชั่วคราว

ใส่ชื่อชนิดข้อมูลในวงเล็บไว้หน้าค่าที่จะ cast:

Program.cs 
int first = 7;
int second = 5;
decimal quotient = (decimal)first / (decimal)second;
Console.WriteLine(quotient);
Output
1.4
ℹ️ วงเล็บ 3 หน้าที่ ตอนนี้คุณเจอวงเล็บ () ทำหน้าที่ 3 อย่างแล้ว: การเรียกใช้เมธอด (method invocation), ลำดับการคำนวณ (order of operations), และการ cast — สังเกตบริบทให้ดีว่ากำลังใช้แบบไหนอยู่

หาเศษที่เหลือจากการหาร (modulus)

modulus operator คือ % ให้ค่าเศษที่เหลือจากการหารแบบ int สิ่งที่มันบอกจริงๆ คือตัวเลขหนึ่งหารลงตัวกับอีกตัวหนึ่งหรือไม่ มีประโยชน์มากเวลาประมวลผลข้อมูลจำนวนมากเป็นลูป แล้วอยากแจ้งความคืบหน้าทุกๆ 100 รายการ เป็นต้น

Program.cs 
Console.WriteLine($"Modulus of 200 / 5 : {200 % 5}");
Console.WriteLine($"Modulus of 7 / 5 : {7 % 5}");
Output
Modulus of 200 / 5 : 0
Modulus of 7 / 5 : 2

เมื่อ modulus เท่ากับ 0 แปลว่าตัวตั้งหารลงตัวกับตัวหาร

ลำดับการคำนวณ (Order of Operations)

คุณใช้ () เป็นตัวกำหนดลำดับการคำนวณไปแล้ว แต่นั่นไม่ใช่วิธีเดียวที่กำหนดลำดับได้ ในวิชาคณิตศาสตร์ ใช้ตัวย่อ PEMDAS ช่วยจำลำดับ:

  1. Parentheses — วงเล็บก่อน
  2. Exponents — เลขยกกำลัง
  3. Multiplication และ Division — คูณ/หาร จากซ้ายไปขวา
  4. Addition และ Subtraction — บวก/ลบ จากซ้ายไปขวา

C# ทำตามลำดับเดียวกับ PEMDAS ยกเว้นเรื่องเลขยกกำลัง — C# ไม่มีตัวดำเนินการยกกำลังโดยตรง แต่ใช้เมธอด System.Math.Pow แทนได้ (จะเรียนเรื่องนี้ในโมดูล "Call methods from the .NET Class Library")

Program.cs 
int value1 = 3 + 4 * 5;
int value2 = (3 + 4) * 5;
Console.WriteLine(value1);
Console.WriteLine(value2);
Output
23
35

4.4 ลงมือ: Increment และ Decrement

เรื่องสุดท้ายของบทนี้คือการเพิ่ม/ลดค่า ด้วยตัวดำเนินการพิเศษที่รวมสัญลักษณ์เข้าด้วยกัน

Compound Assignment Operator

คุณจะต้องเพิ่ม/ลดค่าบ่อยมาก โดยเฉพาะตอนเขียน loop หรือโค้ดที่ทำงานกับโครงสร้างข้อมูล

ตัวดำเนินการ += บวกค่าฝั่งขวาเข้ากับค่าฝั่งซ้ายแล้วกำหนดค่ากลับ บรรทัดที่ 2 กับ 3 ด้านล่างทำงานเหมือนกัน:

Program.cs
int value = 0;     // value is now 0.
value = value + 5; // value is now 5.
value += 5;        // value is now 10.

ตัวดำเนินการ ++ เพิ่มค่าตัวแปรทีละ 1 บรรทัดที่ 2 กับ 3 ด้านล่างทำงานเหมือนกัน:

Program.cs
int value = 0;     // value is now 0.
value = value + 1; // value is now 1.
value++;           // value is now 2.

เทคนิคแบบเดียวกันใช้กับการลบ การคูณ และอื่นๆ ได้ด้วย

ℹ️ ศัพท์ +=, -=, *=, ++, -- เรียกว่า compound assignment operator (ตัวดำเนินการกำหนดค่าแบบผสม) เพราะมันรวมการ คำนวณเข้ากับการกำหนดค่าในตัวเดียว — += มีชื่อเฉพาะว่า addition assignment operator (ตัวดำเนินการกำหนดค่าแบบบวก)

เพิ่ม/ลดค่าทีละขั้น

Program.cs 
int value = 1;

value = value + 1;
Console.WriteLine("First increment: " + value);

value += 1;
Console.WriteLine("Second increment: " + value);

value++;
Console.WriteLine("Third increment: " + value);

value = value - 1;
Console.WriteLine("First decrement: " + value);

value -= 1;
Console.WriteLine("Second decrement: " + value);

value--;
Console.WriteLine("Third decrement: " + value);
Output
First increment: 2
Second increment: 3
Third increment: 4
First decrement: 3
Second decrement: 2
Third decrement: 1

ตำแหน่งของ ++ มีผล: Prefix กับ Postfix

ทั้ง ++ และ -- มีคุณสมบัติน่าสนใจ — ตำแหน่งของมันมีผลว่าจะเพิ่ม/ลด ค่าก่อนหรือหลังดึงค่าไปใช้ ถ้าวางไว้หน้าตัวแปรแบบ ++value (เรียกว่า prefix) จะเพิ่มค่าก่อนแล้วค่อยดึงไปใช้ ถ้าวางไว้หลังแบบ value++ (เรียกว่า postfix) จะดึงค่าไปใช้ก่อนแล้วค่อยเพิ่มทีหลัง

Program.cs 
int value = 1;
value++;
Console.WriteLine("First: " + value);
Console.WriteLine($"Second: {value++}");
Console.WriteLine("Third: " + value);
Console.WriteLine("Fourth: " + (++value));
Output
First: 2
Second: 2
Third: 3
Fourth: 4

บรรทัด {value++} ทำ 2 ขั้นตอน: (1) ดึงค่าปัจจุบันของ value มาใช้ในการ interpolate ก่อน (2) แล้วค่อยเพิ่มค่า — บรรทัดถัดไปยืนยันว่าค่าถูกเพิ่มแล้วจริง ส่วน (++value) สลับลำดับ: (1) เพิ่มค่าก่อน (2) แล้วค่อยดึงค่าใหม่ไปใช้ การใส่วงเล็บรอบ (++value) แม้ไม่จำเป็นเชิงไวยากรณ์ แต่ช่วยให้อ่านง่ายขึ้น — เพราะโค้ดถูกเขียนครั้งเดียว แต่ถูกอ่านหลายครั้ง ควรให้ความสำคัญกับความอ่านง่ายไว้ก่อน

4.5 ท้าทาย: แปลงฟาเรนไฮต์เป็นเซลเซียส

โจทย์ตามต้นฉบับ MS Learn

เริ่มจากโค้ดนี้:

Program.cs — บังคับใช้
int fahrenheit = 94;

สูตรแปลงฟาเรนไฮต์เป็นเซลเซียส: ลบ 32 ก่อน แล้วคูณด้วยห้าในเก้า (5/9) จากนั้นแสดงผลลัพธ์เป็นข้อความจัดรูปแบบแล้ว โดยผสมตัวแปรกับสตริง literal ผ่าน Console.WriteLine()

ผลลัพธ์ที่ต้องได้ (ประมาณนี้)
The temperature is 34.444444444444444444444444447 Celsius.

ยอมรับว่าตัวเลขทศนิยมยาวขนาดนี้ไม่สวยนัก จริงๆ อยากให้จัดรูปแบบเหลือทศนิยมตำแหน่งเดียว คือ 34.4 — แต่การจัดรูปแบบตัวเลขแบบนั้นจะเรียนในโมดูลถัดๆ ไป สำหรับตอนนี้ แค่ให้คำนวณค่าออกมาถูกต้องก็พอ

💡 ขอคำใบ้

คำใบ้: fahrenheit เป็น int แต่สูตรต้องหารเศษ — ต้องแปลง 32 และ 5/9 ให้เป็น literal ชนิด decimal (เติม m) เพื่อให้การหารไม่ถูกตัดเศษทิ้ง

4.6 เฉลยและวิเคราะห์

Program.cs — เฉลยตัวอย่าง 
int fahrenheit = 94;
decimal celsius = (fahrenheit - 32m) * (5m / 9m);
Console.WriteLine("The temperature is " + celsius + " Celsius.");
Output
The temperature is 34.444444444444444444444444447 Celsius.

นี่เป็นเพียงหนึ่งในหลายวิธีที่แก้โจทย์นี้ได้ สังเกตว่า 32m และ 5m/9m ต่อ suffix m เพื่อบังคับให้เป็น decimal ทั้งคู่ ทำให้ fahrenheit - 32m ได้ผลเป็น decimal (แม้ fahrenheit จะเป็น int ก็ตาม เพราะ int แปลงเป็น decimal โดยปริยายได้เสมอ ไม่เหมือนทางกลับกัน) แล้ว 5m / 9m ก็หารแบบ decimal ไม่ถูกตัดเศษ สุดท้ายผลคูณของทั้งสองก็เป็น decimal เต็มความละเอียด

4.7 ⚠️ กับดักที่พบบ่อย

พิมพ์ผิดแบบนี้สาเหตุ / วิธีแก้
int q = 7 / 5; แล้วงงว่าทำไมได้ 1 int หาร int จะตัดเศษทิ้งเสมอ — ต้องใช้ decimal/float/double อย่างน้อยข้างใดข้างหนึ่ง
decimal q = 7 / 5; แล้วงงว่าทำไมได้ 1.0 ไม่ใช่ 1.4 ตัวรับผลลัพธ์เป็น decimal ไม่พอ — ตัวเลขที่หารกัน (7 กับ 5) ก็ต้องมีตัวใดตัวหนึ่งเป็น decimal ด้วย
ลืม cast ตอนหารตัวแปร int สองตัว ต้อง (decimal)ตัวแปร ทั้งสองฝั่ง (หรืออย่างน้อยฝั่งเดียว) ก่อนหาร ไม่งั้นตัดเศษเหมือนเดิม
"text" + 1 + 1 คาดว่าจะบวกเป็น 2 ทำงานซ้าย→ขวา พอเจอ string ก่อน ทุกอย่างถัดไปจะกลายเป็นการต่อสตริง (ได้ "text11")
สับสนว่า value++ กับ ++value ให้ผลต่างกันยังไง postfix (value++) ใช้ค่าเดิมก่อนแล้วค่อยเพิ่ม prefix (++value) เพิ่มก่อนแล้วค่อยใช้

4.8 ❓ Knowledge Check

คำถามชุดนี้แปลจาก Module Assessment จริงของบทนี้ใน Microsoft Learn

1. โค้ดข้อใดพิมพ์ข้อความ Windows 11 ออกมา?

  • AConsole.WriteLine("Windows " + 7 + 4);
  • BConsole.WriteLine($"Windows {1 + 1}");
  • CConsole.Write("Windows " + 1 + 1);
เฉลย: ข้อ C. ทำงานซ้าย→ขวา: "Windows " + 1 ได้ string "Windows 1" ก่อน แล้ว + 1 ต่อท้ายกลายเป็น "Windows 11" (ต่อสตริง ไม่ใช่บวกเลข) ข้อ A ได้ "Windows 74" ข้อ B ปีกกา {1+1} คำนวณทางคณิตศาสตร์ก่อนเป็น 2 ได้ "Windows 2"

2. โค้ด int result = 3 + 1 * 5 / 2; ได้ค่าเท่าไร?

  • A10
  • B5
  • C6
เฉลย: ข้อ B (5). ตาม PEMDAS คูณ/หารมาก่อนบวก/ลบ: 1 * 5 = 5 แล้ว 5 / 2 = 2 (int หารตัดเศษ) สุดท้าย 3 + 2 = 5

3. โค้ด Console.WriteLine(5 / 10); ได้ผลลัพธ์อะไร?

  • A0.5
  • B0
  • C1
เฉลย: ข้อ B (0). ทั้ง 5 และ 10 เป็น int literal การหารแบบ int ตัดเศษทิ้งเสมอ เพราะ 5 น้อยกว่า 10 ผลหารที่แท้จริงคือ 0.5 ซึ่งถูกตัดเหลือ 0

4. โค้ดข้อใดใช้ addition assignment operator?

  • Avalue += 5;
  • Bvalue++;
  • Cvalue = value + 5;
เฉลย: ข้อ A. += คือชื่อเรียกเฉพาะของ addition assignment operator ข้อ B เป็น increment operator (เพิ่มทีละ 1 เท่านั้น) ข้อ C แม้ให้ผลเหมือนกัน แต่เป็นการกำหนดค่าธรรมดาที่มีนิพจน์บวกอยู่ข้างใน ไม่ใช่ตัวดำเนินการแบบผสม

4.9 ✍️ แบบฝึกหัดท้ายบท

ข้อ 1ง่าย

ประกาศตัวแปร int สองตัว ค่า 15 กับ 4 แล้วพิมพ์ผลบวก ผลลบ ผลคูณ และผลหาร (int) ทั้ง 4 ค่า คนละบรรทัด

ดูเฉลย
Program.cs
int a = 15;
int b = 4;
Console.WriteLine(a + b);
Console.WriteLine(a - b);
Console.WriteLine(a * b);
Console.WriteLine(a / b);
ข้อ 2ง่าย

แก้โค้ดข้อ 1 ให้ผลหารแม่นยำ (ไม่ถูกตัดเศษ) โดยใช้ decimal

ดูเฉลย
Program.cs
int a = 15;
int b = 4;
decimal quotient = (decimal)a / (decimal)b;
Console.WriteLine(quotient);
ข้อ 3ง่าย

เขียนโค้ดเช็คว่าเลข 45 หารด้วย 9 ลงตัวหรือไม่ โดยใช้ % แล้วพิมพ์เศษที่ได้ออกมา

ดูเฉลย
Program.cs
Console.WriteLine(45 % 9);

ได้ 0 แปลว่า 45 หารด้วย 9 ลงตัวพอดี (45 ÷ 9 = 5)

ข้อ 4กลาง

ทายผลลัพธ์ก่อนรันจริง แล้วค่อยตรวจคำตอบ:

Program.cs
int x = 2 + 3 * 4 - 1;
int y = (2 + 3) * (4 - 1);
Console.WriteLine(x);
Console.WriteLine(y);
💡 คำใบ้

ใช้ PEMDAS: คูณ/หารก่อน แล้วค่อยบวก/ลบ จากซ้ายไปขวา

ดูเฉลย

x: 3*4=12, 2+12=14, 14-1=13 — y: (2+3)=5, (4-1)=3, 5*3=15

ข้อ 5กลาง

ประกาศ int score = 10; แล้วเขียนโค้ดต่อไปนี้ ทายผลลัพธ์แต่ละบรรทัดก่อนรัน:

Program.cs
int score = 10;
Console.WriteLine(score++);
Console.WriteLine(score);
Console.WriteLine(++score);
Console.WriteLine(score);
ดูเฉลย

ผลลัพธ์คือ 10, 11, 12, 12 — บรรทัดแรกใช้ค่าเดิม (10) ก่อนเพิ่ม บรรทัดที่สามเพิ่มก่อน (11→12) แล้วค่อยใช้

ข้อ 6ท้าทาย

เขียนโปรแกรมแปลงองศาเซลเซียสเป็นฟาเรนไฮต์ (สูตรกลับด้านจากหัวข้อ 4.5: คูณด้วยเก้าในห้า (9/5) ก่อน แล้วค่อยบวก 32) จากตัวแปร decimal celsius = 100m; แสดงผลด้วย string interpolation ทศนิยม เท่าที่คำนวณได้ (ไม่ต้องตัดหลัก):

100 องศาเซลเซียส เท่ากับ 212 องศาฟาเรนไฮต์
💡 คำใบ้

ต้องใช้ 9m / 5m ไม่ใช่ 9 / 5 เพื่อไม่ให้ถูกตัดเศษ ก่อนคูณกับ celsius

ดูเฉลย
Program.cs
decimal celsius = 100m;
decimal fahrenheit = (celsius * (9m / 5m)) + 32m;
Console.WriteLine($"{celsius} องศาเซลเซียส เท่ากับ {fahrenheit} องศาฟาเรนไฮต์");

📌 สรุปบทที่ 4

เป้าหมายของบทนี้คือให้คุณดำเนินการพื้นฐานกับข้อมูล string และตัวเลข เป็นโจทย์ท้าทาย คุณแปลงหน่วยวัดจากฟาเรนไฮต์เป็นเซลเซียส และแสดงผลลัพธ์เป็นข้อความจัดรูปแบบแล้ว คุณใช้ตัวดำเนินการหลายแบบทำงานทั้งกับ string และตัวเลข เรียนรู้ว่าสัญลักษณ์บางตัวถูกใช้ซ้ำ (โอเวอร์โหลด) เป็นตัวดำเนินการต่างกันตามบริบท เรียนรู้ว่าชนิดข้อมูลของ operand มีผลต่อ ความหมายของตัวดำเนินการยังไง และสุดท้ายเรียนวิธีเปลี่ยนชนิดข้อมูลของค่าชั่วคราวด้วย cast operator
