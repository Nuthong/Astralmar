Guided Project — Calculate Final GPA

🎯 จบบทนี้คุณจะ...

  • ฝึกแตกโจทย์ใหญ่เป็นขั้นตอนย่อยๆ ต่อเนื่องจากบทที่แล้ว
  • เลือกชนิดข้อมูลที่เหมาะสมสำหรับตัวแปรแต่ละแบบ

6.1 สถานการณ์: ผู้ช่วยอาจารย์ที่ต้องคำนวณ GPA

สมมติคุณเป็นผู้ช่วยอาจารย์ในมหาวิทยาลัย ได้รับมอบหมายให้พัฒนาแอปช่วยคำนวณเกรดเฉลี่ย (Grade Point Average — GPA) ของนักศึกษา แอปจะใช้เกรดและจำนวนหน่วยกิตของแต่ละวิชา มาคำนวณ GPA รวม อาจารย์ยังกำหนดรูปแบบการรายงานผล GPA ที่ต้องการมาให้ด้วย

บทนี้จะพาคุณสร้างแอป GPA Calculator ครบวงจร โค้ดของคุณจะประกาศและกำหนดค่าตัวแปรตามข้อมูล รายวิชา คำนวณตัวเลขหลายแบบ จัดรูปแบบและแสดงผลลัพธ์ การคำนวณรวมถึงการหาผลรวมแต้มเกรดที่ได้ และหน่วยกิตรวม เพื่อแสดงผลตามฟอร์แมตที่กำหนด คุณจะต้องปรับแต่งค่า decimal ให้แสดงแค่ 3 หลักเอง — เป็นเทคนิคที่ท้าทายที่สุดในบทนี้

💡 เหมือนบทที่ 5 แต่ยากขึ้นอีกขั้น โครงสร้างบทนี้คล้ายบทที่ 5 มาก (สร้างข้อมูล → คำนวณ → จัดรูปแบบ) แต่มีเทคนิคใหม่ที่สำคัญ คือการ "แกะ" ตัวเลขทศนิยมออกมาทีละหลักด้วย cast และ modulo — เทคนิคที่ยังไม่มีเครื่องมือ สำเร็จรูปช่วย (จะมีในโมดูลหลังๆ) แต่ช่วยให้คุณเข้าใจตัวดำเนินการที่เรียนมาอย่างลึกซึ้งขึ้นมาก

6.2 เตรียมพร้อม: โจทย์และข้อมูลตั้งต้น

ภาพรวมโปรเจกต์

คุณกำลังพัฒนา Student GPA Calculator ที่ช่วยคำนวณเกรดเฉลี่ยรวมของนักศึกษา ข้อกำหนด:

  • มีชื่อนักศึกษาและข้อมูลรายวิชา
  • แต่ละวิชามีชื่อวิชา เกรดที่ได้ และจำนวนหน่วยกิต
  • แอปต้องคำนวณทางคณิตศาสตร์เพื่อหา GPA ของนักศึกษาคนนั้น
  • แอปต้องแสดงชื่อนักศึกษา ข้อมูลรายวิชา และ GPA

สูตรคำนวณ GPA:

  1. คูณค่าเกรดของแต่ละวิชาด้วยจำนวนหน่วยกิตของวิชานั้น (ได้ "แต้มเกรด" ของวิชานั้น)
  2. ทำแบบนี้กับทุกวิชา แล้วบวกผลลัพธ์ทั้งหมดเข้าด้วยกัน
  3. เอาผลรวมนั้นหารด้วยจำนวนหน่วยกิตรวมทั้งหมด

ตัวอย่างข้อมูลรายวิชาและ GPA ที่ต้องการ:

ผลลัพธ์ที่ต้องการ
Student: Sophia Johnson

Course          Grade   Credit Hours	
English 101         4       3
Algebra 101         3       3
Biology 101         3       4
Computer Science I  3       4
Psychology 101      4       3

Final GPA:          3.35

เตรียมข้อมูลตั้งต้น

สร้างโปรเจกต์ใหม่ แล้วพิมพ์โค้ดนี้ — ชื่อนักศึกษา ชื่อวิชา และหน่วยกิตของแต่ละวิชา:

Program.cs 
string studentName = "Sophia Johnson";
string course1Name = "English 101";
string course2Name = "Algebra 101";
string course3Name = "Biology 101";
string course4Name = "Computer Science I";
string course5Name = "Psychology 101";

int course1Credit = 3;
int course2Credit = 3;
int course3Credit = 4;
int course4Credit = 4;
int course5Credit = 3;
⚠️ อย่าลบโค้ดนี้ โค้ดชุดนี้เป็นฐานของทั้งโปรเจกต์ในบทนี้ — ทุกหัวข้อถัดจากนี้จะต่อท้ายโค้ดชุดนี้ไปเรื่อยๆ

6.3 ขั้นที่ 1: เก็บค่าเกรดตัวเลขของแต่ละวิชา

ในหัวข้อนี้ คุณจะหาค่าตัวเลขที่แทนเกรดตัวอักษรที่นักศึกษาได้ แล้วประกาศตัวแปรเก็บค่าเกรด ตัวเลขของแต่ละวิชา เนื่องจากค่าเกรดเป็นเลขจำนวนเต็ม จึงใช้ชนิดข้อมูล int

ค่าเทียบเกรดตัวอักษรเป็นตัวเลข

A = 4 แต้ม, B = 3 แต้ม (ในโปรเจกต์นี้ใช้แค่สองเกรดนี้ ส่วน C, D, F ยังไม่ใช้ตอนนี้)

Program.cs — ต่อท้าย 
int gradeA = 4;
int gradeB = 3;

การใช้ค่าคงที่แบบนี้ช่วยให้โค้ดเข้าใจง่าย และลดโอกาสพิมพ์ผิดถ้าต้องใช้ค่าเกรดซ้ำหลายครั้ง

เกรดของนักศึกษาแต่ละวิชา:

วิชาเกรด
English 101A
Algebra 101B
Biology 101B
Computer Science IB
Psychology 101A

สร้างตัวแปรเก็บเกรดตัวเลขของแต่ละวิชา:

Program.cs 
int course1Grade = gradeA;
int course2Grade = gradeB;
int course3Grade = gradeB;
int course4Grade = gradeB;
int course5Grade = gradeA;

แสดงชื่อวิชาคู่กับเกรดตัวเลข:

Program.cs 
Console.WriteLine($"{course1Name} {course1Grade}");
Console.WriteLine($"{course2Name} {course2Grade}");
Console.WriteLine($"{course3Name} {course3Grade}");
Console.WriteLine($"{course4Name} {course4Grade}");
Console.WriteLine($"{course5Name} {course5Grade}");
Output
English 101 4
Algebra 101 3
Biology 101 3
Computer Science I 3
Psychology 101 4

ถ้าไม่ตรง ให้ตรวจชื่อตัวแปรของคุณอีกครั้ง จากนั้นเพิ่มหน่วยกิตเข้าไปใน print statement เพราะผลลัพธ์สุดท้ายต้องแสดงหน่วยกิตด้วย:

Program.cs 
Console.WriteLine($"{course1Name} {course1Grade} {course1Credit}");
Console.WriteLine($"{course2Name} {course2Grade} {course2Credit}");
Console.WriteLine($"{course3Name} {course3Grade} {course3Credit}");
Console.WriteLine($"{course4Name} {course4Grade} {course4Credit}");
Console.WriteLine($"{course5Name} {course5Grade} {course5Credit}");
Output
English 101 4 3
Algebra 101 3 3
Biology 101 3 4
Computer Science I 3 4
Psychology 101 4 3

6.4 ขั้นที่ 2: คำนวณผลรวมหน่วยกิตและแต้มเกรด

ในหัวข้อนี้ คุณจะคำนวณและเก็บจำนวนหน่วยกิตรวม และแต้มเกรดรวมที่ได้ทั้งหมด ค่าทั้งสองจะถูกใช้ คำนวณ GPA ในขั้นถัดไป ทั้งหน่วยกิตและเกรดเป็นเลขจำนวนเต็ม จึงเก็บผลรวมด้วย int

แต้มเกรดของวิชาหนึ่งๆ เท่ากับหน่วยกิตของวิชานั้น คูณ ค่าเกรดตัวเลขที่ได้ ตัวอย่างเช่น English 101 หน่วยกิต 3 ได้เกรด A(4) → แต้มเกรด = 3×4 = 12

คำนวณหน่วยกิตรวม

หาบรรทัด Console.WriteLine() ที่แสดงข้อมูลรายวิชา เว้นบรรทัดว่างเหนือมัน แล้วประกาศตัวแปรเก็บผลรวมหน่วยกิต เริ่มที่ 0:

Program.cs 
int totalCreditHours = 0;

เพิ่มค่าเข้าไปทีละวิชาด้วย += (ทบทวนได้ที่ บทที่ 4):

Program.cs 
totalCreditHours += course1Credit;
totalCreditHours += course2Credit;
totalCreditHours += course3Credit;
totalCreditHours += course4Credit;
totalCreditHours += course5Credit;

โค้ด 5 บรรทัดนี้ให้ผลเหมือนกับเขียนบรรทัดเดียว totalCreditHours = course1Credit + course2Credit + course3Credit + course4Credit + course5Credit; — แค่คนละสไตล์

คำนวณแต้มเกรดรวม

Program.cs 
int totalGradePoints = 0;

เพิ่มแต้มเกรดของแต่ละวิชา (หน่วยกิต × เกรด) เข้าไปทีละวิชา:

Program.cs 
totalGradePoints += course1Credit * course1Grade;
totalGradePoints += course2Credit * course2Grade;
totalGradePoints += course3Credit * course3Grade;
totalGradePoints += course4Credit * course4Grade;
totalGradePoints += course5Credit * course5Grade;

สังเกตว่าโค้ดที่คุณเขียนแตกปัญหาใหญ่ (คำนวณ GPA) เป็นชิ้นเล็กๆ ที่จัดการได้ง่ายกว่า — คำนวณ totalCreditHours ก่อน แล้วค่อยคำนวณ totalGradePoints ทีหลัง จากนั้นค่อยเอาสองค่านี้ไปใช้ในการคำนวณสุดท้าย

เช็คผลระหว่างทางก่อนไปต่อ:

Program.cs 
Console.WriteLine($"{totalGradePoints} {totalCreditHours}");
Output (บรรทัดแรก — จะลบทิ้งภายหลัง)
57 17
ℹ️ บรรทัดนี้ชั่วคราวเท่านั้น Console.WriteLine($"{totalGradePoints} {totalCreditHours}"); มีไว้เพื่อตรวจสอบ ระหว่างทางเท่านั้น ในหัวข้อถัดไปจะลบทิ้งเพราะไม่ใช่ส่วนหนึ่งของผลลัพธ์สุดท้าย

6.5 ขั้นที่ 3: จัดรูปแบบผลลัพธ์ทศนิยม

GPA เท่ากับผลรวมแต้มเกรดหารด้วยผลรวมหน่วยกิต หัวข้อนี้คือหัวใจสำคัญที่สุดของบทนี้

คำนวณ GPA

ลบบรรทัดตรวจสอบชั่วคราวทิ้ง แล้วเว้นบรรทัดว่างเหนือ Console.WriteLine() ชุดที่ แสดงข้อมูลรายวิชา ประกาศตัวแปรเก็บ GPA:

Program.cs
decimal gradePointAverage = totalGradePoints/totalCreditHours;

ทบทวนเรื่องชนิดข้อมูลที่กำลังหารกัน (บทที่ 4) — ทั้งสองข้างเป็น int ต้อง cast อย่างน้อยข้างใดข้างหนึ่งเป็น decimal ก่อน:

Program.cs 
decimal gradePointAverage = (decimal) totalGradePoints/totalCreditHours;

เพิ่มบรรทัดแสดง GPA ท้ายสุด แล้วรันดู:

Program.cs 
Console.WriteLine($"Final GPA: {gradePointAverage}");
Output
Final GPA: 3.3529411764705882352941176471

แกะตัวเลขทศนิยมออกมาทีละหลัก

ทศนิยมยาวขนาดนี้ไม่ใช่ GPA ที่คุ้นตา — ในหัวข้อนี้คุณจะจัดการค่า decimal นี้ด้วยมือ ให้แสดง แค่ 3 หลัก (หลักเดียวหน้าจุด บวกอีก 2 หลักหลังจุด)

ℹ️ ทำไมต้องทำเอง ในเส้นทางการเรียนถัดไป คุณจะเจอฟังก์ชันสำเร็จรูปที่จัดรูปแบบตัวเลขให้อัตโนมัติ แต่ตอนนี้ เป็นโอกาสดีที่จะฝึกฝนสิ่งที่เรียนมาแล้วให้แน่นขึ้น

เว้นบรรทัดว่างเหนือ Console.WriteLine() ชุดแสดงรายวิชา แล้วดึงหลักแรก (leading digit) ออกมาด้วยการ cast เป็น int:

Program.cs 
int leadingDigit = (int) gradePointAverage;

การ cast เศษทศนิยมเป็น int จะตัดทิ้งเสมอ ไม่ปัดขึ้น ถ้า GPA เป็น 2.99 การ cast เป็น int จะได้ 2 เสมอ (วิธีนี้เชื่อถือได้และตรงไปตรงมา)

ต่อไปดึงหลักแรกหลังจุดทศนิยม:

Program.cs 
int firstDigit = (int) (gradePointAverage * 10) % 10;

ครึ่งแรกของสูตร เลื่อนจุดทศนิยมไปทางขวา 1 ตำแหน่งแล้ว cast เป็น int ครึ่งหลัง ใช้ตัวดำเนินการ เศษเหลือ (modulo) หารด้วย 10 เพื่อแยกเอาแค่หลักสุดท้ายออกมา ลองดูตัวอย่างสมมติ gradePointAverage = 2.994573:

ไล่ทีละขั้น
int firstDigit = (int) (2.994573 * 10) % 10;
int firstDigit = 29 % 10;
int firstDigit = 9;

ได้ firstDigit = 9 ต่อไปใช้เทคนิคเดียวกันดึงหลักที่สอง:

Program.cs 
int secondDigit = (int) (gradePointAverage * 100 ) % 10;

บรรทัดนี้เลื่อนจุดทศนิยมไป 2 ตำแหน่ง แล้วใช้ modulo ดึงหลักสุดท้ายเหมือนเดิม

แก้บรรทัดแสดง GPA สุดท้ายให้ประกอบ 3 หลักนี้เข้าด้วยกัน:

Program.cs 
Console.WriteLine($"Final GPA: {leadingDigit}.{firstDigit}{secondDigit}");
Output
Final GPA: 3.35

6.6 ขั้นที่ 4: จัดรูปแบบด้วย Escape Sequence

หัวข้อสุดท้ายนี้จะปรับผลลัพธ์ให้ตรงตามฟอร์แมตที่อาจารย์กำหนด

เพิ่มชื่อนักศึกษาและหัวตาราง

เว้นบรรทัดว่างเหนือ Console.WriteLine() ชุดแสดงรายวิชา แล้วเพิ่มชื่อนักศึกษา:

Program.cs 
Console.WriteLine($"Student: {studentName}\n");

เว้นบรรทัดว่างหลังบรรทัดนี้ แล้วเพิ่มหัวตาราง:

Program.cs 
Console.WriteLine("Course\t\t\tGrade\tCredit Hours");

สังเกตว่าเติม tab ถึง 3 ตัวหลังคำว่า "Course" — เผื่อพื้นที่ไว้สำหรับชื่อวิชาที่ยาวกว่า (ทบทวนหลักการ tab stop ได้ที่ บทที่ 5)

จัดคอลัมน์ข้อมูลรายวิชา

Program.cs 
Console.WriteLine($"{course1Name}\t\t{course1Grade}\t\t{course1Credit}");
Console.WriteLine($"{course2Name}\t\t{course2Grade}\t\t{course2Credit}");
Console.WriteLine($"{course3Name}\t\t{course3Grade}\t\t{course3Credit}");
Console.WriteLine($"{course4Name}\t{course4Grade}\t\t{course4Credit}");
Console.WriteLine($"{course5Name}\t\t{course5Grade}\t\t{course5Credit}");
ℹ️ สังเกตจำนวน \t ที่ไม่เท่ากัน course4Name ("Computer Science I") ใช้ \t แค่ตัวเดียวหลังชื่อวิชา น้อยกว่าวิชาอื่นที่ใช้ \t\t — เพราะชื่อวิชานี้ยาวกว่า ใกล้ตำแหน่ง tab stop ถัดไปมากกว่า ถ้าใช้ 2 ตัวเหมือนวิชาอื่น จะล้นไป tab stop ถัดไปอีกขั้น ทำให้คอลัมน์เยื้องออกไป

สุดท้าย เพิ่มระยะห่างให้บรรทัดแสดง GPA:

Program.cs 
Console.WriteLine($"\nFinal GPA:\t\t{leadingDigit}.{firstDigit}{secondDigit}");

ตรวจงานสุดท้าย

โค้ดทั้งหมดของโปรเจกต์นี้ (ครบทุกขั้น):

Program.cs — ฉบับสมบูรณ์ 
string studentName = "Sophia Johnson";
string course1Name = "English 101";
string course2Name = "Algebra 101";
string course3Name = "Biology 101";
string course4Name = "Computer Science I";
string course5Name = "Psychology 101";

int course1Credit = 3;
int course2Credit = 3;
int course3Credit = 4;
int course4Credit = 4;
int course5Credit = 3;

int gradeA = 4;
int gradeB = 3;

int course1Grade = gradeA;
int course2Grade = gradeB;
int course3Grade = gradeB;
int course4Grade = gradeB;
int course5Grade = gradeA;

int totalCreditHours = 0;
totalCreditHours += course1Credit;
totalCreditHours += course2Credit;
totalCreditHours += course3Credit;
totalCreditHours += course4Credit;
totalCreditHours += course5Credit;

int totalGradePoints = 0;
totalGradePoints += course1Credit * course1Grade;
totalGradePoints += course2Credit * course2Grade;
totalGradePoints += course3Credit * course3Grade;
totalGradePoints += course4Credit * course4Grade;
totalGradePoints += course5Credit * course5Grade;

decimal gradePointAverage = (decimal) totalGradePoints/totalCreditHours;

int leadingDigit = (int) gradePointAverage;
int firstDigit = (int) (gradePointAverage * 10 ) % 10;
int secondDigit = (int) (gradePointAverage * 100 ) % 10;

Console.WriteLine($"Student: {studentName}\n");
Console.WriteLine("Course\t\t\tGrade\tCredit Hours");

Console.WriteLine($"{course1Name}\t\t{course1Grade}\t\t{course1Credit}");
Console.WriteLine($"{course2Name}\t\t{course2Grade}\t\t{course2Credit}");

6.7 ⚠️ กับดักที่พบบ่อย

อาการสาเหตุ / วิธีแก้
decimal gpa = totalGradePoints/totalCreditHours; ได้เลขเต็มไม่มีทศนิยม ลืม cast อีกแล้ว — ทั้งสองข้างเป็น int ต้อง (decimal) ข้างใดข้างหนึ่งก่อนหาร
firstDigit / secondDigit ได้ค่าผิด ลืมวงเล็บรอบ (gpa * 10) ก่อน % — ลำดับการคำนวณผิดจะได้ผลลัพธ์คนละเรื่อง
คิดว่า (int) จะปัดเศษ แต่จริงๆ ตัดทิ้ง cast เป็น int ตัดทศนิยมทิ้งเสมอ ไม่ปัดขึ้น — 3.99 กลายเป็น 3 ไม่ใช่ 4
คอลัมน์เยื้องไม่ตรงกัน ชื่อวิชายาวไม่เท่ากัน ต้องปรับจำนวน \t ต่างกันตามหลักการ tab stop (บทที่ 5)

1. สมมติ decimal gradePointAverage = 3.99872831m; ค่าของ (int) gradePointAverage คือเท่าไร?

  • A3.99
  • B4
  • C3
เฉลย: ข้อ C. การ cast เป็น int ตัดเศษทศนิยมทิ้งเสมอ (ไม่ปัดเศษ) แม้ 3.998 จะใกล้ 4 มาก แต่ผลลัพธ์คือ 3 ข้อ A ผิดเพราะ int เก็บทศนิยมไม่ได้ ข้อ B สับสนกับการปัดเศษ ซึ่งไม่ใช่พฤติกรรมของ cast

2. โค้ด decimal x = 7 / 5; ทำไม x จึงได้ค่า 1?

  • Aชนิด decimal ตัดเศษทิ้งเสมอ
  • Bการหารเลข int สองตัวคือการหารแบบ integer division
  • Cโค้ดบรรทัดนี้ error
เฉลย: ข้อ B. 7 และ 5 เป็น int literal ทั้งคู่ การหารจึงเป็น int/int (ตัดเศษ = 1) ไปแล้วก่อนจะถูกแปลงเป็น decimal เพื่อกำหนดค่า ให้ x — ไม่ใช่ชนิด decimal ที่ตัดเศษ (ข้อ A ผิด) และโค้ดนี้คอมไพล์ผ่านปกติ ไม่ error (ข้อ C ผิด)

6.9 ✍️ แบบฝึกหัดต่อยอดโปรเจกต์

ข้อ 1ง่าย

เขียนโค้ดแกะ leadingDigit, firstDigit, secondDigit จากค่า decimal gpa = 2.7183m; แล้วพิมพ์ผลลัพธ์เป็น 2.71

ดูเฉลย
Program.cs
decimal gpa = 2.7183m;
int leadingDigit = (int) gpa;
int firstDigit = (int) (gpa * 10) % 10;
int secondDigit = (int) (gpa * 100) % 10;
Console.WriteLine($"{leadingDigit}.{firstDigit}{secondDigit}");
ข้อ 2ง่าย

เพิ่มค่าเกรด gradeC = 2; แล้วสมมตินักศึกษาได้เกรด C ในวิชา Psychology 101 (แทน A เดิม) คำนวณ totalGradePoints ใหม่ด้วยมือ (ไม่ต้องรันจริงก็ได้ ตอบเป็นตัวเลข)

ดูเฉลย

เดิม Psychology 101 (3 หน่วยกิต, เกรด A=4) ให้แต้ม 12 ถ้าเปลี่ยนเป็น C=2 จะได้แต้ม 6 แทน → totalGradePoints ใหม่ = 57 - 12 + 6 = 51

ข้อ 3ง่าย

โค้ดนี้ error หาจุดผิดและอธิบาย:

Program.cs (ผิด)
int totalPoints;
totalPoints += 12;
Console.WriteLine(totalPoints);
ดูเฉลย

ลืม initialize totalPoints เป็น 0 ก่อนใช้ += — จะได้ error CS0165 (ทบทวนที่ บทที่ 2) ต้องแก้เป็น int totalPoints = 0;

ข้อ 4กลาง

เขียนโปรเจกต์ GPA ใหม่สำหรับนักศึกษาชื่อ "Marco Reyes" มี 3 วิชา: วิชา A (หน่วยกิต 3, เกรด A) · วิชา B (หน่วยกิต 4, เกรด B) · วิชา C (หน่วยกิต 2, เกรด B) คำนวณ GPA ให้ครบ (ไม่ต้องจัดคอลัมน์ด้วย tab ก็ได้ แค่ให้ตัวเลขถูก)

💡 คำใบ้

totalCreditHours = 3+4+2 = 9, totalGradePoints = 3×4 + 4×3 + 2×3 = 30, GPA = 30/9 = 3.333...

ดูเฉลย
Program.cs
int gradeA = 4;
int gradeB = 3;

int credit1 = 3, grade1 = gradeA;
int credit2 = 4, grade2 = gradeB;
int credit3 = 2, grade3 = gradeB;

int totalCreditHours = credit1 + credit2 + credit3;
int totalGradePoints = (credit1 * grade1) + (credit2 * grade2) + (credit3 * grade3);

decimal gpa = (decimal)totalGradePoints / totalCreditHours;
int leadingDigit = (int)gpa;
int firstDigit = (int)(gpa * 10) % 10;
int secondDigit = (int)(gpa * 100) % 10;

Console.WriteLine($"Marco Reyes GPA: {leadingDigit}.{firstDigit}{secondDigit}");
ข้อ 5กลาง

ทำไมเทคนิคแกะทศนิยมในบทนี้ถึงใช้ไม่ได้ถ้า GPA มีค่าติดลบ เช่น -3.35? (ตอบเป็นข้อความอธิบาย ไม่ต้องเขียนโค้ด)

ดูเฉลย

modulo ของเลขลบใน C# ให้ผลลัพธ์เป็นลบด้วย เช่น -33 % 10 = -3 ไม่ใช่ 7 แบบที่คณิตศาสตร์บริสุทธิ์อาจคาดหวัง ทำให้การประกอบสตริงกลับผิดเพี้ยน (แต่ในบริบทนี้ GPA ไม่มีทางติดลบอยู่แล้ว จึงไม่ใช่ปัญหาจริง)

ข้อ 6ท้าทาย

เขียนโปรเจกต์ GPA ฉบับเต็มสำหรับนักศึกษา 1 คน 4 วิชา ข้อมูลตามใจคุณ โดยต้องมี: หัวตารางจัดคอลัมน์ด้วย tab, การคำนวณ totalCreditHours/totalGradePoints แบบ +=, การ cast หารแบบ decimal, และการแกะ 3 หลักแบบในบทนี้ — ให้ได้ผลลัพธ์ที่จัดรูปแบบ สวยงามเหมือนตัวอย่าง Sophia Johnson ทุกประการ
