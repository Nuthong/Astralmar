25.1 สถานการณ์: ระบบอัตโนมัติอัปเดตเว็บ "โปรโมชั่นโค้งสุดท้าย"

สมมติคุณเป็นนักพัฒนาของแอปที่ให้ธุรกิจอัปเดตเว็บไซต์ "ดีลโค้งสุดท้าย" (last chance deals) ได้ โดยส่งอีเมล อีเมลอัปเดตใช้ข้อความพิเศษที่กำหนดไว้ในหัวเรื่องและเนื้อหาอีเมล เพื่อสั่ง ระบบอัตโนมัติว่าจะอัปเดตเว็บไซต์ยังไง อีเมลรวมชื่อดีลถัดไป เปอร์เซ็นต์ส่วนลด วันหมดอายุ และ เวลาที่จะเผยแพร่ข้อเสนอนั้น

บ่อยครั้งที่ข้อมูลแอปของคุณต้องทำงานด้วยมาจากระบบซอฟต์แวร์อื่น และมีข้อมูลที่คุณไม่ ต้องการหรือไม่จำเป็น บางครั้งข้อมูลอยู่ในรูปแบบที่ใช้งานไม่ได้ มีข้อมูลเกินที่ทำให้ดึง ข้อมูลสำคัญออกมาได้ยาก เพื่อปรับข้อมูลให้เหมาะกับแอปของคุณ คุณต้องมีเครื่องมือและเทคนิคแยก วิเคราะห์ข้อมูล string, แยกข้อมูลที่ต้องการออกมา, และลบข้อมูลที่ไม่ต้องการทิ้ง

ในบทนี้ คุณใช้ string helper method ระบุและแยกข้อมูลที่คุณสนใจออกมา คุณเรียนวิธีก็อปปี้ส่วน ย่อยของ string ที่ใหญ่กว่า คุณแทนที่ตัวอักษร หรือลบตัวอักษรออกจาก string ได้

25.2 IndexOf() และ Substring()

เตรียมโปรเจกต์

Terminal 
dotnet new console -o ch25-stringmod

หาตำแหน่งวงเล็บที่ฝังอยู่ใน String

Program.cs 
string message = "Find what is (inside the parentheses)";

int openingPosition = message.IndexOf('(');
int closingPosition = message.IndexOf(')');

Console.WriteLine(openingPosition);
Console.WriteLine(closingPosition);
Output
13
36

ในกรณีนี้ index ของอักขระ ( คือ 13 — จำไว้ว่าค่าพวกนี้เป็น zero-based เสมอ (ทบทวนจาก บทที่ 10) ดังนั้นมันคือตัวอักษรที่ 14 ของ string จริงๆ index ของอักขระ ) คือ 36 — ตอนนี้คุณมี index ทั้งสองตัวแล้ว ใช้เป็นขอบเขตดึงค่า ที่อยู่ระหว่างกลางได้

ดึงค่าระหว่างวงเล็บด้วย Substring()

Program.cs 
string message = "Find what is (inside the parentheses)";

int openingPosition = message.IndexOf('(');
int closingPosition = message.IndexOf(')');

int length = closingPosition - openingPosition;
Console.WriteLine(message.Substring(openingPosition, length));
Output
(inside the parentheses

Substring() ต้องการตำแหน่งเริ่มต้นและจำนวนตัวอักษร (length) ที่จะดึง — คุณจึง คำนวณ length เก็บไว้ในตัวแปรชั่วคราวชื่อ length แล้วส่งพร้อมกับค่า openingPosition เพื่อดึง string ข้างในวงเล็บออกมา

ผลลัพธ์ใกล้เคียงแล้ว แต่ยังมีวงเล็บเปิดติดมาด้วย ในแบบฝึกหัดนี้ ไม่ต้องการวงเล็บติดมา ต้อง อัปเดตโค้ดให้ข้าม index ของวงเล็บเปิดไปเอง

ปรับตำแหน่งเริ่มต้นให้ข้ามวงเล็บ

Program.cs 
string message = "Find what is (inside the parentheses)";

int openingPosition = message.IndexOf('(');
int closingPosition = message.IndexOf(')');

openingPosition += 1;

int length = closingPosition - openingPosition;
Console.WriteLine(message.Substring(openingPosition, length));
Output
inside the parentheses

ด้วยการเพิ่ม openingPosition ทีละ 1 คุณข้ามอักขระวงเล็บเปิดไป — เหตุผลที่ใช้ค่า 1 เพราะนั่นคือความยาวของอักขระตัวนั้น ถ้าคุณพยายามหาค่าที่เริ่มหลัง string ที่ ยาวกว่า เช่น <div> หรือ --- คุณต้องใช้ความยาวของ string นั้น แทน

Program.cs 
string message = "What is the value between the tags?";

int openingPosition = message.IndexOf("");
int closingPosition = message.IndexOf("");

openingPosition += 6;
int length = closingPosition - openingPosition;
Console.WriteLine(message.Substring(openingPosition, length));
Output
between the tags

ตัวอย่างนี้แสดงวิธีหาค่าข้างในแท็กเปิดและปิด <span> — คุณบวก 6 เข้ากับ openingPosition เป็นค่า offset ในการคำนวณความยาวของ substring ("<span>" มี 6 ตัวอักษรพอดี)

หลีกเลี่ยง Magic Value ด้วย const

string ที่ hardcode ไว้อย่าง "<span>" ในโค้ดก่อนหน้าเรียกว่า "magic string" และค่าตัวเลขที่ hardcode ไว้อย่าง 6 เรียกว่า "magic number" — ค่า "magic" แบบนี้ไม่ดีด้วยหลายเหตุผล และควรหลีกเลี่ยงถ้าทำได้

ลองพิจารณาว่าโค้ดก่อนหน้าอาจพังยังไง ถ้าคุณ hardcode string "<span>" ซ้ำ หลายจุดในโค้ด แต่พิมพ์ผิดไปหนึ่งจุดเป็น "<sapn>" — compiler จับ "<sapn>" ตอน compile time ไม่ได้เลย เพราะค่านั้นอยู่ในรูป string การพิมพ์ ผิดแบบนี้นำไปสู่ปัญหาตอนรันจริง และขึ้นอยู่กับความซับซ้อนของโค้ด อาจตามหาสาเหตุได้ยากมาก ยิ่งไปกว่านั้น ถ้าคุณเปลี่ยน string "<span>" เป็น "<div>" ที่สั้นกว่า แต่ลืมเปลี่ยนเลข 6 เป็น 5 โค้ดของคุณจะให้ผลลัพธ์ที่ไม่ต้องการ

Program.cs 
string message = "What is the value between the tags?";

const string openSpan = "";
const string closeSpan = "";

int openingPosition = message.IndexOf(openSpan);
int closingPosition = message.IndexOf(closeSpan);

openingPosition += openSpan.Length;
int length = closingPosition - openingPosition;
Console.WriteLine(message.Substring(openingPosition, length));
Output
between the tags

โค้ดนี้ใช้ constant ด้วยคีย์เวิร์ด const ใน const string openSpan = ""; — constant ให้คุณประกาศและกำหนดค่าเริ่มต้นให้ตัวแปรที่ค่าของมันไม่มีวันเปลี่ยนได้ เลย คุณใช้ constant นั้นในโค้ดที่เหลือทุกครั้งที่ต้องการค่านั้น ทำให้แน่ใจว่าค่าถูก กำหนดไว้แค่ที่เดียว และการพิมพ์ผิดชื่อ constant จะถูก compiler จับได้ทันที

โค้ดข้างบนเป็นวิธีที่ปลอดภัยกว่าในการเขียนโค้ดแบบเดียวกับที่เห็นในหัวข้อก่อนหน้า ตอนนี้ ถ้าค่า ของ openSpan เปลี่ยนเป็น <div> บรรทัดที่ใช้ property Length ก็ยังใช้งานได้ถูกต้องเสมอ ไม่ต้องแก้เลขด้วยมือเลย

ℹ️ IndexOf() คืน -1 ถ้าหาไม่เจอ ถ้า IndexOf() หาอักขระหรือ string ที่ต้องการไม่เจอเลย มันจะคืนค่า -1 กลับมา (ไม่ throw exception) — คุณจะได้เห็นวิธีใช้ประโยชน์จากพฤติกรรมนี้ในหัวข้อ 25.3

Check ★ myString.IndexOf('C'); คืนค่าอะไร เมื่อ string myString = "C# Time";?

  • A0
  • B1
  • C-1
เฉลย: ข้อ A. 'C' อยู่ที่ตำแหน่งแรกสุดของ string (zero-based index 0) — ไม่ใช่ -1 เพราะเจอตัวอักษรนั้นจริง

25.3 LastIndexOf() และ IndexOfAny()

.IndexOf() คืน index ของการปรากฏครั้งแรกของอักขระหรือ substring ที่ระบุ ภายใน string เมธอด .LastIndexOf() คืน index ของการปรากฏครั้งสุดท้ายของ อักขระหรือ string นั้น ทั้ง IndexOf() และ LastIndexOf() คืนค่า -1 ถ้าหาไม่เจอ

Program.cs 
string message = "hello there!";

int first_h = message.IndexOf('h');
int last_h = message.LastIndexOf('h');

Console.WriteLine($"For the message: '{message}', the first 'h' is at position {first_h} and the last 'h' is at position {last_h}.");
Output
For the message: 'hello there!', the first 'h' is at position 0 and the last 'h' is at position 7.

ดึงค่าจากวงเล็บคู่สุดท้าย

Program.cs 
string message = "(What if) I am (only interested) in the last (set of parentheses)?";
int openingPosition = message.LastIndexOf('(');

openingPosition += 1;
int closingPosition = message.LastIndexOf(')');
int length = closingPosition - openingPosition;
Console.WriteLine(message.Substring(openingPosition, length));
Output
set of parentheses
⚠️ โค้ดนี้เปราะบาง โค้ดตัวอย่างข้างบนรันได้ไม่มี error เพราะ string message มีคู่วงเล็บที่จัดรูปแบบ ถูกต้อง แต่โค้ดนี้ เปราะบาง (fragile) — จะเกิด error ถ้าไม่มีคู่วงเล็บอยู่เลย หรือถ้า วงเล็บคู่สุดท้ายไม่ได้เปิด-ปิดเป็นคู่กันจริงๆ

ดึงค่าจากทุกคู่วงเล็บด้วย while

Program.cs 
string message = "(What if) there are (more than) one (set of parentheses)?";
while (true)
{
    int openingPosition = message.IndexOf('(');
    if (openingPosition == -1) break;

    openingPosition += 1;
    int closingPosition = message.IndexOf(')');
    int length = closingPosition - openingPosition;
    Console.WriteLine(message.Substring(openingPosition, length));

    // ใช้ overload ของ Substring ที่คืนค่าเฉพาะส่วนที่ยังไม่ได้ประมวลผล
    message = message.Substring(closingPosition + 1);
}
Output
What if
more than
set of parentheses

สังเกตบรรทัดสุดท้ายข้างใน loop: message = message.Substring(closingPosition + 1); — เมื่อคุณใช้ Substring() โดยไม่ระบุ length เลย มันจะคืนทุกตัวอักษรหลังตำแหน่ง เริ่มต้นที่คุณระบุ การตัดคู่วงเล็บแรก (What if) ออกจากค่า message ช่วยให้ส่วนที่เหลือถูกประมวลผลต่อใน iteration ถัดไปของ while loop

พิจารณาว่าเกิดอะไรขึ้นตอน iteration สุดท้าย เมื่อเหลือแค่ตัวอักษร ? ตัวเดียว — โค้ดที่จัดการจุดสิ้นสุดของ string คือ:

โค้ดจัดการเงื่อนไขจบ
int openingPosition = message.IndexOf('(');
if (openingPosition == -1) break;

IndexOf() คืน -1 ถ้าหา input parameter ใน string ไม่เจอ คุณแค่เช็ค ค่า -1 แล้ว break ออกจาก loop

ค้นหาหลายชนิดสัญลักษณ์ด้วย IndexOfAny()

คราวนี้ค้นหาตัวอักษรหลายแบบพร้อมกัน ไม่ใช่แค่วงเล็บ ด้วย .IndexOfAny() — เมธอดนี้ รายงาน index ของการปรากฏครั้งแรกของอักขระตัวใดตัวหนึ่งใน array ของอักขระที่คุณส่งเข้าไป เมธอดคืน -1 ถ้าหาอักขระทุกตัวใน array ไม่เจอเลย

Program.cs 
string message = "Hello, world!";
char[] charsToFind = { 'a', 'e', 'i' };

int index = message.IndexOfAny(charsToFind);

Console.WriteLine($"Found '{message[index]}' in '{message}' at index: {index}.");
Output
Found 'e' in 'Hello, world!' at index: 1.

ตอนนี้ลองค้นหาสัญลักษณ์เปิดหลายแบบพร้อมกัน ([, {, () และใช้ overload ของ IndexOfAny() ที่กำหนดตำแหน่งเริ่มค้นหาได้:

Program.cs 
string message = "Help (find) the {opening symbols}";
Console.WriteLine($"Searching THIS Message: {message}");
char[] openSymbols = { '[', '{', '(' };
int startPosition = 5;
int openingPosition = message.IndexOfAny(openSymbols);
Console.WriteLine($"Found WITHOUT using startPosition: {message.Substring(openingPosition)}");

openingPosition = message.IndexOfAny(openSymbols, startPosition);
Console.WriteLine($"Found WITH using startPosition {startPosition}:  {message.Substring(openingPosition)}");
Output
Searching THIS Message: Help (find) the {opening symbols}
Found WITHOUT using startPosition: (find) the {opening symbols}
Found WITH using startPosition 5:  (find) the {opening symbols}

จับคู่สัญลักษณ์เปิด-ปิดหลายแบบพร้อมกัน

ตอนนี้คุณเจอสัญลักษณ์เปิดแล้ว ต้องหาสัญลักษณ์ปิดที่ตรงกันของมันด้วย

Program.cs 
string message = "(What if) I have [different symbols] but every {open symbol} needs a [matching closing symbol]?";

char[] openSymbols = { '[', '{', '(' };

int closingPosition = 0;

while (true)
{
    int openingPosition = message.IndexOfAny(openSymbols, closingPosition);

    if (openingPosition == -1) break;

    string currentSymbol = message.Substring(openingPosition, 1);

    char matchingSymbol = ' ';

    switch (currentSymbol)
    {
        case "[":
            matchingSymbol = ']';
            break;
        case "{":
            matchingSymbol = '}';
            break;
        case "(":
            matchingSymbol = ')';
            break;
    }

    openingPosition += 1;
    closingPosition = message.IndexOf(matchingSymbol, openingPosition);

    int length = closingPosition - openingPosition;
    Console.WriteLine(message.Substring(openingPosition, length));
}
Output
What if
different symbols
open symbol
matching closing symbol

จุดสำคัญของโค้ดนี้คือบรรทัด closingPosition = message.IndexOf(matchingSymbol, openingPosition); — ใช้ overload ของ IndexOf() ที่ระบุว่าการค้นหา matchingSymbol ควรเริ่มที่ตำแหน่ง openingPosition ใน string

ตัวแปร closingPosition ถูกใช้ทั้งหาความยาวที่ส่งให้ Substring() และหาค่า openingPosition ถัดไป (message.IndexOfAny(openSymbols, closingPosition)) ด้วยเหตุนี้ ตัวแปร closingPosition จึงถูกประกาศไว้นอก scope ของ while loop และตั้งค่าเริ่มต้นเป็น 0 สำหรับ iteration แรก

Check ★ ควรใช้เมธอดไหนค้นหาการปรากฏครั้งแรกของคำค้นหา ใน string ยาวๆ?

  • AIndexOfAny()
  • BLastIndexOf()
  • CSubstring()
เฉลย: ข้อ A. ตามนิยามของ IndexOfAny() เอง — "รายงาน index ของการปรากฏครั้งแรก" ตรงกับสิ่งที่คำถามต้องการ ส่วน LastIndexOf() หา ครั้งสุดท้าย (ตรงข้าม) และ Substring() ใช้ดึงค่า ไม่ใช่ค้นหาตำแหน่ง

25.4 Remove() และ Replace()

บางครั้งคุณต้องแก้ไขเนื้อหาของ string ด้วยการลบหรือแทนที่ตัวอักษร แม้จะใช้เครื่องมือที่รู้จัก แล้วแทนที่ตัวอักษรได้ แต่ก็ต้องเก็บและประกอบ string กลับด้วยตัวเองพอสมควร โชคดีที่ string data type มี built-in method อื่นอีกสองตัว คือ Remove() และ Replace() สำหรับสถานการณ์เฉพาะแบบนี้

ใช้ Remove() ลบตำแหน่งที่แน่นอน

คุณมักใช้ Remove() เมื่อตำแหน่งของตัวอักษรที่ต้องการลบออกจาก string นั้นคงที่ และแน่นอนเสมอ

แบบฝึกหัดนี้มีข้อมูลที่เก็บในไฟล์รุ่นเก่าที่มีความยาวคงที่ โดยกำหนดตำแหน่งตัวอักษรไว้สำหรับ แต่ละฟิลด์ข้อมูล: 5 ตัวแรกแทนหมายเลขประจำตัวลูกค้า 20 ตัวถัดไปเก็บชื่อลูกค้า 6 ตำแหน่งถัดมา แทนยอดใบแจ้งหนี้ล่าสุดของลูกค้า และ 3 ตำแหน่งสุดท้ายแทนจำนวนสินค้าที่สั่งในใบแจ้งหนี้นั้น

คุณต้องลบชื่อลูกค้าออก เพื่อจัดรูปแบบข้อมูลให้ส่งไปยัง process แยกต่างหากได้ เพราะคุณรู้ตำแหน่ง และความยาวที่แน่นอนของชื่อผู้ใช้ คุณลบมันออกได้ง่ายๆ ด้วยเมธอด Remove()

Program.cs 
string data = "12345John Smith          5000  3  ";
string updatedData = data.Remove(5, 20);
Console.WriteLine(updatedData);
Output
123455000  3

Remove() ทำงานคล้าย Substring() — คุณส่งตำแหน่งเริ่มต้นและความยาว เพื่อลบตัวอักษรช่วงนั้นออกจาก string

ใช้ Replace() แทนที่ทุกที่ที่เจอ

ใช้ Replace() เมื่อต้องการแทนที่ตัวอักษรหนึ่งตัวหรือมากกว่าด้วยตัวอักษรอื่น (หรือไม่มีตัวอักษรเลย) Replace() ต่างจากเมธออื่นๆ ที่ใช้มาก่อนหน้านี้ตรงที่มัน แทนที่ทุกครั้งที่เจอตัวอักษรที่กำหนด ไม่ใช่แค่ครั้งแรกหรือครั้งสุดท้ายเท่านั้น

Program.cs 
string message = "This--is--ex-amp-le--da-ta";
message = message.Replace("--", " ");
message = message.Replace("-", "");
Console.WriteLine(message);
Output
This is example data

ที่นี่คุณใช้ Replace() สองครั้ง ครั้งแรกแทนที่ string -- ด้วยช่องว่าง ครั้งที่สองแทนที่ string - ด้วย empty string ซึ่งเท่ากับลบตัวอักษรนั้นออกจาก string ไปเลย

💡 ลำดับการเรียก Replace() สำคัญ สังเกตว่าโค้ดข้างบนเรียก Replace("--", " ") ก่อน Replace("-", "") เสมอ — ถ้าสลับลำดับ (ลบ - เดี่ยวก่อน) เครื่องหมาย -- คู่จะถูกลบไป ด้วย ทำให้คำต่างๆ ติดกันหมด ไม่มีช่องว่างคั่นเลย ลำดับการเรียกเมธอดที่ทำงานทับซ้อนกันแบบนี้ ส่งผลต่อผลลัพธ์เสมอ ต้องคิดให้รอบคอบ

Check ★ โค้ด message = message.Replace("B", "D"); เมื่อ string message = "Big Dog"; ค่าใหม่ของ message คืออะไร?

  • A"Big Dog"
  • B"Big Bog"
  • C"Dig Dog"
เฉลย: ข้อ C. "Big Dog" มีตัวอักษร "B" ตัวพิมพ์ใหญ่แค่ตัวเดียว (ใน "Big") — Replace() แทนที่ทุกครั้งที่เจอ "B" (ตัวพิมพ์ใหญ่ ตรงตัว case-sensitive) ด้วย "D" ได้ "Dig Dog" — ตัว "D" ใน "Dog" ไม่ถูกแตะเลย เพราะค้นหา "B" ไม่ใช่ "D"

25.5 ท้าทาย: แยกวิเคราะห์ HTML Fragment

ℹ️ ความรู้พื้นฐาน HTML ที่ต้องใช้ HTML คือภาษามาร์กอัปที่ใช้สร้างหน้าเว็บทั้งหมด ใน HTML คุณกำหนดโครงสร้างของเอกสารด้วย tag — tag ประกอบด้วยวงเล็บเหลี่ยมเปิด < คำที่บอกประเภทของ tag แล้วปิด ด้วยวงเล็บเหลี่ยม > เช่น <div>, <span>, <h2> แต่ละ tag มี tag ปิดคู่กันเสมอ ซึ่งมีเครื่องหมาย / นำหน้า เช่น <div> ต้องมี </div> คู่กัน เนื้อหาระหว่าง tag เปิดกับปิดคือเนื้อหาของ tag นั้น ซึ่งอาจมี text และ tag อื่นซ้อนอยู่ข้างในได้ ทำให้เอกสาร HTML มีโครงสร้างแบบลำดับชั้น
โจทย์ตามต้นฉบับ MS Learn

ใช้ข้อมูลตั้งต้นนี้:

ข้อมูลตั้งต้น (ห้ามลบ)
const string input = "
Widgets ™
5000
";

string quantity = "";
string output = "";

// Your work here

Console.WriteLine(quantity);
Console.WriteLine(output);

ทำตามขั้นตอนนี้:

  1. กำหนดตัวแปร quantity ด้วยค่าที่ดึงจากข้อความระหว่างแท็ก <span> และ </span>
  2. กำหนดตัวแปร output ด้วยค่าของ input แล้วลบแท็ก <div> และ </div> ออก
  3. แทนที่ HTML character ™ (&trade;) ด้วย ® (&reg;) ในตัวแปร output

ผลลัพธ์ที่ต้องได้:

Output:

5000
💡 ขอคำใบ้

ใช้ const ประกาศ tag ที่ต้องใช้ซ้ำ (เช่น openSpan, closeSpan, openDiv, closeDiv) ตามหลักการ หลีกเลี่ยง magic value จากหัวข้อ 25.2e — ทำทีละขั้นตอนตามลำดับที่โจทย์ระบุ (quantity ก่อน แล้วค่อย output)

🔓 ดูเฉลย (เฉลยทางการจาก Microsoft Learn)
Program.cs 
const string input = "
Widgets ™
5000
";

string quantity = "";
string output = "";

// Extract the "quantity"
const string openSpan = "";
const string closeSpan = "";

int quantityStart = input.IndexOf(openSpan) + openSpan.Length;
int quantityEnd = input.IndexOf(closeSpan);
int quantityLength = quantityEnd - quantityStart;
quantity = input.Substring(quantityStart, quantityLength);
quantity = $"Quantity: {quantity}";

// Set output to input, replacing the trademark symbol with the registered trademark symbol
const string tradeSymbol = "™";
const string regSymbol = "®";
output = input.Replace(tradeSymbol, regSymbol);

// Remove the opening 
 tag
const string openDiv = "
";
int divStart = output.IndexOf(openDiv);
output = output.Remove(divStart, openDiv.Length);

// Remove the closing 
 tag and add "Output:" to the beginning
const string closeDiv = "
";
int divCloseStart = output.IndexOf(closeDiv);
output = "Output: " + output.Remove(divCloseStart, closeDiv.Length);

Console.WriteLine(quantity);
Console.WriteLine(output);
Output
Quantity: 5000
Output: 
Widgets ®
5000

นี่เป็นเพียงหนึ่งในหลายวิธีที่แก้โจทย์นี้ได้ สังเกตลำดับการทำงานของเฉลย:

  • ดึง quantity ก่อน — ใช้ input.IndexOf(openSpan) + openSpan.Length คำนวณตำแหน่งเริ่มต้นในขั้นตอนเดียว (รวมการข้าม tag เปิดไว้ในสูตรเดียวเลย แทนที่จะ แยกเป็น 2 บรรทัดแบบหัวข้อ 25.2d)
  • Replace ก่อน Remove เสมอ — สังเกตว่าเฉลยเรียก input.Replace(tradeSymbol, regSymbol) ก่อนจะลบ tag <div>/</div> ออก เพราะ output ต้องมีค่าเริ่มต้นจาก input ก่อนถึงจะเอาไปแก้ไขต่อได้
  • ลบ div เปิดก่อน div ปิด — เพราะการลบ <div> เปิดออกทำให้ ตำแหน่งของ </div> ปิดเปลี่ยนไป (สั้นลง) โค้ดจึงต้องหาตำแหน่ง closeDiv ใหม่หลังลบ openDiv ไปแล้ว ไม่ใช่คำนวณ ตำแหน่งทั้งสองไว้ล่วงหน้าพร้อมกัน

25.6 ⚠️ กับดักที่พบบ่อย

อาการสาเหตุ / วิธีแก้
ArgumentOutOfRangeException ตอนเรียก Substring()/Remove() เกิดเมื่อ IndexOf() คืน -1 (หาไม่เจอ) แล้วโค้ดเอาค่า -1 นั้นไปใช้เป็น startIndex ตรงๆ โดยไม่เช็คก่อน — ต้องเช็ค if (index == -1) ก่อนใช้ค่าที่ได้จาก IndexOf() เสมอ (ทบทวนแพทเทิร์นจากหัวข้อ 25.3b)
ลืมบวก .Length ของ tag เปิด ทำให้ผลลัพธ์ที่ดึงมามี tag ติดมาด้วย Substring() เริ่มดึงจากตำแหน่งที่ IndexOf() คืนมาตรงๆ ซึ่งเป็นตำแหน่งเริ่มต้น ของ tag เปิด ไม่ใช่ตำแหน่งหลังจบ tag เปิด — ต้องบวกความยาวของ tag เปิดเองเสมอ
ลบ tag เปิดแล้ว ตำแหน่งของ tag ปิดที่คำนวณไว้ก่อนหน้าใช้ไม่ได้อีกต่อไป ไม่ใช่บั๊ก — string เป็น immutable (เปลี่ยนแปลงไม่ได้) ทุกเมธอดอย่าง Remove()/Replace() คืน string ใหม่เสมอ ความยาวเปลี่ยนไปตำแหน่งก็เลื่อนตาม ต้องหาตำแหน่งใหม่หลัง แก้ไข string แล้วเสมอ ไม่ใช่คำนวณตำแหน่งทั้งหมดไว้ล่วงหน้าครั้งเดียว
Replace() ลบเครื่องหมายคู่ (--) หายไปหมด ทั้งที่ต้องการแค่ลบเครื่องหมายเดี่ยว (-) เรียก Replace("-", "") ก่อน Replace("--", " ") สลับลำดับผิด — ต้องจัดการ pattern ที่ ยาวกว่า/เจาะจงกว่าก่อนเสมอ แล้วค่อยจัดการ pattern ที่สั้นกว่า/ทั่วไปกว่าทีหลัง
ใช้ magic string/number ซ้ำหลายจุด แล้วพิมพ์ผิดจุดเดียวทำให้โค้ดพังแบบหาสาเหตุยาก เปลี่ยนไปใช้ const ประกาศค่าไว้ที่เดียว แล้วอ้างอิงชื่อ constant แทนพิมพ์ ค่าซ้ำ (ทบทวนหัวข้อ 25.2e)

25.8 ✍️ แบบฝึกหัดท้ายบท

ข้อ 1ง่าย

หาตำแหน่งของ @ ใน "user@example.com" แล้วใช้ Substring() ดึง เฉพาะส่วน username (ก่อน @) กับ domain (หลัง @) ออกมาแยกกัน

ดูเฉลย
Program.cs
string email = "user@example.com";
int atPosition = email.IndexOf('@');

string username = email.Substring(0, atPosition);
string domain = email.Substring(atPosition + 1);

Console.WriteLine($"Username: {username}");
Console.WriteLine($"Domain: {domain}");
ข้อ 2ง่าย

ใช้ Replace() แทนที่ทุกคำว่า "cat" ด้วย "dog" ใน "The cat sat with the cat"

ดูเฉลย
Program.cs
string text = "The cat sat with the cat";
text = text.Replace("cat", "dog");
Console.WriteLine(text);

ผลลัพธ์: "The dog sat with the dog"

ข้อ 3กลาง

โค้ดนี้ throw ArgumentOutOfRangeException ตอนหาคำว่า "xyz" ที่ไม่มีอยู่จริง หาสาเหตุและแก้:

Program.cs (ผิด)
string text = "Hello world";
int pos = text.IndexOf("xyz");
Console.WriteLine(text.Substring(pos));
ดูเฉลย

IndexOf("xyz") คืน -1 เพราะหาไม่เจอ แล้วโค้ดเอา -1 ไปใช้เป็น startIndex ของ Substring() ตรงๆ ซึ่งเป็นค่าที่ ไม่ถูกต้อง (index ติดลบไม่มีในความเป็นจริง) ทำให้เกิด exception ต้องเช็คก่อนเสมอ:

Program.cs (แก้แล้ว)
string text = "Hello world";
int pos = text.IndexOf("xyz");
if (pos != -1)
{
    Console.WriteLine(text.Substring(pos));
}
else
{
    Console.WriteLine("ไม่พบคำที่ค้นหา");
}
ข้อ 4กลาง

เขียนโค้ดวนดึงข้อความในทุกคู่ [...] (วงเล็บเหลี่ยม) จาก string "Buy [milk], [bread], and [eggs] today" ใช้แพทเทิร์น while + IndexOf จาก หัวข้อ 25.3b (เปลี่ยนจาก () เป็น [])

ดูเฉลย
Program.cs
string message = "Buy [milk], [bread], and [eggs] today";
while (true)
{
    int openingPosition = message.IndexOf('[');
    if (openingPosition == -1) break;

    openingPosition += 1;
    int closingPosition = message.IndexOf(']');
    int length = closingPosition - openingPosition;
    Console.WriteLine(message.Substring(openingPosition, length));

    message = message.Substring(closingPosition + 1);
}

ผลลัพธ์: milk, bread, eggs (แต่ละคำคนละบรรทัด)

ข้อ 5ยาก

เขียนโค้ดแปลง fixed-width string "A001Widget 12000" (4 ตัวแรก = ID, 20 ตัวถัดไป = ชื่อสินค้า, ที่เหลือ = ราคาเป็นสตางค์) ให้เป็นข้อความอ่านง่ายรูปแบบ "A001: Widget = $120.00" ใช้ Substring() ดึงแต่ละฟิลด์ แล้วใช้ Trim() (ทบทวนจาก บทที่ 18) ตัดช่องว่างส่วนเกินออก

ดูเฉลย
Program.cs
string data = "A001Widget           12000";

string id = data.Substring(0, 4);
string name = data.Substring(4, 20).Trim();
string priceCents = data.Substring(24);

decimal price = decimal.Parse(priceCents) / 100;

Console.WriteLine($"{id}: {name} = {price:C}");

ใช้ int.Parse/decimal.Parse (ทบทวนจาก บทที่ 22) แปลง string ราคาเป็นตัวเลข หารด้วย 100 แปลงจากสตางค์เป็นบาท แล้วจัด รูปแบบด้วย :C (ทบทวนจาก บทที่ 24)

ข้อ 6ท้าทาย

ดัดแปลงเฉลยของท้าทาย HTML (หัวข้อ 25.5) ให้รองรับ input ที่ซ้อน <div> 2 ชั้น เช่น "<div><div><span>42</span></div></div>" — ต้องดึง quantity (42) ออกมาได้ถูกต้องเหมือนเดิม โดยไม่ต้องแก้โค้ดส่วนดึง quantity เลย (คำใบ้: โค้ดเดิมยังทำงานถูกไหม ลองรันดูก่อนแก้อะไร)

ดูเฉลย

โค้ดส่วนดึง quantity จากเฉลยเดิมทำงานถูกต้องอยู่แล้วโดยไม่ต้องแก้เลย เพราะมันใช้ IndexOf(openSpan) หาตำแหน่งของ <span> โดยตรง ไม่สนใจว่า <div> จะซ้อนกี่ชั้นก่อนหน้า — นี่คือข้อดีของการ ค้นหาด้วย IndexOf() แทนการนับตำแหน่งคงที่ (fixed position) เหมือนที่ใช้ ใน Remove() ตอนหัวข้อ 25.4a ที่ต้องรู้ตำแหน่งตายตัวล่วงหน้า วิธีค้นหา ด้วย tag name จึงยืดหยุ่นกว่ามากเมื่อโครงสร้างข้อมูลเปลี่ยนไป

📌 สรุปบทที่ 25

เป้าหมายของคุณคือดึง ลบ และแทนที่ค่าใน string บ่อยครั้งที่ข้อมูลซึ่งคุณได้รับมามีข้อมูลหรือ ตัวอักษรเกินความจำเป็นที่ต้องหลีกเลี่ยงหรือกำจัดออกก่อนถึงจะใช้ข้อมูลเป้าหมายได้

การใช้เมธอด IndexOf() ทำให้คุณระบุตำแหน่งของตัวอักษรหรือ string ภายใน string อีกอันได้ ตำแหน่งที่คืนกลับมาจาก IndexOf() เป็นส่วนประกอบแรกที่ใช้กับเมธอด Substring() เพื่อดึงส่วนของ string ออกมา โดยกำหนดตำแหน่งเริ่มต้นและจำนวน ตัวอักษรที่จะดึง (ความยาว) มันยังทำให้คุณใช้เมธอด Remove() ลบตัวอักษรออกจาก string โดยกำหนดตำแหน่งเริ่มต้นและความยาวได้ด้วย คุณเรียนรู้ตัวแปรอย่าง LastIndexOf() ที่หาตำแหน่งสุดท้ายของตัวอักษรหรือ string ภายใน string อื่น และ IndexOfAny() ที่หาตำแหน่งของค่าใดๆ ใน char array ที่กำหนด คุณใช้ while statement วนผ่าน string ที่ยาวขึ้น เพื่อหาและดึงทุกการปรากฏของตัวอักษรหรือ string ภายใน source string ที่ใหญ่กว่า สุดท้าย คุณใช้เมธอด Replace() สลับทุก การปรากฏของตัวอักษรหรือ string ภายใน string ที่ใหญ่กว่า

แม้จะเป็นไปได้ที่จะทำการดำเนินการแบบนี้ด้วย char array วนผ่านแต่ละ char เพื่อหาที่ตรงกัน คอยติดตามจุดเริ่มต้นและจุดสิ้นสุดที่ต้องการหา ฯลฯ แต่จะ ต้องใช้ขั้นตอนมากกว่ามากในการทำสิ่งที่ string helper method เหล่านี้ทำได้ในการเรียกครั้งเดียว
