13.1 สถานการณ์: คำขอฟีเจอร์ใหม่จากผู้ใช้

ผู้ใช้มักขอให้นักพัฒนาเพิ่มฟีเจอร์ใหม่ให้แอปอยู่เสมอ คำขอแบบนี้บอกว่าแอปของคุณถูกใช้งานจริง และที่สำคัญกว่านั้นคือลูกค้าตั้งใจจะใช้ต่อไป — แค่อยากให้ฟีเจอร์บางอย่างถูกปรับปรุง ความสามารถในการอัปเดตแอปที่มีอยู่แล้วตามคำขอผู้ใช้เป็นเรื่องสำคัญมาก การอัปเดตที่ดีต้อง รักษาความสมบูรณ์ของแอปเดิมไว้ พร้อมมอบประสบการณ์ที่ดีขึ้นตามที่ผู้ใช้ขอ

สมมติคุณยังเป็นผู้ช่วยครูคนเดิม แอปตัดเกรดที่คุณสร้างจากบทที่ 12 ใช้ array เก็บชื่อนักเรียนและ คะแนนงาน ผสาน iteration กับ selection statement คำนวณและรายงานเกรดสุดท้าย แถมยังแยกคะแนน สอบกับคะแนนพิเศษออกจากกันตอนคำนวณด้วย — แอปทำทุกอย่างที่ครูขอไว้ครบถ้วน แต่ตอนนี้ครูขอ ฟีเจอร์ใหม่: อยากให้รายงานคะแนนแสดงคะแนนสอบและคะแนนพิเศษแยกออกจากคะแนนรวมสุดท้าย และเกรดตัวอักษรด้วย

โดยสรุป คุณต้องใช้สเปกรายงานคะแนนใหม่ของครูเพื่อ:

  • อัปเดตโค้ด iteration และ selection ให้คำนวณคะแนนสอบ คะแนนพิเศษ และเกรดรวม แยกออกจากกัน
  • อัปเดตโค้ดที่เขียนรายงานคะแนนออกคอนโซล

13.2 เตรียมพร้อม: สเปกใหม่จากครู

แอปที่คุณมีอยู่แล้ว (จากบทที่ 12) มีคุณสมบัติครบ: ใช้ array เก็บชื่อ และคะแนน ใช้ foreach ชั้นนอกวนชื่อนักเรียน ใช้ if ข้างในเลือก array คะแนนที่ตรงกับชื่อ ใช้ foreach ชั้นในรวมคะแนน และใช้ if-elseif-else ตัดเกรดอัตโนมัติ พร้อมแยกคะแนนสอบกับคะแนนพิเศษตอนคำนวณแล้ว

ใช้โค้ดฉบับสมบูรณ์จากท้ายหัวข้อ 12.5 เป็นจุดตั้งต้น (ก่อนเพิ่มนักเรียน 4 คนพิเศษ — ใช้แค่ 4 คนแรกพอ) สร้างโปรเจกต์ใหม่แล้ววาง:

Terminal 
dotnet new console -o ch13-challenge
Program.cs — จุดตั้งต้น (จากบทที่ 12) 
int examAssignments = 5;

int[] sophiaScores = new int[] { 90, 86, 87, 98, 100, 94, 90 };
int[] andrewScores = new int[] { 92, 89, 81, 96, 90, 89 };
int[] emmaScores = new int[] { 90, 85, 87, 98, 68, 89, 89, 89 };
int[] loganScores = new int[] { 90, 95, 87, 88, 96, 96 };

string[] studentNames = new string[] { "Sophia", "Andrew", "Emma", "Logan" };

int[] studentScores = new int[10];

string currentStudentLetterGrade = "";

Console.WriteLine("Student\t\tGrade\tLetter Grade\n");

foreach (string name in studentNames)
{
    string currentStudent = name;

    if (currentStudent == "Sophia")
        studentScores = sophiaScores;
    else if (currentStudent == "Andrew")
        studentScores = andrewScores;
    else if (currentStudent == "Emma")
        studentScores = emmaScores;
    else if (currentStudent == "Logan")
        studentScores = loganScores;

    int sumAssignmentScores = 0;
    decimal currentStudentGrade = 0;
    int gradedAssignments = 0;

    foreach (int score in studentScores)
    {
        gradedAssignments += 1;

        if (gradedAssignments <= examAssignments)
            sumAssignmentScores += score;
        else
            sumAssignmentScores += score / 10;
    }

    currentStudentGrade = (decimal)(sumAssignmentScores) / examAssignments;

    if (currentStudentGrade >= 97)
        currentStudentLetterGrade = "A+";
    else if (currentStudentGrade >= 93)
        currentStudentLetterGrade = "A";
    else if (currentStudentGrade >= 90)
        currentStudentLetterGrade = "A-";
    else if (currentStudentGrade >= 87)
        currentStudentLetterGrade = "B+";
    else if (currentStudentGrade >= 83)
        currentStudentLetterGrade = "B";
    else if (currentStudentGrade >= 80)
        currentStudentLetterGrade = "B-";
    else if (currentStudentGrade >= 77)
        currentStudentLetterGrade = "C+";
    else if (currentStudentGrade >= 73)
        currentStudentLetterGrade = "C";
    else if (currentStudentGrade >= 70)
        currentStudentLetterGrade = "C-";
    else if (currentStudentGrade >= 67)
        currentStudentLetterGrade = "D+";
    else if (currentStudentGrade >= 63)
        currentStudentLetterGrade = "D";
    else if (currentStudentGrade >= 60)
        currentStudentLetterGrade = "D-";
    else
        currentStudentLetterGrade = "F";

    Console.WriteLine($"{currentStudent}\t\t{currentStudentGrade}\t{currentStudentLetterGrade}");
}

Console.WriteLine("\nPress the Enter key to continue");
Console.ReadLine();

13.3 ท้าทายที่ 1: ปรับ Output ให้มีคอลัมน์ใหม่

โจทย์ตามต้นฉบับ MS Learn — ไม่มีคำแนะนำทีละขั้น

ในความท้าทายแรกนี้ ให้คุณสร้างตัวแปรที่จำเป็นสำหรับรายงานคะแนนแบบใหม่ แล้วอัปเดต Console.WriteLine() ที่เขียนเกรดนักเรียนออกคอนโซล

แอปที่อัปเดตแล้วต้อง:

  • ใช้ array และค่าใน array เดิมสำหรับการคำนวณเกรดนักเรียนทุกจุด
  • ใช้โครงสร้างซ้อนของ foreach และ if เดิมที่มีอยู่แล้ว
  • ประกาศและกำหนดค่าเริ่มต้นตัวแปร int เพิ่มเติมที่จำเป็นสำหรับคำนวณผลรวม
  • ประกาศและกำหนดค่าเริ่มต้นตัวแปร decimal เพิ่มเติมที่จำเป็นสำหรับการคำนวณและ/หรือ ค่าที่แสดงในรายงาน

รูปแบบรายงานที่ต้องได้ในขั้นนี้ (ยังไม่ต้องคำนวณค่าจริง ใส่ 0 ไปก่อนได้เลย):

เป้าหมายของขั้นนี้ (ฟิลด์ใหม่ยังเป็น 0 ได้)
Student         Exam Score      Overall Grade   Extra Credit

Sophia          0               95.8    A       0 (0 pts)
Andrew          0               91.2    A-      0 (0 pts)
Emma            0               90.4    A-      0 (0 pts)
Logan           0               93      A       0 (0 pts)

สังเกตว่า Overall Grade ยังเป็นค่าเดิมจากรายงานเก่า (95.8, 91.2, 90.4, 93) — ขั้นนี้แค่เพิ่ม "ที่ว่าง" สำหรับฟิลด์ใหม่ในรายงาน ยังไม่ต้องคำนวณค่าจริงให้ครบ (จะทำในหัวข้อ 13.4)

💡 ลองทำเองก่อน! หยุดตรงนี้แล้วลองทำจริงๆ ก่อนเลื่อนลงไปดูเฉลย — key คือแค่เพิ่มตัวแปร placeholder (เช่น decimal examScore = 0;) แล้วใส่ลงใน Console.WriteLine() บรรทัดที่แสดงเกรด ยังไม่ต้องคิดสูตรคำนวณอะไรเลยในขั้นนี้
🔓 ดูเฉลยของผม (ไม่ใช่เฉลยทางการจาก Microsoft — ต้นฉบับไม่มีเฉลยให้)

13.4 ท้าทายที่ 2: คำนวณค่าจริงแทนที่ 0

โจทย์ตามต้นฉบับ MS Learn — ไม่มีคำแนะนำทีละขั้น

ความท้าทายที่สองนี้ ให้คุณคำนวณค่าจริงแทนที่ 0 ทั้งหมด แอปที่อัปเดตแล้วต้อง:

  • ใช้ array และค่าใน array เดิมสำหรับการคำนวณเกรดนักเรียนทุกจุด
  • ใช้โครงสร้างซ้อนของ foreach และ if เดิม
  • คำนวณผลรวมคะแนนสอบและคะแนนพิเศษ แยกจากกัน โดยใช้ตัวแปรจากขั้นก่อนหรือโค้ดเดิม
  • คำนวณค่าเฉลี่ยของคะแนนสอบและคะแนนพิเศษ แยกจากกัน
  • คำนวณคะแนนตัวเลขสุดท้ายดังนี้: เอา 10% ของผลรวมคะแนนพิเศษ บวกเข้ากับผลรวมคะแนนสอบ แล้วหารด้วยจำนวนวิชาสอบ
  • คำนวณแต้มพิเศษที่ได้ดังนี้: เอา 10% ของผลรวมคะแนนพิเศษ หารด้วยจำนวนวิชาสอบ
ℹ️ คำใบ้จากต้นฉบับ ต้องใช้ (decimal) cast ในสมการเพื่อรักษาเศษทศนิยมไว้ (ทบทวนได้ที่ บทที่ 4)

แยกผลรวมเป็นสองตัวแปร แทนที่ sumAssignmentScores ตัวเดียว:

Program.cs — แก้ foreach ชั้นใน

int gradedAssignments = 0;

{

หาจำนวนคะแนนพิเศษจริงด้วย .Length แล้วคำนวณค่าทั้งหมดตามสูตรที่โจทย์กำหนด:

Program.cs — คำนวณค่าจริง

decimal examScore = (decimal)examScoreSum / examAssignments;
decimal extraCreditAverage = (decimal)extraCreditSum / extraCreditCount;
decimal extraCreditPoints = (extraCreditSum * 0.1m) / examAssignments;
decimal currentStudentGrade = (examScoreSum + (extraCreditSum * 0.1m)) / examAssignments;

examScore = 461/5 = 92.2 ✓

extraCreditPoints = (184×0.1)/5 = 18.4/5 = 3.68 ✓
currentStudentGrade = (461 + 18.4)/5 = 479.4/5 = 95.88 ✓ → เกรด A

💡 ทำไมใช้ 0.1m ไม่ใช่ 0.1 0.1m คือ decimal literal (ทบทวนที่ บทที่ 2) decimal เก็บเลขฐาน 10 ได้แม่นยำเป๊ะ ไม่มีปัญหาเศษเล็กๆ คลาดเคลื่อนแบบ double — 184 × 0.1m ได้ 18.4 พอดีเป๊ะ ไม่ใช่ 18.399999... แบบที่อาจเกิดกับ floating-point ทั่วไป

13.5 ⚠️ กับดักที่พบบ่อย

อาการสาเหตุ / วิธีแก้
extraCreditAverage หารด้วย 0 ได้ error ถ้านักเรียนบางคนไม่มีคะแนนพิเศษเลย extraCreditCount จะเป็น 0 — ในโจทย์นี้ไม่มีเคสแบบนั้น (ทุกคนมีอย่างน้อย 1 รายการ) แต่ถ้าจะทำแอปจริงต้องเช็คก่อนหาร เสมอ
ใช้ examScoreSum เดิม (รวมคะแนนพิเศษปนไปด้วย) แทนที่จะแยกก้อน ลืมเปลี่ยนจากตัวแปรผลรวมก้อนเดียว (sumAssignmentScores) เป็นสองก้อนแยกกัน — สเปกใหม่บังคับว่าต้องแยกคะแนนสอบกับคะแนนพิเศษออกจากกันตั้งแต่ตอนรวมผล ไม่ใช่แค่ตอน แสดงผล
ลืม cast (decimal) แล้วได้ค่าผิดเพราะ int หารตัดเศษ ทบทวนกับดักนี้ได้จากบทที่ 4 และ 6 — เกิดขึ้นซ้ำได้เสมอถ้าลืมตรวจสอบชนิดข้อมูลก่อนหาร
เปลี่ยน sumAssignmentScores เป็น examScoreSum แต่ลืมเปลี่ยนบรรทัด WriteLine เดิม เหมือนกับดักตอนเปลี่ยนชื่อ currentAssignments→examAssignments ในบทที่ 12 — ใช้ Find & Replace (Ctrl+H) แทนแก้มือทีละจุดเสมอ

  • Cเพิ่มค่าตัวนับข้างใน foreach ทีละ 1 หยุดบวกเมื่อตัวนับถึง 25
เฉลย: ข้อ C. ตรงกับเทคนิคที่ใช้ตลอดบทที่ 12–13 (ตัวแปร gradedAssignments) — foreach แบบมาตรฐานไม่มีตัวแปร index ให้เช็คตรงๆ ในตัวมันเอง (ข้อ B จึงทำไม่ได้ตรงๆ ต้องมีตัวนับเสริมอยู่ดี) ส่วนข้อ A เป็น วิธีที่ซับซ้อนเกินจำเป็นและเสี่ยงบั๊กถ้าค่าจริงบังเอิญตรงกับ "ค่าเครื่องหมาย"

2. นักพัฒนา 3 คนทำงานร่วมกันอัปเดตชุดแอปพลิเคชัน โดยใช้คอมเมนต์ ระหว่างกระบวนการอัปเดต ข้อใดอธิบายการใช้คอมเมนต์ที่เหมาะสม?

13.7 ✍️ แบบฝึกหัดท้ายบท

ข้อ 1ง่าย

จากโค้ดฉบับสมบูรณ์ในหัวข้อ 13.4 ลองคำนวณด้วยมือว่า Emma ควรได้ค่าอะไรในแต่ละคอลัมน์ (examScore, extraCreditAverage, extraCreditPoints, currentStudentGrade) จาก emmaScores = { 90, 85, 87, 98, 68, 89, 89, 89 } แล้วเทียบกับผลลัพธ์จริง

ดูเฉลย

คะแนนสอบ = 90+85+87+98+68 = 428 → examScore = 428/5 = 85.6
คะแนนพิเศษ = 89+89+89 = 267 (3 รายการ) → extraCreditAverage = 267/3 = 89
extraCreditPoints = (267×0.1)/5 = 26.7/5 = 5.34
currentStudentGrade = (428+26.7)/5 = 454.7/5 = 90.94 → เกรด A-
ตรงกับผลลัพธ์จริงทุกค่า ✓

ข้อ 2ง่าย

ถ้าครูเปลี่ยนใจ อยากให้คะแนนพิเศษมีน้ำหนัก 15% แทน 10% ต้องแก้โค้ดกี่บรรทัด และบรรทัด ไหนบ้าง?

ดูเฉลย

แก้ 2 บรรทัด — เปลี่ยน 0.1m เป็น 0.15m ทั้งในสมการ extraCreditPoints และ currentStudentGrade (ไม่ต้องแก้ที่อื่น เพราะทั้งสองจุดอ้างอิงค่าน้ำหนักเดียวกัน)

ข้อ 3ง่าย

โค้ดนี้ error ตอนรัน หาสาเหตุ (สมมตินักเรียนคนนี้ไม่มีคะแนนพิเศษเลย มีแค่ 5 วิชาสอบ):

Program.cs
int extraCreditCount = studentScores.Length - examAssignments; // = 0
decimal extraCreditAverage = (decimal)extraCreditSum / extraCreditCount;
ดูเฉลย

หารด้วย 0 (extraCreditCount = 0) ทำให้เกิด DivideByZeroException ตอนรัน (ต่างจากหารด้วย 0 แบบ int ที่บางกรณี C# อนุญาต แต่ decimal หารด้วย 0 จะ throw exception เสมอ) ต้องเช็คก่อนด้วย if (extraCreditCount > 0) แล้วค่อยหาร ไม่งั้นกำหนดเป็น 0 ไปเลย

ข้อ 4กลาง

เพิ่มการป้องกันจากข้อ 3 เข้าไปในโค้ดฉบับสมบูรณ์จริงๆ (ใช้ if-else ป้องกันหารด้วย 0 สำหรับ extraCreditAverage โดยเฉพาะ)

ดูเฉลย
Program.cs
decimal extraCreditAverage;

if (extraCreditCount > 0)
    extraCreditAverage = (decimal)extraCreditSum / extraCreditCount;
else
    extraCreditAverage = 0;
ข้อ 5กลาง

เพิ่มนักเรียนคนที่ 5 ชื่อ "Maya" คะแนนสอบ 88,90,92,85,89 และคะแนนพิเศษ 95,95 เข้าไปใน แอปฉบับสมบูรณ์จากหัวข้อ 13.4 คำนวณด้วยมือว่าเธอควรได้ผลลัพธ์อะไรในแต่ละคอลัมน์ ก่อนรันจริงเพื่อตรวจคำตอบ

ดูเฉลย

คะแนนสอบรวม = 88+90+92+85+89 = 444 → examScore = 444/5 = 88.8
คะแนนพิเศษรวม = 95+95 = 190 (2 รายการ) → extraCreditAverage = 190/2 = 95
extraCreditPoints = (190×0.1)/5 = 19/5 = 3.8
currentStudentGrade = (444+19)/5 = 463/5 = 92.6 → เกรด A- (อยู่ในช่วง 90–92)

ข้อ 6ท้าทาย

ครูขอฟีเจอร์เพิ่มอีกอย่าง: อยากรู้ว่าคะแนนพิเศษ "ช่วยดันเกรดตัวอักษรขึ้นจริง" กี่คน (เทียบเกรดตัวอักษรที่คำนวณจากคะแนนสอบอย่างเดียว กับเกรดตัวอักษรสุดท้ายที่รวมคะแนนพิเศษแล้ว ถ้าต่างกันแปลว่า "ขึ้นจริง") เขียนโค้ดเพิ่มจากฉบับสมบูรณ์ในหัวข้อ 13.4 พิมพ์สรุปท้ายรายงาน

💡 คำใบ้

ต้องคำนวณเกรดตัวอักษรสองรอบต่อคนหนึ่ง: รอบแรกจาก examScore อย่างเดียว (ไม่รวมคะแนนพิเศษ) ผ่านเชน if-elseif-else เดิม รอบสองจาก currentStudentGrade ที่รวมแล้ว (ซึ่งมีอยู่แล้ว) — ต้องเขียน เชน if-elseif-else ซ้ำ 2 รอบ หรือแยกเป็นค่าคงที่ตัดเกรดไว้ใช้ร่วมกันก็ได้

ดูเฉลย

วิธีที่ตรงไปตรงมาที่สุด (แม้จะยาวหน่อย) คือคัดลอกเชน if-elseif-else มาอีกชุดสำหรับ examScore อย่างเดียว:

Program.cs (ส่วนที่เพิ่ม)
int boostedCount = 0;  // ประกาศนอกสุด ก่อน foreach ชื่อ

// ... ข้างในลูปชื่อ ต่อจากการตัดเกรดสุดท้ายเดิม ...
string examOnlyLetterGrade;
if (examScore >= 97) examOnlyLetterGrade = "A+";
else if (examScore >= 93) examOnlyLetterGrade = "A";
else if (examScore >= 90) examOnlyLetterGrade = "A-";
else if (examScore >= 87) examOnlyLetterGrade = "B+";
else if (examScore >= 83) examOnlyLetterGrade = "B";
else if (examScore >= 80) examOnlyLetterGrade = "B-";
else if (examScore >= 77) examOnlyLetterGrade = "C+";
else if (examScore >= 73) examOnlyLetterGrade = "C";
else if (examScore >= 70) examOnlyLetterGrade = "C-";
else if (examScore >= 67) examOnlyLetterGrade = "D+";
else if (examScore >= 63) examOnlyLetterGrade = "D";
else if (examScore >= 60) examOnlyLetterGrade = "D-";
else examOnlyLetterGrade = "F";

if (examOnlyLetterGrade != currentStudentLetterGrade)
{
    boostedCount++;
}

// ... หลังจบ foreach ชื่อ ...
Console.WriteLine($"\nคะแนนพิเศษช่วยดันเกรดขึ้นจริง {boostedCount} คน");

สังเกตเครื่องหมาย != ("ไม่เท่ากับ") — เป็นตัวดำเนินการเปรียบเทียบ ที่ยังไม่เคยเจอในเล่มนี้มาก่อน แต่เดาความหมายได้ไม่ยากจากบริบท จะได้เรียนอย่างเป็น ทางการในโมดูล Boolean expression ของ Part 3
