Branch the Flow of Code Using the switch-case Construct

🎯 จบบทนี้คุณจะ...

  • ใช้ construct switch-case จับคู่ตัวแปรหรือ expression กับผลลัพธ์ที่เป็นไปได้หลายแบบ

16.1 ทำไมต้องมี switch-case

ภาษา C# ก็เหมือนภาษามนุษย์ที่พูดหรือเขียน — แต่ละภาษารองรับวิธีสื่อความหมายเดียวกันได้ หลายแบบ ในภาษาพูด บางคำ/วลีสื่อความหมาย แม่นยำ หรือกระชับกว่าคำอื่น ในภาษา C# ก็มีมากกว่า หนึ่งวิธีสร้างตรรกะแตกสาขา เช่น การเลือกด้วย if statement กับการเลือกด้วย switch statement ขึ้นกับบริบทของแอป วิธีหนึ่งอาจสื่อความหมายและกระชับกว่า อีกวิธีหนึ่ง

สมมติคุณทำงานกับแอปที่ใช้ selection statement เยอะมาก บางกรณี if-elseif-else ให้โค้ดที่กระชับ สื่อความหมาย อ่านและดูแลง่าย แต่บางกรณี if-elseif-else ก็ให้ผลลัพธ์ที่ถูกต้อง แต่อ่านและดูแลยาก คุณถูกมอบหมายให้ ตรวจโค้ดและตัดสินว่าเมื่อไรควรใช้ switch statement แทน if statement

ในบทนี้ คุณจะสำรวจการใช้ switch statement สร้างตรรกะแตกสาขา เป็นทางเลือกแทน if statement คุณจะแปลง if-elseif-else construct เป็น switch-case construct ระหว่างทางนี้ คุณจะเรียนรู้ข้อดีของการเลือกใช้ selection statement แบบหนึ่งเหนืออีกแบบหนึ่ง

16.2 ลงมือ: สร้าง switch Statement

สมมติสถานการณ์: คุณทำงานกับแอปเกี่ยวกับข้อมูลโภชนาการอาหาร ส่วนหนึ่งของโค้ดเกี่ยวกับผลไม้ — มีตัวแปร fruit เก็บชื่อผลไม้ชนิดต่างๆ มีรายการผลไม้ที่แอปสนใจถึง 20 ชนิด และต้องการแตกสาขาโค้ดตามค่าที่กำหนดให้ fruit — สถานการณ์แบบนี้ใช้ switch statement สร้างสาขาแยกสำหรับผลไม้แต่ละชนิดได้

switch Statement ทำงานยังไง

switch statement เลือกโค้ดหนึ่งส่วนมารันจากรายการ switch section ที่เป็นไปได้ — เลือกโดยจับคู่รูปแบบกับ match expression ของ statement นั้น

โครงสร้างพื้นฐาน
switch (fruit)
{
    case "apple":
        Console.WriteLine($"App will display information for apple.");
        break;

    case "banana":
        Console.WriteLine($"App will display information for banana.");
        break;

    case "cherry":
        Console.WriteLine($"App will display information for cherry.");
        break;
}

match expression (หรือเรียกว่า switch expression) คือค่าที่ตามหลังคีย์เวิร์ด switch ในตัวอย่างนี้คือ (fruit) — แต่ละ switch section ถูกนิยามด้วย case pattern สร้างจากคีย์เวิร์ด case ตามด้วยค่า case pattern แรกในตัวอย่างนี้คือ case "apple": case pattern เป็น Boolean expression ที่ประเมินได้เป็น true หรือ false แต่ละ switch section มีโค้ดไม่กี่ บรรทัดที่จะถูกรัน ถ้า case pattern นั้นตรงกับ match expression — ในตัวอย่างนี้ ถ้า fruit ถูกกำหนดค่าเป็น "apple" case pattern แรกจะประเมินเป็น true และ switch section นั้นจะถูกรัน

switch statement ต้องมีอย่างน้อย 1 switch section แต่ปกติมักมีตั้งแต่ 3 section ขึ้นไป switch เหมาะที่สุดเมื่อ:

  • มีค่าเดียว (ตัวแปรหรือ expression) ที่ต้องการจับคู่กับค่าที่เป็นไปได้หลายแบบ
  • สำหรับแต่ละคู่ที่ตรงกัน ต้องรันโค้ดแค่ไม่กี่บรรทัดเป็นอย่างมาก

เตรียมโปรเจกต์

Terminal 
dotnet new console -o ch16-switch

สร้างและทดสอบ switch Statement

Program.cs 
int employeeLevel = 200;
string employeeName = "John Smith";

string title = "";

switch (employeeLevel)
{
    case 100:
        title = "Junior Associate";
        break;
    case 200:
        title = "Senior Associate";
        break;
    case 300:
        title = "Manager";
        break;
    case 400:
        title = "Senior Manager";
        break;
    default:
        title = "Associate";
        break;
}

Console.WriteLine($"{employeeName}, {title}");
Output
John Smith, Senior Associate

switch statement นิยาม code block เดียวที่มีรายการ switch section อยู่ข้างใน ทางขวาของคีย์เวิร์ด switch คือ switch expression ที่ล้อมด้วยวงเล็บ switch expression จะถูกประเมินเทียบกับ case label เรียงจากบนลงล่าง จนกว่าจะเจอค่าที่ตรงกับ switch expression ถ้าไม่มี label ไหนตรงเลย statement list ของ default จะถูกรัน ถ้าไม่มี default การทำงานจะข้ามไปจบที่ปลาย switch statement เลย แต่ละ label ต้องให้ค่าชนิดข้อมูลที่ตรงกับชนิดที่ระบุใน switch expression

ℹ️ ตำแหน่งของ default ไม่สำคัญ คีย์เวิร์ด default เป็นตัวเลือกเสริม วางไว้ตำแหน่งไหนในรายการ switch section ก็ได้ แต่นักพัฒนาส่วนใหญ่เลือกวางไว้ท้ายสุด เพราะดูเป็นเหตุเป็นผล (สมเหตุสมผลว่าเป็น ตัวเลือกสุดท้าย) ไม่ว่าจะวางตำแหน่งไหน default จะถูกประเมินเป็นลำดับสุดท้ายเสมอ

ในตัวอย่างนี้: switch expression คือ (employeeLevel) · แต่ละ switch section มี switch label เดียว (case หรือ default) · section ที่ตรงกัน คือ case 200: เพราะ employeeLevel = 200

สังเกตว่าแต่ละ switch section ถูกแยกจากกันด้วย break — มีแค่ 1 switch section เท่านั้นที่ได้รับอนุญาตให้รัน หมายความว่าการทำงานของ section หนึ่งไม่อนุญาตให้ "ไหลต่อ" (fall through) ไปยัง section ถัดไป คีย์เวิร์ด break เป็นหนึ่งในหลายวิธี จบ switch section ก่อนที่จะไปถึง section ถัดไป

🛑 ลืม break = compile error ทันที (ต่างจากหลายภาษา!) ถ้าลืมคีย์เวิร์ด break (หรือทางเลือกอย่าง return) คอมไพเลอร์จะสร้าง error ทันที — นี่ต่างจากภาษาอย่าง C, Java, หรือ JavaScript ที่ปล่อยให้ "fall through" ไปทำงานต่อ section ถัดไปแบบเงียบๆ โดยไม่แจ้งเตือน (ซึ่งเป็นสาเหตุบั๊กที่ มีชื่อเสียงในภาษาเหล่านั้น) C# ออกแบบมาให้ปลอดภัยกว่า — บังคับให้คุณต้องระบุชัดเจนเสมอว่า section หนึ่งจบตรงไหน

เปลี่ยนค่าเพื่อดูว่า default ทำงานยังไง

Program.cs 
int employeeLevel = 201;
Output
John Smith, Associate

เพราะ employeeLevel ไม่ตรงกับ label ไหนเลย default จึงถูกจับคู่แทน

ปรับ switch Section ให้มีหลาย Label

สมมติบริษัทตัดสินใจให้พนักงานระดับ 100 ได้ตำแหน่ง "Senior Associate" เหมือนระดับ 200 — ทำได้โดยลบ switch section ของ case 100: เดิม แล้วให้ทั้ง case 100: และ case 200: ใช้ switch section เดียวกัน:

Program.cs 
int employeeLevel = 100;
string employeeName = "John Smith";

string title = "";

switch (employeeLevel)
{
    case 100:
    case 200:
        title = "Senior Associate";
        break;
    case 300:
        title = "Manager";
        break;
    case 400:
        title = "Senior Manager";
        break;
    default:
        title = "Associate";
        break;
}

Console.WriteLine($"{employeeName}, {title}");
Output
John Smith, Senior Associate

ตอนนี้ case label ทั้ง 100 และ 200 จับคู่กับ switch section เดียวกันที่กำหนด title เป็น "Senior Associate" แล้ว

Check ★ คีย์เวิร์ด break ใน switch-case มีหน้าที่อะไร?

  • Aบอกให้ runtime ประเมิน case อื่นต่อไป
  • Bบอกให้ runtime หยุดประเมิน case pattern และป้องกันไม่ให้ทำงานต่อ section อื่น
  • Cบอกให้ runtime ปิดโปรแกรมทันที
เฉลย: ข้อ B. break จบการทำงานของ switch section ปัจจุบัน ป้องกัน "fall through" ไปยัง section ถัดไป — ไม่เกี่ยวกับการปิดแอป

Check ★ คีย์เวิร์ด default ใน switch-case มีหน้าที่อะไร?

  • Aกำหนดค่าเริ่มต้นให้ตัวแปรถ้ายังไม่ initialize
  • Bทำหน้าที่เป็นค่าที่จับคู่ เมื่อไม่มี case ไหนตรงเลย
  • Cเป็น code block ที่รันเสมอไม่ว่ากรณีใด
เฉลย: ข้อ B. default ทำงานเฉพาะเมื่อไม่มี case label ไหนตรงกับ switch expression เท่านั้น ไม่ใช่รันเสมอ (ข้อ C ผิด) และไม่เกี่ยวกับการ initialize ตัวแปร (ข้อ A ผิด)

Check ★ ข้อใดเกี่ยวกับ switch-case construct ถูกต้อง?

  • Aswitch section เดียวมี case label ได้หลายอัน
  • Bswitch construct ต้องมี default section เสมอ
  • Cเครื่องหมายโคลอนท้าย case label ใส่หรือไม่ใส่ก็ได้
เฉลย: ข้อ A. ตรงกับตัวอย่าง case 100: case 200: ที่ใช้ section ร่วมกันในหัวข้อ 16.2 — default เป็นตัวเลือกเสริม ไม่บังคับ (ข้อ B ผิด) และโคลอนเป็นไวยากรณ์ บังคับของ case label เสมอ (ข้อ C ผิด)

16.3 ท้าทาย: แปลง if-elseif-else เป็น switch-case

โจทย์ตามต้นฉบับ MS Learn

เริ่มจากโค้ดที่ใช้ if-elseif-else ถอดรหัส SKU (Stock Keeping Unit) ของสินค้า รูปแบบ SKU คือ <รหัสสินค้า>-<รหัสสีตัวอักษร 2 ตัว>-<รหัสขนาด> เช่น 01-MN-L แปลว่า (เสื้อกันหนาว)-(สีเลือดหมู)-(ไซส์ L) และให้พิมพ์คำอธิบาย แบบ "Product: Large Maroon Sweat shirt"

Program.cs — บังคับใช้
// SKU = Stock Keeping Unit. 
// SKU value format: <product #>-<2-letter color code>-<size code>
string sku = "01-MN-L";

string[] product = sku.Split('-');

string type = "";
string color = "";
string size = "";

if (product[0] == "01")
{
    type = "Sweat shirt";
} else if (product[0] == "02")
{
    type = "T-Shirt";
} else if (product[0] == "03")
{
    type = "Sweat pants";
}
else
{
    type = "Other";
}

if (product[1] == "BL")
{
    color = "Black";
} else if (product[1] == "MN")
{
    color = "Maroon";
} else
{
    color = "White";
}

if (product[2] == "S")
{
    size = "Small";
} else if (product[2] == "M")
{
    size = "Medium";
} else if (product[2] == "L")
{
    size = "Large";
} else
{
    size = "One Size Fits All";
}

Console.WriteLine($"Product: {size} {color} {type}");

โจทย์: แปลงโค้ดชุดนี้ให้ใช้ switch statement แทน if-elseif-else ทั้งหมด โดยผลลัพธ์ต้องเหมือนเดิมทุกประการ:

ผลลัพธ์ที่ต้องได้
Product: Large Maroon Sweat shirt
ℹ️ เมธอดใหม่: string.Split() sku.Split('-') ตัดสตริงออกเป็นชิ้นๆ ตามอักขระที่กำหนด (ในที่นี้คือ -) แล้วคืนผลเป็น array ของ string เช่น "01-MN-L".Split('-') จะได้ { "01", "MN", "L" } เข้าถึงแต่ละชิ้นด้วย index ตามปกติ (product[0], product[1], product[2]) — จะได้เรียน เมธอดจัดการ string แบบเจาะลึกใน Part 4 ของเล่มนี้
🔓 ดูเฉลย
Program.cs — เฉลย 
// SKU = Stock Keeping Unit
string sku = "01-MN-L";

string[] product = sku.Split('-');

string type = "";
string color = "";
string size = "";

switch (product[0])
{
    case "01":
        type = "Sweat shirt";
        break;
    case "02":
        type = "T-Shirt";
        break;
    case "03":
        type = "Sweat pants";
        break;
    default:
        type = "Other";
        break;
}

switch (product[1])
{
    case "BL":
        color = "Black";
        break;
    case "MN":
        color = "Maroon";
        break;
    default:
        color = "White";
        break;
}

switch (product[2])
{
    case "S":
        size = "Small";
        break;
    case "M":
        size = "Medium";
        break;
    case "L":
        size = "Large";
        break;
    default:
        size = "One Size Fits All";
        break;
}

Console.WriteLine($"Product: {size} {color} {type}");
Output
Product: Large Maroon Sweat shirt

นี่เป็นเพียงหนึ่งในหลายวิธีที่แก้โจทย์นี้ได้ ตราบใดที่ผลลัพธ์ตรงกัน และใช้ switch-case แทน if-elseif-else สำเร็จ ก็ถือว่าทำโจทย์นี้ผ่านแล้ว

สังเกตว่าโค้ดชุดนี้ต้องใช้ switch ถึง 3 ชุดแยกกัน (คนละตัวแปร คนละ match expression) — เพราะแต่ละ switch จับคู่ได้แค่ค่าเดียวต่อครั้ง นี่คือจุดต่างสำคัญ จาก if ที่รวมเงื่อนไขหลายตัวแปรไว้ในนิพจน์เดียวได้ (ทบทวนตัวอย่าง permission/level จาก บทที่ 14 ที่ if ทำได้ในโครงสร้างเดียว)

16.4 ⚠️ กับดักที่พบบ่อย

อาการสาเหตุ / วิธีแก้
ลืม break ท้าย switch section compile error ทันที (ต่างจากหลายภาษาที่ปล่อยผ่านแบบ fall-through) — เพิ่ม break; (หรือ return;) ท้ายทุก section เสมอ
คิดว่า switch เดียวเช็คได้หลายตัวแปรพร้อมกัน switch จับคู่ได้แค่ค่าเดียวต่อครั้ง — ถ้าต้องเช็คหลายตัวแปรร่วมกัน (เช่น permission และ level พร้อมกัน) ต้องใช้ if หรือใช้ switch หลายชุดแยกกัน
คาดว่า default รันเสมอ default รันแค่ตอนไม่มี case ไหนตรงเท่านั้น ไม่ใช่รันคู่กับ case ที่ตรงด้วย
ชนิดข้อมูลของ case label ไม่ตรงกับ switch expression เช่น switch (employeeLevel) เป็น int แต่เขียน case "200": (string) — ต้องให้ชนิดข้อมูลตรงกันเสมอ

16.5 ❓ Knowledge Check

คำถามชุดนี้แปลจาก Microsoft Learn (3 ข้อฝังในเนื้อหา + 2 ข้อ Module Assessment)

1. จุดประสงค์ของ default case ใน switch statement คืออะไร?

  • Aใช้ระบุเงื่อนไขของ switch statement
  • Bใช้จบ switch statement
  • Cใช้รันโค้ดบล็อกหนึ่ง เมื่อไม่มี case ไหนตรงกับ expression
เฉลย: ข้อ C. นิยามตรงตัว — default ไม่ใช่ตัวกำหนดเงื่อนไข (ข้อ A) และไม่ใช่ตัวสั่งจบ statement โดยตรง (ข้อ B คือหน้าที่ของ break)

2. ถ้าลืม break (หรือคีย์เวิร์ดทางเลือกที่ป้องกัน fall-through) ใน switch case จะเกิดอะไรขึ้น?

  • Adefault case จะทำงานแทน
  • Bส่วนของ case ที่ได้รับผลกระทบจะถูกคอมไพเลอร์ลบทิ้ง
  • Cคอมไพเลอร์จะสร้าง error
เฉลย: ข้อ C. C# บังคับให้ทุก switch section ต้องจบอย่างชัดเจน เสมอ ต่างจากภาษาที่ยอมให้ fall-through แบบเงียบๆ — ถ้าลืม break จะได้ compile error ทันที ไม่ใช่ error ตอนรัน และไม่มีการ "ลบทิ้ง" หรือ "ใช้ default แทน" อัตโนมัติ

ข้อ 1ง่าย

เขียน switch statement รับตัวแปร int day = 3; (1=จันทร์ ... 7=อาทิตย์) พิมพ์ชื่อวันเป็นภาษาไทย ถ้าไม่ตรง 1-7 ให้พิมพ์ "ไม่ถูกต้อง"

ดูเฉลย
Program.cs
int day = 3;
string dayName;

switch (day)
{
    case 1:
        dayName = "จันทร์";
        break;
    case 2:
        dayName = "อังคาร";
        break;
    case 3:
        dayName = "พุธ";
        break;
    case 4:
        dayName = "พฤหัสบดี";
        break;
    case 5:
        dayName = "ศุกร์";
        break;
    case 6:
        dayName = "เสาร์";
        break;
    case 7:
        dayName = "อาทิตย์";
        break;
    default:
        dayName = "ไม่ถูกต้อง";
        break;
}

Console.WriteLine(dayName);
ข้อ 2ง่าย

ต่อจากข้อ 1 ใช้เทคนิค "หลาย label ต่อ 1 section" รวมวันเสาร์-อาทิตย์ (6,7) ให้พิมพ์ "วันหยุดสุดสัปดาห์" แทนชื่อวันเดี่ยวๆ

ดูเฉลย
Program.cs (ส่วนที่แก้)
case 6:
case 7:
    dayName = "วันหยุดสุดสัปดาห์";
    break;
ข้อ 3ง่าย

โค้ดนี้ compile ไม่ผ่าน หาสาเหตุ:

Program.cs (ผิด)
int grade = 90;
string result;

switch (grade)
{
    case 90:
        result = "ผ่าน";
    default:
        result = "ไม่ผ่าน";
        break;
}

Console.WriteLine(result);
ดูเฉลย

ขาด break; หลัง case 90: ทำให้เกิด compile error (C# ไม่อนุญาตให้ fall-through แบบเงียบๆ) ต้องเพิ่ม break; ก่อนถึงบรรทัด default:

ข้อ 4กลาง

แปลงโค้ดนี้จาก if-elseif-else เป็น switch statement:

Program.cs (ก่อนแก้)
string season = "summer";
string activity;

if (season == "summer")
{
    activity = "ว่ายน้ำ";
}
else if (season == "winter")
{
    activity = "เล่นสกี";
}
else
{
    activity = "เดินป่า";
}

Console.WriteLine(activity);
ดูเฉลย
Program.cs (หลังแก้)
string season = "summer";
string activity;

switch (season)
{
    case "summer":
        activity = "ว่ายน้ำ";
        break;
    case "winter":
        activity = "เล่นสกี";
        break;
    default:
        activity = "เดินป่า";
        break;
}

Console.WriteLine(activity);
ข้อ 5กลาง

ใช้ string.Split() แยกวันที่รูปแบบ "2026-09-04" (ปี-เดือน-วัน คั่นด้วย -) ออกเป็น array แล้วใช้ switch statement แปลง เลขเดือน (index 1) เป็นชื่อเดือนภาษาไทยแบบย่อ (01=ม.ค., 02=ก.พ., ... อย่างน้อย 3 เดือนแรกพอ ที่เหลือ default เป็น "เดือนอื่น")

ดูเฉลย
Program.cs
string date = "2026-09-04";
string[] parts = date.Split('-');
string monthName;

switch (parts[1])
{
    case "01":
        monthName = "ม.ค.";
        break;
    case "02":
        monthName = "ก.พ.";
        break;
    case "03":
        monthName = "มี.ค.";
        break;
    default:
        monthName = "เดือนอื่น";
        break;
}

Console.WriteLine(monthName);
ข้อ 6ท้าทาย

ขยายโจทย์ SKU จากหัวข้อ 16.3 ให้รองรับรหัสสีเพิ่มอีก 2 สี: "RD" = Red, "BU" = Blue (ยังคง default เป็น White เหมือนเดิม) แล้วทดสอบด้วย sku = "02-RD-S"; ควรได้ผลลัพธ์ Product: Small Red T-Shirt

ดูเฉลย
Program.cs (switch สีที่แก้)
switch (product[1])
{
    case "BL":
        color = "Black";
        break;
    case "MN":
        color = "Maroon";
        break;
    case "RD":
        color = "Red";
        break;
    case "BU":
        color = "Blue";
        break;
    default:
        color = "White";
        break;
}

เปลี่ยน sku = "02-RD-S"; → product[0]="02"→T-Shirt, product[1]="RD"→Red, product[2]="S"→Small → Product: Small Red T-Shirt ✓

📌 สรุปบทที่ 16

เป้าหมายของบทนี้คือเพิ่มตรรกะแตกสาขาที่จับคู่ตัวแปรหรือ expression หนึ่งตัว กับค่าที่เป็นไปได้ หลายแบบ ด้วย switch-case construct คุณจับคู่ระดับตัวเลขของพนักงานกับตำแหน่ง คุณใช้ switch-case แทน if-elseif-else เพื่อสื่อเจตนาของการแปลง รหัส SKU (Stock Keeping Unit) ให้เป็นคำอธิบายแบบเต็มได้กระชับขึ้น

นักพัฒนา C# ใช้ selection statement ทั้ง if และ switch ร่วมกับ conditional operator เพื่อแตกสาขาโค้ด ประสบการณ์ที่คุณได้จากการใช้ selection statement เหล่านี้ ช่วยให้คุณเลือกเครื่องมือ C# ที่เหมาะสมที่สุดในการสื่อเจตนาผ่านโค้ดของคุณได้
