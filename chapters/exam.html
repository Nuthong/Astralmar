💡 ถึงจุดนี้แล้ว คุณพร้อมแล้วจริงๆ ถ้าคุณอ่านและฝึกทำแบบฝึกหัดมาครบทั้ง 6 Part (บทที่ 1-38) คุณมีความรู้ครบตามที่ใบรับรองนี้ ต้องการแล้ว — บทนี้ไม่ใช่เนื้อหาใหม่ แต่เป็นคู่มือสอบจริงพร้อมข้อสอบจำลองให้ลองทำก่อน

เกี่ยวกับใบรับรองนี้

Foundational C# with Microsoft Certification เป็นใบรับรองฟรีที่ Microsoft ร่วมมือ กับ freeCodeCamp เปิดให้ทุกคนทั่วโลกสอบได้โดยไม่มีค่าใช้จ่าย ประกอบด้วยสองส่วน:

  • คอร์สเรียน — เนื้อหาการฝึกอบรมจาก Microsoft Learn ประมาณ 35 ชั่วโมง แบ่งเป็น 6 Learning Path (ตรงกับ Part 1-6 ของหนังสือเล่มนี้) แต่ละบทเรียนมีลิงก์ไปยังโมดูล Microsoft Learn ที่ต้องทำเป็นการบ้าน พร้อมคำถามเช็คความเข้าใจ
  • ข้อสอบออนไลน์ — จัดสอบผ่านแพลตฟอร์มของ freeCodeCamp เมื่อผ่านแล้วจะได้ใบรับรอง ที่ verify ได้จริง นำไปใส่ Resume, LinkedIn หรือ CV ได้

ก่อนสอบต้องทำอะไรบ้าง

  1. ทำโมดูล Microsoft Learn ทั้ง 6 Learning Path ให้ครบ (เนื้อหาตรงกับ Part 1-6 ของ หนังสือเล่มนี้ทุกประการ) — ระบบของ freeCodeCamp จะเชื่อมกับ transcript ของ Microsoft Learn อัตโนมัติ เพื่อยืนยันว่าคุณทำครบจริง
  2. เซ็นรับรอง Academic Honesty Pledge ของ freeCodeCamp (คำมั่นว่าจะทำข้อสอบด้วย ตัวเอง ไม่ทุจริต)
  3. เตรียมเวลาว่างต่อเนื่องอย่างน้อย 1 ชั่วโมงเต็ม — ข้อสำคัญมาก: เมื่อเริ่มสอบแล้ว จะออกจากหน้าสอบไม่ได้ ถ้าออกกลางคันจะเสียความคืบหน้าทั้งหมดและต้องเริ่มใหม่

รูปแบบข้อสอบจริง

รายละเอียดข้อมูล
จำนวนข้อ80 ข้อ แบบปรนัย (multiple-choice)
เวลาจับเวลาไว้ แต่ไม่มีขีดจำกัดเวลาตายตัว (ทำได้เกิน 1 ชั่วโมง) — แต่ห้ามออกจากหน้าสอบระหว่างทำเด็ดขาด
แพลตฟอร์มเว็บไซต์ freeCodeCamp
เนื้อหาที่ครอบคลุม6 ทักษะ: สร้างแอปแรก, เขียนแอปพื้นฐาน, สร้าง method, เพิ่ม logic, จัดการข้อมูลตัวแปร, debug แอป — ตรงกับ Part 1-6 ของหนังสือเล่มนี้เป๊ะ

เทคนิคการทำข้อสอบ

  • อ่านโจทย์และตัวเลือกให้ละเอียด — ข้อสอบเป็น multiple-choice ที่บางข้ออาจมี ตัวเลือกใกล้เคียงกันมาก (เช่น != กับ !, catch เจาะจงชนิดกับ catch ทั่วไป) ต้องอ่านให้รอบคอบ
  • อย่าเร่งรีบตอนเตรียมตัว — เข้าใจให้ลึกสำคัญกว่าทำเร็ว แม้แต่คนที่มีพื้นฐาน C# มาก่อนก็ยังพบว่าเนื้อหาบางส่วน (โดยเฉพาะเรื่อง debugging) มีอะไรใหม่ให้เรียนรู้เสมอ
  • ทบทวน Part 6 (Debugging) เป็นพิเศษ — เป็น Part ที่มักถูกมองข้ามเพราะอยู่ท้ายเล่ม แต่มีสัดส่วนในข้อสอบเท่าๆ กับ Part อื่น
  • เตรียมพื้นที่เงียบและเวลาว่างจริงๆ ก่อนเริ่มสอบ เพราะออกกลางคันไม่ได้

Part 1 · Write Your First Code

1. เมธอดใดพิมพ์ข้อความออกคอนโซลแล้วไม่ขึ้นบรรทัดใหม่ต่อท้าย?

  • AConsole.WriteLine()
  • BConsole.Write()
  • CConsole.Print()
เฉลย: ข้อ B. ทบทวนบทที่ 1

2. ชนิดข้อมูลใดเหมาะกับการเก็บเงิน (ต้องการความแม่นยำสูงกับทศนิยม)?

  • Adouble
  • Bdecimal
  • Cfloat
เฉลย: ข้อ B. ทบทวนบทที่ 2

3. string interpolation เขียนขึ้นต้นด้วยสัญลักษณ์ใด?

  • A@
  • B$
  • C#
เฉลย: ข้อ B. ทบทวนบทที่ 3

4. ผลลัพธ์ของ 7 / 2 เมื่อทั้งสองค่าเป็น int คือเท่าไหร่?

  • A3.5
  • B3
  • C4
เฉลย: ข้อ B. integer division ตัดเศษทศนิยมทิ้ง — ทบทวนบทที่ 4

5. Guided Project ของ Part 1 (คำนวณเกรดนักเรียน) ฝึกเรื่องใดเป็นหลัก?

  • Aผสมผสาน variable, การคำนวณ, และ string formatting เข้าด้วยกันในโปรเจกต์เดียว
  • Bการเขียน class และ object
  • Cการเชื่อมต่อฐานข้อมูล
เฉลย: ข้อ A. ทบทวนบทที่ 5-6

Part 2 · Console Applications

6. array ใน C# เริ่มนับ index จากเลขอะไร?

  • A0
  • B1
  • C-1
เฉลย: ข้อ A. ทบทวนบทที่ 10

7. เข้าถึง index ที่เกินขอบเขตของ array จะเกิด exception ชนิดใด?

  • ANullReferenceException
  • BIndexOutOfRangeException
  • CFormatException
เฉลย: ข้อ B. ทบทวนบทที่ 10

8. ข้อใดคือชื่อตัวแปรแบบ camelCase ที่ถูกต้อง?

  • ATotal_Score
  • BtotalScore
  • CTOTALSCORE
เฉลย: ข้อ B. ทบทวนบทที่ 11

9. เมธอด static ของ .NET class library ที่เรียกใช้ได้โดยไม่ต้องสร้าง object ก่อน เรียกว่าอะไร?

  • Astateless method
  • Bstateful method
  • Cabstract method
เฉลย: ข้อ A. ทบทวนบทที่ 8

10. Challenge Project ของ Part 2 ต่างจาก Guided Project อย่างไร?

  • Aไม่มีคำแนะนำทีละขั้นอย่างเป็นทางการ ต้องออกแบบเองมากกว่า
  • Bใช้ภาษาอื่นแทน C#
  • Cไม่มีการให้คะแนน
เฉลย: ข้อ A. ทบทวนบทที่ 13

Part 3 · Add Logic

11. ตัวดำเนินการเงื่อนไข (conditional/ternary operator) เขียนในรูปแบบใด?

  • Aเงื่อนไข ? จริง : เท็จ
  • Bเงื่อนไข : จริง ? เท็จ
  • Cif(เงื่อนไข){จริง}{เท็จ}
เฉลย: ข้อ A. ทบทวนบทที่ 14

12. ตัวแปรที่ประกาศข้างใน code block ของ if จะมี scope แค่ไหน?

  • Aใช้ได้เฉพาะภายใน block นั้นเท่านั้น
  • Bใช้ได้ทั้งไฟล์
  • Cใช้ได้เฉพาะใน method อื่นที่เรียกมา
เฉลย: ข้อ A. ทบทวนบทที่ 15

13. switch-case ใน C# ต่างจาก C/Java ตรงไหน?

  • Aไม่มี fall-through อัตโนมัติ ไม่ต้องใส่ break เพื่อกันตกหล่น
  • Bใช้ได้กับ string ไม่ได้
  • Cต้องมี default เสมอ
เฉลย: ข้อ A. ทบทวนบทที่ 16

14. for statement มีกี่ส่วนหลัก?

  • A2 (เงื่อนไข, การทำงาน)
  • B3 (initializer, condition, iterator)
  • C4
เฉลย: ข้อ B. ทบทวนบทที่ 17

15. do-while ต่างจาก while ตรงไหน?

  • Ado-while รัน code block อย่างน้อยหนึ่งครั้งก่อนเช็คเงื่อนไข
  • Bdo-while ใช้กับ array เท่านั้น
  • Cไม่มีความต่างกันเลย
เฉลย: ข้อ A. ทบทวนบทที่ 18

Part 4 · Variable Data

16. array เป็น value type หรือ reference type?

  • Areference type — แก้ไขข้างใน method กระทบตัวต้นฉบับด้วย
  • Bvalue type — copy ค่าไปให้เสมอ
  • Cไม่จัดอยู่ในทั้งสองประเภท
เฉลย: ข้อ A. ทบทวนบทที่ 21

17. เมธอดใดแปลง string เป็นตัวเลขโดยไม่ throw exception ถ้าแปลงไม่ได้?

  • Aint.Parse()
  • Bint.TryParse()
  • CConvert.ToInt32()
เฉลย: ข้อ B. ทบทวนบทที่ 22

18. เมธอดใดของ array ใช้เรียงลำดับข้อมูล?

  • AArray.Sort()
  • BArray.Reverse()
  • CArray.Clear()
เฉลย: ข้อ A. ทบทวนบทที่ 23

19. composite format specifier :C ใช้จัดรูปแบบอะไร?

  • Aสกุลเงิน (currency)
  • Bเปอร์เซ็นต์
  • Cวันที่
เฉลย: ข้อ A. ทบทวนบทที่ 24

20. เมธอดใดของ string ใช้หาตำแหน่งของ substring?

  • AIndexOf()
  • BLength
  • CToUpper()
เฉลย: ข้อ A. ทบทวนบทที่ 25

Part 5 · Create Methods

21. optional parameter ต้องอยู่ตำแหน่งไหนใน method signature?

  • Aต้องมาหลัง required parameter เสมอ
  • Bต้องมาก่อน required parameter เสมอ
  • Cตำแหน่งไหนก็ได้
เฉลย: ข้อ A. ทบทวนบทที่ 29

22. named argument ช่วยเรื่องอะไรตอนเรียก method?

  • Aระบุชัดว่า argument แต่ละตัวตรงกับ parameter ไหน อ่านง่ายขึ้น
  • Bทำให้ method ทำงานเร็วขึ้น
  • Cลด parameter ที่ต้องใช้
เฉลย: ข้อ A. ทบทวนบทที่ 29

23. compile error "not all code paths return a value" เกิดจากอะไร?

  • Amethod มี return type ไม่ใช่ void แต่บางเส้นทางในโค้ดไม่มี return
  • Bลืมใส่เซมิโคลอน
  • Cเรียก method ก่อนนิยาม
เฉลย: ข้อ A. ทบทวนบทที่ 30

24. pass-by-value หมายความว่าอย่างไร?

  • Amethod ได้รับ "สำเนา" ของค่า แก้ไขข้างในไม่กระทบตัวแปรต้นฉบับ
  • Bmethod ได้รับตัวแปรต้นฉบับโดยตรง แก้ไขข้างในกระทบต้นฉบับเสมอ
  • Cใช้ได้กับ array เท่านั้น
เฉลย: ข้อ A. ทบทวนบทที่ 29

25. Fisher-Yates algorithm ใช้ทำอะไร?

  • Aสับเปลี่ยน (shuffle) array แบบสุ่มไม่ bias
  • Bเรียงลำดับ array
  • Cค้นหาค่าใน array
เฉลย: ข้อ A. ทบทวนบทที่ 31

Part 6 · Debug Applications

26. ข้อผิดพลาดที่เกิดตอน build (เช่น syntax ผิด) เรียกว่าอะไร?

  • Aerror — ไม่ใช่ exception เพราะไม่ได้เกิดตอน runtime
  • Bexception เหมือนกัน
  • Cwarning เสมอ
เฉลย: ข้อ A. ทบทวนบทที่ 33

27. ปุ่มใดบน Debug toolbar ใช้ "ข้าม" การดูรายละเอียดข้างใน method ที่เรียก?

  • AStep Over
  • BStep Into
  • CStep Out
เฉลย: ข้อ A. ทบทวนบทที่ 34

28. code block ใดของ try-catch-finally ที่รันเสมอไม่ว่าจะเกิด exception หรือไม่?

  • Afinally
  • Btry
  • Ccatch
เฉลย: ข้อ A. ทบทวนบทที่ 35

29. เมื่อมีหลาย catch ต่อกัน ลำดับที่ถูกต้องคือ?

  • Aเจาะจงชนิดที่สุดก่อน แล้วค่อยกว้างขึ้นเรื่อยๆ (Exception ทั่วไปอยู่ล่างสุด)
  • Bกว้างที่สุดก่อนเสมอ
  • Cลำดับไม่มีผลอะไร
เฉลย: ข้อ A. ทบทวนบทที่ 35

30. throw; (ไม่มี operand) ใน catch block ทำอะไร?

  • Are-throw exception object เดิม รักษา StackTrace เดิมไว้
  • Bสร้าง exception ใหม่ทุกครั้ง
  • Cทำให้ compile error เสมอ
เฉลย: ข้อ A. ทบทวนบทที่ 36
