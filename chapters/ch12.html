12.1 สถานการณ์: อัปเกรดแอปตัดเกรด

การแตกสาขาโค้ดและการวนซ้ำ code block เป็นความสามารถที่จำเป็นมากสำหรับนักพัฒนา ใน C# if ใช้ประเมิน expression และแตกเส้นทางการทำงาน ส่วน code block ของ foreach ใช้วนผ่านทุก element ของ array ได้ พอผสานความสามารถทั้งสองเข้าด้วยกัน จะสร้างแอปที่ทรงพลังและขยายต่อได้ง่ายขึ้นมาก

สมมติคุณยังเป็นผู้ช่วยครูคนเดิมจากบทที่ 5 ทักษะ C# ของคุณพัฒนาขึ้นมากแล้วนับตั้งแต่ทำ เวอร์ชันแรกของแอปตัดเกรด ครูขอให้อัปเดตแอป โดยเน้นใช้ array, foreach, และ if พร้อมรวมคะแนนพิเศษ (extra credit) เข้าไปในการคำนวณเกรดสุดท้ายด้วย

จบบทนี้ คุณจะมีประสบการณ์พัฒนาแอปที่ใช้ array, foreach, และ if ร่วมกัน และคุ้นเคยกับการสร้างแอปที่ประมวลผลข้อมูลอย่างมีประสิทธิภาพด้วย nested iteration และ selection statement

12.2 เตรียมพร้อม: โจทย์และข้อกำหนด

ภาพรวมโปรเจกต์

ข้อกำหนดของแอปเวอร์ชันใหม่:

  • เริ่มจากนักเรียน 4 คน แต่ละคนมีคะแนนสอบ 5 ครั้ง (0–100)
  • คะแนนรวมของนักเรียนคือค่าเฉลี่ยของคะแนนสอบ 5 ครั้ง
  • คะแนนพิเศษ (extra credit): เก็บไว้ใน array คะแนนของนักเรียนเดียวกัน มีค่า10% ของคะแนนสอบปกติตอนคำนวณเกรดสุดท้าย ต้องบวกเข้าไปในผลรวมก่อนคำนวณเกรด (ยอมรับความคลาดเคลื่อนจากการปัดเศษได้)

12.3 ขั้นที่ 1: แปลงเป็น Array และรวมคะแนนด้วย foreach

แปลงตัวแปรคะแนนดิบเป็น Array

แทนที่ตัวแปร sophia1...sophia5 ด้วย array เดียว — initialize ค่าตรงตอนประกาศเลย เพราะรู้ค่าล่วงหน้าแล้ว:

Program.cs 
int[] sophiaScores = new int[] { 90, 86, 87, 98, 100 };
int[] andrewScores = new int[] { 92, 89, 81, 96, 90 };
int[] emmaScores = new int[] { 90, 85, 87, 98, 68 };
int[] loganScores = new int[] { 90, 95, 87, 88, 96 };

ลบตัวแปรเดี่ยวๆ ทั้ง 20 ตัว (sophia1...logan5) ทิ้งได้เลย — ไม่ต้องใช้แล้ว

ℹ️ ทำไม initialize ตรงๆ ถึงเหมาะกับกรณีนี้ เมื่อรู้ค่าล่วงหน้าแล้วและไม่น่าจะเปลี่ยนบ่อย (เช่น คะแนนสอบที่ให้ไปแล้ว) การกำหนดค่าตอน ประกาศแบบนี้เหมาะสมกว่า — ถ้าไม่รู้ค่าล่วงหน้า (เช่น รอผู้ใช้กรอก) ต้องประกาศแบบว่างก่อน แล้วค่อยกำหนดทีหลัง

สร้าง foreach รวมคะแนนของ Sophia

ตอนนี้ลองโฟกัสแค่ Sophia คนเดียวก่อน (ยังไม่ลบ sophiaSum/sophiaScore) แทนสูตรบวกตรงๆ ด้วย foreach:

Program.cs 
int[] sophiaScores = new int[] { 90, 86, 87, 98, 100 };
int[] andrewScores = new int[] { 92, 89, 81, 96, 90 };
int[] emmaScores = new int[] { 90, 85, 87, 98, 68 };
int[] loganScores = new int[] { 90, 95, 87, 88, 96 };

int sophiaSum = 0;

decimal sophiaScore;

foreach (int score in sophiaScores)
{
    // add the exam score to the sum
    sophiaSum += score;
}

sophiaScore = (decimal)sophiaSum / currentAssignments;

Console.WriteLine("Student\t\tGrade\n");
Console.WriteLine("Sophia:\t\t" + sophiaScore + "\tA-");

Console.WriteLine("Press the Enter key to continue");
Console.ReadLine();

Press the Enter key to continue
💡 ทำไมถึงทำแค่คนเดียวก่อน แบบเดียวกับที่บทที่ 5 สอนไว้: แตกปัญหาใหญ่เป็นชิ้นเล็ก แล้วเช็คผลบ่อยๆ พิสูจน์ให้ตัวเองมั่นใจ ว่า pattern ที่คิดไว้ (foreach รวมคะแนน) ใช้ได้กับคนเดียวก่อน ค่อยขยายไปทุกคนทีหลัง

12.4 ขั้นที่ 2: ลูปซ้อนประมวลผลนักเรียนทุกคน

หัวข้อนี้คือหัวใจของการรีแฟกเตอร์ — สร้าง array ชื่อนักเรียน วนด้วย foreach ชั้นนอก แล้วข้างในใช้ if เลือก array คะแนนที่ตรงกับชื่อปัจจุบัน

สร้าง Array ชื่อนักเรียน + Loop ชั้นนอก

Program.cs 
// Student names
string[] studentNames = new string[] { "Sophia", "Andrew", "Emma", "Logan" };

foreach (string name in studentNames)
{
    Console.WriteLine($"{name}");
}

รันดูก่อน — ควรเห็นชื่อทั้ง 4 คนพิมพ์ออกมา ตามด้วยรายงานคะแนนของ Sophia เหมือนเดิม (เพราะยังไม่ได้ย้ายโค้ดคำนวณเข้าไปในลูปนี้)

ย้ายโค้ดคำนวณเข้าไปในลูปชื่อ

ย้ายโค้ดคำนวณและแสดงผลของ Sophia จากด้านนอก เข้าไปอยู่ข้างใน code block ของ foreach (name in studentNames):

Program.cs — ย้ายเข้าไปในลูปชื่อ 
foreach (string name in studentNames)
{
    int sophiaSum = 0;
    decimal sophiaScore;

    foreach (int score in sophiaScores)
    {
        sophiaSum += score;
    }

    sophiaScore = (decimal)sophiaSum / currentAssignments;

    Console.WriteLine("Student\t\tGrade\n");
    Console.WriteLine("Sophia:\t\t" + sophiaScore + "\tA-");
}

ตอนนี้โค้ดคำนวณ Sophia ทำงานซ้ำ 4 รอบ (เพราะอยู่ในลูปที่วน 4 ชื่อ) แต่ยังโชว์แค่ Sophia ทุกรอบอยู่ดี — ต้องเพิ่ม if จำกัดว่าให้ทำงานเฉพาะตอนชื่อปัจจุบันคือ Sophia จริงๆ:

Program.cs 
foreach (string name in studentNames)
{
    if (name == "Sophia")
    {
        int sophiaSum = 0;
        decimal sophiaScore;

        foreach (int score in sophiaScores)
        {
            sophiaSum += score;
        }

        sophiaScore = (decimal)sophiaSum / currentAssignments;

        Console.WriteLine("Student\t\tGrade\n");
        Console.WriteLine("Sophia:\t\t" + sophiaScore + "\tA-");
    }
}
Output
Student		Grade

Sophia:		92.2	A-

ดีขึ้น — แสดงแค่ Sophia ครั้งเดียว ไม่ซ้ำ 4 รอบแล้ว แต่ยังไม่ใช่เป้าหมายสุดท้าย เพราะ ยังต้องพิมพ์ if แยกทีละคนแบบนี้ไปเรื่อยๆ (ยังไม่ยืดหยุ่นพอ) ขั้นถัดไปคือทำให้โค้ดคำนวณ "ใช้ได้กับทุกคน" ไม่ใช่ผูกติดกับ Sophia คนเดียว

ใช้ if-elseif เลือก Array คะแนนตามชื่อ

สร้างตัวแปร array กลาง studentScores ที่ "เป็นกลาง" ไม่ผูกกับใครคนใดคนหนึ่ง แล้วใช้ if-elseif กำหนดว่าจะ "เอา array ของใครมาใส่" ตามชื่อปัจจุบัน:

Program.cs 
int[] studentScores = new int[10];

foreach (string name in studentNames)
{
    string currentStudent = name;

    if (currentStudent == "Sophia")
        studentScores = sophiaScores;

    else if (currentStudent == "Andrew")
        studentScores = andrewScores;

    else if (currentStudent == "Emma")
        studentScores = emmaScores;

    else if (currentStudent == "Logan")
        studentScores = loganScores;

    // ... โค้ดคำนวณเดิมของ Sophia อยู่ตรงนี้ (จะแก้ต่อในขั้นถัดไป)
}
ℹ️ if โดยไม่มีปีกกาก็ได้ ถ้ามีแค่บรรทัดเดียว สังเกตว่า if (currentStudent == "Sophia") studentScores = sophiaScores; ไม่มี { } — C# อนุญาตให้ละปีกกาได้ถ้า code block มีแค่ 1 บรรทัด (ทบทวนกับดัก นี้ได้ที่ บทที่ 9) ในโปรเจกต์จริงหลายทีมนิยมใส่ปีกกาเสมอเพื่อกันบั๊ก แต่ในบทนี้เราตามสไตล์ต้นฉบับ MS Learn ที่ละไว้ได้เพื่อความกระชับ

ทำให้ตัวแปรคำนวณ "เป็นกลาง" ไม่ผูกกับ Sophia

เปลี่ยน sophiaSum→sumAssignmentScores, sophiaScore→currentStudentGrade, และเปลี่ยน foreach ชั้นในให้วน studentScores (ตัวแปรกลาง) แทน sophiaScores (ตัวแปรเฉพาะคน):

Program.cs — ฉบับสมบูรณ์ของขั้นนี้ 
int[] sophiaScores = new int[] { 90, 86, 87, 98, 100 };
int[] andrewScores = new int[] { 92, 89, 81, 96, 90 };
int[] emmaScores = new int[] { 90, 85, 87, 98, 68 };
int[] loganScores = new int[] { 90, 95, 87, 88, 96 };

// Student names
string[] studentNames = new string[] { "Sophia", "Andrew", "Emma", "Logan" };

int[] studentScores = new int[10];

// Write the Report Header to the console
Console.WriteLine("Student\t\tGrade\n");

foreach (string name in studentNames)
{
    string currentStudent = name;

    if (currentStudent == "Sophia")
        studentScores = sophiaScores;

    else if (currentStudent == "Andrew")
        studentScores = andrewScores;

    else if (currentStudent == "Emma")
        studentScores = emmaScores;

    else if (currentStudent == "Logan")
        studentScores = loganScores;

    // initialize/reset the sum of scored assignments
    int sumAssignmentScores = 0;

    // initialize/reset the calculated average of exam + extra credit scores
    decimal currentStudentGrade = 0;

    foreach (int score in studentScores)
    {
        sumAssignmentScores += score;
    }

    currentStudentGrade = (decimal)(sumAssignmentScores) / currentAssignments;

    Console.WriteLine($"{currentStudent}\t\t{currentStudentGrade}\t?");
}

Console.WriteLine("Press the Enter key to continue");
Console.ReadLine();
Output
Student		Grade

Sophia		92.2	?
Andrew		89.6	?
Emma		85.6	?
Logan		91.2	?
Press the Enter key to continue
✅ ก้าวสำคัญ! คราวนี้ตัวเลขทั้ง 4 คนขึ้นครบถูกต้อง! แค่เกรดตัวอักษรยังเป็น ? อยู่ (จะแก้ในหัวข้อถัดไป) — สังเกตว่าไม่มีตรงไหนในโค้ดคำนวณที่ต้องพิมพ์ชื่อ "Sophia" ตรงๆ อีกแล้ว ยกเว้นแค่ตรง if-elseif ที่เลือก array — นี่คือความยืดหยุ่นที่เราต้องการ

12.5 ขั้นที่ 3: ตัดเกรดอัตโนมัติ + คะแนนพิเศษ

สร้าง if-elseif-else ตัดเกรดจากคะแนน

ประกาศตัวแปรเก็บเกรดตัวอักษร แล้วเทียบคะแนนกับตารางตัดเกรดของครู เรียงจากสูงสุดลงมา — เหมือนหลักการที่เรียนใน บทที่ 9:

Program.cs 
string currentStudentLetterGrade = "";

// ... (หลัง currentStudentGrade = (decimal)(sumAssignmentScores) / currentAssignments;)

if (currentStudentGrade >= 97)
    currentStudentLetterGrade = "A+";

else if (currentStudentGrade >= 93)
    currentStudentLetterGrade = "A";

else if (currentStudentGrade >= 90)
    currentStudentLetterGrade = "A-";

else if (currentStudentGrade >= 87)
    currentStudentLetterGrade = "B+";

else if (currentStudentGrade >= 83)
    currentStudentLetterGrade = "B";

else if (currentStudentGrade >= 80)
    currentStudentLetterGrade = "B-";

else if (currentStudentGrade >= 77)
    currentStudentLetterGrade = "C+";

else if (currentStudentGrade >= 73)
    currentStudentLetterGrade = "C";

else if (currentStudentGrade >= 70)
    currentStudentLetterGrade = "C-";

else if (currentStudentGrade >= 67)
    currentStudentLetterGrade = "D+";

else if (currentStudentGrade >= 63)
    currentStudentLetterGrade = "D";

else if (currentStudentGrade >= 60)
    currentStudentLetterGrade = "D-";

else
    currentStudentLetterGrade = "F";

แก้บรรทัดแสดงผลให้ใช้ currentStudentLetterGrade แทน ?:

Program.cs 
Console.WriteLine($"{currentStudent}\t\t{currentStudentGrade}\t{currentStudentLetterGrade}");

รวมคะแนนพิเศษ (Extra Credit)

ครูให้คะแนนพิเศษของแต่ละคนมา: Sophia (94, 90), Andrew (89), Emma (89, 89, 89), Logan (96) — เพิ่มเข้าไปท้าย array คะแนนเดิม:

Program.cs 
int[] sophiaScores = new int[] { 90, 86, 87, 98, 100, 94, 90 };
int[] andrewScores = new int[] { 92, 89, 81, 96, 90, 89 };
int[] emmaScores = new int[] { 90, 85, 87, 98, 68, 89, 89, 89 };
int[] loganScores = new int[] { 90, 95, 87, 88, 96, 96 };

ปัญหาคือ: foreach ไม่รู้ว่า element ไหนคือ "คะแนนสอบ" (นับเต็ม) กับ "คะแนนพิเศษ" (นับแค่ 10%) ต้องแยกให้ออก — วิธีคือนับลำดับ element ที่กำลังวนอยู่ ถ้าเกินจำนวนวิชาสอบปกติ (5 วิชา) แปลว่าเป็นคะแนนพิเศษ

เปลี่ยนชื่อ currentAssignments เป็น examAssignments ให้สื่อ ความหมายชัดขึ้น (ตอนนี้มีทั้งคะแนนสอบและคะแนนพิเศษแล้ว) — อย่าลืมเปลี่ยนให้ครบทุกจุดที่ใช้ ชื่อนี้ในไฟล์ (ใช้ Find & Replace Ctrl+H ใน VS Code ช่วยได้)

Program.cs 
// initialize/reset a counter for the number of assignments
int gradedAssignments = 0;

foreach (int score in studentScores)
{
    // increment the assignment counter
    gradedAssignments += 1;

    if (gradedAssignments <= examAssignments)
        // add the exam score to the sum
        sumAssignmentScores += score;

    else
        // add the extra credit points to the sum - bonus points equal to 10% of an exam score. rounding errors are acceptable
        sumAssignmentScores += score / 10;
}

ทดสอบความยืดหยุ่น: เพิ่มนักเรียน 4 คน

ตอนนี้มาทดสอบข้อกำหนดสำคัญที่สุด: "ต้องรองรับนักเรียนเพิ่มโดยกระทบโค้ดเดิมน้อยที่สุด" เพิ่ม array คะแนนกับชื่อ 4 คนใหม่:

Program.cs — เพิ่มนักเรียนใหม่ 
int[] beckyScores = new int[] { 92, 91, 90, 91, 92, 92, 92 };
int[] chrisScores = new int[] { 84, 86, 88, 90, 92, 94, 96, 98 };
int[] ericScores = new int[] { 80, 90, 100, 80, 90, 100, 80, 90 };
int[] gregorScores = new int[] { 91, 91, 91, 91, 91, 91, 91 };

string[] studentNames = new string[] { "Sophia", "Andrew", "Emma", "Logan", "Becky", "Chris", "Eric", "Gregor" };

เพิ่ม else if อีก 4 บรรทัดต่อท้ายเชนเดิม พร้อม else ปิดท้ายกัน ไว้ (เผื่อชื่อไม่ตรงกับใครเลย):

Program.cs 
else if (currentStudent == "Becky")
    studentScores = beckyScores;
else if (currentStudent == "Chris")
    studentScores = chrisScores;
else if (currentStudent == "Eric")
    studentScores = ericScores;
else if (currentStudent == "Gregor")
    studentScores = gregorScores;
else
    continue;

Becky		94.8	A

Eric		93.4	A
Gregor		94.6	A
Press the Enter key to continue
ℹ️ คีย์เวิร์ดใหม่: continue continue; สั่งให้ข้ามส่วนที่เหลือของรอบปัจจุบันใน loop แล้วกระโดดไปเริ่มรอบถัดไป ทันที ในที่นี้ใช้เป็นเกราะป้องกัน — ถ้าชื่อในลูปไม่ตรงกับใครในเชน if-elseif เลย (พิมพ์ชื่อผิด หรือลืมเพิ่ม array ให้คนใหม่) โค้ดจะข้ามการคำนวณของคนนั้นไปเลย แทนที่จะ พยายามคำนวณด้วย studentScores ตัวเก่าที่ค้างจากรอบก่อนหน้า (ซึ่งจะให้ผลลัพธ์ผิด แบบเงียบๆ) — continue จะได้เรียนละเอียดในโมดูล loop ขั้นสูงต่อไป
✅ เสร็จสมบูรณ์! เพิ่มนักเรียน 4 คนโดยแก้แค่ 2 จุด: (1) เพิ่ม array คะแนน + ชื่อ (2) เพิ่ม else if อีก 4 บรรทัด — ไม่ต้องแตะโค้ดคำนวณหรือตัดเกรดเลยแม้แต่บรรทัดเดียว นี่คือพลังของการรวม array + foreach + if เข้าด้วยกัน

12.6 ⚠️ กับดักที่พบบ่อย

อาการสาเหตุ / วิธีแก้
ทุกคนได้เกรดเหมือนกันหมด ลืมย้ายตัวแปร sumAssignmentScores ให้ reset เป็น 0 ทุกรอบของ loop ชั้นนอก (ต้องประกาศไว้ข้างใน loop ชื่อ ไม่ใช่นอกสุด)
เปลี่ยนชื่อตัวแปรแล้วโค้ดที่อื่น error เปลี่ยนชื่อไม่ครบทุกจุดที่ใช้ตัวแปรนั้น — ใช้ Find & Replace (Ctrl+H) แทนแก้มือทีละจุด
คะแนนพิเศษถูกนับเต็ม 100% แทนที่จะเป็น 10% ลืมเช็ค gradedAssignments <= examAssignments ก่อนตัดสินว่าเป็น คะแนนสอบหรือคะแนนพิเศษ
เพิ่มนักเรียนใหม่แล้วโปรแกรมค้าง/error ลืมเพิ่ม else if ให้ชื่อใหม่ในเชน — ถ้าไม่มี else { continue; } กันไว้ studentScores จะยังเป็นของคนก่อนหน้า ให้ผลลัพธ์ผิดแบบไม่ error ให้เห็น
เกรดตัวอักษรผิด (เช่น ควรได้ B+ แต่ได้ A-) เรียงลำดับ if-elseif ผิด — ต้องเรียงจากคะแนนสูงสุดลงมาต่ำสุดเสมอ เพราะ C# หยุดที่ เงื่อนไขแรกที่ตรง (ทบทวนที่ บทที่ 9)

12.7 ❓ Knowledge Check

คำถามชุดนี้แปลจาก Module Assessment จริงของบทนี้ใน Microsoft Learn

1. นักพัฒนาเขียนแอปใช้ foreach วน array 20 element ต่อมาต้องอัปเดต array ให้มี 40 element และต้องประมวลผลครบทั้ง 40 element ต้องแก้โค้ดยังไง?

  • Aสร้าง foreach ตัวที่สองวนส่วนที่เพิ่มมา
  • Bไม่ต้องแก้ foreach เลย
  • Cเอา foreach เดิมไปซ้อนไว้ใน foreach ใหม่ที่วน 2 รอบ
เฉลย: ข้อ B. foreach วนตามขนาดจริงของ array เสมอ (ไม่ผูกติดกับตัวเลขคงที่) เพิ่ม element กี่ตัวก็ยังทำงานถูกต้องโดยไม่ต้องแก้อะไรเลย — นี่คือเหตุผลที่บทนี้ให้เพิ่มนักเรียน 4 คนได้โดยแทบไม่แตะโค้ดคำนวณ

2. นักพัฒนาสร้างโครงสร้าง foreach ซ้อนกันเพื่อวนข้อมูลทุก array โดย array แรกเก็บชื่อสถานที่เก็บตัวอย่างน้ำ ส่วน array ที่เหลือเก็บผลตรวจจากแต่ละสถานที่ ข้อความใดถูกต้องเกี่ยวกับวิธีประมวลผล array เหล่านี้?

  • Aarray ผลตรวจแต่ละอันใช้ loop ชั้นนอกได้ ส่วน loop ชั้นในไว้ตรวจสอบสถานที่
  • Bลำดับการประมวลผล array ไม่สำคัญ เพราะยังไงก็ต้องประมวลผลข้อมูลครบทุกอันอยู่ดี
  • Cloop ชั้นนอกต้องประมวลผล array สถานที่ loop ชั้นในต้องประมวลผล array ผลตรวจ
เฉลย: ข้อ C. ตรงกับ pattern ที่ใช้ตลอดบทนี้: loop นอก = "ใคร/ที่ไหน" (studentNames) loop ใน = "ข้อมูลของคนนั้น/ที่นั้น" (studentScores) — สลับกันจะทำให้โครงสร้าง ไม่สมเหตุสมผล เพราะ loop ในต้องรู้ก่อนว่ากำลังประมวลผล "ของใคร" อยู่

12.8 ✍️ แบบฝึกหัดท้ายบท

ข้อ 1ง่าย

เพิ่มนักเรียนคนที่ 9 ชื่อ "Nina" คะแนนสอบ 88, 90, 85, 92, 87 (ไม่มีคะแนนพิเศษ) เข้าไปในแอปที่ทำเสร็จจากหัวข้อ 12.5 — ต้องแก้กี่จุด?

ดูเฉลย

แก้ 3 จุด: (1) เพิ่ม int[] ninaScores = new int[] { 88, 90, 85, 92, 87 }; (2) เพิ่ม "Nina" ใน studentNames array (3) เพิ่ม else if (currentStudent == "Nina") studentScores = ninaScores;

ข้อ 2ง่าย

อธิบายว่าทำไมตัวแปร sumAssignmentScores และ gradedAssignments ต้องถูกประกาศไว้ข้างใน loop ชื่อนักเรียน (ไม่ใช่ประกาศครั้งเดียวข้างนอกสุด)

ดูเฉลย

ถ้าประกาศไว้นอกสุด ค่าจะไม่ถูกรีเซ็ตเป็น 0 ทุกรอบ — คะแนนของนักเรียนคนที่สองจะถูก บวกทับกับผลรวมของคนแรก ทำให้ตัวเลขสะสมผิดเพี้ยนไปเรื่อยๆ ทุกคนถัดไป ต้องประกาศไว้ ข้างในเพื่อให้รีเซ็ตใหม่ทุกครั้งที่เริ่มประมวลผลนักเรียนคนใหม่

ข้อ 3ง่าย

โค้ดนี้ตัดเกรดผิด (นักเรียนคะแนน 85 ควรได้ B แต่กลับได้ A-) หาสาเหตุ:

Program.cs (ผิด)
if (currentStudentGrade >= 80)
    currentStudentLetterGrade = "B-";
else if (currentStudentGrade >= 83)
    currentStudentLetterGrade = "B";
else if (currentStudentGrade >= 90)
    currentStudentLetterGrade = "A-";
ดูเฉลย

เรียงลำดับผิด — ต้องเรียงจากคะแนนสูงสุดไปต่ำสุด (90 → 83 → 80) เพราะ C# หยุดที่ เงื่อนไขแรกที่ตรง คะแนน 85 เจอ >= 80 เป็นจริงตั้งแต่บรรทัดแรก เลยได้ B- ทั้งที่ควรเป็น B

ข้อ 4กลาง

ครูเปลี่ยนกฎ: คะแนนพิเศษให้ค่า 20% ของคะแนนสอบแทนที่จะเป็น 10% แก้โค้ดส่วนที่เกี่ยวข้อง

💡 คำใบ้

หาบรรทัด sumAssignmentScores += score / 10; ในหัวข้อ 12.5

ดูเฉลย
Program.cs
else
    // 20% ของคะแนนสอบ
    sumAssignmentScores += score / 5;

หาร 5 แทนหาร 10 เพราะ 1/5 = 20% (ทบทวนเรื่องหาร int จาก บทที่ 4)

ข้อ 5กลาง

ทำไม else continue; ท้ายเชน if-elseif ถึงสำคัญ? ลองอธิบายว่าจะเกิดอะไรขึ้น ถ้าลืมใส่บรรทัดนี้ แล้ว studentNames มีชื่อที่สะกดผิด เช่น "Sofia" แทน "Sophia" (ตอบเป็นข้อความ ไม่ต้องเขียนโค้ด)

ดูเฉลย

ถ้าไม่มี else continue; เมื่อชื่อไม่ตรงกับเงื่อนไขไหนเลยในเชน if-elseif ตัวแปร studentScores จะยังเก็บค่าจากรอบก่อนหน้า (ของนักเรียนคนที่ประมวลผลไปก่อนหน้านี้) ค้างอยู่ — โปรแกรมจะไม่ error แต่จะคำนวณ และแสดงเกรดผิดคนแบบเงียบๆ ซึ่งอันตรายกว่า error ที่เห็นชัดเจนมาก else continue; ป้องกันปัญหานี้โดยข้ามการประมวลผลของชื่อที่ไม่รู้จักไปเลย

ข้อ 6ท้าทาย

ดัดแปลงแอปทั้งหมดจากหัวข้อ 12.5 ให้เพิ่มการนับ "จำนวนนักเรียนที่ได้เกรด A หรือ A-" แล้วพิมพ์สรุปท้ายรายงาน เช่น มีนักเรียนเกรด A/A- ทั้งหมด 5 คน (ใช้ข้อมูล 8 คนจากหัวข้อ 12.5 ตอนท้าย)

💡 คำใบ้

ประกาศตัวนับไว้นอกสุด (ไม่ใช่ในลูปชื่อ เพราะต้องสะสมข้าม ทุกคน) แล้วเพิ่มค่าด้วย if เช็คว่า currentStudentLetterGrade เป็น "A" หรือ "A-" ก่อนจบ loop แต่ละรอบ

ดูเฉลย
Program.cs (ส่วนที่เพิ่ม)
int topGradeCount = 0;  // ประกาศไว้นอกสุด ก่อน foreach ชื่อ

// ... ข้างในลูปชื่อ ต่อจากบรรทัดตัดเกรด ...
if (currentStudentLetterGrade == "A" || currentStudentLetterGrade == "A-")
{
    topGradeCount++;
}

// ... หลังจบ foreach ชื่อ ก่อน Console.ReadLine() ...
Console.WriteLine($"\nมีนักเรียนเกรด A/A- ทั้งหมด {topGradeCount} คน");

📌 สรุปบทที่ 12

เป้าหมายของบทนี้คือสร้างแอปที่ใช้ iteration และ selection statement ผสมกันประมวลผลเนื้อหา ใน array เพื่อบรรลุเป้าหมายของแอป ด้วยการรวม foreach และ if เข้าด้วยกันแบบซ้อนกัน คุณสร้างแอปที่ประมวลผล array ชื่อและคะแนนของนักเรียน เพื่อคำนวณและ รายงานเกรด ตรรกะของแอปรองรับการเพิ่มนักเรียนและคะแนนใหม่ได้โดยแก้โค้ดน้อยที่สุด

การมีความสามารถสร้าง nested iteration statement ที่ประมวลผลข้อมูลใน array และ selection statement ที่แตกเส้นทางการทำงานของโค้ด ช่วยให้คุณสร้างโค้ดที่มีประสิทธิภาพและขยายต่อได้ดีขึ้นมาก

Cheat Sheet — บทที่ 12
