23.1 สถานการณ์: บริษัทโลจิสติกส์

สมมติคุณเป็นนักพัฒนาซอฟต์แวร์ในทีมที่ทำงานร่วมกับบริษัทโลจิสติกส์ งานของคุณคือรวบรวมและ จัดระเบียบข้อมูลธุรกิจของพวกเขา คุณมีส่วนร่วมในหลายโปรเจกต์ แต่ละโปรเจกต์ไม่เหมือนกันแต่ทั้งหมด เกี่ยวข้องกับการประมวลผลข้อมูล โปรเจกต์เหล่านี้รวมถึงการติดตามและรายงานสินค้าคงคลัง การ แลกเปลี่ยนข้อมูลกับพาร์ทเนอร์ทางธุรกิจ และการระบุคำสั่งซื้อที่อาจเป็นการฉ้อโกง การดำเนินการ ที่พบร่วมกันในทุกโปรเจกต์นี้คือ การเพิ่ม ลบ เรียงลำดับ รวมข้อมูล คำนวณ ตรวจสอบข้อมูล และจัด รูปแบบผลลัพธ์

ในบทนี้ คุณทำงานกับ C# array เพื่อเก็บลำดับของค่าในโครงสร้างข้อมูลเดียว เมื่อเก็บข้อมูลใน array แล้ว คุณปรับทั้งลำดับและเนื้อหาของมันได้ นอกจากนี้ คุณยังทำ string operation ที่ซับซ้อน ได้ด้วย array helper method

คุณเริ่มจากใช้ helper method เรียงลำดับหรือสลับลำดับข้อมูล ต่อไปคุณเรียนวิธีลบ item ออกจาก array และปรับขนาด array ให้รองรับ item ใหม่ จากนั้นคุณเรียนวิธีแปลง string เป็น array ด้วย การแยกมันเป็น string ย่อยๆ ทุกครั้งที่เจออักขระที่กำหนด เช่น เครื่องหมายจุลภาค เมธอดเดียวกันนี้ ยังใช้แยก string เป็น array ของตัวอักษรได้ด้วย สุดท้าย คุณเรียนวิธีรวม element ทั้งหมดของ array กลับเป็น string เดียว

ℹ️ Collection Expression Syntax ใหม่ (C# 12) โค้ดในบทนี้ใช้ syntax ใหม่ประกาศ array: string[] pallets = [ "B14", "A11" ]; — สังเกตว่าใช้ [ ] แทน new string[] { } แบบที่คุณคุ้นเคยจากบทก่อนๆ นี่คือ collection expression syntax เพิ่มมาใน C# 12 เป็นวิธีย่อเขียน array ให้กระชับ ขึ้น ทั้งสองแบบทำงานเหมือนกันทุกประการ:
เทียบกัน
// แบบเดิม (ที่ใช้มาตลอดในหนังสือเล่มนี้)
string[] pallets = new string[] { "B14", "A11", "B12", "A13" };

// แบบใหม่ (C# 12 collection expression) — สั้นกว่า
string[] pallets = [ "B14", "A11", "B12", "A13" ];
ในหนังสือเล่มนี้จากนี้ไปจะใช้ syntax แบบใหม่ตามต้นฉบับ MS Learn — ใช้แบบไหนก็ได้ตามที่คุณ ถนัด compiler ยอมรับทั้งคู่

23.2 Array.Sort() และ Array.Reverse()

Array class มีเมธอดที่ใช้จัดการเนื้อหา ลำดับ และขนาดของ array ได้ ในหัวข้อนี้ คุณเขียนโค้ดที่ทำการดำเนินการต่างๆ กับ array ของรหัสพาเลท (pallet identifier) — โค้ดของคุณ อาจเป็นจุดเริ่มต้นของแอปติดตามและปรับการใช้พาเลทของบริษัทให้เหมาะสม

เตรียมโปรเจกต์

Terminal 
dotnet new console -o ch23-arrayops

เรียงลำดับ Array ด้วย Sort()

Program.cs 
string[] pallets = [ "B14", "A11", "B12", "A13" ];

Console.WriteLine("Sorted...");
Array.Sort(pallets);
foreach (var pallet in pallets)
{
    Console.WriteLine($"-- {pallet}");
}
Output
Sorted...
-- A11
-- A13
-- B12
-- B14

คุณใช้เมธอด Sort() ของ Array class เรียงลำดับ item ใน array แบบ alphanumeric (ตามตัวอักษรและตัวเลข)

⚠️ Sort() เรียงลำดับแบบ in-place Array.Sort(pallets) ไม่ได้คืน array ใหม่ที่เรียงแล้ว — มันแก้ไข pallets ตัวเดิมโดยตรง (in-place) ต่างจากบางภาษาที่ sort() คืนค่า array ใหม่ ถ้าต้องการเก็บลำดับเดิมไว้ด้วย ต้องก็อปปี้ array ก่อน sort (ทบทวนเทคนิคก็อปปี้ array แยกจริงจาก บทที่ 21 แบบฝึกหัดข้อ 3)

สลับลำดับ Array ด้วย Reverse()

Program.cs 
string[] pallets = [ "B14", "A11", "B12", "A13" ];

Console.WriteLine("Sorted...");
Array.Sort(pallets);
foreach (var pallet in pallets)
{
    Console.WriteLine($"-- {pallet}");
}

Console.WriteLine("");
Console.WriteLine("Reversed...");
Array.Reverse(pallets);
foreach (var pallet in pallets)
{
    Console.WriteLine($"-- {pallet}");
}
Output
Sorted...
-- A11
-- A13
-- B12
-- B14

Reversed...
-- B14
-- B12
-- A13
-- A11

ที่นี่คุณใช้เมธอด Reverse() ของ Array class สลับลำดับของ item — สังเกตว่า "Reversed" ในตัวอย่างนี้ทำงานบน array ที่ถูก Sort() ไปแล้ว จึงได้ผล เป็นลำดับจากมากไปน้อย ไม่ใช่การย้อนกลับลำดับเดิมก่อน sort

Check ★ ข้อใดอธิบายโค้ด Array.Sort(pallets); (เมื่อ pallets เป็น string array) ได้ถูกต้องที่สุด?

  • ASort คือการทำ cast operation
  • BSort เป็นเมธอดของ Array class
  • CSort ใช้เรียง precision ของ array
เฉลย: ข้อ B. Sort() เป็น static method บน Array class ไม่เกี่ยวกับ การ cast หรือ precision เลย

23.3 Array.Clear() และ Array.Resize()

เมื่อพัฒนาระบบติดตามพาเลทต่อไป คุณต้องติดตามพาเลทใหม่และลบพาเลทเก่าออกจากระบบด้วย จะสร้าง ฟังก์ชันที่รองรับการเพิ่มและลบพาเลทได้ยังไง?

Array.Clear() ใช้ล้างเนื้อหาของ element ที่กำหนดใน array ของคุณ แทนที่ด้วยค่า default ของ array นั้น เช่น ถ้าล้าง element ใน string array ค่าที่ถูกล้างจะกลายเป็น null ถ้าล้าง element ใน int array ค่าที่แทนที่จะเป็น 0

Array.Resize() ใช้เพิ่มหรือลบ element ออกจาก array ได้

ล้างค่าด้วย Clear()

Program.cs 
string[] pallets = [ "B14", "A11", "B12", "A13" ];
Console.WriteLine("");

Array.Clear(pallets, 0, 2);
Console.WriteLine($"Clearing 2 ... count: {pallets.Length}");
foreach (var pallet in pallets)
{
    Console.WriteLine($"-- {pallet}");
}
Output
Clearing 2 ... count: 4
-- 
-- 
-- B12
-- A13

Array.Clear(pallets, 0, 2); ล้างค่าที่เก็บใน element ของ array pallets โดยเริ่มที่ index 0 และล้างทั้งหมด 2 element เมื่อรัน คุณจะเห็นว่าค่าใน 2 element แรกถูกล้างออก — ใน property Length และ foreach statement, element เหล่านั้นยังคงอยู่ แค่ว่างเปล่า

Empty String กับ null ต่างกันยังไง

ตอนใช้ Array.Clear() element ที่ถูกล้างจะไม่อ้างอิงไปยัง string ใดๆ ในหน่วย ความจำอีกต่อไป — จริงๆ แล้ว element นั้นไม่ได้ชี้ไปยังอะไรเลย การชี้ไปยัง "ไม่มีอะไร" เป็น แนวคิดสำคัญที่อาจเข้าใจยากในตอนแรก

Program.cs 
string[] pallets = [ "B14", "A11", "B12", "A13" ];
Console.WriteLine("");

Console.WriteLine($"Before: {pallets[0]}");
Array.Clear(pallets, 0, 2);
Console.WriteLine($"After: {pallets[0]}");
Output
Before: B14
After:

ถ้าดูที่บรรทัด After: คุณอาจคิดว่าค่าที่เก็บใน pallets[0] เป็น empty string ("") แต่จริงๆ แล้ว C# Compiler แปลงค่า null เป็น empty string โดยปริยาย (implicit) แค่ตอนแสดงผลเท่านั้น

เพื่อพิสูจน์ว่าค่าที่เก็บใน pallets[0] หลังถูกล้างเป็น null จริงๆ ลองเรียกเมธอด ToLower() บน pallets[0] ดู — ถ้าเป็น string มันควร ทำงานได้ปกติ แต่ถ้าเป็น null ควรทำให้เกิด exception:

Program.cs 
string[] pallets = [ "B14", "A11", "B12", "A13" ];
Console.WriteLine("");

Console.WriteLine($"Before: {pallets[0].ToLower()}");
Array.Clear(pallets, 0, 2);
Console.WriteLine($"After: {pallets[0].ToLower()}");
Output
System.NullReferenceException: Object reference not set to an instance of an object.

exception นี้เกิดขึ้นเพราะความพยายามเรียกเมธอดบนเนื้อหาของ element pallets[0] เกิดขึ้นก่อนที่ C# Compiler จะมีโอกาสแปลง null เป็น empty string โดย ปริยาย

⚠️ บทเรียนสำคัญ: เช็ค null ก่อนเรียกเมธอดเสมอ Array.Clear() ลบการอ้างอิงของ array element ไปยังค่าที่มีอยู่ (ถ้ามี) เพื่อแก้ ปัญหานี้ ควรเช็ค null ก่อนพยายามพิมพ์หรือเรียกเมธอดบนค่านั้น เพื่อหลีกเลี่ยง error ให้เพิ่ม if statement ก่อนเข้าถึง array element ที่อาจเป็น null:
วิธีป้องกัน
if (pallets[0] != null)
    Console.WriteLine($"After: {pallets[0].ToLower()}");

ปรับขนาด Array ให้ใหญ่ขึ้นด้วย Resize()

Program.cs 
string[] pallets = [ "B14", "A11", "B12", "A13" ];
Console.WriteLine("");

Array.Clear(pallets, 0, 2);
Console.WriteLine($"Clearing 2 ... count: {pallets.Length}");
foreach (var pallet in pallets)
{
    Console.WriteLine($"-- {pallet}");
}

Console.WriteLine("");
Array.Resize(ref pallets, 6);
Console.WriteLine($"Resizing 6 ... count: {pallets.Length}");

pallets[4] = "C01";
pallets[5] = "C02";

foreach (var pallet in pallets)
{
    Console.WriteLine($"-- {pallet}");
}
Output
Clearing 2 ... count: 4
-- 
-- 
-- B12
-- A13

Resizing 6 ... count: 6
-- 
-- 
-- B12
-- A13
-- C01
-- C02

สังเกตบรรทัด Array.Resize(ref pallets, 6); — คุณกำลังเรียกเมธอด Resize() โดยส่ง array pallets เข้าไปแบบ pass by reference ด้วย คีย์เวิร์ด ref บางกรณี เมธอดต้องการให้คุณส่ง argument แบบ pass by value (ค่า default) หรือ pass by reference (ใช้คีย์เวิร์ด ref) เหตุผลที่จำเป็นต้อง ใช้ ref ตรงนี้ต้องอธิบายยาวและซับซ้อนเกี่ยวกับวิธีที่ .NET จัดการ object ซึ่งเกิน ขอบเขตของบทนี้ — เมื่อไม่แน่ใจ แนะนำให้ดู IntelliSense หรือ Microsoft Docs เพื่อดูตัวอย่างวิธี เรียกเมธอดนั้นอย่างถูกต้อง

ในกรณีนี้ คุณกำลังปรับขนาด array pallets จาก 4 element เป็น 6 element ใหม่ที่เพิ่มมาถูกเติมต่อท้าย element เดิม element ใหม่ทั้งสองจะเป็น null จนกว่าคุณจะกำหนดค่าให้มัน

💡 ทำไม Resize() ต้องใช้ ref Array.Resize() ไม่ได้แค่แก้ไข array เดิม แต่จริงๆ แล้วสร้าง array ใหม่ทั้งชุดในหน่วยความจำ (เพราะ array มีขนาดคงที่เมื่อสร้างแล้ว เปลี่ยนขนาดของมันตรงๆ ไม่ได้ — ทบทวนแนวคิด reference type จาก บทที่ 21) แล้วก็อปปี้ค่าเดิม ไปยัง array ใหม่นั้น เพราะเมธอดต้องเปลี่ยนว่าตัวแปร pallets ของคุณชี้ไปยัง array ตัวไหน (ไม่ใช่แค่แก้ไขเนื้อหาข้างในของตัวเดิม) มันจึงต้องการ ref เพื่อแก้ไข ตัวแปรต้นทางของคุณโดยตรง

ปรับขนาด Array ให้เล็กลง (ลบ Element)

Program.cs (เพิ่มต่อจากด้านบน) 
Console.WriteLine("");
Array.Resize(ref pallets, 3);
Console.WriteLine($"Resizing 3 ... count: {pallets.Length}");

foreach (var pallet in pallets)
{
    Console.WriteLine($"-- {pallet}");
}
Output
Resizing 3 ... count: 3
-- 
-- 
-- B12

สังเกตว่าการเรียก Array.Resize() ครั้งนี้ไม่ได้ลบ 2 element ที่เป็น null ออก แต่กลับลบ 3 element สุดท้ายออกไปแทน — ที่น่าสังเกตคือ 3 element สุดท้ายถูกลบไปแม้จะมีค่า string อยู่จริงก็ตาม เพราะ Resize() ตัดจากท้าย array เสมอ ไม่สนใจว่า element ไหนมีค่าหรือเป็น null

⚠️ ไม่มีเมธอดสำเร็จรูปสำหรับ "ลบเฉพาะ element ที่เป็น null" ถ้า Array.Resize() ไม่ได้ลบ element ที่ว่างเปล่าออกให้ มีเมธอด helper อื่นที่ทำ แบบนั้นอัตโนมัติไหม? ไม่มี วิธีที่ดีที่สุดในการล้าง element ว่างเปล่าออกจาก array คือ นับจำนวน element ที่ไม่ใช่ null ด้วยการวนผ่านแต่ละ item แล้วเพิ่มค่าตัวแปร (ตัวนับ) จากนั้น สร้าง array ที่สองที่มีขนาดเท่ากับตัวแปรตัวนับนั้น สุดท้ายวนผ่านแต่ละ element ใน array เดิม แล้วก็อปปี้เฉพาะค่าที่ไม่ใช่ null ไปยัง array ใหม่

Check ★ ข้อใดอธิบายโค้ด Array.Clear(pallets, 0, 2); (เมื่อ pallets เป็น string array) ได้ถูกต้องที่สุด?

  • Aลบข้อมูลออกจาก 2 element เริ่มจากตำแหน่ง 0
  • Bลบข้อมูลออกจากตำแหน่ง pallets[0] และ pallets[2]
  • Cลบ element ที่มีค่าเท่ากับ 0 หรือ 2
เฉลย: ข้อ A. พารามิเตอร์คือ (array, startIndex, count) — เริ่มที่ index 0 ล้างทั้งหมด 2 element (index 0 กับ 1) ไม่ใช่ index 0 กับ 2 ตรงๆ และไม่เกี่ยวกับค่า ใน element เลย

23.4 String ↔ Array: ToCharArray(), Join(), Split()

คุณทำงานพัฒนาต่อให้บริษัทโลจิสติกส์ต่อไป เริ่มสร้างชุดแอปเล็กๆ ที่ทำงานร่วมกัน — รับข้อมูลจาก ระบบของพาร์ทเนอร์รายหนึ่ง ปรับแก้ แล้วส่งต่อไปยังระบบภายในตามรูปแบบที่กำหนด เพื่อแปลงข้อมูล คุณต้องรับข้อมูลที่เข้ามาเป็น string, แยกเป็นชิ้นข้อมูลย่อย แล้วปรับให้ตรงกับรูปแบบที่ต้องการ — จะแยก string เป็นชิ้นข้อมูลย่อยได้ยังไง?

ตัวแปรชนิด string มี built-in method จำนวนมากที่แปลง string เดียวให้กลายเป็น array ของ string ย่อยๆ หรือ array ของตัวอักษรแต่ละตัวได้ เมื่อคุณประมวลผลข้อมูลจากระบบ คอมพิวเตอร์อื่น บางครั้งมันถูกจัดรูปแบบหรือ encode มาในแบบที่ใช้ประโยชน์ตรงๆ ไม่ได้ ในกรณีนี้ คุณใช้ Array method ของ string data type แยก string เป็น array

ใช้ ToCharArray() กลับด้าน String

Program.cs 
string value = "abc123";
char[] valueArray = value.ToCharArray();

ตัวอย่างนี้ใช้เมธอด ToCharArray() สร้าง array ของ char โดยแต่ละ element แทนตัวอักษรหนึ่งตัวของ string ต้นฉบับ

กลับด้านแล้วรวมกลับเป็น String ใหม่

Program.cs 
string value = "abc123";
char[] valueArray = value.ToCharArray();
Array.Reverse(valueArray);
string result = new string(valueArray);
Console.WriteLine(result);
Output
321cba

expression new string(valueArray) สร้าง instance ใหม่ของ System.String class (ซึ่งก็คือ string data type ใน C#) แล้วส่ง char array เข้าไปเป็น constructor

💡 new string(...) คืออะไรกันแน่ คีย์เวิร์ด new คืออะไร? System.String class เกี่ยวข้องกับ string data type ใน C# ยังไง? constructor คืออะไร? คำถามดีๆ ทั้งหมดนี้ยังอยู่ นอกขอบเขตของบทนี้ (จะได้เรียนเรื่อง class และ constructor แบบเต็มๆ ในโมดูลถัดๆ ไปของหลักสูตร) ตอนนี้แค่จำไว้ว่า new string(char[]) คือวิธีมาตรฐานแปลง char array กลับเป็น string

รวม char เข้าเป็น Comma-Separated String ด้วย Join()

บางกรณีคุณอาจต้องการคั่นแต่ละ element ของ char array ด้วยเครื่องหมายจุลภาค ซึ่งเป็นวิธีที่ นิยมทำเวลาทำงานกับข้อมูลที่แทนเป็น ASCII text — ใช้เมธอด Join() ของ String class โดยส่งตัวอักษรที่ต้องการใช้คั่น (จุลภาค) กับตัว array เข้าไป:

Program.cs 
string value = "abc123";
char[] valueArray = value.ToCharArray();
Array.Reverse(valueArray);
string result = String.Join(",", valueArray);
Console.WriteLine(result);
Output
3,2,1,c,b,a

string[] items = result.Split(',');
foreach (string item in items)
{
    Console.WriteLine(item);
}
Output รวม (ต่อจากโค้ด Join ด้านบน)

เมธอด .Split() ออกแบบมาสำหรับตัวแปรชนิด string สร้าง array ของ string ขึ้นมา — เครื่องหมายจุลภาคถูกส่งให้ .Split() เป็นตัวคั่น (delimiter) ใช้แยก string ยาวหนึ่งอันเป็น string ย่อยๆ จากนั้นโค้ดใช้ foreach loop วนผ่าน แต่ละ element ของ array ใหม่ที่ชื่อ items

ℹ️ สรุปทิศทางการแปลง String → Array: .ToCharArray() (เป็น char array) หรือ .Split(delimiter) (เป็น string array) — Array → String: new string(charArray) หรือ String.Join(separator, array)

Check ★ String.Join("-", myArray); เป็น ตัวอย่างของ Join คำอธิบายข้อใดตรงกับตัวอย่างนี้ที่สุด?

  • Aสร้าง character array จาก item ใน myArray เชื่อมด้วยเครื่องหมายจุลภาค (,)
  • Bสร้าง string จาก item ใน myArray เชื่อมด้วยเครื่องหมายขีดกลาง (-)
  • Cสร้าง string ชื่อ myArray เชื่อมด้วยเครื่องหมายขีดกลาง (-)
เฉลย: ข้อ B. Join() รวม element ของ array เข้าเป็น string เดียว โดย ใส่ตัวคั่นที่กำหนด (ในที่นี้คือ "-") ระหว่างแต่ละ element — ไม่เกี่ยวกับ character array หรือจุลภาคเลย และผลลัพธ์เป็น string ที่มีเนื้อหาจาก myArray ไม่ใช่ string ที่ชื่อว่า "myArray"

23.5 ท้าทาย 1: กลับตัวอักษรแต่ละคำในประโยค

โจทย์ตามต้นฉบับ MS Learn

ใช้ตัวแปรตั้งต้นนี้:

ข้อมูลตั้งต้น
string pangram = "The quick brown fox jumps over the lazy dog";

เขียนโค้ดกลับตัวอักษรของแต่ละคำในตำแหน่งเดิมของมัน แล้วแสดงผลลัพธ์ — พูดอีกแบบคือ อย่าแค่กลับทุกตัวอักษรในตัวแปร pangram ทั้งก้อน แต่ต้องกลับเฉพาะตัวอักษร ในแต่ละคำ แล้วพิมพ์คำที่กลับด้านแล้วในตำแหน่งเดิมของมันในประโยค

ผลลัพธ์ที่ต้องได้:

ehT kciuq nworb xof spmuj revo eht yzal god
💡 ขอคำใบ้

โจทย์นี้ยากพอสมควร ต้องรวมหลายแนวคิดจากบทนี้เข้าด้วยกัน รวมถึงการใช้ Split(), ToCharArray(), Array.Reverse(), และ String.Join() คุณจะต้องสร้าง array หลายตัว และใช้ iteration statement อย่างน้อยหนึ่งตัว — ลองแตกปัญหาใหญ่เป็นขั้นตอนย่อยๆ ก่อน: (1) แยกประโยคเป็นคำๆ (2) กลับ แต่ละคำ (3) ประกอบกลับเป็นประโยคเดียว

🔓 ดูเฉลย (เฉลยทางการจาก Microsoft Learn)

เฉลยนี้แบ่งเป็น 4 ขั้นตอน:

  1. สร้าง string array message โดยแยก pangram ที่อักขระ ช่องว่าง
  2. สร้าง array newMessage ใหม่ เก็บสำเนาของแต่ละ "คำ" ที่กลับด้านแล้วจาก array message
  3. วนผ่านแต่ละ element ใน message กลับด้านมัน แล้วเก็บลง newMessage
  4. รวมคำใน newMessage เข้าด้วยกันด้วยช่องว่างอีกครั้ง สร้าง string เดียว เพื่อพิมพ์ออกมา
Program.cs 
string pangram = "The quick brown fox jumps over the lazy dog";

// Step 1
string[] message = pangram.Split(' ');

// Step 2
string[] newMessage = new string[message.Length];

// Step 3
for (int i = 0; i < message.Length; i++)
{
    char[] letters = message[i].ToCharArray();
    Array.Reverse(letters);
    newMessage[i] = new string(letters);
}

// Step 4
string result = String.Join(" ", newMessage);
Console.WriteLine(result);
Output
ehT kciuq nworb xof spmuj revo eht yzal god

นี่เป็นเพียงหนึ่งในหลายวิธีที่แก้โจทย์นี้ได้ — คุณอาจใช้วิธีอื่นในแต่ละขั้นตอนก็ได้ ขอแค่ผลลัพธ์ตรงกันก็ถือว่าสำเร็จ

สังเกตว่า loop ใน Step 3 ใช้ for ไม่ใช่ foreach เพราะต้องใช้ ตัวแปร i เป็น index อ้างอิงทั้ง message[i] (อ่านคำต้นฉบับ) และ newMessage[i] (เขียนคำที่กลับด้านแล้วลงตำแหน่งเดียวกัน) — นี่คือรูปแบบ ที่คุณเจอบ่อยเมื่อต้อง "map" ข้อมูลจาก array หนึ่งไปยังอีก array หนึ่งแบบ 1-ต่อ-1

23.6 ท้าทาย 2: แยกวิเคราะห์ Order, เรียงลำดับ, และแท็ก Error

โจทย์ตามต้นฉบับ MS Learn

ข้อมูลมาในหลายรูปแบบ ในโจทย์นี้ คุณต้องแยกวิเคราะห์ "Order ID" แต่ละตัว แล้วแสดง "Order ID" ที่เรียงลำดับแล้ว พร้อมแท็ก "Error" ให้ตัวที่ความยาวไม่เท่ากับ 4 ตัวอักษร พอดี

ข้อมูลตั้งต้น
string orderStream = "B123,C234,A345,C15,B177,G3003,C235,B179";

ตัวแปร orderStream เก็บ string ของ Order ID หลายตัวคั่นด้วยจุลภาค เขียนโค้ด ที่:

  • แยกวิเคราะห์ Order ID จาก string ของคำสั่งซื้อที่เข้ามา แล้วเก็บไว้ใน array
  • แสดงแต่ละ Order ID แบบเรียงลำดับแล้ว และแท็ก order ที่ความยาวไม่เท่ากับ 4 ตัวอักษร พอดีด้วย "- Error"

ผลลัพธ์ที่ต้องได้:

A345
B123
B177
B179
C15     - Error
C234
C235
G3003   - Error
💡 ขอคำใบ้

ใช้ Split(',') แยก order ก่อน แล้วใช้ Array.Sort() เรียง แล้ววนด้วย foreach เช็ค .Length ของแต่ละ order

🔓 ดูเฉลย (เฉลยทางการจาก Microsoft Learn)
Program.cs 
string orderStream = "B123,C234,A345,C15,B177,G3003,C235,B179";
string[] items = orderStream.Split(',');
Array.Sort(items);

foreach (var item in items)
{
    if (item.Length == 4)
    {
        Console.WriteLine(item);
    }
    else
    {
        Console.WriteLine(item + "\t- Error");
    }
}
Output
A345
B123
B177
B179
C15     - Error
C234
C235
G3003   - Error

นี่เป็นเพียงหนึ่งในหลายวิธีที่แก้โจทย์นี้ได้ สังเกตว่าเฉลยนี้ทำแค่ 3 ขั้นตอนหลัก: แยก (Split) → เรียง (Sort) → วนพิมพ์พร้อมเช็คเงื่อนไข (foreach + if) — ตัวอักษร \t คือ escape sequence สำหรับ tab (ทบทวนจาก บทที่ 3) ใช้จัดตำแหน่งข้อความ "- Error" ให้อยู่ห่างจาก Order ID เล็กน้อย

23.7 ⚠️ กับดักที่พบบ่อย

อาการสาเหตุ / วิธีแก้
System.NullReferenceException ตอนเรียกเมธอดบน array element element นั้นอาจถูก Clear() ไปแล้ว หรือเป็น element ใหม่จาก Resize() ที่ยังไม่ได้ กำหนดค่า — ต้องเช็ค != null ก่อนเรียกเมธอดบนมันเสมอ
Resize() แล้ว element ว่างเปล่ายังอยู่ ทั้งที่คาดว่าจะถูกลบไปด้วย ไม่ใช่บั๊ก — Resize() ตัดจากท้าย array เสมอ ไม่สนใจว่า element ไหนว่างหรือไม่ ถ้าต้องการ ลบเฉพาะ element ว่าง ต้องเขียนโค้ดกรองเองด้วยการนับ+สร้าง array ใหม่
ลืมใส่ ref ตอนเรียก Array.Resize() แล้ว compile error Resize() ต้องการ ref เพราะมันเปลี่ยนตัวแปรต้นทางให้ชี้ไปยัง array ใหม่ทั้งชุด (ไม่ใช่ แค่แก้ไขของเดิม) ต้องเขียน Array.Resize(ref arr, newSize) เสมอ
Sort() แล้วข้อมูลชุดเดิมหายไป ไม่มีลำดับต้นฉบับให้ใช้อีก Sort() แก้ไข array แบบ in-place เสมอ ถ้าต้องการเก็บลำดับเดิมไว้ด้วย ต้องก็อปปี้ array ก่อน sort
Split() ได้ element ว่างเปล่าปนมาในผลลัพธ์ (เช่น จาก string ที่มีจุลภาคติดกัน "a,,b") เป็นพฤติกรรมปกติของ Split() — ถ้าไม่ต้องการ element ว่าง ใช้ overload Split(',', StringSplitOptions.RemoveEmptyEntries) แทน

ข้อ 4กลาง

เขียนโค้ดที่มี array string[] data = ["x", null, "y", null, "z"]; แล้วสร้าง array ใหม่ที่มีแค่ element ที่ไม่ใช่ null เท่านั้น (ทบทวนแนวทางจาก note ในหัวข้อ 23.3d)

ดูเฉลย
Program.cs
string?[] data = ["x", null, "y", null, "z"];

int count = 0;
foreach (var item in data)
{
    if (item != null) count++;
}

string[] cleaned = new string[count];
int index = 0;
foreach (var item in data)
{
    if (item != null)
    {
        cleaned[index] = item;
        index++;
    }
}

foreach (var item in cleaned)
{
    Console.WriteLine(item);
}

ผลลัพธ์: x, y, z — ตรงตามแนวทาง "นับก่อน แล้วค่อยสร้าง array ใหม่ขนาดพอดี" ที่อธิบายไว้ ในหัวข้อ 23.3d

ข้อ 6ท้าทาย

ดัดแปลงเฉลยท้าทาย 2 (หัวข้อ 23.6) ให้ error ที่ตรวจสอบเปลี่ยนกฎเป็น: Order ID ต้องขึ้นต้น ด้วยตัวอักษร A, B, หรือ C เท่านั้น (นอกเหนือจากกฎความยาว 4 ตัวอักษรเดิม) ถ้าขึ้นต้นด้วย ตัวอักษรอื่น (เช่น G) ให้แท็กเป็น "- Error (invalid prefix)" แยกจาก error ความยาว ทดสอบกับ orderStream เดิม

ดูเฉลย
Program.cs
string orderStream = "B123,C234,A345,C15,B177,G3003,C235,B179";
string[] items = orderStream.Split(',');
Array.Sort(items);

foreach (var item in items)
{
    char prefix = item[0];
    bool validPrefix = (prefix == 'A' || prefix == 'B' || prefix == 'C');

    if (!validPrefix)
    {
        Console.WriteLine(item + "\t- Error (invalid prefix)");
    }
    else if (item.Length != 4)
    {
        Console.WriteLine(item + "\t- Error");
    }
    else
    {
        Console.WriteLine(item);
    }
}

ใช้ item[0] เข้าถึงตัวอักษรแรกของ string ตรงๆ (string เข้าถึงแบบ index ได้ เหมือน char array) เช็ค prefix ก่อนเช็คความยาว เพราะ G3003 ผิดทั้งสองกฎ แต่โจทย์ต้องการ ให้แท็กเป็น "invalid prefix" เป็นหลัก

📌 สรุปบทที่ 23

ในบทนี้ คุณทำแบบฝึกหัดที่ใช้ helper method ทำงานกับ array ได้อย่างมีประสิทธิภาพมากขึ้น:

  • ล้าง item ใน array ด้วยเมธอด Array.Clear() และเรียนรู้ว่า element ที่ถูกล้าง จะถูกตั้งเป็น null
  • ปรับขนาด array เพิ่ม/ลบ element ด้วยเมธอด Array.Resize()
  • แปลง string เป็น array ด้วย String.Split() โดยกำหนดตัวคั่นเพื่อสร้างค่าใน array ที่คืนกลับมา
  • รวม element ทั้งหมดของ array เป็น string เดียวด้วยเมธอด String.Join()

array helper method ช่วยให้คุณทำงานกับข้อมูลในแอปพลิเคชันได้อย่างยืดหยุ่น ถ้าไม่มีฟีเจอร์ เหล่านี้ array จะมีประโยชน์น้อยลงมาก
