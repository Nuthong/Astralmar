ตาราง Error Code (CSxxxx) รวม

Common C# Compiler Error & Warning Codes

เวลาเขียนโค้ดแล้ว VS Code ขึ้นเส้นหยักสีแดงพร้อมรหัสแบบ CS0103 นั่นคือรหัส ข้อผิดพลาดของคอมไพเลอร์ C# เอง (ต่างจาก exception ที่เกิดตอน runtime อย่าง DivideByZeroException ซึ่งไม่มีรหัส CSxxxx) — รหัสพวกนี้คงที่และค้นหาได้เสมอ ลอง copy รหัสไปค้นใน Google หรือพิมพ์ในช่อง "Filter by title" ของเอกสาร Microsoft Learn ได้โดยตรง

💡 วิธีอ่านตารางนี้ ตารางเรียงตามลำดับที่เจอบ่อยตามช่วงที่เรียนในหนังสือเล่มนี้ — ถ้าเจอ error ไม่รู้จัก ลอง Ctrl+F หารหัสในหน้านี้ก่อน ถ้าไม่เจอให้ลองอ่านข้อความ error เต็มๆ จาก VS Code เอง เพราะ คอมไพเลอร์บอกตำแหน่งบรรทัดที่ผิดไว้เสมอ

CS0128ErrorA local variable named 'X' is already defined in this scope ประกาศตัวแปรชื่อซ้ำกันใน scope เดียวกัน

CS0152ErrorThe label 'X' already occurs in this switch statement เขียน case ค่าเดียวกันซ้ำสองครั้งใน switch เดียว — ทบทวน บทที่ 16
CS0163ErrorControl cannot fall through from one case label ('label') to another ลืมปิด case ด้วย break/return (C# ไม่มี fall-through แบบ C/Java) — ทบทวนบทที่ 16

เรื่องชนิดข้อมูลและ Casting (Part 4)

CS0029ErrorCannot implicitly convert type 'X' to 'Y' กำหนดค่าชนิดหนึ่งให้ตัวแปรอีกชนิดที่เข้ากันไม่ได้เลย (ไม่มีทาง cast ได้ด้วยซ้ำ)
CS0266ErrorCannot implicitly convert type 'X' to 'Y'. An explicit conversion exists (are you missing a cast?) ลืมใส่ (ชนิด) ข้างหน้าตอนแปลงชนิดข้อมูลแคบลง เช่น double เป็น int — ทบทวนบทที่ 22
CS1503ErrorArgument N: cannot convert from 'X' to 'Y' ส่ง argument ชนิดผิดให้เมธอด/constructor ตอนเรียกใช้ — ทบทวน บทที่ 29

เรื่อง Method (Part 5)

รหัสระดับข้อความจากคอมไพเลอร์สาเหตุที่พบบ่อย
CS0161Error'method': not all code paths return a value เมธอดมี return type ไม่ใช่ void แต่บางเส้นทาง (เช่น if ไม่มี else) ไม่มี return — ทบทวนบทที่ 30
CS0127ErrorSince 'method' returns void, a return keyword must not be followed by an object expression เขียน return ค่า; ในเมธอดที่ประกาศเป็น void — ทบทวนบทที่ 30
CS1501ErrorNo overload for method 'X' takes N arguments เรียกเมธอดโดยใส่จำนวน argument ไม่ตรงกับ parameter ที่นิยามไว้ — ทบทวน บทที่ 29
CS8321WarningThe local function 'X' is declared but never used ประกาศ local function ไว้ใน top-level statements แต่ไม่เคยเรียกใช้เลย
CS0219WarningThe variable 'X' is assigned but its value is never used ประกาศและกำหนดค่าตัวแปรไว้ แต่ไม่เคยอ่านค่ามันไปใช้ที่ไหนเลย — ไม่ทำให้โค้ดพัง แต่มักบ่งบอกว่าลืมเขียนบางบรรทัด
ℹ️ Error vs Warning ต่างกันอย่างไร Error (สีแดง) ทำให้คอมไพล์ไม่ผ่านเลย ต้องแก้ก่อนถึงจะรันได้ ส่วน Warning (สีเหลือง) ไม่ขวางการคอมไพล์ โค้ดยังรันได้ปกติ แต่เป็นสัญญาณเตือนว่าอาจมีบางอย่างไม่ตั้งใจ เกิดขึ้น (เช่น ประกาศตัวแปรไว้เฉยๆ ไม่ได้ใช้) — มืออาชีพมักตั้งใจไล่แก้ warning ให้เกลี้ยง ด้วยเหมือนกัน แม้จะไม่บังคับก็ตาม
