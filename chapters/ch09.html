เพิ่มตรรกะการตัดสินใจด้วย if, else, else if

Add Decision Logic Using if, else, and else if Statements
⏱ ใช้เวลา 60–80 นาที 📦 ผลลัพธ์ เขียนโค้ดแตกเส้นทางการทำงานตามเงื่อนไขได้ 🎯 ความยาก เริ่มต้น–กลาง

🎯 จบบทนี้คุณจะ...

  • เขียนโค้ดประเมินเงื่อนไขด้วย if, else, else if ได้
  • สร้าง Boolean expression เพื่อประเมินเงื่อนไขได้
  • รวม Boolean expression หลายตัวด้วย logical operator (&&, ||) ได้
  • ซ้อน code block ไว้ในกันและกันได้ (nesting)

9.1 ทำไมต้องมีตรรกะการตัดสินใจ

C# ให้คุณสร้างแอปที่มีตรรกะการตัดสินใจได้ สมมติอยากแสดงข้อมูลต่างกันให้ผู้ใช้ตามกฎธุรกิจ บางอย่าง เช่น แสดงข้อความพิเศษบนบิลลูกค้าตามภูมิภาค ให้ส่วนลดตามขนาดคำสั่งซื้อ หรือแสดง ตำแหน่งพนักงานตามระดับในบริษัท — ทุกกรณีต้องใช้ตรรกะการตัดสินใจ

จบบทนี้ คุณจะเขียนโค้ดที่เปลี่ยนเส้นทางการทำงานตามเงื่อนไขที่กำหนดได้

9.2 ลงมือ: สร้างตรรกะตัดสินใจด้วย if

แอปส่วนใหญ่มีเส้นทางการทำงานหลายแบบ — นักพัฒนาเรียกโค้ดที่สร้างเส้นทางต่างๆ ว่า code branch (สาขาของโค้ด) คำสั่งแตกสาขาที่ใช้บ่อยที่สุดคือ if ซึ่งอาศัย Boolean expression ในวงเล็บ ถ้า expression เป็น true โค้ดหลัง if จะทำงาน ถ้าไม่ .NET runtime จะข้ามไปเฉยๆ

ในหัวข้อนี้คุณจะสร้างเกมทอยลูกเต๋า 3 ลูก:

  • ถ้าลูกเต๋า 2 ลูกออกเลขเดียวกัน ได้โบนัส 2 แต้ม (double)
  • ถ้าลูกเต๋าทั้ง 3 ลูกออกเลขเดียวกัน ได้โบนัส 6 แต้ม (triple)
  • ถ้าผลรวม (รวมโบนัส) ≥ 15 ชนะ ไม่งั้นแพ้

เตรียมโปรเจกต์

เปิด VS Code → โฟลเดอร์ CsharpProjects → Terminal → สร้างโปรเจกต์ใหม่:

Terminal 
dotnet new console -o ch09-decisions

สร้างข้อมูลตั้งต้น

Program.cs 
Random dice = new Random();

int roll1 = dice.Next(1, 7);
int roll2 = dice.Next(1, 7);
int roll3 = dice.Next(1, 7);

int total = roll1 + roll2 + roll3;

Console.WriteLine($"Dice roll: {roll1} + {roll2} + {roll3} = {total}");
Output (ตัวเลขสุ่มทุกครั้ง)
Dice roll: 4 + 5 + 2 = 11

เพิ่ม if แสดงข้อความตามค่า total

Program.cs — ต่อท้าย 
if (total > 14)
{
    Console.WriteLine("You win!");
}

if (total < 15)
{
    Console.WriteLine("Sorry, you lose.");
}

if statement ประกอบด้วย 3 ส่วน:

  • คีย์เวิร์ด if
  • Boolean expression ในวงเล็บ ()
  • code block ในปีกกา { }

ตอนรัน expression total > 14 ถูกประเมิน ถ้าเป็น true โค้ดใน code block จะ ทำงาน ถ้า false จะถูกข้ามไป

Boolean Expression คืออะไร

Boolean expression คือโค้ดใดๆ ที่คืนค่า true หรือ false ง่ายที่สุด ก็คือค่า true/false ตรงๆ หรือจะเป็นผลจากเมธอดที่คืน bool ก็ได้:

ตัวอย่าง
string message = "The quick brown fox jumps over the lazy dog.";
bool result = message.Contains("dog");
Console.WriteLine(result);

if (message.Contains("fox"))
{
    Console.WriteLine("What does the fox say?");
}

สร้าง Boolean expression ได้ด้วยตัวดำเนินการเปรียบเทียบ:

ตัวดำเนินการความหมาย
==เท่ากับ
>มากกว่า
<น้อยกว่า
>=มากกว่าหรือเท่ากับ
<=น้อยกว่าหรือเท่ากับ
ℹ️ เจาะลึกเพิ่มเติม หลักสูตรนี้มีโมดูลเต็มๆ ว่าด้วยเรื่อง Boolean expression โดยเฉพาะ (Part 3 ของเล่มนี้) บทนี้แค่ปูพื้นฐานเท่าที่จำเป็นก่อน

เปลี่ยน total > 14 เป็น total >= 15 จะได้ผลเหมือนกันทุกประการ (เพราะทำงานกับเลข int) แต่สื่อความหมายตรงกับกฎเกมที่เขียนไว้ว่า "≥ 15" มากกว่า

Code Block คืออะไร

code block คือกลุ่มโค้ดหนึ่งบรรทัดขึ้นไป ที่ถูกล้อมด้วยปีกกาเปิด-ปิด { } เป็นหน่วยโค้ดสมบูรณ์ที่มีจุดประสงค์เดียว ตอนรัน ถ้า Boolean expression เป็น true โค้ดทุกบรรทัดใน block จะทำงาน ถ้า false ทุกบรรทัดจะถูกข้าม — code block ซ้อนกัน ได้ด้วย (nested) ซึ่งพบบ่อยมากในแอปจริง จะได้ลองทำในหัวข้อถัดไป

เพิ่มโบนัส Doubles

Program.cs — เพิ่มก่อน if แรก 
if ((roll1 == roll2) || (roll2 == roll3) || (roll1 == roll3))
{
    Console.WriteLine("You rolled doubles! +2 bonus to total!");
    total += 2;
}

นี่คือการรวม Boolean expression 3 ตัวเป็น compound condition เดียว เครื่องหมาย pipe คู่ || คือ logical OR — แปลว่า "ฝั่งซ้ายหรือฝั่งขวาต้องเป็น true อย่างน้อยหนึ่งฝั่ง ทั้ง expression ถึงจะ true" ถ้าทั้งสองฝั่ง false ทั้ง expression ก็ false ตามลำดับ C# ประเมินจากซ้ายไปขวา: เช็ค roll1==roll2 ก่อน ถ้า false ค่อยเช็ค roll2==roll3 ถ้ายัง false ค่อยเช็ค roll1==roll3

เพิ่มโบนัส Triples

Program.cs — เพิ่มต่อจาก if doubles 
if ((roll1 == roll2) && (roll2 == roll3))
{
    Console.WriteLine("You rolled triples! +6 bonus to total!");
    total += 6;
}

เครื่องหมาย ampersand คู่ && คือ logical AND — "ต้องเป็น true ทั้งสองฝั่ง expression ถึงจะ true" ในที่นี้ ถ้า roll1==roll2 และ roll2==roll3 ก็สรุปได้ว่า roll1==roll3 ด้วย แปลว่าออกเลข เดียวกันทั้ง 3 ลูก

ตัวอย่างผลลัพธ์ที่เป็นไปได้
Dice roll: 6 + 6 + 6 = 18
You rolled doubles! +2 bonus to total!
You rolled triples! +6 bonus to total!
You win!
🛑 พบบั๊ก! ทอยได้ triple แต่กลับได้โบนัสทั้ง double (+2) และ triple (+6) พร้อมกัน — ทั้งที่ triple ก็ถือเป็น double อยู่แล้วในตัว โบนัสไม่ควร "ซ้อน" กันแบบนี้ ต้องมีเงื่อนไขแยกกันจริงๆ สองแบบ — จะแก้ในหัวข้อถัดไป

9.3 ลงมือ: if, else if, else แบบซ้อน

หัวข้อนี้จะใช้ else และ else if ปรับปรุงการแตกสาขาโค้ด และ แก้บั๊กโบนัสซ้อนกันด้วยการซ้อน (nesting) if

ใช้ else แทน if 2 อัน

แทนที่จะเช็ค 2 รอบแยกกัน ใช้ else รวมเป็นชุดเดียว:

Program.cs 
if (total >= 15)
{
    Console.WriteLine("You win!");
}
else 
{
    Console.WriteLine("Sorry, you lose.");
}

ถ้า total >= 15 เป็น false โค้ดใน code block หลัง else จะ ทำงานแทน — เพราะทั้งสองผลลัพธ์เป็นด้านตรงข้ามกันพอดี นี่คือสถานการณ์ที่เหมาะกับ else ที่สุด

ซ้อน if แก้บั๊กโบนัสซ้อนกัน

Nesting คือการวาง code block ไว้ในกันและกัน ในที่นี้จะซ้อนชุด if-else (เช็ค doubles) ไว้ข้างใน if อีกชั้น (เช็ค doubles ก่อน) เพื่อป้องกันไม่ให้ ได้โบนัสทั้งสองแบบพร้อมกัน:

Program.cs 
if ((roll1 == roll2) || (roll2 == roll3) || (roll1 == roll3))
{
    if ((roll1 == roll2) && (roll2 == roll3))
    {
        Console.WriteLine("You rolled triples! +6 bonus to total!");
        total += 6;
    }
    else
    {
        Console.WriteLine("You rolled doubles! +2 bonus to total!");
        total += 2;
    }
}

if (total >= 15)
{
    Console.WriteLine("You win!");
}
else 
{
    Console.WriteLine("Sorry, you lose.");
}

โครงสร้างนี้สร้าง if-else ชั้นในที่ผลลัพธ์ตรงข้ามกันพอดี แล้วใช้ทั้งสองด้าน (if/true และ else/false) มอบแต้มโบนัสให้ triples กับ doubles — เช็ค doubles ที่ชั้นนอกก่อน แล้วเช็ค triples ที่ชั้นในทีหลัง แบบนี้พอชั้นในตรวจ triples แล้วได้ false ชั้น else ก็มอบแต้มให้ doubles ได้อย่างแน่ใจว่าไม่ใช่ triples

ลอง hard-code ค่าทอยชั่วคราวเพื่อทดสอบโดยไม่ต้องรันซ้ำหลายสิบครั้ง — เพิ่มบรรทัดนี้เหนือ บรรทัดประกาศ total:

Program.cs — ทดสอบ doubles
roll1 = 6;
roll2 = 6;
roll3 = 5;
Output
Dice roll: 6 + 6 + 5 = 17
You rolled doubles! +2 bonus to total!
You win!

เปลี่ยนเป็น roll3 = 6; ทดสอบ triples:

Output
Dice roll: 6 + 6 + 6 = 18
You rolled triples! +6 bonus to total!
You win!

คราวนี้ได้แค่โบนัสเดียวแล้ว — บั๊กแก้เรียบร้อย!

ใช้ if, else if, else มอบรางวัลหลายระดับ

เปลี่ยนจากข้อความ win/lose เป็นมอบรางวัลสมมติ 4 แบบ (ได้รางวัลเดียวเท่านั้น):

  • คะแนน ≥ 16 → ได้รถใหม่
  • คะแนน ≥ 10 → ได้แล็ปท็อปใหม่
  • คะแนน = 7 พอดี → ได้ทริปเที่ยว
  • นอกนั้น → ได้ลูกแมว
Program.cs 
if (total >= 16)
{
    Console.WriteLine("You win a new car!");
}
else if (total >= 10)
{
    Console.WriteLine("You win a new laptop!");
}
else if (total == 7)
{
    Console.WriteLine("You win a trip for two!");
}
else
{
    Console.WriteLine("You win a kitten!");
}

if, else if, else ให้คุณสร้างเงื่อนไขที่แยกจากกัน (mutually exclusive) ได้หลายชุด — ใช้เมื่อต้องการให้เกิดผลลัพธ์เดียวเท่านั้น จากหลาย เงื่อนไขที่เป็นไปได้ ใช้ else if ได้กี่ตัวก็ได้ ถ้าไม่มีเงื่อนไขไหนตรงเลย code block ของ else ตัวสุดท้ายจะทำงาน — else เป็นตัวเลือกเสริม แต่ถ้าจะใส่ ต้องอยู่ท้ายสุดเสมอ

✅ สรุปหลักการ คู่ if/else ใช้ทดสอบเงื่อนไขเดียว แล้วเลือกทำ 1 ใน 2 ทาง — ซ้อน if เพื่อจำกัดเงื่อนไขให้แคบลงได้ แต่ควรพิจารณาใช้ if, else if, else แทนถ้าเงื่อนไขมีหลายทางเลือก

9.4 ท้าทาย: กฎธุรกิจการต่ออายุสมาชิก

โจทย์ตามต้นฉบับ MS Learn

เริ่มจากโค้ดนี้ (ลบได้แค่บรรทัดคอมเมนต์ ห้ามลบบรรทัดอื่น และต้องใช้ตัวแปรทั้ง 3 ตัว ในคำตอบ):

Program.cs — บังคับใช้
Random random = new Random();
int daysUntilExpiration = random.Next(12);
int discountPercentage = 0;

// เขียนโค้ดของคุณต่อจากตรงนี้

daysUntilExpiration เป็นค่าสุ่ม 0–11 (จำนวนวันก่อนหมดอายุ) discountPercentage เริ่มที่ 0

กฎ 1: แสดงข้อความได้แค่ข้อความเดียวเท่านั้น กฎที่เลขสูงกว่ามีความสำคัญเหนือกว่า

กฎ 2: เหลือ ≤10 วัน → Your subscription will expire soon. Renew now!

กฎ 3: เหลือ ≤5 วัน → Your subscription expires in _ days. (แทน _ ด้วยค่า daysUntilExpiration) บวกบรรทัด Renew now and save 10%!

กฎ 4: เหลือ 1 วัน → Your subscription expires within a day! บวก Renew now and save 20%!

กฎ 5: หมดอายุแล้ว (0 วัน) → Your subscription has expired.

กฎ 6: เหลือมากกว่า 10 วัน → ไม่ต้องแสดงอะไรเลย

ต้องใช้ if-else แยกอย่างน้อย 2 ชุด: ชุดหนึ่งแสดงข้อความวันหมดอายุ อีกชุดแสดงข้อเสนอส่วนลด

💡 ขอคำใบ้

คำใบ้: ใช้ if, else if, else if, else if เรียงจากกฎที่เจาะจง ที่สุด (0 วัน) ไปหากฎที่กว้างที่สุด (≤10 วัน) — เพราะ C# ประเมินจากบนลงล่าง แล้วหยุดที่เงื่อนไขแรกที่ตรง

9.5 เฉลยและวิเคราะห์

Program.cs — เฉลยตัวอย่าง 
Random random = new Random();
int daysUntilExpiration = random.Next(12);
int discountPercentage = 0;

if (daysUntilExpiration == 0)
{
    Console.WriteLine("Your subscription has expired.");
}
else if (daysUntilExpiration == 1)
{
    Console.WriteLine("Your subscription expires within a day!");
    discountPercentage = 20;
}
else if (daysUntilExpiration <= 5)
{
    Console.WriteLine($"Your subscription expires in {daysUntilExpiration} days.");
    discountPercentage = 10;
}
else if (daysUntilExpiration <= 10)
{
    Console.WriteLine("Your subscription will expire soon. Renew now!");
}

if (discountPercentage > 0)
{
    Console.WriteLine($"Renew now and save {discountPercentage}%.");
}
ตัวอย่าง Output (สุ่มค่า daysUntilExpiration)
Your subscription expires in 3 days.
Renew now and save 10%.

เฉลยนี้ใช้ if-else if ชุดเดียวจัดการทั้ง 4 กฎเรื่องข้อความหมดอายุ (กฎ 2–5) เรียงจากเจาะจงสุด (0 วัน, 1 วัน) ไปกว้างสุด (≤10 วัน) แล้วใช้ if แยกต่างหาก อีกชุดตรวจว่ามีส่วนลดให้แสดงหรือไม่ — ตอบโจทย์ "กฎ 1: แสดงข้อความได้แค่ข้อความเดียว" เพราะแต่ละ else if loyalอยู่ในเชนเดียวกัน มีแค่เงื่อนไขเดียวที่จะทำงาน

9.6 ⚠️ กับดักที่พบบ่อย

อาการสาเหตุ / วิธีแก้
ได้โบนัสซ้อนกันทั้งที่ไม่ควร ใช้ if แยกกันหลายชุดแทนที่จะซ้อน (nest) — ทำให้เงื่อนไขที่ควรแยกกัน กลับทำงานพร้อมกันได้ทั้งคู่
ลืมใส่ { } เพราะคิดว่ามีโค้ดบรรทัดเดียว C# อนุญาตให้ไม่ใส่ปีกกาได้ถ้ามีแค่ 1 บรรทัด แต่ไม่แนะนำ — เพิ่มบรรทัดทีหลัง โดยไม่รู้ตัวว่ามันไม่อยู่ใน if แล้วจะกลายเป็นบั๊กเงียบ ควรใส่ปีกกาเสมอ
ใช้ = แทน == ใน Boolean expression = คือกำหนดค่า ไม่ใช่เปรียบเทียบ — C# จะ error ทันทีถ้าใช้ผิดแบบนี้ ในเงื่อนไขที่ต้องการ bool (ต่างจากบางภาษาที่ปล่อยผ่านแล้วเกิดบั๊กเงียบ)
วาง else ไว้กลางเชค else if แล้ว error else ต้องอยู่ท้ายสุดของเชนเสมอ ถ้ามี
ลำดับ else if ผิด ทำให้เงื่อนไขที่ตั้งใจไม่เคยถูกเช็คถึง C# ประเมินจากบนลงล่าง หยุดที่ตัวแรกที่ตรง — เรียงจากเงื่อนไขแคบ/เจาะจงไปกว้าง เสมอ (เหมือนโจทย์ 9.4 ที่เรียง 0 วัน → 1 วัน → ≤5 วัน → ≤10 วัน)

2. Boolean statement/expression คืออะไร?

  • Aนิพจน์ modulus
  • Bคำศัพท์เชิงลำดับ
  • Cโค้ดที่คืนค่า true หรือ false
เฉลย: ข้อ C. นิยามตรงตัว

3. กำหนด int x = 5 Boolean expression ข้อใดถูกต้องและได้ผลเป็น true?

  • Ax < 5
  • Bx > 5
  • Cx == 5
เฉลย: ข้อ C. 5==5 เป็น true ส่วนข้อ A และ B เป็น false ทั้งคู่ (5 ไม่น้อยกว่า 5 และไม่มากกว่า 5)

4. ตัวเลือกใดไม่ใช่ตัวดำเนินการที่ถูกต้องใน C#?

  • A%%
  • B&&
  • C||
เฉลย: ข้อ A. %% ไม่มีอยู่จริงใน C# (มีแค่ % ตัวเดียวสำหรับ modulus) ส่วน && และ || เป็นตัวดำเนินการ logical AND/OR ที่ถูกต้อง

5. ข้อความใดอธิบายไวยากรณ์ if statement ได้ถูกต้อง?

  • ABoolean expression ที่ if ประเมินเป็นตัวเลือกเสริม ใส่หรือไม่ใส่ก็ได้
  • Belse statement วางไว้ก่อน else if ไม่ได้
  • Cถ้ามี else if ต้องมี else เสมอ
เฉลย: ข้อ B. else ต้องอยู่ท้ายสุดของเชนเสมอ (ถ้ามี) ข้อ A ผิดเพราะ Boolean expression เป็นส่วนบังคับของ if ข้อ C ผิดเพราะ else เป็นตัวเลือก เสริม ไม่บังคับต้องมี

9.8 ✍️ แบบฝึกหัดท้ายบท

ข้อ 1ง่าย

เขียนโค้ดตรวจว่าตัวแปร int age = 20; เป็นผู้ใหญ่ (≥18) หรือไม่ พิมพ์ข้อความ "เป็นผู้ใหญ่" หรือ "ยังไม่บรรลุนิติภาวะ" ตามผล

ดูเฉลย
Program.cs
int age = 20;
if (age >= 18)
{
    Console.WriteLine("เป็นผู้ใหญ่");
}
else
{
    Console.WriteLine("ยังไม่บรรลุนิติภาวะ");
}
ข้อ 2ง่าย

เขียนโค้ดตัดเกรดจากคะแนน int score = 78;: ≥90=A, ≥80=B, ≥70=C, ต่ำกว่านั้น=F ใช้ if/else if/else

ดูเฉลย
Program.cs
int score = 78;
if (score >= 90)
{
    Console.WriteLine("A");
}
else if (score >= 80)
{
    Console.WriteLine("B");
}
else if (score >= 70)
{
    Console.WriteLine("C");
}
else
{
    Console.WriteLine("F");
}
ข้อ 3ง่าย

โค้ดนี้ error หาสาเหตุและแก้ไข:

Program.cs (ผิด)
int x = 10;
if (x = 10)
{
    Console.WriteLine("เท่ากับ 10");
}
ดูเฉลย

ใช้ = (กำหนดค่า) แทน == (เปรียบเทียบ) ต้องแก้เป็น if (x == 10)

ข้อ 4กลาง

เขียนโค้ดตรวจว่าปี int year = 2028; เป็นปีอธิกสุรทิน (leap year) หรือไม่ ด้วยกฎ: หารด้วย 4 ลงตัวและ(หารด้วย 100 ไม่ลงตัวหรือหารด้วย 400 ลงตัว)

💡 คำใบ้

ใช้ % เช็คหารลงตัว (เศษ=0) รวมกับ && และ || ตามกฎ ใส่วงเล็บให้ชัดเจนแบบเดียวกับหัวข้อ 9.2

ดูเฉลย
Program.cs
int year = 2028;
if ((year % 4 == 0) && ((year % 100 != 0) || (year % 400 == 0)))
{
    Console.WriteLine($"{year} เป็นปีอธิกสุรทิน");
}
else
{
    Console.WriteLine($"{year} ไม่ใช่ปีอธิกสุรทิน");
}
ข้อ 5กลาง

เขียนโค้ดกำหนดค่าตั๋วหนัง: อายุ <12 = "เด็ก 100 บาท", อายุ 12–59 = "ผู้ใหญ่ 200 บาท", อายุ ≥60 = "ผู้สูงอายุ 120 บาท" จากตัวแปร int age = 65;

ดูเฉลย
Program.cs
int age = 65;
if (age < 12)
{
    Console.WriteLine("เด็ก 100 บาท");
}
else if (age < 60)
{
    Console.WriteLine("ผู้ใหญ่ 200 บาท");
}
else
{
    Console.WriteLine("ผู้สูงอายุ 120 บาท");
}
ข้อ 6ท้าทาย

ดัดแปลงเกมทอยลูกเต๋าจากหัวข้อ 9.3 ให้เพิ่มกฎใหม่: ถ้าทอยได้ triple แล้วยังผลรวม (ก่อนบวกโบนัส) เป็น 18 พอดี (คือทอยได้ 6-6-6) ให้แสดงข้อความพิเศษ "JACKPOT! Perfect roll!" เพิ่มขึ้นมาอีกบรรทัด ก่อนข้อความ win/lose ปกติ (ต้องซ้อน if เพิ่มอีกชั้นจากโค้ดเดิม)

💡 คำใบ้

เพิ่ม if ตรวจ total == 18 (ก่อนบวกโบนัส) ไว้ข้างใน code block ของ triple ก่อนบรรทัด total += 6;

ดูเฉลย
Program.cs (ส่วนที่แก้)
if ((roll1 == roll2) || (roll2 == roll3) || (roll1 == roll3))
{
    if ((roll1 == roll2) && (roll2 == roll3))
    {
        if (total == 18)
        {
            Console.WriteLine("JACKPOT! Perfect roll!");
        }
        Console.WriteLine("You rolled triples! +6 bonus to total!");
        total += 6;
    }
    else
    {
        Console.WriteLine("You rolled doubles! +2 bonus to total!");
        total += 2;
    }
}

📌 สรุปบทที่ 9
