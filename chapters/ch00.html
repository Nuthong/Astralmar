0.4 ติดตั้ง .NET SDK

เราจะติดตั้งแค่ตัวเดียวก่อน คือ .NET SDK (ส่วน Visual Studio Code จะติดตั้งตอนบทที่ 7 ตามลำดับของหลักสูตรจริง) เลือกวิธีไหนก็ได้:

วิธี ก — โหลดตัวติดตั้งจากเว็บ Microsoft

  1. เข้า dotnet.microsoft.com/download
  2. เลือกรุ่นที่ติดป้าย LTS (Long-Term Support) — เสถียรและได้รับการดูแลยาว
  3. กด Download .NET SDK x64 แล้วเปิดไฟล์ที่ได้ กด Next จนจบ
  4. ปิด PowerShell/Terminal ที่เปิดค้างไว้ทั้งหมด แล้วเปิดใหม่ (ไม่งั้นจะยังหาคำสั่ง dotnet ไม่เจอ)

วิธี ข — ติดตั้งผ่านคำสั่งเดียว (Windows)

PowerShell 
winget install Microsoft.DotNet.SDK.8

ตรวจว่าติดตั้งสำเร็จหรือยัง

PowerShell 
dotnet --version
ผลลัพธ์ที่ควรได้ (ตัวเลขอาจต่างกัน)
8.0.404
🛑 ถ้าขึ้นแบบนี้แทน dotnet : The term 'dotnet' is not recognized...
แปลว่า Windows ยังหาคำสั่งไม่เจอ → ปิดหน้าต่าง PowerShell แล้วเปิดใหม่ ถ้ายังไม่ได้ ให้ รีสตาร์ตเครื่อง หนึ่งครั้ง เกือบทุกกรณีหายด้วยวิธีนี้

0.5 รันโปรแกรม C# ตัวแรกของคุณ

ยังไม่ต้องเข้าใจโค้ดนะครับ แค่พิสูจน์ว่าเครื่องพร้อมใช้งาน ทำตาม 4 ขั้นนี้:

PowerShell 
dotnet new console -o HelloCSharp
cd HelloCSharp
dotnet run
  1. บรรทัด 1 — สร้างโปรเจกต์ console เปล่า ๆ ไว้ในโฟลเดอร์ชื่อ HelloCSharp
  2. บรรทัด 2 — เดินเข้าไปในโฟลเดอร์นั้น
  3. บรรทัด 3 — คอมไพล์แล้วรันทันทีในคำสั่งเดียว
Output
Hello, World!

โปรเจกต์ที่เพิ่งสร้างจะมีไฟล์แค่ 2 อย่าง ลองเปิด Program.cs ด้วย Notepad ดูได้ — ข้างในมีบรรทัดเดียวเท่านั้น:

HelloCSharp/Program.cs 
// See https://aka.ms/new-console-template for more information
Console.WriteLine("Hello, World!");
✅ นี่แหละคือบทที่ 1 บรรทัด Console.WriteLine("Hello, World!"); คือสิ่งที่เราจะผ่ามันออกเป็นชิ้น ๆ ในบทถัดไป — ทุกคำ ทุกจุด ทุกวงเล็บ มีเหตุผลของมันหมด

0.6 ถ้ายังไม่อยากติดตั้งอะไรเลย

ไม่เป็นไรครับ คุณยังอ่านหนังสือเล่มนี้ได้ครบทุกบท เพราะ:

  • ทุกตัวอย่างโค้ดมีปุ่ม ▶ Run ที่จะเล่นผลลัพธ์ให้ดูในหน้าเว็บทันที
  • แบบฝึกหัดมีเฉลยพับซ่อนไว้ให้เทียบ
  • ข้อสอบกดตอบได้ตามปกติ
⚠️ แต่ต้องเข้าใจตรงกัน ปุ่ม ▶ Run ในหน้าเว็บ ไม่ใช่คอมไพเลอร์จริง — มันแค่เล่นซ้ำผลลัพธ์ที่เตรียมไว้ เพื่อให้คุณเห็นภาพ ถ้าอยากรู้ว่าโค้ดที่คุณแก้เองให้ผลอะไร ต้องรันด้วย dotnet run เท่านั้น และการพิมพ์โค้ดเองคือส่วนที่ทำให้จำได้จริง
