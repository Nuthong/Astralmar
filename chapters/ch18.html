18.1 ทำไมต้องมี do-while และ while

ตามที่เราพูดถึงหลายครั้งในโมดูลก่อนหน้าเรื่อง iteration และ decision statement — มีหลาย เทคนิคที่ให้ผลลัพธ์คล้ายกัน เหมือนภาษาพูดและภาษาเขียน ภาษาโปรแกรมก็สื่อความคิดเดียวกันได้ หลายแบบ แต่ละแบบก็มีความหมายที่ต่างกันเล็กน้อย

do-while และ while statement ควบคุม flow การทำงานของโค้ดด้วยการ วน code block จนกว่าเงื่อนไขจะเป็นจริง ตอนใช้ foreach เราวนหนึ่งครั้งต่อหนึ่ง item ในลำดับข้อมูล เช่น array ส่วน for ให้เราวนตามจำนวนรอบที่กำหนดไว้ล่วงหน้า และควบคุมกระบวนการวนซ้ำได้ do-while และ while ให้เราวน code block โดยที่ตรรกะข้างใน code block เองเป็นตัวกำหนดว่าจะหยุดวนเมื่อไร

สมมติคุณต้องการรับและประมวลผล input จากผู้ใช้ต่อเนื่องไปเรื่อยๆ จนกว่าผู้ใช้จะกด q เพื่อ "quit" คุณใช้ do-while และ while วนรับและประมวลผล input จนกว่าผู้ใช้จะพร้อมหยุดได้

ในบทนี้ คุณใช้ do-while statement และ while statement วน code block คุณจะเข้าใจว่าเมื่อไรควรเลือกใช้อันไหน และใช้ continue statement ข้ามการประมวลผลที่เหลือใน code block ไปประเมินเงื่อนไข Boolean ของ while โดยตรง

18.2 ลงมือ: do-while, while, และ continue

do-while Statement คืออะไร

do-while statement รัน statement หรือ code block ตราบเท่าที่เงื่อนไข Boolean ที่กำหนดเป็นจริง เพราะเงื่อนไขนั้นถูกประเมินหลังการรันแต่ละรอบ loop แบบ do-while จึงรัน code block อย่างน้อยหนึ่งครั้งเสมอ

syntax 
do
{
    // โค้ดนี้รันอย่างน้อยหนึ่งครั้ง
} while (true);

flow การทำงานเริ่มข้างในปีกกา โค้ดรันอย่างน้อยหนึ่งครั้ง จากนั้นเงื่อนไข Boolean ข้างๆ คีย์เวิร์ด while ถูกประเมิน ถ้าเงื่อนไขคืนค่า true code block จะถูกรันอีกครั้ง

⚠️ ระวัง infinite loop ถ้า hard-code เงื่อนไข Boolean เป็น true ตรงๆ แบบตัวอย่างข้างบน จะได้ infinite loop — loop ที่ไม่มีวันจบ (อย่างน้อยก็ไม่จบตามที่เขียนไว้ตอนนี้) ต้องมีวิธี break ออกจาก loop ข้างใน code block

เตรียมโปรเจกต์

Terminal 
dotnet new console -o ch18-dowhile

เขียน do-while ที่ break เมื่อสุ่มได้เลขที่กำหนด

ลองเขียนโค้ดที่สุ่มตัวเลข 1 ถึง 10 ไปเรื่อยๆ จนกว่าจะสุ่มได้เลข 7 — อาจใช้แค่ 1 รอบ หรือ หลายสิบรอบก็ได้ แล้วแต่โชค

Program.cs 
Random random = new Random();
int current = 0;

do
{
    current = random.Next(1, 11);
    Console.WriteLine(current);
} while (current != 7);
Output (ค่าสุ่ม — ตัวอย่าง)
2
5
8
2
7

เพราะเป็นเลขสุ่ม ผลลัพธ์ของคุณจะต่างออกไป แต่ค่า 7 จะเป็นเลขสุดท้ายที่ถูกพิมพ์ เสมอ เพราะเงื่อนไข Boolean จะเป็น false ทันทีที่สุ่มได้ 7 และ flow การทำงาน จะออกจาก code block

ข้อสังเกตสำคัญ: code block ของ do-while loop รันอย่างน้อยหนึ่งครั้งเสมอ อาจวนซ้ำหลายรอบมาก และมักไม่รู้ล่วงหน้าว่าจะวนกี่รอบ นอกจากนี้โค้ดข้างใน code block เองเป็นตัวกำหนดว่าจะวนต่อหรือไม่ — นี่คือเหตุผลหลักที่เลือกใช้ do-while หรือ while แทนที่จะใช้ foreach หรือ for ซึ่งทั้งคู่ อาศัยปัจจัยภายนอก code block ในการกำหนดจำนวนรอบ

while Statement คืออะไร

ทีนี้มาดู while statement บ้าง

Program.cs 
Random random = new Random();
int current = random.Next(1, 11);

while (current >= 3)
{
    Console.WriteLine(current);
    current = random.Next(1, 11);
}
Console.WriteLine($"Last number: {current}");
Output (ค่าสุ่ม — ตัวอย่าง)
9
7
5
Last number: 1
ℹ️ ตำแหน่งของเงื่อนไขสำคัญ คราวนี้เราวางคีย์เวิร์ด while และเงื่อนไข Boolean ก่อน code block ทำให้ความหมายเปลี่ยนไป — มันทำหน้าที่เป็น "ประตู" ที่ยอม flow การทำงานเข้าไปเฉพาะเมื่อ เงื่อนไข Boolean เป็นจริงเท่านั้น

โค้ดข้างบน: เริ่มต้นใช้ random กำหนดค่าเริ่มต้นให้ตัวแปร int ชื่อ current บรรทัดถัดไปที่ทำงานจริงคือ while statement ซึ่งวน ตามเงื่อนไข (current >= 3) — เราไม่รู้ค่าที่ current จะได้รับ แต่มี 2 ความเป็นไปได้ที่ส่งผลต่อ loop:

  • ถ้า current เริ่มต้นด้วยค่ามากกว่าหรือเท่ากับ 3 เงื่อนไข Boolean จะคืน true flow การทำงานจึงเข้า code block — ข้างในพิมพ์ค่า current ก่อน จากนั้นสุ่มค่าใหม่ให้ current แล้ววนกลับไป ประเมินเงื่อนไขที่หัว while ใหม่ ทำแบบนี้ต่อไปจนกว่าเงื่อนไขจะเป็น false
  • ถ้า current เริ่มต้นด้วยค่าน้อยกว่า 3 เงื่อนไขจะคืน false ทันที และ code block จะไม่ทำงานเลยสักครั้ง

บรรทัดสุดท้ายพิมพ์ค่า current ออกมา ทำงานไม่ว่า code block จะรันหรือไม่ก็ตาม เป็นโอกาสสุดท้ายที่เราจะพิมพ์ค่าสุดท้ายของ current

ใช้ continue ข้ามไปประเมินเงื่อนไขทันที

บางครั้งเราต้องการตัดจบส่วนที่เหลือของ code block แล้ววนไปรอบถัดไปเลย ทำได้ด้วย continue statement

Program.cs 
Random random = new Random();
int current = random.Next(1, 11);

do
{
    current = random.Next(1, 11);

    if (current >= 8) continue;

    Console.WriteLine(current);
} while (current != 7);
Output (ค่าสุ่ม — ตัวอย่าง)
5
1
6
7

สังเกตว่ากลับไปใช้ do-while — เพราะ do-while รับประกันว่า loop จะวนอย่างน้อยหนึ่งครั้ง

บรรทัดแรกใน code block สุ่มค่าใหม่ให้ current จากนั้นเช็คว่า current มากกว่าหรือเท่ากับ 8 หรือไม่ ถ้าใช่ คีย์เวิร์ด continue จะโอนควบคุมไปที่ท้าย code block ทันที แล้ว while จะประเมิน (current != 7) loop จึงวนต่อไปตราบที่ current ไม่เท่ากับ 7

บรรทัดหัวใจของขั้นตอนนี้คือ:

Program.cs
if (current >= 8) continue;

เพราะโค้ดที่พิมพ์ค่า current อยู่หลังบรรทัดนี้ ค่าที่มากกว่าหรือเท่ากับ 8 จึงไม่มีวันถูกพิมพ์ออกมาเลย

💡 continue vs break continue โอนควบคุมไปท้ายรอบปัจจุบันของ loop (แล้ววนต่อ) ส่วน break (จาก บทที่ 17 และ บทที่ 16) หยุด iteration (หรือ switch) ทันที แล้วโอนควบคุมไปยัง statement ถัดจาก loop นั้น ถ้าไม่มี statement ถัดไป ก็จะไปสิ้นสุดที่ท้ายไฟล์หรือท้ายเมธอด

Check ★ ข้อใดอธิบายพฤติกรรมของ do-while หรือ while ได้ถูกต้อง?

  • Ado-while statement รัน code block ศูนย์ครั้งหรือมากกว่า
  • Bwhile statement รัน code block อย่างน้อยหนึ่งครั้ง
  • Cdo-while statement รัน code block อย่างน้อยหนึ่งครั้ง
เฉลย: ข้อ C. do-while ประเมินเงื่อนไขหลังรันแต่ละรอบ จึงรัน code block อย่างน้อย 1 ครั้งเสมอ (ข้อ A ผิด) ส่วน while ประเมินเงื่อนไขก่อนเข้า code block จึงอาจไม่รันเลยสักครั้งก็ได้ ไม่ใช่รันอย่างน้อยหนึ่งครั้งเสมอ (ข้อ B ผิด)

Check ★ ต้องการรับ input จากผู้ใช้ในลูป โดยผู้ใช้กด ctrl + Esc เพื่อออกเมื่อกรอกเสร็จ ควรใช้ iteration statement ตัวไหนดีที่สุด?

  • Awhile
  • Bfor
  • Cdo-while
เฉลย: ข้อ C. ต้องรับ input อย่างน้อยหนึ่งครั้งก่อนถึงจะเช็คได้ว่าผู้ใช้ กด ctrl+Esc หรือไม่ — do-while ตอบโจทย์นี้พอดี เพราะรัน code block ก่อนแล้วค่อยเช็คเงื่อนไข

18.3 ท้าทาย: เกมต่อสู้ RPG

โจทย์ตามต้นฉบับ MS Learn

ในเกม RPG หลายเกม ตัวละครผู้เล่นต่อสู้กับ NPC ที่มักเป็นสัตว์ประหลาดหรือ "ตัวร้าย" บางครั้งการต่อสู้ประกอบด้วยแต่ละฝ่ายทอยลูกเต๋าสุ่มค่าขึ้นมา แล้วเอาค่านั้นไปลบเลือด (health) ของฝ่ายตรงข้าม พอฝ่ายใดฝ่ายหนึ่งเลือดหมด ฝ่ายนั้นแพ้

ในโจทย์นี้ เราตัดทอนกลไกให้เหลือแก่นสำคัญที่สุด: hero กับ monster เริ่มต้นด้วยเลือด เท่ากัน ในตาของ hero จะสุ่มค่าหนึ่งมาลบเลือดของ monster ถ้าเลือดของ monster ยังมากกว่า 0 ก็จะโจมตี hero กลับ ตราบใดที่ทั้งคู่ยังมีเลือดมากกว่า 0 การต่อสู้ก็ดำเนินต่อไป

กติกาที่ต้อง implement:

  • ต้องใช้ do-while หรือ while statement เป็น game loop ชั้นนอก
  • hero และ monster เริ่มต้นด้วยเลือด 10 หน่วยเท่ากัน
  • ค่าโจมตีทุกครั้งเป็นค่าสุ่มระหว่าง 1 ถึง 10
  • hero โจมตีก่อนเสมอ
  • พิมพ์ปริมาณเลือดที่ monster เสีย และเลือดที่เหลือ
  • ถ้าเลือดของ monster มากกว่า 0 ให้ monster โจมตี hero กลับ
  • พิมพ์ปริมาณเลือดที่ hero เสีย และเลือดที่เหลือ
  • ทำลำดับการโจมตีนี้ต่อไปจนกว่าเลือดของ monster หรือ hero จะเหลือศูนย์หรือน้อยกว่า
  • พิมพ์ผู้ชนะ

ตัวอย่างผลลัพธ์ที่โค้ดควรให้ (ค่าสุ่ม ผลลัพธ์จริงของคุณจะต่างออกไป):

Monster was damaged and lost 1 health and now has 9 health.
Hero was damaged and lost 1 health and now has 9 health.
Monster was damaged and lost 7 health and now has 2 health.
Hero was damaged and lost 6 health and now has 3 health.
Monster was damaged and lost 9 health and now has -7 health.
Hero wins!
💡 ขอคำใบ้

ใช้ continue ในจังหวะที่ monster เลือดหมดแล้ว เพื่อข้ามไม่ให้ monster โจมตี hero กลับ (ทบทวนหัวข้อ 18.2e) และใช้ ternary operator ( บทที่ 8) ตัดสินผู้ชนะในบรรทัดสุดท้าย

🔓 ดูเฉลย
Program.cs 
int hero = 10;
int monster = 10;

Random dice = new Random();

do
{
    int roll = dice.Next(1, 11);
    monster -= roll;
    Console.WriteLine($"Monster was damaged and lost {roll} health and now has {monster} health.");

    if (monster <= 0) continue;

    roll = dice.Next(1, 11);
    hero -= roll;
    Console.WriteLine($"Hero was damaged and lost {roll} health and now has {hero} health.");

} while (hero > 0 && monster > 0);

Console.WriteLine(hero > monster ? "Hero wins!" : "Monster wins!");
Output (ค่าสุ่ม — ตัวอย่าง)
Monster was damaged and lost 1 health and now has 9 health.
Hero was damaged and lost 2 health and now has 8 health.
Monster was damaged and lost 1 health and now has 8 health.
Hero was damaged and lost 4 health and now has 4 health.
Monster was damaged and lost 7 health and now has 1 health.
Hero was damaged and lost 6 health and now has -2 health.
Monster wins!

นี่เป็นเพียงหนึ่งในหลายวิธีที่แก้โจทย์นี้ได้ ตรรกะการโจมตีเขียนได้หลายแบบ จุดสำคัญที่ควรสังเกต:

  • do-while รับประกันว่า hero โจมตีก่อนอย่างน้อยหนึ่งครั้งเสมอ ตรงตาม กติกา "hero โจมตีก่อน"
  • if (monster <= 0) continue; ข้ามการโจมตีกลับของ monster ทันทีที่มัน เลือดหมด แล้ววนไปประเมินเงื่อนไข while เลย
  • เงื่อนไข hero > 0 && monster > 0 ทำให้ loop หยุดทันทีที่ฝ่ายใดฝ่ายหนึ่ง เลือดหมด

18.4 ท้าทาย: แยกแยะ do-while กับ while

C# มี iteration statement 4 แบบ: for, foreach, do-while, และ while เอกสารอ้างอิงภาษาของ Microsoft อธิบายไว้ว่า:

Statementคำนิยาม
forรัน body ตราบเท่าที่เงื่อนไข Boolean ที่กำหนด ("condition") เป็นจริง
foreachenumerate element ของ collection แล้วรัน body สำหรับแต่ละ element
do-whileรัน body แบบมีเงื่อนไข อย่างน้อยหนึ่งครั้งหรือมากกว่า
whileรัน body แบบมีเงื่อนไข ศูนย์ครั้งหรือมากกว่า

for กับ foreach แยกความแตกต่างจากตัวอื่นได้ชัดเจน แต่นิยามของ do-while กับ while ดูคล้ายกันมาก การจะรู้ว่าเมื่อไรควรเลือกใช้ ตัวไหนจึงดูค่อนข้างไม่แน่นอน และอาจสับสนได้ โจทย์ท้าทายนี้จะช่วยให้ความแตกต่างชัดเจนขึ้น ผ่าน 3 โปรเจกต์โค้ด

ℹ️ รับ input ตัวเลขด้วย int.TryParse() เมื่อรับ input ด้วย Console.ReadLine() ค่าที่ได้เป็น string ถ้าต้องแปลงเป็นตัวเลข ใช้ int.TryParse() ซึ่งรับ 2 พารามิเตอร์ (string ที่จะ แปลง + ตัวแปร out ที่จะรับค่า) และคืนค่า bool บอกว่าแปลงสำเร็จ หรือไม่:
ตัวอย่าง
int numericValue = 0;
bool validNumber = int.TryParse(readResult, out numericValue);
ถ้า readResult เป็น "7" ค่า 7 จะถูกกำหนดให้ numericValue และ validNumber เป็น true ถ้าแปลงไม่ได้ validNumber จะเป็น false

โปรเจกต์ 1 — ตรวจสอบ input ตัวเลข

โจทย์กลาง
  • ต้องใช้ do-while หรือ while
  • ก่อนเข้า loop: พิมพ์ข้อความขอให้ผู้ใช้กรอกเลขจำนวนเต็มระหว่าง 5 ถึง 10
  • ข้างใน loop: รับ input ด้วย Console.ReadLine(), ตรวจว่าเป็นเลขจำนวนเต็มที่ ถูกต้อง, ถ้าค่าไม่อยู่ระหว่าง 5-10 ให้พิมพ์ขอ input ใหม่
  • ต้องมั่นใจว่าค่าตัวเลขอยู่ระหว่าง 5-10 ก่อนออกจาก loop

💡 คำใบ้: ทำไมต้องเป็น for ไม่ใช่ foreach ชั้นนอก

ถ้าใช้ foreach (string myString in myStrings) แล้วพยายามแก้ไข myString ข้างใน (ซึ่งจำเป็นสำหรับโจทย์นี้) จะเจอ compile error เหมือนที่เจอใน บทที่ 17 หัวข้อ 17.2h — "Cannot assign to ... because it is a 'foreach iteration variable'" จึงต้องใช้ for แทน

🔓 ดูเฉลย
Program.cs 
string[] myStrings = new string[2] { "I like pizza. I like roast chicken. I like salad", "I like all three of the menu choices" };
int stringsCount = myStrings.Length;

string myString = "";
int periodLocation = 0;

for (int i = 0; i < stringsCount; i++)
{
    myString = myStrings[i];
    periodLocation = myString.IndexOf(".");

    string mySentence;

    while (periodLocation != -1)
    {
        mySentence = myString.Remove(periodLocation);
        myString = myString.Substring(periodLocation + 1);
        myString = myString.TrimStart();
        periodLocation = myString.IndexOf(".");

        Console.WriteLine(mySentence);
    }

    mySentence = myString.Trim();
    Console.WriteLine(mySentence);
}
Output
I like pizza
I like roast chicken
I like salad
I like all three of the menu choices

loop ชั้นนอกใช้ for (ไม่ใช่ foreach) เพราะเหตุผลข้างบน ส่วน loop ชั้นในใช้ while — ไม่ใช่ do-while — เพราะขึ้นอยู่ กับข้อมูลของแต่ละ string อาจไม่จำเป็นต้องรัน code block เลยสักครั้ง (กรณี string ไม่มีจุดอยู่เลย) จึงไม่ควรใช้ do ในสถานการณ์ที่ iteration block อาจไม่จำเป็นต้องทำงานเลย

วิธีคิดของลูปชั้นใน: Remove(periodLocation) ตัดเอาส่วนก่อนจุดออกมาเป็น ประโยค, Substring(periodLocation + 1) เอาส่วนที่เหลือหลังจุด, TrimStart() ตัดช่องว่างหน้าประโยคถัดไปออก แล้ววนหาจุดตัวถัดไป — ทำแบบนี้ ไปเรื่อยๆ จนไม่เจอจุดอีก (periodLocation == -1) แล้วพิมพ์ส่วนที่เหลือ สุดท้ายที่ไม่มีจุดต่อท้ายออกมา

💡 สรุปหลักการเลือก do-while vs while รู้แน่ชัดว่าต้องรัน code block อย่างน้อยหนึ่งครั้ง (เช่น ต้องรับ input ก่อนถึงจะตรวจสอบได้) → do-while. ไม่แน่ใจว่า code block จำเป็นต้องรันเลยหรือเปล่า (ขึ้นอยู่กับเงื่อนไข ที่รู้อยู่แล้วก่อนเข้า loop) → while

ดัดแปลงเกม RPG จากหัวข้อ 18.3 ให้มีโอกาสสุ่ม "critical hit" — ถ้าค่าที่ทอยได้เท่ากับ 10 พอดี ให้ค่าความเสียหายเพิ่มเป็น 2 เท่า และพิมพ์ข้อความ "CRITICAL HIT!" เพิ่มก่อนพิมพ์ ข้อความความเสียหายปกติ (ใช้กติกาที่เหลือเหมือนเดิมทั้งหมด)

ดูเฉลย
Program.cs
int hero = 10;
int monster = 10;
Random dice = new Random();

do
{
    int roll = dice.Next(1, 11);
    if (roll == 10)
    {
        Console.WriteLine("CRITICAL HIT!");
        roll *= 2;
    }
    monster -= roll;
    Console.WriteLine($"Monster was damaged and lost {roll} health and now has {monster} health.");

    if (monster <= 0) continue;

    roll = dice.Next(1, 11);
    if (roll == 10)
    {
        Console.WriteLine("CRITICAL HIT!");
        roll *= 2;
    }
    hero -= roll;
    Console.WriteLine($"Hero was damaged and lost {roll} health and now has {hero} health.");

} while (hero > 0 && monster > 0);

Console.WriteLine(hero > monster ? "Hero wins!" : "Monster wins!");
ข้อ 6ท้าทาย

เขียนโปรแกรมที่มี array string[] sentences = { "Cats are great, dogs are great, birds are okay", "Fish are quiet pets" }; ใช้แนวทางเดียวกับโปรเจกต์ 3 ในหัวข้อ 18.4c แต่เปลี่ยนตัวคั่นจากเครื่องหมายจุด "." เป็นเครื่องหมายจุลภาค "," แทน แล้วพิมพ์แต่ละท่อนออกมา (ตัดช่องว่างหน้า-หลังด้วย)

💡 คำใบ้

โครงสร้างเหมือนเฉลยโปรเจกต์ 3 ทุกอย่าง แค่เปลี่ยน IndexOf(".") เป็น IndexOf(",")

ดูเฉลย
Program.cs
string[] sentences = { "Cats are great, dogs are great, birds are okay", "Fish are quiet pets" };

for (int i = 0; i < sentences.Length; i++)
{
    string current = sentences[i];
    int commaLocation = current.IndexOf(",");
    string part;

    while (commaLocation != -1)
    {
        part = current.Remove(commaLocation);
        current = current.Substring(commaLocation + 1);
        current = current.TrimStart();
        commaLocation = current.IndexOf(",");

        Console.WriteLine(part.Trim());
    }

    part = current.Trim();
    Console.WriteLine(part);
}

📌 สรุปบทที่ 18

เป้าหมายของบทนี้คือใช้ do-while และ while statement ทำ iteration — do-while และ while พิเศษตรงที่ตัว code block เองเป็นตัวกำหนด ว่า flow การทำงานควรวนต่อหรือหยุด

ด้วย do-while คุณรัน code block หนึ่งครั้งก่อน แล้วค่อยประเมินเงื่อนไข Boolean และอาจออกจาก iteration ด้วย while คุณประเมินเงื่อนไข Boolean ทันที และวน ประเมินต่อจนกว่าจะออกจาก iteration คุณใช้ continue statement ข้างใน code block ข้ามไปที่เงื่อนไข Boolean โดยตรง

คุณพัฒนาแอปพลิเคชันที่ใช้ do-while และ continue จำลองการต่อสู้ใน เกม role-playing สถานการณ์ในโลกจริงที่เกี่ยวกับ do-while และ while มักเกี่ยวกับการทำงานกับ stream ข้อมูล จากไฟล์ จากอินเทอร์เน็ต หรือสถานการณ์อื่นที่คุณต้อง ทำ iteration ต่อไปจนกว่าเงื่อนไขจะสำเร็จ

ถ้าไม่มี do-while และ while statement การเขียนและดูแลโค้ดที่ตั้ง เงื่อนไขจบไว้ข้างใน iteration code block จะทำได้ยากมาก
