10.1 ทำไมต้องมี Array

Array ของ C# ให้คุณเก็บลำดับของค่าไว้ในโครงสร้างข้อมูลเดียว พูดง่ายๆ คือตัวแปรตัวเดียว ที่เก็บค่าได้หลายค่า พอมีตัวแปรเดียวที่เก็บค่าทั้งหมดแล้ว คุณเรียงลำดับ กลับลำดับ วนดูค่า แต่ละค่าทีละตัวได้

สมมติคุณทำงานแผนกความปลอดภัยของบริษัทที่จับคู่ผู้ขายออนไลน์กับผู้ลงโฆษณาแบบจ่ายค่าคอมมิชชัน คุณถูกขอให้เขียนโค้ด C# วนดู Order ID ของคำสั่งซื้อที่เข้ามา เพื่อตรวจหาคำสั่งซื้อที่อาจ เป็นการฉ้อโกง — ต้องใช้ array ทำงานนี้

ในบทนี้คุณจะสร้างและกำหนดค่าเริ่มต้นให้ array กำหนด/เรียกคืนค่าจาก element ผ่าน index และสร้าง loop วนทำงานกับทุก element ในนั้น

10.2 ลงมือ: พื้นฐาน Array

Array คืออะไร

array คือกลุ่มข้อมูลแต่ละชิ้นที่เข้าถึงได้ผ่านชื่อตัวแปรเดียว เข้าถึงแต่ละ element ด้วย index ตัวเลขที่เริ่มนับจาก 0 (zero-based) array ให้คุณรวมค่าข้อมูลที่มีจุดประสงค์ หรือคุณลักษณะร่วมกันไว้ภายใต้ชื่อตัวแปรเดียว ทำให้ประมวลผลง่ายขึ้น

เตรียมโปรเจกต์

Terminal 
dotnet new console -o ch10-arrays

ประกาศ Array ใหม่

Program.cs 
string[] fraudulentOrderIDs = new string[3];

ตัวดำเนินการ new สร้าง instance ของ array ในหน่วยความจำที่เก็บค่า string ได้ 3 ค่า วงเล็บเหลี่ยมชุดแรก [] แค่บอกคอมไพเลอร์ว่าตัวแปร fraudulentOrderIDs เป็น array ส่วนวงเล็บเหลี่ยมชุดที่สอง [3] บอกจำนวน element ที่ array นี้เก็บได้

ℹ️ ไม่ใช่แค่ string ตัวอย่างนี้ใช้ string เพื่อลดความซับซ้อนตอนเริ่มต้น แต่จริงๆ สร้าง array ของชนิดข้อมูลไหนก็ได้ ทั้ง primitive อย่าง int, bool หรือชนิดซับซ้อนกว่าอย่าง class ก็ได้

กำหนดค่าให้ Element

ตอนนี้ array มี 3 ช่องแต่ยังว่างเปล่า เข้าถึง element ด้วย index ตัวเลขเริ่มจาก 0 ในวงเล็บเหลี่ยม แล้วกำหนดค่าด้วย = เหมือนตัวแปรปกติ:

Program.cs 
string[] fraudulentOrderIDs = new string[3];

fraudulentOrderIDs[0] = "A123";
fraudulentOrderIDs[1] = "B456";
fraudulentOrderIDs[2] = "C789";

ลองใช้ Index ที่เกินขอบเขต

เรื่องที่มือใหม่มักลืม: array ที่ประกาศไว้ 3 ช่อง เข้าถึงได้แค่ index 0, 1, 2 เท่านั้น — index 3 ไม่มีอยู่จริง! ลองดูว่า เกิดอะไรขึ้น:

Program.cs
fraudulentOrderIDs[3] = "D000";
Output (ตอนรัน dotnet run)
Unhandled exception. System.IndexOutOfRangeException: Index was outside the bounds of the array.
   at Program.<Main>$(String[] args) in ...\Program.cs:line 6

สังเกตว่านี่คือ runtime exception ไม่ใช่ compile error — โค้ด build ผ่านปกติ แต่พัง ตอนรันจริง คอมเมนต์บรรทัดนี้ทิ้งไปก่อน (// fraudulentOrderIDs[3] = "D000";)

เรียกคืนค่าจาก Element

Program.cs 
string[] fraudulentOrderIDs = new string[3];

fraudulentOrderIDs[0] = "A123";
fraudulentOrderIDs[1] = "B456";
fraudulentOrderIDs[2] = "C789";
// fraudulentOrderIDs[3] = "D000";

Console.WriteLine($"First: {fraudulentOrderIDs[0]}");
Console.WriteLine($"Second: {fraudulentOrderIDs[1]}");
Console.WriteLine($"Third: {fraudulentOrderIDs[2]}");
Output
First: A123
Second: B456
Third: C789

กำหนดค่าใหม่ให้ Element

element ของ array ก็เหมือนตัวแปรทั่วไป กำหนด/เรียกคืน/กำหนดค่าใหม่ได้:

Program.cs — เพิ่มท้าย 
fraudulentOrderIDs[0] = "F000";

Console.WriteLine($"Reassign First: {fraudulentOrderIDs[0]}");
Output รวม
First: A123
Second: B456
Third: C789
Reassign First: F000

Initialize Array ในบรรทัดเดียว

เหมือนตัวแปรทั่วไป array ก็ initialize ในบรรทัดเดียวได้ ใช้ collection expression syntax (C# 12 ขึ้นไป รองรับใน .NET 10):

Program.cs 
string[] fraudulentOrderIDs = [ "A123", "B456", "C789" ];

คุณอาจเห็นไวยากรณ์เก่ากว่าที่ใช้ปีกกา {} ก็ได้:

Program.cs — ไวยากรณ์เก่า (ก็ยังถูกต้อง)
string[] fraudulentOrderIDs = { "A123", "B456", "C789" };
ℹ️ ทั้งสองแบบถูกต้อง คุณอาจเห็นทั้งสองรูปแบบผสมกันในหลักสูตรนี้และในโค้ดจริงทั่วไป — เลือกใช้แบบไหนก็ได้ แต่ควรใช้ให้สม่ำเสมอในโปรเจกต์เดียวกัน

Property Length ของ Array

บางครั้งคุณไม่รู้ล่วงหน้าว่า array มีกี่ element ใช้ property Length หาขนาดได้:

Program.cs 
string[] fraudulentOrderIDs = [ "A123", "B456", "C789" ];

Console.WriteLine($"There are {fraudulentOrderIDs.Length} fraudulent orders to process.");
Output
There are 3 fraudulent orders to process.
⚠️ Length ไม่ใช่ zero-based Length คืนจำนวน element จริง (3 ช่อง = Length เท่ากับ 3) ต่างจาก index ที่นับจาก 0 — index สูงสุดที่ใช้ได้เสมอคือ Length - 1

10.3 ลงมือ: ใช้ foreach วนซ้ำ Array

สมมติคุณทำงานให้บริษัทผลิตสินค้า ต้องนับสต็อกสินค้าพร้อมส่งในโกดัง ต้องรายงานทั้งจำนวนรวม และจำนวนในแต่ละถังเก็บ พร้อมยอดสะสม (running total) เพื่อใช้ตรวจสอบย้อนหลัง

วนลูปผ่าน Array ด้วย foreach

foreach เป็นวิธีง่ายและสะอาดที่สุดในการวนดูทุก element ของ array — ประมวลผลตามลำดับ index จากน้อยไปมาก เริ่มที่ 0 จนถึง Length - 1 ใช้ตัวแปร ชั่วคราวเก็บค่า element ปัจจุบันในแต่ละรอบ:

ตัวอย่าง 
string[] names = { "Rowena", "Robin", "Bao" };
foreach (string name in names)
{
    Console.WriteLine(name);
}
Output
Rowena
Robin
Bao

ทุกครั้งที่ .NET runtime วนไปยัง element ถัดไปของ names ค่านั้นจะถูกกำหนดให้ ตัวแปรชั่วคราว name เพื่อให้เข้าถึงได้ง่ายใน code block

สร้างและ Initialize Array แบบ int

Program.cs 
int[] inventory = { 200, 450, 700, 175, 250 };

เพิ่ม foreach วนอ่าน

Program.cs 
foreach (int items in inventory)
{

}

รวมยอดทุก Element

Program.cs 
int[] inventory = { 200, 450, 700, 175, 250 };
int sum = 0;
foreach (int items in inventory)
{
    sum += items;
}

Console.WriteLine($"We have {sum} items in inventory.");
Output
We have 1775 items in inventory.
⚠️ ประกาศ sum ไว้นอก foreach เสมอ ถ้าประกาศ int sum = 0; ไว้ข้างใน code block ของ foreach มันจะถูกรีเซ็ตเป็น 0 ใหม่ทุกรอบ ทำให้ยอดสะสมไม่ทำงาน — ต้องประกาศไว้ก่อน foreach เริ่ม

แสดงยอดสะสมพร้อมหมายเลขถัง

Program.cs 
int[] inventory = { 200, 450, 700, 175, 250 };
int sum = 0;
int bin = 0;
foreach (int items in inventory)
{
    sum += items;
    bin++;
    Console.WriteLine($"Bin {bin} = {items} items (Running total: {sum})");
}
Console.WriteLine($"We have {sum} items in inventory.");
Output
Bin 1 = 200 items (Running total: 200)
Bin 2 = 450 items (Running total: 650)
Bin 3 = 700 items (Running total: 1350)
Bin 4 = 175 items (Running total: 1525)
Bin 5 = 250 items (Running total: 1775)
We have 1775 items in inventory.

ใช้ bin++ เพิ่มค่าทีละ 1 ทุกรอบ — เป็นทางลัดของ bin = bin + 1; (ทบทวนได้ที่ บทที่ 4)

10.4 ท้าทาย: หา Order ID ต้องสงสัย

โจทย์ตามต้นฉบับ MS Learn

ทีมของคุณพบแพทเทิร์นว่า Order ID ที่ขึ้นต้นด้วยตัวอักษร "B" มีอัตราฉ้อโกงสูงกว่าปกติ 25 เท่า ให้เขียนโค้ดพิมพ์ Order ID ที่ขึ้นต้นด้วย "B" ออกมา จากอาร์เรย์นี้:

ข้อมูลตั้งต้น
B123
C234
A345
C15
B177
G3003
C235
B179

ใช้ foreach วนดูทุก element ใช้เมธอด String.StartsWith() เช็คว่าขึ้นต้นด้วย "B" หรือไม่:

ตัวอย่างการใช้ StartsWith()
string name = "Bob";
if (name.StartsWith("B"))
{
    Console.WriteLine("The name starts with 'B'!");
}
ผลลัพธ์ที่ต้องได้
B123
B177
B179
💡 ขอคำใบ้

โครงสร้างคือ: ประกาศ array ของ string → foreach วนดูทุกตัว → ข้างใน ใช้ if เช็ค StartsWith("B") → ถ้าจริงค่อยพิมพ์

10.5 เฉลยและวิเคราะห์

Program.cs — เฉลยตัวอย่าง 
string[] orderIDs = { "B123", "C234", "A345", "C15", "B177", "G3003", "C235", "B179" };

foreach (string orderID in orderIDs)
{
    if (orderID.StartsWith("B"))
    {
        Console.WriteLine(orderID);
    }
}
Output
B123
B177
B179

โค้ดนี้ผสมสิ่งที่เรียนมาจากสองบทเข้าด้วยกัน: foreach จากบทนี้ วนดูทุก element และ if จากบทที่ 9 คัดกรองเฉพาะที่ตรงเงื่อนไข — เป็นรูปแบบที่จะพบบ่อยมากในแอปจริง (วนดูข้อมูล + คัดกรองตามเงื่อนไข)

10.6 ⚠️ กับดักที่พบบ่อย

อาการสาเหตุ / วิธีแก้
IndexOutOfRangeException เข้าถึง index ที่ไม่มีอยู่จริง — array ขนาด N ใช้ index ได้แค่ 0 ถึง N-1 เท่านั้น
ลืมว่า index เริ่มจาก 0 element ตัวที่ "สาม" อยู่ที่ index 2 ไม่ใช่ 3
ตัวแปรสะสม (sum) รีเซ็ตทุกรอบ ประกาศตัวแปรไว้ข้างใน code block ของ foreach โดยไม่ตั้งใจ — ต้องประกาศไว้ นอก foreach เสมอ ถ้าต้องการให้ค่าคงอยู่ข้ามรอบ
สับสน .Length กับ index สูงสุด Length คือจำนวน element (ไม่ zero-based) แต่ index สูงสุดที่ใช้ได้คือ Length - 1 เสมอ

คำถามชุดนี้แปลจาก Microsoft Learn (2 ข้อฝังในเนื้อหา + 3 ข้อ Module Assessment)

1. array คืออะไร?

  • Aตัวแปรชนิด string
  • Bกลุ่มข้อมูลแต่ละชิ้นที่เข้าถึงได้ผ่านชื่อตัวแปรเดียว
  • C.NET Class Library
เฉลย: ข้อ B. array เก็บได้ทุกชนิดข้อมูล ไม่ใช่แค่ string (ข้อ A แคบเกินไป)

2. ข้อใดสร้างและกำหนดค่าเริ่มต้นให้ array ได้ถูกต้อง?

  • Astring[] myarray = new string[3]; myarray = "test1"; myarray = "test2"; myarray = "test3";
  • Bstring[] myarray = string[3]; myarray[0] = test1; ...
  • Cint[] myarray = new int[3]; myarray[0] = 1; myarray[1] = 2; myarray[2] = 3;
เฉลย: ข้อ C. ใช้ index ในวงเล็บเหลี่ยมกำหนดค่าแต่ละช่องถูกต้อง ข้อ A ไม่มี index เลย (พยายามกำหนดค่าให้ตัวแปร array ทั้งก้อนเป็น string ซึ่งผิดชนิด) ข้อ B ขาด new และค่า string ไม่ได้ใส่เครื่องหมายคำพูด

3. วิธีใดใช้เข้าถึง element ตัวที่สามของ array ได้ถูกต้อง?

  • AmyArray[3]
  • BmyArray[2]
  • CmyArray{3}
เฉลย: ข้อ B. index เริ่มนับจาก 0 element ตัวที่สามจึงอยู่ที่ index 2 ข้อ A จะได้ตัวที่สี่ (ถ้ามี) หรือ error ถ้าไม่มี ข้อ C ใช้ปีกกาผิดประเภทวงเล็บ

4. ข้อใดสร้าง int array ขนาด 3 ช่องได้ถูกต้อง?

  • Aint[] myArray = new int[3];
  • Bint[] myArray = new int[2];
  • Cint myArray = new int[3];
เฉลย: ข้อ A. ข้อ B ได้แค่ 2 ช่อง ข้อ C ขาด [] หลัง ชื่อชนิดข้อมูลตอนประกาศตัวแปร (ผิดชนิด ไม่ใช่ array)

5. foreach statement ข้อใดถูกไวยากรณ์?

  • Aforeach (int value in values)
  • Bforeach (int value of values)
  • Cforeach (int value with values)
เฉลย: ข้อ A. C# ใช้คีย์เวิร์ด in — of เป็นไวยากรณ์ของ JavaScript ไม่ใช่ C#

10.8 ✍️ แบบฝึกหัดท้ายบท

ข้อ 1ง่าย

สร้าง array ของ int เก็บคะแนนสอบ 5 วิชา: 85, 90, 78, 92, 88 แล้ว foreach พิมพ์ ทีละค่าออกมา

ดูเฉลย
Program.cs
int[] scores = { 85, 90, 78, 92, 88 };
foreach (int score in scores)
{
    Console.WriteLine(score);
}
ข้อ 2ง่าย

ต่อจากข้อ 1 คำนวณคะแนนเฉลี่ยด้วย foreach (บวกสะสมแล้วหารด้วย .Length)

ดูเฉลย
Program.cs
int[] scores = { 85, 90, 78, 92, 88 };
int sum = 0;
foreach (int score in scores)
{
    sum += score;
}
decimal average = (decimal)sum / scores.Length;
Console.WriteLine($"เฉลี่ย: {average}");
ข้อ 3ง่าย

โค้ดนี้ error ตอนรัน หาสาเหตุและแก้ไข:

Program.cs (ผิด)
int[] numbers = { 10, 20, 30 };
Console.WriteLine(numbers[3]);
ดูเฉลย

IndexOutOfRangeException — array มี 3 ช่อง (index 0,1,2) แต่พยายาม เข้าถึง index 3 ที่ไม่มีอยู่จริง แก้เป็น numbers[2] ถ้าต้องการค่าสุดท้าย

ข้อ 4กลาง

สร้าง array ของชื่อผลไม้ 6 ชนิด ใช้ foreach นับว่ามีกี่ชนิดที่ชื่อยาวเกิน 5 ตัวอักษร (ใช้ property .Length ของ string เทียบ — คนละตัวกับ .Length ของ array)

💡 คำใบ้

string ก็มี property .Length เหมือนกัน แต่หมายถึงจำนวนตัวอักษร ไม่ใช่จำนวน element

ดูเฉลย
Program.cs
string[] fruits = { "apple", "banana", "kiwi", "pineapple", "fig", "mango" };
int count = 0;
foreach (string fruit in fruits)
{
    if (fruit.Length > 5)
    {
        count++;
    }
}
Console.WriteLine($"มี {count} ชนิดที่ชื่อยาวเกิน 5 ตัวอักษร");
ข้อ 5กลาง

ดัดแปลงโจทย์ 10.4 ให้หา Order ID ที่ขึ้นต้นด้วย "C" และยาวเกิน 4 ตัวอักษร (จากข้อมูลเดิม ควรได้แค่ C234 กับ C235 เพราะ C15 สั้นไป)

ดูเฉลย
Program.cs
string[] orderIDs = { "B123", "C234", "A345", "C15", "B177", "G3003", "C235", "B179" };

foreach (string orderID in orderIDs)
{
    if (orderID.StartsWith("C") && orderID.Length > 4)
    {
        Console.WriteLine(orderID);
    }
}
ข้อ 6ท้าทาย

สร้าง array เก็บอุณหภูมิ 7 วัน (เลือกค่าเอง เป็น int) ใช้ foreach หาว่าวันไหนร้อนที่สุด (ค่าสูงสุด) โดยห้ามใช้เมธอดสำเร็จรูปอย่าง Array.Max() หรือ Math.Max() — ต้องเทียบค่าด้วย if เอง แล้วพิมพ์ทั้งค่าและลำดับวันที่ (1-7) ที่ร้อนที่สุด

💡 คำใบ้

ตั้งตัวแปร "ค่าสูงสุดเท่าที่เจอ" ไว้ก่อนเริ่ม foreach (ใช้ค่าช่องแรก เป็นค่าเริ่มต้น) แล้วอัปเดตทุกครั้งที่เจอค่าที่มากกว่า พร้อมนับลำดับวันไปด้วย (คล้ายตัวแปร bin ในหัวข้อ 10.3)

ดูเฉลย
Program.cs
int[] temps = { 31, 34, 29, 36, 33, 30, 35 };
int day = 0;
int hottestDay = 0;
int hottestTemp = temps[0];

foreach (int temp in temps)
{
    day++;
    if (temp > hottestTemp)
    {
        hottestTemp = temp;
        hottestDay = day;
    }
}

Console.WriteLine($"วันที่ร้อนที่สุดคือวันที่ {hottestDay} ({hottestTemp} องศา)");

📌 สรุปบทที่ 10

เป้าหมายของบทนี้คือทำงานกับลำดับ Order ID แบบเป็นโปรแกรม เพื่อหาคำสั่งซื้อที่อาจฉ้อโกง คุณสร้าง array ของ Order ID แล้ววนดูทุก element เพื่อหาคุณลักษณะร่วมที่บ่งชี้การฉ้อโกง array ช่วยให้เก็บแต่ละ Order ID เป็น element ของตัวแปรเดียว เข้าถึงแต่ละ element ด้วย index ตัวเลขเริ่มจาก 0 กำหนด/เรียกคืนค่าได้ และวนดูค่าทุกตัวเพื่อตรวจสอบหรือแสดงผลได้ ลองนึกภาพว่าจะยากแค่ไหนถ้าไม่มีโครงสร้างแบบ array — คุณต้องรู้ล่วงหน้าว่าจะมีข้อมูลกี่ชิ้น แล้วสร้างตัวแปรแยกทีละตัว ซึ่งเปราะบางมาก
