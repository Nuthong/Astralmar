โปรเจกต์นำทาง: คำนวณและแสดงเกรดนักเรียน

Guided Project — Calculate and Print Student Grades
⏱ ใช้เวลา 40–60 นาที 📦 ผลลัพธ์ แอปคำนวณเกรดนักเรียนที่ทำงานได้จริง ครบวงจร 🎯 ความยาก ประยุกต์บทที่ 1–4

🎯 จบบทนี้คุณจะ...

  • ฝึกแตกโจทย์ใหญ่เป็นขั้นตอนย่อยๆ แบบที่นักพัฒนาจริงทำ
  • ใช้ตัวแปรเก็บและเรียกคืนข้อมูลได้คล่องขึ้น
  • ทำการคำนวณทางคณิตศาสตร์พื้นฐานกับข้อมูลจริง
  • จัดรูปแบบผลลัพธ์ให้ตรงตามสเปกที่กำหนดมาให้
💡 บทนี้ต่างจากบทก่อนๆ ยังไง บทที่ 1–4 แยกเป็น "ท้าทาย" กับ "เฉลย" ให้ลองเองก่อนดูคำตอบ แต่บทนี้เป็น Guided Project คุณจะเขียนโค้ดต่อยอดไปเรื่อยๆ ทีละขั้น จนได้แอปที่ทำงานได้จริงครบวงจร — เหมือนวิธีที่ นักพัฒนาตัวจริงทำงาน คือแตกปัญหาใหญ่เป็นชิ้นเล็กๆ แล้วเช็คผลทีละก้าว

5.1 สถานการณ์: ผู้ช่วยครูที่ต้องเขียนโปรแกรมตัดเกรด

นักพัฒนาต้องทำงานประจำแบบนี้แทบทุกวัน: ประกาศตัวแปร string และตัวเลข กำหนด/ดึงค่า และคำนวณ — เป็นงานประจำแต่สำคัญมาก พอๆ กับการสื่อสารผลลัพธ์ให้ผู้ใช้เข้าใจ การนำทักษะเหล่านี้ มาแก้โจทย์จริงได้คือสิ่งที่นักพัฒนาทุกคนต้องฝึก

สมมติคุณเป็นผู้ช่วยครูในโรงเรียน ได้รับมอบหมายให้เขียนแอปช่วยตัดเกรดนักเรียนอัตโนมัติ แอปจะใช้คะแนนงานที่ให้คะแนนแล้วทุกชิ้นของนักเรียนแต่ละคน มาคำนวณเกรด/คะแนนรวมปัจจุบัน ของวิชานั้น ครูยังกำหนดรูปแบบการรายงานผลที่ต้องการมาให้ด้วย

บทนี้จะพาคุณทำโปรเจกต์ Student Grading แบบครบวงจร โค้ดของคุณจะประกาศและกำหนดค่าตัวแปร ตามชื่อนักเรียน คำนวณตัวเลขหลายแบบ และแสดงผลลัพธ์ การคำนวณรวมถึงหาผลรวมคะแนนงาน และ คำนวณเกรดปัจจุบันของนักเรียนแต่ละคน เพื่อแสดงผลตามฟอร์แมตที่กำหนด คุณจะใช้ Console.WriteLine() ร่วมกับ character escape sequence ที่ช่วยจัดรูปแบบผลลัพธ์

5.2 เตรียมพร้อม: โจทย์และข้อมูลตั้งต้น

ภาพรวมโปรเจกต์

คุณกำลังพัฒนาแอป Student Grading ที่คำนวณเกรดปัจจุบันของนักเรียนแต่ละคนในชั้นอัตโนมัติ ข้อกำหนดของแอปมีดังนี้:

  • มีรายชื่อนักเรียน 4 คน แต่ละคนมีคะแนนงาน 5 ชิ้น
  • คะแนนแต่ละชิ้นเป็นจำนวนเต็ม 0–100 (100 คือถูกทั้งหมด)
  • คะแนนสุดท้ายคำนวณจากค่าเฉลี่ยของคะแนนงานทั้ง 5 ชิ้น
  • แอปต้องคำนวณทางคณิตศาสตร์พื้นฐานเพื่อหาเกรดสุดท้ายของแต่ละคน
  • แอปต้องแสดงชื่อและคะแนนสุดท้ายของนักเรียนแต่ละคน

สมุดคะแนนของครูตอนนี้มีข้อมูลดังนี้ (คะแนนงาน 5 ชิ้นของแต่ละคน):

Sophia93879895100
Nicolas8083828885
Zahirah8496738579
Jeong90929810097

5.3 ขั้นที่ 1: คำนวณผลรวมคะแนนของแต่ละคน

ในหัวข้อนี้ คุณจะสร้างตัวแปรแทนผลรวมคะแนนงานของนักเรียนแต่ละคน แล้วแสดงผลรวมนั้นคู่กับชื่อ ในคอนโซล เนื่องจากคะแนนงานเป็นเลขจำนวนเต็ม จึงใช้ตัวแปรชนิด int เก็บผลรวม

สร้างตัวแปรเก็บผลรวม

เลื่อนไปท้ายโค้ด เว้นบรรทัดว่างไว้ แล้วพิมพ์:

Program.cs — ต่อท้าย 
int sophiaSum = 0;
int nicolasSum = 0;
int zahirahSum = 0;
int jeongSum = 0;

สังเกตว่ากำหนดค่า 0 ให้ตอนประกาศเลย (initialize) แม้การกำหนดค่าตอนประกาศจะไม่ บังคับ แต่ช่วยให้โค้ดมีประสิทธิภาพกว่า — ขั้นถัดไปคือแสดงผลลัพธ์ ซึ่งจะอ้างอิงตัวแปรพวกนี้ จึงต้องกำหนดค่าไว้ก่อน

เพิ่ม Console.WriteLine() แสดงชื่อคู่กับผลรวม:

Program.cs — ต่อท้าย 
Console.WriteLine("Sophia: " + sophiaSum);
Console.WriteLine("Nicolas: " + nicolasSum);
Console.WriteLine("Zahirah: " + zahirahSum);
Console.WriteLine("Jeong: " + jeongSum);

รันโค้ดตอนนี้ดู — จะเห็นค่า 0 ทั้งหมด (ยังไม่ error อะไร เพราะเราแค่ยังไม่ได้ คำนวณจริง) วิธีนี้คือการเช็คว่าโค้ดพื้นฐานยังทำงานถูกต้อง ก่อนเพิ่มความซับซ้อน

💡 เคล็ดลับมืออาชีพ เครื่องมือพัฒนาระดับสูงอย่าง Visual Studio Code มี debugger ให้ดูค่าตัวแปรระหว่างโปรแกรม กำลังรันได้ ช่วยประหยัดเวลามาก (จะเรียนใน Part 6 ของเล่มนี้) แต่ตอนนี้ใช้ Console.WriteLine() ช่วยตรวจสอบไปก่อนก็เพียงพอ
🛑 สำคัญมาก โค้ดที่คำนวณต้องอยู่เหนือโค้ดที่แสดงผลเสมอ — ลำดับการทำงานของ C# ไล่จาก บนลงล่าง ถ้าสลับลำดับ ตัวแปรจะยังเป็นค่าเดิมตอนถูกพิมพ์ออกมา

เขียนสูตรคำนวณผลรวมจริง

หาบรรทัด int sophiaSum = 0; แล้วแก้เป็น:

Program.cs 
int sophiaSum = sophia1 + sophia2 + sophia3 + sophia4 + sophia5;

รันดู — ผลรวมของ Sophia ควรเป็น 473 ส่วนคนอื่นยังเป็น 0 อยู่ เติมสูตรให้ครบทุกคน:

Program.cs 
int nicolasSum = nicolas1 + nicolas2 + nicolas3 + nicolas4 + nicolas5;
int zahirahSum = zahirah1 + zahirah2 + zahirah3 + zahirah4 + zahirah5;
int jeongSum = jeong1 + jeong2 + jeong3 + jeong4 + jeong5;

5.4 ขั้นที่ 2: คำนวณค่าเฉลี่ยของแต่ละคน

ในหัวข้อนี้ คุณจะคำนวณและเก็บค่าเฉลี่ยของคะแนนงาน เนื่องจากรู้จำนวนงานที่ให้คะแนนแล้ว (5 ชิ้น) ค่าเฉลี่ยคำนวณได้จากผลรวมหารด้วยจำนวนงาน คุณจะใช้ชนิดข้อมูล decimal เก็บค่าเฉลี่ยนี้

สร้างตัวแปรเก็บค่าเฉลี่ย

หาบรรทัด Console.WriteLine() ที่แสดงผลรวม เว้นบรรทัดว่างไว้เหนือมัน แล้วประกาศตัวแปร decimal (ยังไม่ต้องกำหนดค่า):

Program.cs 
decimal sophiaScore;
decimal nicolasScore;
decimal zahirahScore;
decimal jeongScore;

เหตุผลที่เลือกใช้ decimal เพราะกำลังแทนค่าคะแนนเฉลี่ยที่ต้องมีทศนิยม (ซึ่ง int ทำไม่ได้) — ถ้านักเรียนได้คะแนน 89.9 คุณจะเห็นความต่างจาก B เป็น A ได้ชัดเจน

กำหนดค่าให้ Sophia ก่อน: เอาผลรวมหารด้วยจำนวนงาน

Program.cs 
decimal sophiaScore = sophiaSum / currentAssignments;

เติมให้ครบทุกคน:

Program.cs 
decimal nicolasScore = nicolasSum / currentAssignments;
decimal zahirahScore = zahirahSum / currentAssignments;
decimal jeongScore = jeongSum / currentAssignments;

แก้ Console.WriteLine() ให้แสดงคะแนนเฉลี่ยแทนผลรวม:

Program.cs 
Console.WriteLine("Sophia: " + sophiaScore);
Console.WriteLine("Nicolas: " + nicolasScore);
Console.WriteLine("Zahirah: " + zahirahScore);
Console.WriteLine("Jeong: " + jeongScore);
Output
Sophia: 94
Nicolas: 83
Zahirah: 83
Jeong: 95
⚠️ สังเกตให้ดี — นี่คือจุดที่คนพลาดบ่อยที่สุดในโปรเจกต์นี้ คะแนนออกมาเป็นเลขจำนวนเต็ม ไม่มีทศนิยมเลย ทั้งที่ตัวแปรรับผลลัพธ์เป็น decimal! สาเหตุคือ sophiaSum และ currentAssignments ทั้งคู่เป็น int — การหาร int/int ถูกตัดเศษทิ้งไปตั้งแต่ก่อนกำหนดค่าให้ตัวแปร decimal แล้ว (ทบทวนเรื่องนี้ได้ที่ บทที่ 4 หัวข้อ 4.3)

แก้ปัญหาด้วยการ Cast

ต้องการผลหารเป็น decimal จึงต้อง cast ตัวตั้งหรือตัวหารตัวใดตัวหนึ่งเป็น decimal ก่อนหาร — ในที่นี้จะ cast ตัวแปรผลรวม (dividend):

Program.cs 
decimal sophiaScore = (decimal) sophiaSum / currentAssignments;
decimal nicolasScore = (decimal) nicolasSum / currentAssignments;
decimal zahirahScore = (decimal) zahirahSum / currentAssignments;
decimal jeongScore = (decimal) jeongSum / currentAssignments;

แค่ต้องมีข้างใดข้างหนึ่งของการหารเป็น decimal เท่านั้น ที่นี่เลือก cast แค่ตัวตั้ง (ผลรวม)

อ้างอิงเกณฑ์เกรดของครู

ช่วงคะแนนเกรด
97 – 100A+
93 – 96A
90 – 92A-
87 – 89B+
83 – 86B

รันโค้ดดูค่าคะแนนของแต่ละคนก่อน แล้วเทียบกับตารางนี้ด้วยตาเปล่าเพื่อกำหนดเกรด (ขั้นตอนนี้ ทำด้วยมือ ยังไม่ใช้ if/else — เรื่องนั้นจะเรียนใน Part 3 ของเล่ม) แล้วต่อท้ายตัวอักษรเกรด เข้าไปในผลลัพธ์:

Program.cs 
Console.WriteLine("Sophia: " + sophiaScore + " A");
Console.WriteLine("Nicolas: " + nicolasScore + " B");
Console.WriteLine("Zahirah: " + zahirahScore + " B");
Console.WriteLine("Jeong: " + jeongScore + " A");
Output
Sophia: 94.6 A
Nicolas: 83.6 B
Zahirah: 83.4 B
Jeong: 95.4 A

เทียบผลลัพธ์กับด้านบนให้ตรงเป๊ะก่อนไปขั้นถัดไป

5.5 ขั้นที่ 3: จัดรูปแบบผลลัพธ์ด้วย Escape Sequence

หัวข้อนี้จะปรับผลลัพธ์ให้ตรงตามฟอร์แมตที่ครูกำหนด เริ่มจากเพิ่มหัวตาราง แล้วใช้ escape sequence เพิ่มระยะห่างระหว่างคอลัมน์

เพิ่มหัวตาราง

เว้นบรรทัดว่างเหนือ Console.WriteLine() ชุดที่แสดงคะแนน แล้วเพิ่มหัวตาราง:

Program.cs 
Console.WriteLine("Student Grade\n");

\n ท้ายข้อความ จะเพิ่มบรรทัดว่างหลัง "Student Grade" (ทบทวนได้ที่ บทที่ 3) ตำแหน่งของ escape sequence สำคัญมาก — ในที่นี้อยู่ท้ายสุด บรรทัดใหม่จึงเกิดขึ้นหลังข้อความนั้น

ใช้ Tab จัดคอลัมน์

แทนที่ช่องว่างระหว่างคำด้วย \t:

Program.cs 
Console.WriteLine("Student\tGrade\n");
Console.WriteLine("Sophia:\t" + sophiaScore + "\tA");
Console.WriteLine("Nicolas:\t" + nicolasScore + "\tB");
Console.WriteLine("Zahirah:\t" + zahirahScore + "\tB");
Console.WriteLine("Jeong:\t" + jeongScore + "\tA");
Output
Student	Grade

Sophia: 94.6	A
Nicolas:	83.6	B
Zahirah:	83.4	B
Jeong:	95.4	A

สังเกตว่าแม้ใช้ tab แล้ว บางบรรทัดก็ยังมีช่องว่างระหว่างชื่อกับคะแนนน้อยผิดปกติ (เช่น "Sophia:" กับคะแนนแทบชิดกัน)

ℹ️ ทำไมถึงเป็นแบบนั้น — เรื่อง tab stop ตำแหน่ง tab stop ถูกกำหนดไว้ทุกๆ 4 ตัวอักษร แต่ละ tab จะเลื่อนไปยัง tab stop ถัดไป ถ้าสตริงมี 5 ตัวอักษรแล้วตามด้วย tab มันจะเลื่อนไปที่ตำแหน่งตัวอักษรที่ 8 (เติมช่องว่างให้เต็ม) แต่ถ้าสตริงมี 7 ตัวอักษรแล้วตามด้วย tab ก็เลื่อนไปตำแหน่งเดียวกันคือ 8 — ทำให้ tab ที่อยู่ใกล้ tab stop ถัดไปแสดงช่องว่างน้อยกว่า tab ที่อยู่ไกลจาก tab stop ถัดไป "Sophia:" มี 7 ตัวอักษร ใกล้ตำแหน่ง tab stop มาก ช่องว่างที่ได้จึงน้อย

เพิ่ม Tab อีกตัวให้ชื่อสั้น

เติม \t อีกตัวหลังชื่อที่สั้นกว่า (Sophia, Jeong):

Program.cs 
Console.WriteLine("Student\t\tGrade\n");
Console.WriteLine("Sophia:\t\t" + sophiaScore + "\tA");
Console.WriteLine("Nicolas:\t" + nicolasScore + "\tB");
Console.WriteLine("Zahirah:\t" + zahirahScore + "\tB");
Console.WriteLine("Jeong:\t\t" + jeongScore + "\tA");

5.6 ⚠️ กับดักที่พบบ่อย

อาการสาเหตุ / วิธีแก้
คำนวณผลรวมแล้วโค้ดแสดงผล 0 ตลอด ลืมย้ายบรรทัดคำนวณให้อยู่เหนือบรรทัดแสดงผล (โค้ดทำงานบนลงล่าง)
ตัวแปร decimal แต่ได้ผลลัพธ์เป็นเลขจำนวนเต็ม ลืม cast — ทั้ง sum และ currentAssignments เป็น int ทั้งคู่ ต้อง (decimal) ข้างใดข้างหนึ่งก่อนหาร
คอลัมน์ไม่ตรงกันแม้ใช้ \t แล้ว tab stop คำนวณทุก 4 ตัวอักษร ชื่อยาวไม่เท่ากันจึงต้องปรับจำนวน \t ต่างกัน
อ้างอิงตัวแปรที่ยังไม่กำหนดค่า error CS0165 (ทบทวนที่ บทที่ 2) — ต้อง initialize ก่อนใช้เสมอ
โค้ดยาวจนงงว่าตัวแปรไหนของใคร นี่คือเหตุผลที่ชื่อตัวแปรต้องสื่อความหมาย (camelCase + ชื่อเต็ม) ตามที่เรียนในบทที่ 2

5.7 ❓ Knowledge Check

คำถามชุดนี้แปลจาก Module Assessment จริงของบทนี้ใน Microsoft Learn (บทนี้มี 3 ข้อ)

1. โค้ดนี้ทำอะไร? var value = (int) dividend / (int) divisor;

  • Acast ตัวถูกดำเนินการเพื่อให้ผลลัพธ์ถูกตัดเศษทิ้ง
  • Bประกาศตัวแปร int แบบระบุชนิดชัดเจน
  • Ccast ตัวถูกดำเนินการเพื่อป้องกันไม่ให้ผลลัพธ์ถูกตัดเศษ
เฉลย: ข้อ A. การ cast ทั้งสองข้างเป็น (int) บังคับให้เป็น การหารแบบ int ซึ่งตัดเศษทิ้งเสมอ — ตรงข้ามกับข้อ C ส่วนข้อ B ผิดเพราะ var คือการอนุมานชนิดแบบปริยาย ไม่ใช่การระบุชนิดชัดเจน

2. เครื่องหมาย $ ในสตริงของ C# ทำหน้าที่อะไร?

  • Aให้ใช้ string interpolation แทรกตัวแปรลงในสตริงได้
  • Bบอกว่าสตริงนี้เป็น regular expression
  • Cบอกว่าสตริงนี้เป็น verbatim string literal
เฉลย: ข้อ A. $ คือสัญลักษณ์ของ string interpolation (ทบทวนที่ บทที่ 3) ข้อ C สับสนกับ @ ซึ่งเป็น verbatim string ต่างหาก

3. โค้ดนี้ผิดตรงไหน? int sophiaSum; Console.WriteLine("Sophia: " + sophiaSum);

  • AsophiaSum ยังไม่ถูกกำหนดค่าก่อนถูกใช้งาน
  • BsophiaSum ไม่ถูกอนุมานชนิดเป็น string โดยปริยาย
  • CsophiaSum ควรใช้คีย์เวิร์ด var
เฉลย: ข้อ A. ตัวแปรถูกประกาศแต่ไม่มีค่าเริ่มต้น พอนำไปใช้ในบรรทัดถัดมา จะเกิด error CS0165 "Use of unassigned local variable" — ทบทวนได้ที่ บทที่ 2 หัวข้อ 2.4

5.8 ✍️ แบบฝึกหัดต่อยอดโปรเจกต์

ข้อ 1ง่าย

เพิ่มนักเรียนคนที่ 5 ชื่อ Aiden คะแนนงาน 5 ชิ้น: 88, 91, 79, 85, 94 ประกาศตัวแปรคะแนนดิบและคำนวณผลรวมตามรูปแบบเดียวกับ 4 คนแรก

ดูเฉลย
Program.cs
int aiden1 = 88;
int aiden2 = 91;
int aiden3 = 79;
int aiden4 = 85;
int aiden5 = 94;

int aidenSum = aiden1 + aiden2 + aiden3 + aiden4 + aiden5;
Console.WriteLine("Aiden: " + aidenSum);
ข้อ 2ง่าย

ต่อจากข้อ 1 คำนวณคะแนนเฉลี่ยของ Aiden (ใช้ cast ให้ถูกต้อง) แล้วเทียบกับตารางเกรด หัวข้อ 5.4 ว่าควรได้เกรดอะไร

ดูเฉลย
Program.cs
decimal aidenScore = (decimal)aidenSum / currentAssignments;
Console.WriteLine("Aiden: " + aidenScore);

ผลรวม = 437, เฉลี่ย = 87.4 → อยู่ในช่วง 87–89 = เกรด B+

ข้อ 3ง่าย

จากผลลัพธ์ในหัวข้อ 5.5 (Sophia 94.6, Nicolas 83.6, Zahirah 83.4, Jeong 95.4) ใครได้คะแนนเฉลี่ยสูงสุด และใครได้ต่ำสุด?

ดูเฉลย

สูงสุด: Jeong (95.4) — ต่ำสุด: Zahirah (83.4)

ข้อ 4กลาง

เขียนโค้ดคำนวณคะแนนเฉลี่ยรวมของทั้งชั้น (ค่าเฉลี่ยของคะแนนเฉลี่ยทั้ง 4 คนเดิม) แล้วพิมพ์ออกมาด้วย string interpolation

💡 คำใบ้

บวกตัวแปร xxxScore ทั้ง 4 ตัวเข้าด้วยกัน แล้วหารด้วย 4 (ทั้งหมดเป็น decimal อยู่แล้ว ไม่ต้อง cast เพิ่ม)

ดูเฉลย
Program.cs
decimal classAverage = (sophiaScore + nicolasScore + zahirahScore + jeongScore) / 4;
Console.WriteLine($"คะแนนเฉลี่ยรวมของทั้งชั้น: {classAverage}");
ข้อ 5กลาง

โค้ดนี้พยายามคำนวณค่าเฉลี่ยแต่ error หาจุดผิดและอธิบายว่าทำไม (ใช้ความรู้จากบทที่ 2 และ 4):

Program.cs (ผิด)
decimal average;
int total = 350;
int count = 5;
average = total / count;
Console.WriteLine(average);
ดูเฉลย

ไม่ error แต่ได้ผลลัพธ์ผิด — total / count เป็น int/int ตัดเศษก่อน (350/5=70 พอดี กรณีนี้บังเอิญลงตัว แต่ถ้าตัวเลขอื่นไม่ลงตัวจะเห็นปัญหาทันที) ต้อง cast ให้ถูกต้อง:

Program.cs (ถูก)
decimal average;
int total = 350;
int count = 5;
average = (decimal)total / count;
Console.WriteLine(average);
ข้อ 6ท้าทาย

รวมทุกอย่างที่เรียนในบทนี้: เขียนโปรแกรมคำนวณเกรดนักเรียน 2 คนตั้งแต่ต้นจนจบ (ข้อมูลดิบ → ผลรวม → ค่าเฉลี่ย cast → จัดรูปแบบด้วย \t \n) ให้ได้ผลลัพธ์ตรงเป๊ะ:

Student		Grade

Maya:		91.5	A-
Kenji:		78.0	C+

ข้อมูลดิบ: Maya คะแนน 88, 95, 90, 92, 93 · Kenji คะแนน 75, 80, 79, 76, 80

ดูเฉลย
Program.cs
int assignments = 5;

int maya1 = 88, maya2 = 95, maya3 = 90, maya4 = 92, maya5 = 93;
int kenji1 = 75, kenji2 = 80, kenji3 = 79, kenji4 = 76, kenji5 = 80;

int mayaSum = maya1 + maya2 + maya3 + maya4 + maya5;
int kenjiSum = kenji1 + kenji2 + kenji3 + kenji4 + kenji5;

decimal mayaScore = (decimal)mayaSum / assignments;
decimal kenjiScore = (decimal)kenjiSum / assignments;

Console.WriteLine("Student\t\tGrade\n");
Console.WriteLine("Maya:\t\t" + mayaScore + "\tA-");
Console.WriteLine("Kenji:\t\t" + kenjiScore + "\tC+");

หมายเหตุ: บรรทัด int maya1 = 88, maya2 = 95, ...; ประกาศตัวแปร หลายตัวชนิดเดียวกันในบรรทัดเดียวด้วยจุลภาค — เป็นไวยากรณ์ที่ถูกต้อง ย่อโค้ดให้สั้นลงได้

📌 สรุปบทที่ 5

เป้าหมายของบทนี้คือสร้างแอปที่รับคะแนนงานของนักเรียนในชั้น คำนวณเกรด แล้วแสดงผลลัพธ์ เพื่อให้สำเร็จ คุณประกาศและกำหนดค่าตัวแปรหลายชนิดข้อมูล ทำการคำนวณทางตัวเลข และใช้เทคนิค การ cast เพื่อให้ได้ผลลัพธ์แม่นยำ คุณยังใช้ Console.WriteLine() ร่วมกับ character escape sequence จัดรูปแบบผลลัพธ์ให้ตรงสเปก ด้วยการแตกปัญหาใหญ่เป็นชิ้นเล็กๆ คุณสร้างโซลูชันได้จากทักษะที่เรียนมาในโมดูลก่อนหน้าทั้งหมด ยินดีด้วยที่พัฒนาแอปพลิเคชัน แบบมีโครงสร้างสำเร็จ!
